# IP地址分类与判断方法

## 适用场景

当需要判断给定IP地址的类别、网络号、主机号，或判断两个IP地址是否在同一网络时使用。

## 方法步骤

### Step 1: 判断IP地址类别

根据IP地址的第一个十进制数：

| 第一个十进制数范围 | 地址类别 | 默认子网掩码 |
|------------------|---------|-------------|
| 1 ~ 126 | A类 | 255.0.0.0 (/8) |
| 128 ~ 191 | B类 | 255.255.0.0 (/16) |
| 192 ~ 223 | C类 | 255.255.255.0 (/24) |
| 224 ~ 239 | D类（多播） | 无 |
| 240 ~ 255 | E类（保留） | 无 |

### Step 2: 判断是否为特殊地址

| 特殊地址 | 说明 |
|---------|------|
| 0.x.x.x | 本地网络（只能作为源地址） |
| 10.x.x.x | A类私有地址 |
| 127.x.x.x | 环回测试地址 |
| 169.254.x.x | 链路本地地址（DHCP失败时自动分配） |
| 172.16~31.x.x | B类私有地址 |
| 192.168.x.x | C类私有地址 |
| 255.255.255.255 | 有限广播（只能作为目的地址） |

### Step 3: 计算网络号

网络号 = IP地址 AND 子网掩码

**示例**：IP=192.168.1.10，子网掩码=255.255.255.0
- 网络号 = 192.168.1.0

### Step 4: 判断两个IP是否在同一网络

1. 分别计算两个IP的网络号（IP AND 子网掩码）
2. 如果网络号相同，则在同一个网络

## 示例

### 示例1：判断IP类别
**题目**：判断 172.20.15.8 的类别

**解题**：第一个数字172，在128~191范围内 → B类地址
默认子网掩码：255.255.0.0
网络号：172.20.0.0

### 示例2：是否在同一网络
**题目**：IP1=192.168.1.10/24，IP2=192.168.2.10/24，判断是否在同一网络

**解题**：
- IP1网络号 = 192.168.1.0
- IP2网络号 = 192.168.2.0
- 网络号不同 → 不在同一网络

## 注意事项

1. 主机号全0是网络地址，全1是广播地址，都不是合法主机地址
2. A类的网络号减2（0和127不指派）
3. 私有IP地址不能在公网路由
4. CIDR出现后，分类地址已被无类地址取代，但分类IP仍然是考点
