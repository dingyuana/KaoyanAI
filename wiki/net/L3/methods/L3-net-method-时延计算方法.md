# 网络时延计算方法

## 适用场景

当需要计算数据在网络中传输的总时延，或者比较不同交换方式（电路交换、报文交换、分组交换）的传输时间时使用。

## 方法步骤

### Step 1: 明确四类时延

总时延 = 发送时延 + 传播时延 + 排队时延 + 处理时延

| 时延类型 | 计算公式 | 关键参数 |
|---------|---------|---------|
| **发送时延** | $T_{发送} = \frac{数据长度}{信道带宽}$ | 数据长度(bit)、带宽(b/s) |
| **传播时延** | $T_{传播} = \frac{链路长度}{传播速率}$ | 链路长度(m)、传播速率(m/s) |
| **排队时延** | 取决于网络负载 | — |
| **处理时延** | 取决于路由器性能 | — |

### Step 2: 分组交换时延计算

对于分组交换，将报文分为多个分组：

发送时延 = 分组的数量 × 单个分组的发送时延 + (路径上的跳数 - 1) × 单个分组的发送时延

即：$T = \frac{M}{v} + (k-1)\frac{p}{v} + \frac{D}{c}$

其中：M=报文总长度，p=分组长度，v=传输速率，k=跳数（经过的路由器数+1），c=传播速度，D=总链路长度

### Step 3: 电路交换时延计算

$T = \text{呼叫建立时间} + \frac{M}{v} + \frac{D}{c}$

### Step 4: 时延带宽积计算

时延带宽积 = 传播时延 × 带宽（单位：bit）

表示在途比特数量，即发送方已发出但尚未到达接收方的数据量。

## 示例

### 示例1：分组交换总时延

**题目**：报文长度10Mb，分成1000个分组（每个分组10kb），链路带宽10Mb/s，传播距离200km，传播速率2×10⁸m/s，经过4段链路（3个路由器）。

**解题**：
1. 发送时延 = (10×10⁶) / (10×10⁶) = 1s
2. 每个分组发送时延 = 10×10³ / (10×10⁶) = 0.001s
3. 中间转发时延 = 3 × 0.001 = 0.003s
4. 传播时延 = 200×10³ / (2×10⁸) = 0.001s
5. 总时延 ≈ 1 + 0.003 + 0.001 = 1.004s

### 示例2：RTT计算

**题目**：卫星通信，传播距离36000km×2（上下行），传播速率3×10⁸m/s，数据包1kb，带宽1Mb/s

**解题**：
1. 传播时延 = (2×36000×10³) / (3×10⁸) = 0.24s
2. 发送时延 = 1000 / (10⁶) = 0.001s
3. RTT = 2×0.24 = 0.48s（往返传播时延）

## 注意事项

1. 发送时延和传播时延是最常见的考点
2. 排队时延和处理时延通常忽略（题目会告知）
3. 分组交换需考虑中间节点的转发时延
4. 卫星通信中传播时延远大于发送时延
