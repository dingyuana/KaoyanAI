# CSMA/CA协议

## 形式化定义

> 引用自 [[RAW-net-3数据链路层-3.5.2随机接入协议分类]]：

CSMA/CA（Carrier Sense Multiple Access with Collision Avoidance），即**载波监听多址接入/碰撞避免**，是802.11局域网采用的无线信道访问控制协议。

## 为什么无线网不能使用CSMA/CD

| 原因 | 说明 |
|------|------|
| **隐藏站问题** | 无线信号传播范围有限，站点无法检测到所有正在发送的站点 |
| **无法边发边听** | 无线网卡发送信号强度远大于接收信号，难以检测碰撞 |
| **信号衰减** | 无线信道通信质量远不如有线信道 |

## CSMA/CA工作原理

1. **信道预约（RTS/CTS机制）**
   - 发送站发送RTS（请求发送）帧
   - 接收站回复CTS（允许发送）帧
   - 其他站收到CTS后，在预约时间内不发送数据

2. **载波监听**
   - 发送前监听信道是否空闲
   - 采用能量检测、载波检测和能量载波混合检测三种方式

3. **帧间间隔（IFS）**
   - 不同优先级的帧有不同的帧间间隔
   - 短IFS（SIFS）用于高优先级帧（ACK、CTS等）
   - DCF帧间间隔（DIFS）用于普通数据帧

4. **退避算法**
   - 信道由忙变空闲时，需等待一个随机退避时间
   - 目的：减少碰撞概率

5. **虚拟载波监听**
   - 通过RTS/CTS中的Duration字段，其他站点更新NAV（网络分配向量）
   - NAV表示信道忙的时间长度

## CSMA/CA和停止-等待协议

- 802.11使用CSMA/CA的同时，还使用停止-等待协议
- 每发送完一个数据帧，要等到收到对方的确认帧（ACK）后才能继续发送下一帧
- 这是因为无线信道的通信质量远不如有线信道

## 注意事项

1. CSMA/CA是避免碰撞而不是检测碰撞
2. 802.11局域网使用CSMA/CA + 停止-等待协议
3. RTS/CTS不是必须的，只在帧长超过一定阈值时使用
