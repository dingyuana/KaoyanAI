# 路由选择协议（RIP/OSPF/BGP）

## 形式化定义

> 引用自 [[RAW-net-4网络层-4.4.3 RIP]]、[[RAW-net-4网络层-4.4.4 OSPF]]、[[RAW-net-4网络层-4.4.5 BGP]]：

路由选择协议是路由器之间交换路由信息、建立路由表的协议。按作用范围分为内部网关协议（IGP）和外部网关协议（EGP）。RIP和OSPF属于IGP，BGP属于EGP。

## 三种路由协议比较

| 特性 | RIP | OSPF | BGP |
|------|-----|------|-----|
| 类型 | 内部网关协议(IGP) | 内部网关协议(IGP) | 外部网关协议(EGP) |
| 算法 | 距离向量算法 | 链路状态算法(SPF) | 路径向量算法 |
| 度量 | 跳数（≤15跳） | 代价（带宽等） | 路径属性 |
| 路由更新 | 周期性广播 | 触发更新 | 增量更新 |
| 收敛速度 | 慢 | 快 | 较慢 |
| 适用规模 | 小型网络 | 大型网络 | 自治系统间 |
| 是否分区域 | 不分 | 分区域(Area) | 分AS |

## RIP（路由信息协议）

### 基本概念
- 基于**距离向量算法**
- 使用**跳数**作为度量标准
- 最大跳数为15，16表示不可达
- 每隔**30秒**广播一次路由信息
- 使用**UDP**传输（端口520）

### 工作原理
1. 路由器初始只知道自己直连的网络
2. 定期与相邻路由器交换完整的路由表
3. 根据距离向量算法更新路由表
4. 收敛后每个路由器都知道到达所有网络的最短路径

### 缺点：坏消息传得慢
- 路由环路问题
- 采用毒性逆转、水平分割等措施缓解

## OSPF（开放最短路径优先）

### 基本概念
- 基于**链路状态算法**
- 使用**代价（Cost）** 作为度量标准
- 链路代价通常与带宽成反比
- 使用**IP**直接传输（协议号89）
- 支持**分区域**（Area），减少路由更新量

### 工作过程
1. **交互问候分组**：发现和维护邻居关系
2. **洪泛链路状态**：向区域内所有路由器发送LSA
3. **构建LSDB**：每个路由器拥有相同的链路状态数据库
4. **计算最短路径**：使用SPF（Dijkstra）算法计算最短路径树

### OSPF分组类型

| 分组类型 | 说明 |
|---------|------|
| Hello分组 | 发现和维护邻居关系 |
| DD分组 | 数据库描述分组 |
| LSR分组 | 链路状态请求分组 |
| LSU分组 | 链路状态更新分组 |
| LSACK分组 | 链路状态确认分组 |

### DR和BDR
- 在广播网络中，选举指定路由器（DR）和备份指定路由器（BDR）
- 减少邻居关系数量，降低网络开销

## BGP（边界网关协议）

### 基本概念
- 在不同自治系统（AS）之间交换路由信息
- 基于**路径向量算法**
- 交换的是**网络可达性信息**（要到达某个网络所要经过的一系列自治系统/路径）
- 使用**TCP**传输（端口179）

### 工作原理
- BGP发言人之间建立TCP连接
- 交换完整的BGP路由信息
- 根据AS路径属性进行路由选择

## 关联概念

- **前置知识**：IP地址
- **后续延伸**：路由表与分组转发

## 注意事项

1. RIP限制网络直径不超过15跳
2. OSPF使用Dijkstra算法计算最短路径
3. BGP是唯一的EGP协议
4. OSPF支持VLSM和CIDR，RIP不支持
