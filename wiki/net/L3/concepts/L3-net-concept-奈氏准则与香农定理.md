# 奈氏准则与香农定理

## 形式化定义

> 引用自 [[RAW-net-2物理层-2.1.2奈氏准则和香农定理]]：

奈氏准则（Nyquist准则）和香农定理（Shannon定理）是衡量信道容量和极限数据传输率的两个重要定理。

## 失真与码间串扰

### 失真
信号在传输过程中，由于实际信道有噪声、干扰、带宽的限制，导致接收端接收的信号和发送端发送的信号不一致。影响失真的因素：码元传输速率、信号的传输距离、噪声干扰、传输媒体的质量。

### 码间串扰
接收端收到的信号波形失去了码元之间清晰界限的现象。具体的信道所能通过的频率范围是有限的。

## 奈氏准则

| 项目 | 内容 |
|------|------|
| **适用条件** | 理想低通信道（无噪声） |
| **核心公式** | $C = 2W \log_2 V$ |
| **参数** | C—极限数据传输率(b/s)，W—信道带宽(Hz)，V—信号电平级数/码元状态数 |
| **物理意义** | 理想低通信道中，码元传输速率有上限（$2W$ Baud），超过该上限会产生码间串扰 |

**常考公式**：理想低通信道中，极限码元传输速率为 $2W$ Baud（常用 $2W$）
最大数据传输率 = $2W \log_2 V$

## 香农定理

| 项目 | 内容 |
|------|------|
| **适用条件** | 有噪声的信道 |
| **核心公式** | $C = W \log_2(1 + S/N)$ |
| **参数** | C—信道极限传输速率(b/s)，W—信道带宽(Hz)，S/N—信噪比 |
| **物理意义** | 在带宽受限且有噪声的信道中，信息传输速率有上限 |

**信噪比**：$SNR(dB) = 10\log_{10}(S/N)$ dB

### 常考转换
- 信噪比30dB → $S/N = 1000$
- 信噪比20dB → $S/N = 100$

## 两个定理的对比

| 特性 | 奈氏准则 | 香农定理 |
|------|---------|---------|
| 信道条件 | 理想低通（无噪声） | 有噪声的实际信道 |
| 考虑因素 | 带宽、信号电平级数 | 带宽、信噪比 |
| 提高方法 | 增加电平级数V | 提高信噪比S/N |
| 限制因素 | 码间串扰 | 噪声干扰 |

## 注意事项

1. 奈氏准则给出了码元传输速率的上限（不考虑噪声）
2. 香农定理给出了信息传输速率的上限（考虑噪声）
3. 实际信道的数据传输率受两者中较低者的限制
4. 考试中常需两个公式结合使用
