# TCP/IP体系结构与五层协议结构

## 形式化定义

> 引用自 [[RAW-net-1计算机网络体系结构-TCP IP结构]] 和 [[RAW-net-1计算机网络体系结构-1.2.3三种网络模型]]：

TCP/IP体系结构只有四层：应用层、传输层、网际层、网络接口层（相当于五层协议中数据链路层和物理层合并）。考研408采用**五层协议结构**作为教学模型。

## 五层协议结构

| 层次 | 功能 | 数据单元 | 主要协议 |
|------|------|---------|---------|
| **应用层** | 通过应用进程间的交互来完成特定网络应用 | 报文 | HTTP, DNS, SMTP, FTP |
| **传输层** | 为进程提供通用数据传输服务 | 报文段(TCP)/用户数据报(UDP) | TCP, UDP |
| **网络层** | 为主机提供数据传输服务，封装分组 | 分组/IP数据报 | IP, ICMP, ARP |
| **数据链路层** | 为同一链路的主机提供数据传输服务 | 帧 | PPP, CSMA/CD |
| **物理层** | 在物理线路上传输原始的二进制数据 | 比特流 | — |

## 核心要点

### 三种网络模型对比

| 特性 | OSI七层模型 | TCP/IP四层模型 | 五层协议结构(考研) |
|------|-------------|----------------|-------------------|
| 层次数 | 7层 | 4层 | 5层 |
| 特点 | 理论完善，结构清晰 | 实用性强，实际应用 | 折中方案，便于教学 |
| 表示层/会话层 | 独立实现 | 未独立实现 | 包含在应用层 |
| 数据链路层/物理层 | 分开 | 合并为网络接口层 | 分开 |

### 实体、协议、服务访问点

| 概念 | 定义 |
|------|------|
| **实体** | 任何可以发送或接受信息的硬件或软件进程，同一层的实体称为对等实体 |
| **协议** | 为进行网络中的数据交换而建立的规则、标准或约定，是"水平的"（控制对等实体之间通信） |
| **接口(SAP)** | 同一系统中相邻两层的实体进行交互的地方，所提供服务的具体实现细节对上一层完全屏蔽 |
| **服务** | 下层为相邻上层提供的功能调用，是"垂直的" |

### 协议三要素

1. **语法**：规定传输数据的格式
2. **语义**：规定所要完成的功能
3. **同步/时序**：规定各种操作的顺序

### 数据单元关系

- **SDU（服务数据单元）**：为完成用户所要求的功能而应传送到的数据
- **PCI（协议控制信息）**：控制协议操作的信息
- **PDU（协议数据单元）**：对等层次之间传送的数据单位
- 每一层的PDU会作为下一层的SDU，和PCI组成该层的PDU，直到物理层

## 注意事项

1. TCP/IP体系结构不严格遵循OSI分层概念
2. 应用层可能会直接使用IP层或网络接口层
3. 考研408以五层协议结构为教学标准
4. 路由器最多能到达网络层，传输层是主机才有的层次
