# ICMP互联网控制报文协议

## 形式化定义

> 引用自 [[RAW-net-4网络层-4.2.7 ICMP]]：

ICMP（Internet Control Message Protocol）互联网控制报文协议，用于在IP主机、路由器之间传递控制消息。ICMP报文封装在IP数据报的数据部分中传输。

## ICMP报文类型

### 差错报告报文（5种）

| 报文类型 | 说明 |
|---------|------|
| **终点不可达** | 路由器或主机不能交付数据报时发送 |
| **源点抑制** | 路由器拥塞时丢弃数据报，向源点发送 |
| **时间超过** | TTL=0时丢弃数据报，发送时间超过报文 |
| **参数问题** | 数据报首部有错误时发送 |
| **改变路由（重定向）** | 路由器发现更好的路由时发送 |

### 询问报文

| 报文类型 | 说明 |
|---------|------|
| **回送请求和回答** | Ping命令使用，测试目的主机是否可达 |
| **时间戳请求和回答** | 获取时间信息 |

## ICMP应用

| 应用 | 说明 |
|------|------|
| **Ping** | 测试连通性，使用ICMP回送请求和回答报文 |
| **Tracert** | 跟踪路由，利用ICMP时间超过报文 |

### 不应该发送差错报文的情况
1. 对ICMP差错报文不再发送差错报文
2. 对第一个分片的数据报片发送ICMP差错报文，之后的不发送
3. 对具有多播地址的数据报不发送
4. 对特殊地址（如127.0.0.0或0.0.0.0）的数据报不发送

3. 对ICMP差错报文不再发送ICMP差错报文
