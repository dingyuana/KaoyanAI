# 点对点协议PPP

## 形式化定义

> 引用自 [[RAW-net-3数据链路层-3.7.2点对点协议PPP]]：

PPP（Point-to-Point Protocol）点对点协议，是数据链路层协议，用于在两个网络节点之间建立直接连接。PPP支持多种网络层协议，提供差错检测但不纠错，是不可靠的传输协议。

## PPP协议的组成

| 组件 | 说明 |
|------|------|
| **链路控制协议LCP** | 建立、配置和测试数据链路连接 |
| **网络控制协议NCP** | 配置不同的网络层协议 |
| **封装方法** | 将IP数据报封装到串行链路的方法 |

## PPP协议特点

| 特性 | 说明 |
|------|------|
| 多协议支持 | PPP两端的网络层可运行不同协议，仍能使用PPP通信 |
| 差错检测 | 提供差错检测但不提供纠错能力 |
| 不可靠传输 | PPP是不可靠的传输协议 |
| 支持认证 | 支持PAP和CHAP认证 |
| 动态IP | 可用于拨号连接，支持动态分配IP地址 |
| 面向字节 | PPP协议是面向字节的协议 |

## PAP与CHAP认证对比

| 特性 | PAP | CHAP |
|------|-----|------|
| 安全性 | 密码明文传输 | 传输哈希值 |
| 握手次数 | 2次握手 | 3次握手 |
| 安全性 | 低 | 高 |

## PPP与HDLC对比
- PPP和HDLC协议均是数据链路层协议
- HDLC是面向比特的数据链路层协议
- PPP协议是面向字节的协议

## 关联概念

- **前置知识**：数据链路层功能
- **后续延伸**：广域网技术

## 注意事项

1. PPP只检测差错不纠正差错
2. PPP支持PAP和CHAP两种认证方式
3. PPP是面向字节的，HDLC是面向比特的
