# 编码与调制

## 形式化定义

> 引用自 [[RAW-net-2物理层-2.1.3编码与调制]]：

信道上传送的信号可以分为基带信号和带通信号。将数字信号转换为另一种形式的数字信号称为编码（基带调制）；将数字信号转换为模拟信号称为调制（带通调制）。

## 信号类型

| 信号类型 | 说明 |
|---------|------|
| **基带信号** | 来源于信源的信号，将数字信号1和0直接用两种不同的电压表示，再送到数字信道上传输（基带传输） |
| **带通信号** | 经过载波调制后的信号（仅在一段频率范围内能通过信道） |

## 调制方式

### 基带调制（编码）
仅对基带信号的波形进行变换，使其与信道特性相适应，变换后的信号仍是基带信号。

#### 数字数据编码为数字信号（四种编码方式）

| 编码方式 | 特点 |
|---------|------|
| **不归零码(NRZ)** | 1用高电平，0用低电平 |
| **曼彻斯特编码** | 每个码元中间有跳变，既代表时钟也代表数据（以太网使用） |
| **差分曼彻斯特编码** | 码元开始处有跳变表示0，无跳变表示1 |
| **归零码(RZ)** | 每个码元结束后信号归零 |

### 带通调制
使用载波进行调制，把基带信号的频率搬移到更高的频段，并转换为模拟信号。

| 调制方式 | 说明 |
|---------|------|
| **调幅(ASK)** | 载波的振幅随基带数字信号而变化 |
| **调频(FSK)** | 载波的频率随基带数字信号而变化 |
| **调相(PSK)** | 载波的初相随基带数字信号而变化 |
| **正交振幅调制(QAM)** | 调频 + 调相，达到更高的信息传输速率 |

## 模拟数据编码为数字信号（PCM编码）

PCM（脉码调制）的主要步骤：

| 步骤 | 说明 |
|------|------|
| **抽样** | 对模拟信号进行周期性扫描，把时间上连续的信号变成时间上离散的信号。抽样频率 ≥ 2倍信号最高频率 |
| **量化** | 把抽样取得的电平幅值按分级标度转换为对应的数字值，取整数 |
| **编码** | 把量化的结果转换为与之对应的二进制编码 |

## 注意事项

1. 曼彻斯特编码和差分曼彻斯特编码自带时钟信号
2. 以太网使用曼彻斯特编码
3. 采样定理：$f_{采样} \geq 2f_{信号最高频率}$
4. QAM是调幅和调相的结合
