# DNS域名系统

## 形式化定义

> 引用自 [[RAW-net-6应用层-6.2域名系统DNS]]：

DNS（Domain Name System）域名系统，用于将域名转换为IP地址。DNS采用C/S模型，运行在UDP上，使用53端口。

## DNS组成部分

| 组件 | 说明 |
|------|------|
| **层次域名空间** | 域名的层次结构，如 www.example.com |
| **域名服务器** | 存储域名与IP地址映射的服务器 |
| **域名解析过程** | 将域名转换为IP地址的过程 |
| **高速缓存** | 缓存查询结果，提高查询效率 |

## 层次域名空间

域名采用层次结构，从右到左依次为：
- **根域名**：如 `.`
- **顶级域名**：如 `.com`, `.edu`, `.cn`
- **二级域名**：如 `example.com`
- **三级域名**：如 `www.example.com`

## 域名服务器

| 服务器类型 | 说明 |
|-----------|------|
| **根域名服务器** | 知道所有顶级域名服务器的域名和IP地址 |
| **顶级域名服务器** | 管理顶级域名下的所有二级域名 |
| **权限域名服务器** | 负责某个区域的域名解析 |
| **本地域名服务器** | 默认域名服务器，客户机直接查询的对象 |

## 域名解析过程

### 递归查询
- 客户机向本地域名服务器发送查询请求
- 若本地域名服务器无法解析，则代为向其他服务器查询
- 最终将结果返回给客户机

### 递归迭代查询
1. 客户机向本地域名服务器发送查询请求（递归）
2. 本地域名服务器向根域名服务器查询（迭代）
3. 根域名服务器返回顶级域名服务器地址
4. 本地域名服务器向顶级域名服务器查询
5. 顶级域名服务器返回权限域名服务器地址
6. 本地域名服务器向权限域名服务器查询
7. 权限域名服务器返回IP地址
8. 本地域名服务器将结果返回给客户机

## DNS缓存
- DNS查询结果可缓存在本地域名服务器中
- 缓存有生存时间（TTL）
- 提高查询效率，减轻根服务器负担

## 关联概念

- **前置知识**：UDP协议
- **后续延伸**：[HTTP协议](L3-net-concept-HTTP协议.md)

## 注意事项

1. DNS使用UDP（53端口），不是TCP
2. 递归查询中，客户机只需发送一次请求
3. DNS缓存可提高查询速度，但可能返回过时结果
