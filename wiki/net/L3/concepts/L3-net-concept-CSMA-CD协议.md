# CSMA/CD协议

## 形式化定义

> 引用自 [[RAW-net-3数据链路层-3.5.2随机接入协议分类]]：

CSMA/CD（Carrier Sense Multiple Access with Collision Detection），即**载波监听多址接入/碰撞检测**，是早期共享信道以太网使用的信道访问控制协议。

## 协议三要素

| 要素 | 说明 |
|------|------|
| **载波监听(CS)** | 每一个站在发送数据之前要检测一下总线上是否有其他计算机在发送数据 |
| **多址接入(MA)** | 多个站点连接在一条总线上，共享传输媒体 |
| **碰撞检测(CD)** | 边发送边监听，当检测到碰撞时立即停止发送 |

## 协议工作原理

1. **载波监听**：适配器从网络层获得一个分组，封装成帧，放入适配器缓存
2. **发送前监听**：检测信道是否空闲
   - 信道空闲：开始发送帧
   - 信道忙：继续监听，直到信道变为空闲
3. **边发边听**：发送过程中持续检测信道
4. **碰撞检测**：若检测到碰撞，立即停止发送，发送干扰信号通知所有站点
5. **退避重发**：执行截断二进制指数退避算法，等待随机时间后重新监听

## 关键参数

### 征用期（碰撞期）
- 主机最多需要 $2\tau$ 的时间才能检测到碰撞（$\tau$ 为单程传播时延）
- 以太网的端到端往返时延 $2\tau$ 称为争用期

### 最小帧长
- 为了确保在发送过程中能检测到碰撞，帧的发送时间必须 ≥ $2\tau$
- 公式：$\text{最小帧长} = \text{争用期} \times \text{数据传输率}$
- 以太网的最小帧长为 **64B**（512bit）

### 最大帧长
- 以太网的最大帧长为 **1518B**
- 防止某个站点长时间占用信道

### 截断二进制指数退避算法

| 步骤 | 说明 |
|------|------|
| 基本退避时间 | 取为争用期 $2\tau$ |
| 重传次数k | $k = \min(重传次数, 10)$ |
| 随机时延 | 从$[0, 2^k - 1]$中随机取r，退避时间为 $r \times 2\tau$ |
| 重传限制 | 重传16次仍不成功，丢弃该帧并向上层报告 |

### 信道利用率
- 以太网的信道利用率不可能达到100%
- 极限信道利用率 $S_{max} = \frac{1}{1 + 2\tau / T_0}$（$T_0$为发送一帧所需时间）

## 帧发送流程
1. 准备发送 → 2. 检测信道 → 3. 空闲发送 → 4. 碰撞检测 → 5. 成功/退避

## 帧接收流程
1. 检查MAC地址是否匹配 → 2. 检查帧校验序列FCS → 3. 检查帧长 → 4. 提交给上层

## CSMA/CD与CSMA/CA区别

| 特性 | CSMA/CD | CSMA/CA |
|------|---------|---------|
| 检测方式 | 检测碰撞（边发边听） | 避免碰撞（预约信道） |
| 适用网络 | 总线形以太网 | 无线局域网 |
| 确认机制 | 不需要确认 | 需要确认（停止-等待） |
| 检测方式 | 通过电缆中电压变化检测 | 能量检测、载波检测 |

## 注意事项

1. CSMA/CD不适用确认机制
2. 最小帧长64B是关键考点
3. 检测到碰撞后需发送32bit或48bit的干扰信号
4. 物理层和链路层共同实现CSMA/CD
