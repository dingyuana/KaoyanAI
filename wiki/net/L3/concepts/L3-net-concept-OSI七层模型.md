# OSI七层模型

## 形式化定义

> 引用自 [[RAW-net-1计算机网络体系结构-OSI七层模型]]：

OSI（Open Systems Interconnection）七层模型是国际标准化组织ISO制定的网络体系结构参考模型，将计算机网络通信划分为七个层次，从下到上依次为：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

## 直观解释

OSI七层模型是计算机网络通信的"分层蓝图"。每一层负责特定的通信功能，下层为上层提供服务。分层将庞大复杂的网络通信问题分解为若干个较小的、易于处理的局部问题。

## 核心要点

1. **物理层**：负责在物理线路上传输原始的二进制数据比特流
2. **数据链路层**：为同一链路的主机提供数据传输服务，将网络层传下来的分组封装成帧
3. **网络层**：为主机提供数据传输服务，把传输层传递下来的报文段封装成分组，实现路由选择和转发
4. **传输层**：为进程提供通用数据传输服务（TCP面向连接可靠传输，UDP无连接尽最大努力传输）
5. **会话层**：建立及管理会话
6. **表示层**：数据压缩、加密及数据描述，处理不同主机数据内部格式不同的问题
7. **应用层**：通过应用进程间的交互来完成特定网络应用

## 分层基本原则

| 原则 | 说明 |
|------|------|
| 相互独立 | 各层之间相互独立，每层只实现一种相对独立的功能 |
| 界面清晰 | 每层之间界面自然清晰，易于理解，相互交流尽可能少 |
| 结构可分割 | 每层都采用最合适的技术来实现 |
| 下层对上层的独立性 | 上层单向使用下层提供的服务 |
| 促进标准化 | 能促进标准化工作 |

## 各层功能对比

| 功能 | 说明 |
|------|------|
| 差错控制 | 使相应层次对等方的通信更加可靠 |
| 流量控制 | 发送端的发送速率必须使接收端来得及接收 |
| 拥塞控制 | 结点来不及接受分组而要丢弃大量分组的情况 |
| 分段和重装 | 发送端将要发送的数据块划分为更小的单位，在接收端还原 |
| 复用和分用 | 发送端几个高层会话复用一条低层连接，接收端再分用 |
| 连接建立和释放 | 交换数据前先建立一条逻辑连接，数据传送结束后释放连接 |

## 注意事项

1. OSI七层模型是理论参考模型，实际互联网使用TCP/IP体系结构
2. 数据链路层和网络层是"点对点通信"（计算机节点与节点之间）
3. 传输层是"端到端通信"（进程与进程通过端口进行通信）
4. 表示层和会话层在TCP/IP模型中未被独立实现
