# 奈氏准则和香农定理计算题

## 题目列表

### 题目1：奈氏准则应用
**来源**：408真题2014年第35题
**难度**：简单
**考点**：奈氏准则

**题目**：
设信道带宽为3000Hz，采用4种不同的信号电平级数（即V=4），根据奈氏准则，该信道的最大数据传输率是多少？

**解析**：
1. 奈氏准则公式：$C = 2W \log_2 V$
2. W=3000Hz，V=4
3. $C = 2 × 3000 × \log_2 4 = 6000 × 2 = 12000b/s$

**答案**：12000b/s = 12kb/s

**关键点**：奈氏准则中V是信号电平级数，不是码元状态数

### 题目2：香农定理应用
**来源**：408真题2009年第34题
**难度**：中等
**考点**：香农定理

**题目**：
在无噪声的情况下，若某通信链路的带宽为3kHz，采用4个相位，每个相位具有4种振幅的QAM调制技术，则该链路的最大数据传输率是多少？若信噪比S/N=1000，带宽不变，最大数据传输率又是多少？

**解析**：
1. 无噪声情况下（奈氏准则）：
   - V = 4相位 × 4振幅 = 16种信号状态
   - C = 2W log₂V = 2 × 3000 × log₂16 = 6000 × 4 = 24000b/s

2. 有噪声情况下（香农定理）：
   - C = W log₂(1 + S/N) = 3000 × log₂(1+1000) = 3000 × log₂1001
   - log₂1001 ≈ 9.97
   - C = 3000 × 9.97 = 29910b/s

**答案**：无噪声：24kb/s，有噪声：29.91kb/s

**关键点**：QAM中信号状态数是振幅数×相位数

### 题目3：信噪比转换
**来源**：408真题2016年第34题
**难度**：简单
**考点**：信噪比转换

**题目**：
若信道带宽为4kHz，信噪比为30dB，求该信道的最大数据传输率。

**解析**：
1. 信噪比30dB → S/N = 10^(30/10) = 1000
2. 香农定理：C = W log₂(1+S/N)
3. C = 4000 × log₂(1+1000) = 4000 × log₂1001
4. log₂1001 ≈ 9.97
5. C = 4000 × 9.97 = 39880b/s ≈ 40kb/s

**答案**：约40kb/s

**关键点**：dB与比值换算：SNR(dB)=10log₁₀(S/N)，30dB对应S/N=1000

### 题目4：奈氏准则与香农定理结合
**来源**：408真题2017年第34题
**难度**：困难
**考点**：两个公式结合

**题目**：
若信道带宽为3kHz，信噪比为30dB，信号电平级数为8。问该信道的实际最大数据传输率受什么限制？最终最大数据传输率是多少？

**解析**：
1. 根据奈氏准则：C₁ = 2W log₂V = 2×3000×log₂8 = 6000×3 = 18000b/s
2. 根据香农定理：C₂ = W log₂(1+S/N)，30dB→S/N=1000
   C₂ = 3000 × log₂1001 = 3000 × 9.97 ≈ 29910b/s
3. 实际数据传输率受两者中较小者的限制
4. min(C₁, C₂) = min(18000, 29910) = 18000b/s

**答案**：受奈氏准则限制，最大为18000b/s

**关键点**：实际信道数据传输率受奈氏准则和香农定理两者中较小者限制

## 学习建议

1. 熟记奈氏准则公式：C=2W log₂V
2. 熟记香农定理公式：C=W log₂(1+S/N)
3. 掌握dB与S/N的换算（30dB→1000，20dB→100）
4. 实际信道的极限传输率取两个公式计算结果中较小者
