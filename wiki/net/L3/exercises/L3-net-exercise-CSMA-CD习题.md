# CSMA/CD协议计算题

## 题目列表

### 题目1：最小帧长计算
**来源**：408真题2009年第37题
**难度**：中等
**考点**：最小帧长

**题目**：
在一个采用CSMA/CD协议的网络中，传输介质是一根完整的电缆，数据传输率为1Gb/s，信号在电缆中的传播速率为200000km/s。若要求最小的数据帧长度不少于1250B，则电缆的最大长度约为多少？

**解析**：
1. 最小帧长的定义：帧的发送时间 ≥ 2τ（争用期），τ为单向传播时延
2. 最小帧长 = 争用期 × 数据传输率 = 2τ × 数据传输率
3. 1250B = 1250 × 8 = 10000bit
4. 争用期 = 10000 / (10^9) = 10μs
5. τ = 5μs
6. 电缆长度 = τ × 传播速率 = 5μs × 200000km/s = 5×10^{-6} × 2×10^8 = 1000m

**答案**：约1000m

**关键点**：最小帧长 = 2τ × 数据传输率

### 题目2：截断二进制指数退避
**来源**：408真题改编
**难度**：中等
**考点**：退避算法

**题目**：
以太网中，某站点第1次冲突后，其退避时间的可能取值是什么？第2次冲突后呢？第11次冲突后呢？（假设争用期为512bit时间）

**解析**：
1. 截断二进制指数退避算法：$k = \min(重传次数, 10)$
   - 退避时间 = 随机数r × 512bit时间，r ∈ [0, 2^k-1]

2. 第1次冲突：k=1，r ∈ [0, 1]
   - 可能退避时间：0 或 512bit时间

3. 第2次冲突：k=2，r ∈ [0, 3]
   - 可能退避时间：0, 512, 1024, 1536bit时间

4. 第11次冲突：k=10，r ∈ [0, 1023]
   - 可能退避时间：0 ~ 1023 × 512bit时间

**答案**：第1次：0或512；第2次：0,512,1024,1536；第11次：0~523776bit时间

**关键点**：k=min(重传次数,10)，退避时间=r×争用期

### 题目3：争用期与最短帧长
**来源**：408真题2013年改编
**难度**：中等
**考点**：争用期

**题目**：
以太网中，数据传输速率为100Mb/s，电缆长度为1km，信号传播速率为200000km/s。问：
（1）争用期是多少？
（2）最短帧长至少是多少字节？
（3）若接收方收到一个长度为64B的帧，是否能直接确认该帧正常？

**解析**：
1. τ = 1km / (200000km/s) = 5μs
2. 争用期 = 2τ = 10μs
3. 最短帧长 = 10μs × 100Mb/s = 1000bit = 125B
4. 但以太网标准规定最短帧长为64B=512bit，这里计算结果125B>64B
   - 实际以太网最短帧长为64B(512bit)，这是基于更早的10Mb/s标准定下来的
   - 当速率更高时，需要限制电缆长度或使用其他技术

**答案**：
（1）10μs （2）至少125B（实际以太网标准64B）

**关键点**：最短帧长与数据传输率成正比，与电缆长度成正比
