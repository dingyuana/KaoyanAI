# 子网划分与IP地址综合练习题

## 题目列表

### 题目1：IP地址类别判断
**来源**：408真题改编
**难度**：简单
**考点**：IP地址分类

**题目**：
IP地址 `192.168.10.5` 属于哪一类？它的网络号和主机号分别是什么？默认子网掩码是什么？

**解析**：
1. 第一个十进制数192，在192~223范围内 → C类地址
2. C类地址网络号24位，主机号8位
3. 默认子网掩码：255.255.255.0
4. 网络号：192.168.10.0，主机号：0.0.0.5

**答案**：C类，网络号192.168.10.0，主机号0.0.0.5，子网掩码255.255.255.0

**关键点**：根据首字节范围确定IP类别

### 题目2：子网划分计算
**来源**：408真题改编
**难度**：中等
**考点**：子网划分、可用主机数

**题目**：
某单位申请到一个C类地址 `200.100.50.0`，需要划分为5个子网，每个子网至少15台主机。请问：
（1）应借用几位作为子网号？
（2）新的子网掩码是多少？
（3）每个子网的可用主机数是多少？

**解析**：
1. 需要5个子网，$2^2=4<5$，$2^3=8\geq5$，借用3位
2.新子网掩码：255.255.255.224 （因为224=11100000）
3. 主机位=8-3=5位，每个子网可用主机数=$2^5-2=30$台

**答案**：
（1）借用3位
（2）255.255.255.224（/27）
（3）30台

**关键点**：子网数≥实际需求，且主机数也要满足

### 题目3：CIDR路由聚合
**来源**：408真题改编
**难度**：中等
**考点**：CIDR、路由聚合

**题目**：
四个网络地址 `192.168.0.0/24`、`192.168.1.0/24`、`192.168.2.0/24`、`192.168.3.0/24` 可以聚合成一个多大的CIDR地址块？

**解析**：
1. 四个网络地址的前22位相同：
   - 192.168.00000000.0
   - 192.168.00000001.0
   - 192.168.00000010.0
   - 192.168.00000011.0
2. 前22位相同 → 聚合为 /22

**答案**：192.168.0.0/22

**关键点**：路由聚合后网络前缀长度取决于共同前缀的位数

### 题目4：判断是否在同一子网
**来源**：408真题
**难度**：中等
**考点**：子网判断

**题目**：
IP1 = `192.168.10.65/26`，IP2 = `192.168.10.130/26`，判断这两个IP是否在同一子网？

**解析**：
1. /26 → 子网掩码255.255.255.192
2. IP1网络号：192.168.10.65 AND 255.255.255.192
   - 65 = 01000001, 192 = 11000000 → 01000000 = 64
   - 网络号：192.168.10.64
3. IP2网络号：192.168.10.130 AND 255.255.255.192
   - 130 = 10000010, 192 = 11000000 → 10000000 = 128
   - 网络号：192.168.10.128
4. 网络号不同 → 不在同一子网

**答案**：不在同一子网

**关键点**：同一子网的IP地址网络号相同

1. 熟练掌握十进制和二进制的转换
2. 记住各类IP地址的范围和默认子网掩码

4. CIDR聚合时要找共同的前缀位
