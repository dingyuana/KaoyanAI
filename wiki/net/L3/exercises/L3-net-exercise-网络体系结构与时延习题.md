# 计算机网络体系结构与时延计算习题

## 题目列表

### 题目1：OSI七层模型各层功能
**来源**：408真题改编
**难度**：简单
**考点**：OSI七层模型

**题目**：
在OSI参考模型中，下列功能分别由哪一层实现？
（1）将比特流转换为电信号
（2）路由选择
（3）端到端的可靠数据传输
（4）数据压缩

**解析**：
（1）物理层 — 负责在物理线路上传输原始的二进制比特流
（2）网络层 — 为主机提供数据传输服务，实现路由选择和转发
（3）传输层 — 为进程提供通用数据传输服务，TCP提供可靠传输
（4）表示层 — 数据压缩、加密以及数据描述

**答案**：（1）物理层 （2）网络层 （3）传输层 （4）表示层

**关键点**：熟记各层功能和典型协议

### 题目2：分组交换时延计算
**来源**：408真题改编
**难度**：中等
**考点**：分组交换时延

**题目**：
一个长度为10000B的报文，需经过2段链路（1个中间路由器）从A传送到B。每段链路的长度均为10km，信号传播速率为2×10⁸m/s，链路带宽为100Mb/s。报文被分成10个等长的分组（不考虑首部开销）。问：
（1）该报文的总发送时延是多少？
（2）总传播时延是多少？
（3）从A开始发送第一个比特到B收到最后一个比特共需多少时间？

**解析**：
1. 发送时延：
   - 每个分组长度 = 10000/10 = 1000B = 8000bit
   - 一个分组的发送时延 = 8000 / (100×10⁶) = 80μs
   - 总发送时延 = 10 × 80μs = 800μs
   - 加上中间路由器转发：1个路由器×80μs = 80μs
   - 总发送时延 = 800 + 80 = 880μs

2. 传播时延：
   - 每段链路传播时延 = 10×10³ / (2×10⁸) = 50μs
   - 总传播时延 = 2 × 50μs = 100μs

3. 总时间 = 最后一个分组的发送完成时间 + 传播时延
   - 实际上：第一个分组发送+转发+传播，同时后续分组陆续发出
   - 总时间 = 10×80μs + 1×80μs + 2×50μs = 880 + 100 = 980μs

**答案**：约980μs

**关键点**：分组交换中，发送时延需考虑中间节点的转发时延

### 题目3：三种交换方式比较
**来源**：408真题改编
**难度**：中等
**考点**：交换方式比较

**题目**：
一个总长度为L比特的报文，要通过k段链路（k-1个路由器）从A传送到B，链路的带宽为Rb/s，不考虑排队时延和处理时延，传播时延为D秒。
（1）使用电路交换，建立连接时间为S秒，总时延为多少？
（2）使用分组交换，将报文分为n个分组，每个分组长度为L/n比特，总时延为多少？

**解析**：
1. 电路交换：总时延 = S（建立连接）+ L/R（发送时延）+ D（传播时延）
2. 分组交换：总时延 = (L/R) + (k-1)×(L/nR) + D
   - 发送时延：将整个报文发送完 = L/R
   - 转发时延：n个分组的流水线效果 → 最后(k-1)个分组的发送时间
   - 其中关键：最后一个分组经过k-1次转发

**答案**：
（1）$T = S + \frac{L}{R} + D$
（2）$T = \frac{L}{R} + (k-1)\frac{L}{nR} + D$

**关键点**：分组交换中由于分组流水线传输，中间节点转发时延只需考虑最后一个分组
