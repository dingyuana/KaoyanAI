# AGENT.md - 计算机网络学科 AI 约束

> 本文件定义AI在操作计算机网络知识库时的行为规范和约束条件。
> 通用约束请参阅 `../WIKI_SCHEMA.md`。

---

## 一、AI 操作原则

### 1.1 知识生成规则

1. **忠实原文**：L1 层不得修改、总结、纠错原文内容
2. **三层架构**：严格遵循 L1→L2→L3 的知识加工流程
3. **类型分离**：概念、方法、习题必须分离到对应目录
4. **格式统一**：严格遵循 SCHEMA.md 定义的格式规范

### 1.2 协议描述规范

1. **层次明确**：标明协议所属的网络层次
2. **报文格式**：使用表格描述报文字段
3. **交互时序**：协议交互必须描述完整时序

### 1.3 地址与端口规范

1. **IP地址**：标明掩码长度或子网掩码
2. **端口号**：标明协议类型（TCP/UDP）
3. **MAC地址**：使用标准十六进制格式

---

## 二、L1 处理规则

### 2.1 Chunk 拆分标准

- 一个网络协议 = 一个 Chunk
- 一个网络设备 = 一个 Chunk
- 一个计算题 = 一个 Chunk
- 一道例题 = 一个 Chunk

### 2.2 锚点生成规则

```
RAW-net-{章节名}-{序号}
示例：RAW-net-5传输层-P001-C01
```

---

## 三、L3 生成规则

### 3.1 概念文档

- 必须包含：形式化定义、协议报文格式、工作流程
- 可选包含：典型应用、关联协议

### 3.2 方法文档

- 必须包含：适用场景、计算/分析步骤、示例
- 可选包含：注意事项、常见错误

### 3.3 习题文档

- 必须包含：题目、解析、答案
- 可选包含：子网划分过程、协议分析

---

## 四、禁止行为

1. ❌ 不得在 L1 层修改原文内容
2. ❌ 不得将协议报文格式拆分
3. ❌ 不得省略协议交互的时序描述
4. ❌ 不得将概念和计算方法混在同一文档
5. ❌ 不得修改网络拓扑题目的原始数据
