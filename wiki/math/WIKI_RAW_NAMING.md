# raw/ 命名规范与 Raw→L3 映射规则

> 本文件定义 raw 层文件命名规范，以及 raw → L3 的标准化转换规则。
> 建立于 2026-05-13。

---

## 一、Raw 层文件类型分类

| 类型 | 命名特征 | 示例 | L3 映射 |
|------|---------|------|---------|
| **概念型** | 纯概念名，无前缀后缀 | `极限.md`, `乘法公式.md` | ✅ 有对应 L3 |
| **讲座转写型** | 含"第N讲" | `高等数学-第100讲.md` | ❌ Raw 仅存档 |
| **方法型** | 含【方法】【方法论】 | `【方法】反向思路.md` | ✅ 有对应 L3 |
| **说明型** | 含【说明】【指南】 | `【说明】解题指南.md` | 部分有 L3 |
| **编号型** | 含数字前缀 | `线性代数/01-行列式.md` | ✅ 有对应 L3 |
| **习题型** | `基础篇_` / `强化篇_` 前缀 | `基础篇_一元函数微分学的应用.md` | ✅ 有对应 L3（通过 P001-P030 映射） |

## 二、Raw→L3 转换规则

### Rule 1: 简单概念（直接映射）

```
raw/高等数学/极限.md         → L3-math-concept-极限.md
raw/概率论与数理统计/乘法公式.md → L3-math-concept-乘法公式.md
```

转换逻辑：`L3-math-concept-{文件名去掉.md}.md`

---

### Rule 2: 编号型文件（剥离数字前缀）

```
raw/线性代数/01-行列式.md   → L3-math-concept-行列式.md
raw/线性代数/02-余子式和代数余子式的计算.md → L3-math-concept-余子式和代数余子式的计算.md
```

转换逻辑：剥离 `NN-` 前缀（两位数字 + 连字符），剩余部分作为 L3 文件名。

---

### Rule 3: 讲座转写型（Raw 仅存档，不生成 L3）

```
raw/高等数学/高等数学-第100讲.md   → (无 L3)
raw/概率论与数理统计/概率论与数理统计-第10讲.md → (无 L3)
```

说明：讲座转写是原始教学记录，保留在 raw 层供参考，不生成结构化概念文档。

---

### Rule 4: 方法型文件（Subject 前缀添加规则）

```
raw/概率论与数理统计/【方法】反向思路.md  → L3-math-method-概率论-反向思路.md
raw/高等数学/【方法】反向思路.md          → L3-math-method-反向思路.md
```

转换逻辑：
1. 剥离 `【方法】` / `【方法论】` 标签
2. 如果同一方法名在多个 subject 下存在（概率论/高等数学都叫"反向思路"），L3 加上 subject 前缀以区分
3. 如果只有一个 subject 有，则不加前缀

---

### Rule 5: 习题型文件（P001-P030 编号映射）

```
raw/exams/基础篇_一元函数微分学的应用.md   → L3-math-exercise-P001-一元函数微分学的应用.md
raw/exams/强化篇_一元函数微分学的应用.md   → L3-math-exercise-P018-一元函数微分学的应用.md
```

说明：习题文件按"基础篇"在前（P001-P017）、"强化篇"在后（P018-P030）顺序分配编号。

---

## 三、命名一致性检查清单

处理新的 raw 文件时，对照以下检查：

- [ ] 文件名是否以 `第N讲` 结尾？是 → 讲座转写，存档即可
- [ ] 文件名是否含 `【方法】` 或 `【方法论】`？是 → 方法型，检查是否需加 subject 前缀
- [ ] 文件名是否含数字前缀（如 `01-`, `02-`）？是 → 编号型，剥离数字前缀
- [ ] 文件名是否以 `基础篇_` 或 `强化篇_` 开头？是 → 习题型，按顺序分配 P 编号
- [ ] 其他情况 → 概念型，直接映射
