## 1. 概念定义

**经济应用**是指利用定积分解决经济学中的总量问题。当已知边际量（边际函数），求总量时，使用定积分：

> 若 $F'(x) = f(x)$，则总量 $F(x) = F(a) + \int_a^x f(t)\,dt$

### 常用经济函数关系

| 名称 | 定义 | 经济学含义 |
|------|------|------------|
| 需求函数 $Q(p)$ | 价格 $p$ 与需求量 $Q$ 的关系 | 价格越高，需求量越低 |
| 供给函数 $S(p)$ | 价格 $p$ 与供给量 $S$ 的关系 | 价格越高，供给量越高 |
| 成本函数 $C(x)$ | 产量 $x$ 的总成本 | $C(x) = C(0) + \int_0^x C'(t)\,dt$ |
| 收益函数 $R(x)$ | 销量 $x$ 的总收入 | $R(x) = \int_0^x R'(t)\,dt$ |
| 利润函数 $L(x)$ | 总收益减总成本 | $L(x) = R(x) - C(x)$ |
| 边际函数 | 总量函数的导数 | $C'(x), R'(x), L'(x)$ |


## 2. 核心公式

### 2.1 成本与收益

总成本：
$$C(x) = C(0) + \int_0^x C'(t)\,dt$$

总收益：
$$R(x) = \int_0^x R'(t)\,dt = \int_0^x p(t)\,dt$$

> 其中 $p(x)$ 为需求价格函数

### 2.2 消费者剩余与生产者剩余

**消费者剩余**（CS）：
$$\text{CS} = \int_0^{Q_0} D(Q)\,dQ - P_0 \cdot Q_0$$

**生产者剩余**（PS）：
$$\text{PS} = P_0 \cdot Q_0 - \int_0^{Q_0} S(Q)\,dQ$$

### 2.3 利润

总利润：
$$L(x) = R(x) - C(x)$$

最大利润条件：
$$L'(x) = R'(x) - C'(x) = 0 \Rightarrow R'(x) = C'(x)$$


## 3. 典型例题

### 例题：边际分析与利润最大化

> 已知某企业的边际成本为 $C'(x) = 3x^2 - 12x + 25$（万元/单位），固定成本为 $C(0) = 50$ 万元。边际收益为 $R'(x) = 80 - 5x$（万元/单位）。
>
> (1) 求总成本函数 $C(x)$ 和总收益函数 $R(x)$；
>
> (2) 求最大利润及此时的产量。

### 解：

**(1) 求总成本函数**

$$C(x) = C(0) + \int_0^x (3t^2 - 12t + 25)\,dt$$

$$= 50 + \left[t^3 - 6t^2 + 25t\right]_0^x$$

$$\boxed{C(x) = x^3 - 6x^2 + 25x + 50}$$

**求总收益函数**

$$R(x) = \int_0^x (80 - 5t)\,dt = \left[80t - \frac{5}{2}t^2\right]_0^x$$

$$\boxed{R(x) = 80x - \frac{5}{2}x^2}$$

**(2) 求最大利润**

利润函数：
$$L(x) = R(x) - C(x) = \left(80x - \frac{5}{2}x^2\right) - (x^3 - 6x^2 + 25x + 50)$$

$$= -x^3 + \frac{7}{2}x^2 + 55x - 50$$

求导：
$$L'(x) = -3x^2 + 7x + 55$$

令 $L'(x) = 0$：
$$3x^2 - 7x - 55 = 0$$

$$x = \frac{7 \pm \sqrt{49 + 660}}{6} = \frac{7 \pm \sqrt{709}}{6}$$

由于 $\sqrt{709} \approx 26.6$，取正根：
$$x \approx \frac{7 + 26.6}{6} \approx 5.6$$

验证 $L''(x) = -6x + 7 < 0$（当 $x > 5.6$ 时），确为最大值。

最大利润：
$$L(5.6) = -(5.6)^3 + \frac{7}{2}(5.6)^2 + 55 \times 5.6 - 50 \approx 207.3 \text{（万元）}$$

$$\boxed{\text{最大利润约为 207.3 万元，产量约为 5.6 单位}}$$


## 4. 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|----------|----------|----------|
| 忽略固定成本 | 令 $C(0) = 0$ | 成本函数必须加上固定成本 $C(0)$ |
| 积分上下限错误 | $R(x) = \int_0^x p(x)\,dx$ 中 $p$ 用 $x$ | 积分变量与上限变量要区分：$\int_0^x p(t)\,dt$ |
| 混淆边际与总量 | 以为 $C'(x)$ 就是总成本 | $C'(x)$ 是边际成本，$\int C'(x)\,dx$ 才是总量 |
| 最大最小值判别 | 直接令导数为零不验证 | 必须用二阶导数或实际问题判断 |
| 需求函数方向 | 误用 $p = D(Q)$ 当 $Q = D(p)$ | 明确哪个是自变量，注意积分变量对应 |
