# 数列极限的判定


## 1. 概念定义

**数列极限判定**是指通过单调性和有界性来判定数列收敛性的方法。

### 基本定理：单调有界准则

> 若数列 $\{x_n\}$ **单调递增且有上界**，或**单调递减且有下界**，则数列 $\{x_n\}$ 必收敛。


## 2. 核心公式

### 判定单调性的三种方法

| 方法 | 公式 | 判定规则 |
| **直接比较法** | $x_{n+1} - x_n$ | $>0$ 递增，$<0$ 递减 |
| **作差法** | $x_{n+1} - x_n$ | 同上 |
| **作商法** | $\dfrac{x_{n+1}}{x_n}$ | $>1$ 递增，$<1$ 递减（需 $x_n > 0$） |

### 极限的求法

设 $\lim\limits_{n \to \infty} x_n = A$，则对递推关系 $x_{n+1} = f(x_n)$ 两边取极限：

$$A = f(A)$$

解此方程即可得到极限值。


## 3. 典型例题

### 例题（例2.3）

> 设 $0 < x_1 < 1$，$x_{n+1} = 1 - \sqrt{1 - x_n}$（$n = 1, 2, \cdots$），求 $\lim\limits_{n \to \infty} x_n$。

**解：**

**Step 1：判定单调性**

$$x_{n+1} - x_n = 1 - \sqrt{1 - x_n} - x_n = 1 - x_n - \sqrt{1 - x_n}$$

由于 $0 < x_n < 1$，有 $1 - x_n < 1$，故 $\sqrt{1 - x_n} > 1 - x_n$，因此：

$$x_{n+1} - x_n = 1 - x_n - \sqrt{1 - x_n} < 0$$

即 $\{x_n\}$ **单调递减**。

**Step 2：判定有界性**

显然 $x_n > 0$（由递推公式保证），故 $\{x_n\}$ **有下界**。

**Step 3：由单调有界准则**

数列 $\{x_n\}$ 收敛。

**Step 4：求极限**

设 $\lim\limits_{n \to \infty} x_n = A$，则：

$$A = 1 - \sqrt{1 - A}$$

解得：

$$A = 0 \quad \text{或} \quad A = 1$$

由 $x_n < 1$ 排除 $A = 1$，故：

$$\boxed{\lim\limits_{n \to \infty} x_n = 0}$$


## 4. 常见错误

| 错误类型 | 说明 | 正确做法 |
| **忽略有界性** | 只证单调就下结论收敛 | 必须同时验证**单调**且**有界** |
| **作商法符号问题** | 未验证 $x_n > 0$ 就用 $\frac{x_{n+1}}{x_n}$ | 使用作商法前必须保证各项**同号** |
| **增根未排除** | 极限方程可能有多解 | 需结合数列的范围**舍去不合理的根** |
| **归纳法跳步** | 归纳证明时假设不严谨 | $n=1$ 验证后，假设 $n=k$ 成立，推出 $n=k+1$ |
| **$\sqrt{}$ 漏绝对值** | $\sqrt{a^2} = |a|$ 而非 $a$ | 开方运算注意正负号 |
