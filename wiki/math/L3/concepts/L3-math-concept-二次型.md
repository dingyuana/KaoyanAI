# 二次型

## 概念定义

**二次型**是 n 个变量的二次齐次多项式，其一般形式为：

$$f(x_1, x_2, \ldots, x_n) = \sum_{i=1}^{n} \sum_{j=1}^{n} a_{ij} x_i x_j$$

其中 $a_{ij} = a_{ji}$，即系数矩阵 $A = (a_{ij})$ 为[[实对称矩阵]]。

二次型可以简洁地表示为矩阵形式：

$$f = \mathbf{x}^T A \mathbf{x}$$

其中 $\mathbf{x} = (x_1, x_2, \ldots, x_n)^T$，$A = A^T$ 为 n 阶实对称矩阵。

**核心目标**：通过可逆线性变换，将二次型化为标准形或规范形。


## 核心公式

### 1. 二次型的矩阵表示

$$f = \mathbf{x}^T A \mathbf{x}, \quad A = A^T$$

### 2. 可逆线性变换（配方法）

$$\mathbf{x} = C\mathbf{y}, \quad C \text{ 可逆}$$

$$f = \mathbf{x}^T A \mathbf{x} = \mathbf{y}^T (C^T A C) \mathbf{y}$$

使得 $C^T A C = \diag(\lambda_1, \lambda_2, \ldots, \lambda_n)$

### 3. 正交变换

$$\mathbf{x} = Q\mathbf{y}, \quad Q \text{ 为正交矩阵 } (Q^T = Q^{-1})$$

$$f = \mathbf{x}^T A \mathbf{x} = \mathbf{y}^T (Q^T A Q) \mathbf{y} = \mathbf{y}^T \Lambda \mathbf{y}$$

其中 $\Lambda = \diag(\lambda_1, \lambda_2, \ldots, \lambda_n)$，$\lambda_i$ 为 A 的特征值。

### 4. 惯性定理

合同变换保持正、负惯性指数不变：
- 正惯性指数 $p$：正特征值的个数
- 负惯性指数 $q$：负特征值的个数

### 5. 正定性的判定条件

对于实对称矩阵 A，以下条件等价：

| 条件 | 描述 |
|------|------|
| 定义 | $\forall \mathbf{x} \neq \mathbf{0}$，有 $\mathbf{x}^T A \mathbf{x} > 0$ |
| 特征值 | A 的所有特征值 $\lambda_i > 0$ |
| 顺序主子式 | 各阶顺序主子式均大于 0 |
| 合同关系 | $A \sim E$（A 与单位矩阵合同） |
| 分解形式 | 存在可逆矩阵 D，使得 $A = D^T D$ |

### 6. 合同与相似的区别

- **相似**：$Q^{-1} A Q = B$，Q 为任意可逆矩阵
- **合同**：$C^T A C = B$，C 为任意可逆矩阵
- 对于[[实对称矩阵]]：相似必合同，反之不一定成立


## 典型例题

### 例9.1（规范形的判定）

**题目**：已知三元二次型 $f$ 表示为 $\underline{?}$，则 $f$ 的规范形为（ ）。

(A) $y_1^2 - y_2^2 + y_3^2$  
(B) $y_1^2 + y_2^2 + y_3^2$  
(C) $-y_1^2 - y_2^2 - y_3^2$  
(D) $y_1^2 - y_2^2 - y_3^2$

**解**：应选(B)。

二次型的矩阵为

$$A = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix}$$

其各阶顺序主子式为：

$$\Delta_1 = 1 > 0, \quad \Delta_2 = \begin{vmatrix} 1 & 0 \\ 0 & 1 \end{vmatrix} = 1 > 0, \quad \Delta_3 = |A| = 1 > 0$$

所以 A 是[[正定矩阵]]，其正惯性指数 $p = 3$。

因此二次型的规范形为 $y_1^2 + y_2^2 + y_3^2$。

## 常见错误

### 1. 混淆配方法与正交变换法

**错误**：认为两种方法本质相同，可以随意混用。

**正确理解**：
- **配方法**：$C$ 只满足可逆，$C^T A C = \Lambda$，$C^{-1} \neq C^T$
- **正交变换**：$Q$ 满足 $Q^T = Q^{-1}$，$Q^T A Q = \Lambda$，变换矩阵是[[正交矩阵]]

### 2. 忽视伪配方法的可逆性条件

**错误**：看到平方和形式 $A^2 + B^2 + C^2$ 就认为二次型正定。

**正确理解**：
- 伪配方法的平方和未必由拉格朗日配方法得到
- 必须验证变换矩阵的**可逆性**
- 若变换不可逆，会改变原图形的几何性质（如封闭性）

### 3. 合同与相似的混淆

**错误**：认为合同的两个矩阵必定相似。

**正确理解**：
- [[实对称矩阵]]必可对角化：既合同又相似于对角矩阵
- 一般矩阵合同不相似，如 $A = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ 与 $B = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$ 合同但不相似

### 4. 正定性判定的必要条件误用

**错误**：认为 $a_{ii} > 0$ 且 $|A| > 0$ 即可判定正定。

**正确理解**：
- $a_{ii} > 0$ 和 $|A| > 0$ 是**必要条件**，不是充分条件
- 必须验证**所有**顺序主子式均大于 0

### 5. 配方顺序不当

**错误**：机械地按 $x_1, x_2, \ldots, x_n$ 顺序配方。

**正确理解**：
- 灵活选择配方顺序，看哪个变量最容易配方就先配哪个
- 注意从对角线元素出发

## 补充说明

### 配方法与正交变换法的异同

| 比较项 | 配方法 | 正交变换法 |
|--------|--------|------------|
| 变换矩阵 | C（可逆） | Q（正交矩阵） |
| 变换关系 | $C^T A C = \Lambda$ | $Q^T A Q = \Lambda$ |
| 矩阵性质 | $C^{-1} \neq C^T$ | $Q^T = Q^{-1}$ |
| 标准形 | $d_1 y_1^2 + d_2 y_2^2 + \cdots + d_n y_n^2$ | $\lambda_1 y_1^2 + \lambda_2 y_2^2 + \cdots + \lambda_n y_n^2$ |
| 惯性指数 | 相同 | 相同 |
| 计算复杂度 | 较低 | 较高（需求特征值） |

### 正定二次型的重要结论

1. 若 A [[正定矩阵|正定]]，则 $A^{-1}$、$A^*$、$A^k$（k 为正整数）、$kA$（k > 0）、$C^T A C$（C 可逆）均正定。

2. 若 A、B [[正定矩阵|正定]]，则 A + B 正定，AB 正定的充要条件是 AB = BA。

3. 若 $A = D^T D$（D 可逆），则 A [[正定矩阵|正定]]（此为格拉姆矩阵）。
