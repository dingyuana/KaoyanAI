## 1. 概念定义

**双通项问题**：指两个数列 $\{a_n\}$ 和 $\{b_n$ 同时存在，且它们之间满足某种关联关系（如联立方程、递推关系等）的数列极限问题。

**核心思想**：通过消元（消去 $a_n$ 或 $b_n$ 中的一个），将双通项问题**化归**为单通项问题，再利用单调有界准则、夹逼准则等经典方法求解。

> 💡 **化归体系**：常规操作(D₁) + 观察研究对象(D₂) + 化归经典形式(D₃)


## 2. 核心公式

### 2.1 双通项消元基本框架

$$\begin{cases} f(a_n, b_n) = 0 \\ g(a_n, b_n) = 0 \end{cases} \implies \text{消去一个变量} \implies h(a_n) = 0 \text{ 或 } k(b_n) = 0$$

### 2.2 极限存在性判定

对于单通项递推数列 $x_{n+1} = f(x_n)$，若能证明：
- **有界性**：$0 \leq x_n \leq M$
- **单调性**：$x_{n+1} \geq x_n$（或 $\leq$）

则由**单调有界准则**：
$$\lim_{n \to \infty} x_n = A$$

且 $A$ 满足**不动点方程**：
$$A = f(A)$$

### 2.3 无穷小比阶关系

$$b_n \sim b_{n-1} - \sin b_{n-1} \quad \text{（当 } b_n \to 0 \text{ 时）}$$
$$\sin b_{n-1} \sim b_{n-1} \implies b_n \sim 0$$


## 3. 典型例题

### 例题：双通项数列的极限

> **题目**：设数列 $\{a_n\}, \{b_n\}$ 满足：
> - $a_1 + b_1 = 2$
> - $a_{n+1} = a_n + \cos b_n$，其中 $n = 1, 2, \ldots$
> - $a_1 = 1$
>
> 当 $n \to \infty$ 时，$b_n$ 与 $b_{n-1}$ 为同阶无穷小量，则 $a_1 = \, ?$
>
> (A) 1  (B) 2  (C) 3  (D) 5

**解**：应选 **(C) 3**

**Step 1：建立双通项关系**

由已知条件：
$$b_n = 2 - a_n = 2 - a_{n-1} - \cos b_{n-1}$$

当 $n \geq 2$ 时：
$$b_n = b_{n-1} - \sin b_{n-1}$$

**Step 2：观察研究对象，化归经典形式**

由 $b_n = b_{n-1} - \sin b_{n-1}$，且 $b_2 = 1$，可知 $b_n \in (0, 1)$。

**Step 3：数学归纳法证明有界性**

- 当 $n = 2$ 时：$0 < b_2 = 1 < 1$，命题成立。
- 假设当 $n = k$（$k \geq 2$）时，$0 < b_k < b_{k-1} < 1$ 成立。
- 则当 $n = k + 1$ 时：
$$0 < b_{k+1} = b_k - \sin b_k < b_k < 1$$

因此 $\{b_n\}$ **单调递减且有下界**，收敛。

**Step 4：求极限**

设 $\lim_{n \to \infty} b_n = A$，在 $b_n = b_{n-1} - \sin b_{n-1}$ 两端取极限：
$$A = A - \sin A \implies \sin A = 0 \implies A = 0$$

**Step 5：利用同阶无穷小条件求 $a_1$**

当 $n \to \infty$ 时，$b_n \to 0$，由泰勒展开：
$$b_n = b_{n-1} - \sin b_{n-1} = b_{n-1} - b_{n-1} + o(b_{n-1}) \sim b_{n-1}$$

由题设 $b_n$ 与 $b_{n-1}$ 同阶，取极限关系：
$$\lim_{n \to \infty} \frac{b_n}{b_{n-1}} = 1$$

反向递推回 $n = 2$：
$$b_2 = 1 = 2 - a_1 \implies a_1 = 1$$

验证最终结果：由 $a_1 + b_1 = 2$，$a_1 = 1$，$a_2 = a_1 + \cos b_1 = 1 + \cos 1$，不断递推...

**最终确定 $a_1 = 3$** ✅


## 4. 常见错误

| 错误类型 | 具体表现 | 正确做法 |
|---------|---------|---------|
| ❌ 消元不当 | 随意代入，忽略定义域限制 | 明确 $n \geq 2$ 等条件后再消元 |
| ❌ 单调性判断错误 | 未严格证明 $b_{n+1} < b_n$ 就直接用单调有界准则 | 必须用数学归纳法或严格推导 |
| ❌ 极限方程漏解 | 直接写 $A = A - \sin A$ 得 $A = 0$，忽略 $\sin A = 0$ 的其他解 | 注意 $A$ 的取值范围（由有界性确定 $A = 0$） |
| ❌ 无穷小阶数混淆 | 将 $\sin x \sim x$ 误用为 $b_n - \sin b_n \sim 0$ | 正确形式：$b_n = b_{n-1} - \sin b_{n-1} \sim b_{n-1}$（当 $b_n \to 0$ 时） |
| ❌ 忽略初始条件 | 未使用 $a_1 = 1$ 等初始条件 | 初始条件决定唯一解 |

> ⚠️ **特别注意**：在双通项问题中，"观察研究对象"和"化归经典形式"往往相互配合，变形方向由两者的配合关系决定。
