# 原函数与导函数的关系

## 1. 概念定义

### 原函数（不定积分）

若函数 $F'(x) = f(x)$，则称 $F(x)$ 为 $f(x)$ 的一个**原函数**。

$$F'(x) = f(x) \Leftrightarrow F(x) = \int f(x)\,dx + C$$

### 导函数

已知函数 $f(x)$，其**导函数**为 $f'(x)$，描述函数的变化率。

### 核心关系

$$f(x) = F'(x)$$

即：**导函数是原函数的导数**。


## 2. 核心公式

### 基本关系式

| 形式 | 公式 |
|------|------|
| **原函数求导** | $\dfrac{d}{dx}\left[\int f(x)\,dx\right] = f(x)$ |
| **变上限积分求导** | $\dfrac{d}{dx}\left[\int_a^x f(t)\,dt\right] = f(x)$ |
| **牛顿-莱布尼茨公式** | $\int_a^b f(x)\,dx = F(b) - F(a)$ |

### 函数值递推公式

$$f(x_2) = f(x_1) + \int_{x_1}^{x_2} f'(t)\,dt$$

> **几何意义**：函数值的变化等于导函数在该区间的"面积积累"。


## 3. 典型例题

### 例题 5.9

设 $f'(x)$ 在区间 $[0,4]$ 上连续，曲线 $y = f'(x)$ 与直线 $x = 0$，$x = 4$，$y = 0$ 围成如图所示的三个区域，其面积分别为 $S_1 = 3$，$S_2 = 4$，$S_3 = 2$，且 $f(0) = 1$，则 $f(x)$ 在 $[0,4]$ 上的最大值与最小值分别为（  ）。

(A) $2, -3$　(B) $4, -3$　(C) $2, -2$　(D) $4, -2$

### 【解题步骤】

**第一步：识别驻点**

由图可知 $f'(1) = f'(3) = 0$，即 $x = 1$ 和 $x = 3$ 为驻点。

**第二步：利用变上限积分求函数值**

$$f(x) = f(0) + \int_0^x f'(t)\,dt$$

计算各关键点：

$$f(1) = f(0) + \int_0^1 f'(t)\,dt = 1 + S_1 = 1 - 3 = -2$$

$$f(3) = f(1) + \int_1^3 f'(t)\,dt = -2 + S_2 = -2 + 4 = 2$$

$$f(4) = f(3) + \int_3^4 f'(t)\,dt = 2 - S_3 = 2 - 2 = 0$$

**第三步：比较端点与驻点处的函数值**

| $x$ | $f(x)$ |
|-----|--------|
| $0$ | $1$ |
| $1$ | $-2$（最小值） |
| $3$ | $2$（最大值） |
| $4$ | $0$ |

$$\boxed{\text{最大值为 } 2,\ \text{最小值为 } -2 \quad \Rightarrow \text{选(C)}}$$


## 4. 常见错误

| 错误类型 | 错误示例 | 正确理解 |
|----------|----------|----------|
| **混淆原函数与导函数** | 误认为 $\int f'(x)\,dx = f(x)$ | 应为 $\int f'(x)\,dx = f(x) + C$（差常数） |
| **变上限积分符号错误** | $\dfrac{d}{dx}\int_a^x f(t)\,dt = -f(x)$ | 应为 $\dfrac{d}{dx}\int_a^x f(t)\,dt = f(x)$ |
| **忽略定积分正负号** | 直接累加面积 | 注意：位于 $x$ 轴下方的面积为负 |
| **漏掉常数 $C$** | 求不定积分后不写 $+C$ | 不定积分结果必须加常数 |
| **求最值遗漏驻点** | 只比较端点值 | 需比较所有驻点 $f'(x) = 0$ 处的函数值 |
