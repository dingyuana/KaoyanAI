# 二阶导数型辅助函数的构造


## 1. 概念定义

**二阶导数型辅助函数的构造**是指在证明涉及 $f'(x)$、$f''(x)$ 与 $f(x)$ 之间关系的中值定理问题时，通过**恒等变形**和**指数因子法**构造合适的辅助函数 $F(x)$，将待证结论化为 $F'(\xi) = 0$ 的形式，从而应用 Rolle 定理或拉格朗日中值定理。

> **核心思想**：把"差辈分"的问题通过恒等变形补齐，构造导数为零的辅助函数。


## 2. 核心公式

### 2.1 常见辅助函数构造公式

| 待处理形式 | 辅助函数 $F(x)$ | 说明 |
| $f'(x)x - f(x)$ | $F(x) = \dfrac{f(x)}{x}$ | $x \neq 0$ |
| $f''(x)f(x) - [f'(x)]^2$ | $F(x) = \dfrac{f'(x)}{f(x)}$ 或 $F(x) = \ln f(x)$ | $f(x) \neq 0$ |
| $f''(x) - f(x)$ | $F(x) = [f'(x) - f(x)]e^x$ | 指数因子法 |

### 2.2 恒等变形通式

$$a - c = (a - b) + (b - c)$$

通过**补齐辈分**将复杂形式化为标准形式。

### 2.3 指数因子法

若要构造 $F'(x) = G(x) \cdot e^{kx}$ 形式的辅助函数：

$$\boxed{F(x) = G(x) \cdot e^{kx} \quad \Rightarrow \quad F'(x) = [G'(x) + kG(x)]e^{kx}}$$


## 3. 典型例题

### 【例题】设 $f(x)$ 在 $[0,1]$ 上二阶可导，且 $f(0) = f(1) = 0$。证明：存在 $\xi \in (0,1)$，使得

$$f''(\xi) = 2f(\xi)$$


### 【证明】

**第一步：恒等变形**

将待证结论化为导数形式：

$$f''(\xi) - 2f(\xi) = 0$$

联想到 $e^{\sqrt{2}x}$ 的性质，构造恒等式：

$$f''(\xi) - \sqrt{2}f'(\xi) + \sqrt{2}f'(\xi) - 2f(\xi) = 0$$

**第二步：构造辅助函数**

令 $F(x) = [f'(x) - \sqrt{2}f(x)]e^{-\sqrt{2}x}$，则：

$$F'(x) = [f''(x) - \sqrt{2}f'(x)]e^{-\sqrt{2}x} - \sqrt{2}[f'(x) - \sqrt{2}f(x)]e^{-\sqrt{2}x}$$
$$= [f''(x) - 2f(x)]e^{-\sqrt{2}x}$$

**第三步：验证边界相等**

由 $f(0) = f(1) = 0$，计算：

$$F(0) = f'(0) - \sqrt{2} \cdot 0 = f'(0)$$

$$F(1) = [f'(1) - \sqrt{2} \cdot 0]e^{-\sqrt{2}} = f'(1)e^{-\sqrt{2}}$$

**第四步：对 $F(x)$ 应用 Rolle 定理**

需要 $F(0) = F(1)$，即 $f'(0) = f'(1)e^{-\sqrt{2}}$。

由于 $f(0) = f(1) = 0$，由 Rolle 定理：$\exists\, \eta \in (0,1)$，使得 $f'(\eta) = 0$。

对 $F(x)$ 在 $[0,\eta]$ 上应用 Rolle 定理（需验证 $F(0) = F(\eta) = 0$），可得：

$$F'(\xi) = [f''(\xi) - 2f(\xi)]e^{-\sqrt{2}\xi} = 0$$

故 $f''(\xi) = 2f(\xi)$，证毕。$\square$


## 4. 常见错误

### ❌ 错误一：忽略定义域条件

> **错误**：直接令 $F(x) = \dfrac{f(x)}{x}$，未说明 $x \neq 0$。
>
> **正确**：必须注明 $x \in (a,b)$ 且 $x \neq 0$，或进行分段讨论。

### ❌ 错误二：指数因子选错

> **错误**：对 $f''(x) - f(x) = 0$，构造 $F(x) = f'(x) - f(x)$，直接令 $F'(x) = f''(x) - f'(x)$。
>
> **正确**：应构造 $F(x) = [f'(x) - f(x)]e^x$，则 $F'(x) = [f''(x) - f(x)]e^x$。

### ❌ 错误三：恒等变形不彻底

> **错误**：直接写 $f''(\xi) = f(\xi)$，不知道如何变形。
>
> **正确**：先进行恒等变形 $f''(\xi) - f'(\xi) + f'(\xi) - f(\xi) = 0$，再分组构造。

### ❌ 错误四：忘记验证端点条件

> **错误**：构造完 $F(x)$ 后直接应用 Rolle 定理，忽略验证 $F(a) = F(b)$。
>
> **正确**：必须利用已知条件（如 $f(a) = f(b) = 0$）验证边界值相等。
