## 1. 概念定义

### 基本概念

**max{X,Y} 与 min{X,Y}** 是两个随机变量 $X$ 和 $Y$ 的最值函数：

- $\max\{X,Y\}$：取 $X$ 与 $Y$ 中的较大值
- $\min\{X,Y\}$：取 $X$ 与 $Y$ 中的较小值

### 核心思想

当处理涉及最值的概率问题时，关键是**将最值事件转化为集合的交并运算**：

| 最值条件 | 转化规律 | 逻辑关系 |
|---------|---------|---------|
| $\max\{X,Y\} \leq a$ | $X \leq a$ **且** $Y \leq a$ | 交集 |
| $\max\{X,Y\} > a$ | $X > a$ **或** $Y > a$ | 并集 |
| $\min\{X,Y\} \leq a$ | $X \leq a$ **或** $Y \leq a$ | 并集 |
| $\min\{X,Y\} > a$ | $X > a$ **且** $Y > a$ | 交集 |

> **记忆口诀**："大"在左边（$\max$）取交，"大"在右边（$>$）取并


## 2. 核心公式

### 2.1 基础等价关系

| 编号 | 公式 | 文字描述 |
|-----|------|---------|
| ① | $\{\max\{X,Y\} \leq a\} = \{X \leq a\} \cap \{Y \leq a\}$ | 最大值 ≤ a 等价于两者都 ≤ a |
| ② | $\{\max\{X,Y\} > a\} = \{X > a\} \cup \{Y > a\}$ | 最大值 > a 等价于至少有一个 > a |
| ③ | $\{\min\{X,Y\} \leq a\} = \{X \leq a\} \cup \{Y \leq a\}$ | 最小值 ≤ a 等价于至少有一个 ≤ a |
| ④ | $\{\min\{X,Y\} > a\} = \{X > a\} \cap \{Y > a\}$ | 最小值 > a 等价于两者都 > a |

### 2.2 补集关系

$$P\{\max\{X,Y\} \leq a\} = 1 - P\{\max\{X,Y\} > a\}$$

$$P\{\min\{X,Y\} > a\} = 1 - P\{\min\{X,Y\} \leq a\}$$

### 2.3 包含关系

| 编号 | 公式 | 含义 |
|-----|------|------|
| ⑤ | $\{\max\{X,Y\} \leq a\} \subseteq \{\min\{X,Y\} \leq a\}$ | 最大值 ≤ a 则最小值必 ≤ a |
| ⑥ | $\{\min\{X,Y\} > a\} \subseteq \{\max\{X,Y\} > a\}$ | 最小值 > a 则最大值必 > a |

### 2.4 运算恒等式

| 编号 | 公式 | 说明 |
|-----|------|------|
| ⑨ | $\max\{X,Y\} + \min\{X,Y\} = X + Y$ | 最值之和等于两数之和 |
| ⑩ | $\max\{X,Y\} - \min\{X,Y\} = |X - Y|$ | 最值之差等于两数差的绝对值 |

### 2.5 几何意义速记

```
    Y
    ↑
    │     max区      │
    │   ╱    ╲      │
    │  ╱  ↗   ╲     │
────┼─╱────┼────╲────→ X
    │╱  ↘  │  min区│
    │       │       │
```


## 3. 典型例题

### 例 1.6（张宇概率论）

**题目** 设 $X, Y$ 为连续型随机变量，且
$$P\{X \geq 0, Y \geq 0\} = \frac{3}{4}, \quad P\{X \geq 0\} = P\{Y \geq 0\} = \frac{4}{5}$$

求下列事件的概率：
- (1) $A = \{\max\{X,Y\} \geq 0\}$
- (2) $B = \{\max\{X,Y\} \geq 0, \min\{X,Y\} < 0\}$


### 【解】

#### 第(1)问

**步骤1：事件转化**

由公式②：
$$A = \{\max\{X,Y\} \geq 0\} = \{X \geq 0\} \cup \{Y \geq 0\}$$

**步骤2：应用加法公式**

$$P(A) = P\{X \geq 0\} + P\{Y \geq 0\} - P\{X \geq 0, Y \geq 0\}$$

**步骤3：代入数值**

$$P(A) = \frac{4}{5} + \frac{4}{5} - \frac{3}{4} = \frac{16}{20} + \frac{16}{20} - \frac{15}{20} = \frac{17}{20}$$


#### 第(2)问

**步骤1：全集分解**

$$\Omega = \{\min\{X,Y\} < 0\} \cup \{\min\{X,Y\} \geq 0\}$$

则：
$$A = A \cap \Omega = A \cap \big(\{\min\{X,Y\} < 0\} \cup \{\min\{X,Y\} \geq 0\}\big)$$

**步骤2：分配律展开**

$$A = \underbrace{\big(A \cap \{\min\{X,Y\} < 0\}\big)}_{B} \cup \underbrace{\big(A \cap \{\min\{X,Y\} \geq 0\}\big)}_{\{X \geq 0, Y \geq 0\}}$$

**步骤3：分析第二项**

由包含关系：
$$\{\max\{X,Y\} \geq 0, \min\{X,Y\} \geq 0\} = \{X \geq 0, Y \geq 0\}$$

**步骤4：求概率**

$$P(B) = P(A) - P\{X \geq 0, Y \geq 0\} = \frac{17}{20} - \frac{3}{4} = \frac{17}{20} - \frac{15}{20} = \frac{2}{20} = \frac{1}{10}$$


### 【答案】

$$\boxed{P(A) = \frac{17}{20}, \quad P(B) = \frac{1}{10}}$$


## 4. 常见错误

### ❌ 错误1：混淆交并关系

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| $\{\max\{X,Y\} > a\} = \{X > a\} \cap \{Y > a\}$ | $\{\max\{X,Y\} > a\} = \{X > a\} \cup \{Y > a\}$ | "最大"意味着"至少有一个大"，取**并集** |
| $\{\min\{X,Y\} \leq a\} = \{X \leq a\} \cap \{Y \leq a\}$ | $\{\min\{X,Y\} \leq a\} = \{X \leq a\} \cup \{Y \leq a\}$ | "最小"意味着"至少有一个小"，取**并集** |

### ❌ 错误2：忘记容斥原理

**错误做法**：
$$P(A \cup B) = P(A) + P(B) \quad \text{（错误！）}$$

**正确做法**：
$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

### ❌ 错误3：逆向转化错误

**错误**：$\{\max\{X,Y\} \leq a\}$ 的补集是 $\{\max\{X,Y\} < a\}$

**正确**：$\{\max\{X,Y\} \leq a\}$ 的补集是 $\{\max\{X,Y\} > a\}$（注意是严格大于）

### ❌ 错误4：包含关系判断错误

**易混淆点**：

```
✓ {max ≤ a} ⊆ {min ≤ a}     // 最大值小，小值必小
✗ {max > a} ⊆ {min > a}     // 反过来不成立！
```

### ❌ 错误5：正负号遗漏

公式⑩中容易忘记绝对值：
$$\max\{X,Y\} - \min\{X,Y\} = |X - Y| \quad \neq X - Y$$


## 5. 关联知识点

### 📚 前置知识

| 知识点 | 内容概要 |
|-------|---------|
| **随机事件与集合** | 事件的交、并、补运算，$\cap, \cup, \overline{A}$ |
| **概率加法公式** | $P(A \cup B) = P(A) + P(B) - P(AB)$ |
| **全集分解** | $A = A\Omega = A(B \cup \bar{B}) = AB \cup A\bar{B}$ |

### 📚 并行知识

| 知识点 | 与本节关系 |
|-------|-----------|
| **条件概率** | $P(A\|B) = \dfrac{P(AB)}{P(B)}$，用于求交事件概率 |
| **独立性** | $P(AB) = P(A)P(B)$ 时，交事件概率可简化 |
| **分布函数** | $F(a) = P\{X \leq a\}$，与 $\max$ 事件联系紧密 |

### 📚 延伸知识

| 知识点 | 进阶应用 |
|-------|---------|
| **顺序统计量** | $X_{(1)} = \min\{X_1, \cdots, X_n\}$，$X_{(n)} = \max\{X_1, \cdots, X_n\}$ |
| **二维均匀分布** | 利用几何概型计算 $\{\max > a\}$ 类型概率 |
| **协方差公式** | $\max + \min = X+Y$，$\max - \min = |X-Y|$ |
