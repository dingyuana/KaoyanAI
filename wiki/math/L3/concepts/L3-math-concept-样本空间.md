# 样本空间

## 概念定义

**样本空间**是随机试验中所有可能基本结果组成的集合，用大写希腊字母 $\Omega$ 表示。样本空间中的每个元素称为**样本点**，用小写字母 $\omega$ 表示。

> 样本空间是概率论的逻辑起点，任何概率问题都必须首先明确其样本空间。


## 核心公式

### 基本定义

$$\Omega = \{\omega_1, \omega_2, \omega_3, \ldots\}$$

### 常用符号

| 符号 | 含义 |
| $\Omega$ | 样本空间 |
| $\omega$ | 样本点 |
| $A$ | 随机事件（样本空间的子集） |
| $\emptyset$ | 不可能事件（空集） |

### 样本空间的类型

1. **离散样本空间**：有限个或可数无限个样本点
   $$\Omega = \{\omega_1, \omega_2, \ldots, \omega_n\}$$

2. **连续样本空间**：不可数无限个样本点
   $$\Omega = \{x \mid 0 \leq x \leq 1\}$$


## 典型例题

### 例题一：离散样本空间

**题目**：抛掷一枚均匀硬币两次，观察正反面出现情况。写出该试验的样本空间。

**解答**：

记"正面向上"为 $H$，"反面向上"为 $T$。

$$\Omega = \{HH, HT, TH, TT\}$$

其中 $HH$ 表示第一次正面、第二次正面，其余同理。

**考点分析**：
- 基本概念：样本空间的定义
- 涉及排列组合原理
- 样本点总数：$2^2 = 4$ 个


### 例题二：连续样本空间

**题目**：在区间 $[0, 1]$ 上随机取一点，用 $X$ 表示该点的坐标。写出该试验的样本空间。

**解答**：

$$\Omega = \{x \mid 0 \leq x \leq 1\} = [0, 1]$$

这是一个连续样本空间，包含无穷多个不可数的样本点。

**考点分析**：
- 连续型样本空间的识别
- 区间表示法
- 与离散样本空间的区别


### 例题三：复合试验样本空间

**题目**：袋中有 3 个白球和 2 个黑球，从中不放回地依次取出 2 个球。求样本空间。

**解答**：

设白球为 $W_1, W_2, W_3$，黑球为 $B_1, B_2$。

第一次可能摸到 $W_1, W_2, W_3, B_1, B_2$；
第二次在第一次的基础上，从剩余 4 个球中任取 1 个。

样本空间包含 $5 \times 4 = 20$ 个有序样本点：
$$\Omega = \{(W_1, W_2), (W_1, W_3), (W_1, B_1), \ldots\}$$

**考点分析**：
- 不放回抽样
- 有序样本点的计数：$A_5^2 = 5 \times 4 = 20$
- 与有序/无序的区分


## 常见错误

### ❌ 错误一：遗漏样本点

**错误表述**：
抛掷一枚骰子，样本空间写成 $\Omega = \{1, 2, 3, 4, 5, 6\}$ ❌

**正确理解**：
样本点是"基本结果"，骰子的每个面都是一个样本点。上述写法实际上是正确的，但学生常在复杂问题中遗漏某些结果。


### ❌ 错误二：混淆"有序"与"无序"

**错误表述**：
从 3 本书中选 2 本，样本点写成 $(A, B), (B, A)$ 等有序对

**正确理解**：
- 若强调**顺序**（依次抽取）：$\Omega = \{(A,B), (B,A), (A,C), (C,A), (B,C), (C,B)\}$
- 若不强调**顺序**（一次抽取）：$\Omega = \{AB, AC, BC\}$


### ❌ 错误三：连续样本空间写成离散形式

**错误表述**：
设 $X \in [0,1]$，样本空间写成 $\Omega = \{0, 0.1, 0.2, \ldots, 1\}$

**正确理解**：
$[0,1]$ 是连续区间，包含无穷多个不可数的点，不能用列举法表示。

## 延伸思考

### 样本空间的"完备性"

一个正确的样本空间必须满足**互不相容**且**完全穷尽**：
- 任意两个样本点不能同时发生
- 所有样本点涵盖了一切可能结果

### 样本空间的"相对性"

同一个物理试验，从不同角度观察可以定义不同的样本空间：

| 试验 | 关注点 | 样本空间 |
| 抛硬币 | 正反面 | $\{H, T\}$ |
| 抛硬币 | 正反面次数 | $\{0, 1, 2\}$ |
| 抛硬币 | 落地姿态 | 更复杂的空间 |
