# 拉格朗日中值定理的增量形式

- **章节**：2026 张宇高数 18讲(OCR)
- **难度**：★★☆☆☆


## 1. 概念定义

**拉格朗日中值定理的增量形式**是拉格朗日中值定理的另一种等价表述，用于描述函数增量与导数之间的关系。

> 若函数 $f(x)$ 满足：
> 1. 在闭区间 $[a,b]$ 上连续
> 2. 在开区间 $(a,b)$ 内可导
>
> 则存在 $\xi \in (a,b)$，使得：
> $$f(b) - f(a) = f'(\xi)(b-a)$$

**增量形式（更精确）**：存在 $\theta \in (0,1)$，使得
$$f(b) - f(a) = f'[a + \theta(b-a)](b-a)$$


## 2. 核心公式

### 标准形式
$$f(b) - f(a) = f'(\xi)(b-a), \quad \xi \in (a,b)$$

### 增量形式（θ形式）
$$f(b) - f(a) = f'[a + \theta(b-a)](b-a), \quad 0 < \theta < 1$$

### 常见特殊情形
$$f(x) - f(0) = f'(\theta x) \cdot x, \quad 0 < \theta < 1$$


## 3. 典型例题

### 例 6.13

**题目**：已知 $\displaystyle \int_0^1 f(t)\,dt = x f(x)$，$x > 0$，且 $f(x) = e^x$，求 $\displaystyle\lim_{x \to 0} \theta = $？

**解**：

由积分条件得：
$$e^x - 1 = x e^{\theta x}$$

由拉格朗日中值定理的增量形式，对于 $g(t) = e^t$，存在 $\theta \in (0,1)$ 使：
$$e^x - e^0 = e^{\theta x} \cdot x$$

即 $e^x - 1 = x e^{\theta x}$

两边同除以 $x^2$：
$$\frac{e^x - 1 - x}{x^2} = \frac{e^{\theta x} - 1}{x}$$

对左边应用洛必达法则（$x \to 0$ 时为 $\frac{0}{0}$ 型）：
$$\lim_{x \to 0} \frac{e^x - 1 - x}{x^2} = \lim_{x \to 0} \frac{e^x - 1}{2x} = \frac{1}{2}$$

右边：$\displaystyle \lim_{x \to 0} \frac{e^{\theta x} - 1}{x} = \lim_{x \to 0} \theta \cdot \frac{e^{\theta x} - 1}{\theta x} = \theta$

由等式两边极限相等：
$$\theta = \frac{1}{2}$$

**答案**：$\boxed{\dfrac{1}{2}}$


## 4. 常见错误

| 错误类型 | 错误示例 | 正确理解 |
|---------|---------|---------|
| 区间端点错误 | 写成 $\xi \in [a,b]$ | 拉格朗日定理要求 $\xi \in (a,b)$（开区间） |
| 忽略连续性条件 | 跳跃间断点处使用定理 | 必须满足区间连续、开区间可导 |
| θ的范围混淆 | 认为 $\theta \in (0,2)$ | 标准形式要求 $0 < \theta < 1$ |
| 导数符号遗漏 | 写成 $f(b) - f(a) = f(\xi)(b-a)$ | 右边必须是 **导数** $f'(\xi)$ |
| 泰勒展开混淆 | 与泰勒公式余项混淆 | 中值定理是"精确等式"，不是近似 |


## 5. 关联知识点

```
拉格朗日中值定理（增量形式）
         │
         ├──▶ 柯西中值定理（参数化推广）
         │
         ├──▶ 泰勒公式（增量形式的高阶推广）
         │         │
         │         └──▶ 拉格朗日余项
         │
         ├──▶ 导数的应用
         │         │
         │         ├──▶ 单调性判别
         │         └──▶ 极值判定（费马定理）
         │
         └──▶ 微分中值定理族
                  │
                  ├──▶ 罗尔中值定理（特殊情形）
                  └──▶ 积分中值定理
```

**核心联系**：
- **柯西中值定理**：$\dfrac{f(b)-f(a)}{g(b)-g(a)} = \dfrac{f'(\xi)}{g'(\xi)}$，令 $g(x) = x$ 即得拉格朗日中值定理
- **泰勒公式**：$f(x) = f(x_0) + f'(x_0)(x-x_0) + \dfrac{f''(\xi)}{2!}(x-x_0)^2$，可视为增量形式的"高阶版本"
- **费马定理**：在极值点处 $f'(\xi) = 0$，是拉格朗日定理的重要应用


> **使用场景**：当题目中出现"曲线在一点的切线斜率"或需要"求中值点的极限位置"时，优先考虑使用增量形式。
