# 简单化处理技巧

## 元数据

- **章节**：2026 张宇高数 18讲(OCR) - 第6讲 一元函数微分学的应用(二)——中值定理、微分等式与微分不等式
- **难度**：★★☆☆☆


## 1. 概念定义

**简单化处理技巧**是中值定理证明题中常用的"障眼法"技巧，核心思想是**将复杂的待证式子化简为熟悉的标准形式**，从而快速找到辅助函数的构造思路。

### 四种基本手段

| 类型 | 核心思想 | 适用场景 |
|------|----------|----------|
| **简单化** | 复杂式子直接化简为基本形式 | 简单代数运算 |
| **升辈降辈** | 升降导数阶数 | 涉及高阶导数 |
| **平移** | 变量替换 | 含特定结构的函数 |
| **恒等变形** | 移项/乘除运算 | 等式证明 |


## 2. 核心公式

### 2.1 简单化原则

$$x^2 - x = x(x-1)$$

$$f(b) - f(a) \Rightarrow \int_a^b f'(x)\,dx$$

$$\ln f(x) \Rightarrow [\ln f(x)]' = \frac{f'(x)}{f(x)}$$

$$\sqrt{x} \Rightarrow (\sqrt{x})' = \frac{1}{2\sqrt{x}}$$

### 2.2 升辈降辈

**降辈（求导化简）**：

$$f(x) \Rightarrow f'(x) \cdot e^x \Rightarrow e^x\left[f'(x) + f(x)\right]$$

**升辈（积分化简）**：

$$f(x) \Rightarrow \int_a^x f(t)\,dt \quad \text{或} \quad f(b) - f(x) = \int_x^b f'(t)\,dt$$

### 2.3 平移变换

令 $u = x + 1$，则：

$$f(x) - (x+1)^2 \Rightarrow f'(x)(x+1)^2 + f(x) - 2(x+1)$$

$$f(x) - e^x \Rightarrow f'(x)e^x + f(x) - e^x = e^x\left[f'(x) + f(x) - 1\right]$$

### 2.4 恒等变形

**移项法**（使右端为0）：

欲证 $f''(\xi) - 1 = 0$，即 $f''(\xi) = 1$

欲证 $f'(\xi)\cdot\xi - 2f(\xi) = 0$，即 $\xi f'(\xi) = 2f(\xi)$

**乘除逆运算**（化归 $[\square]' = 0$）：

$$g(\xi)f'(\xi) - f(\xi)g'(\xi) = 0 \Longrightarrow \left[\frac{f(x)}{g(x)}\right]' = 0$$


## 3. 典型例题

### 例题：双中值定理证明

**题目**：已知函数 $f(x)$ 和 $g(x)$ 在 $[a,b]$ 上连续，在 $(a,b)$ 内可导，且 $g'(x) \neq 0$，证明：存在 $\xi \in (a,b)$，使得

$$\frac{f(b)-f(a)}{g(b)-g(a)} = \frac{f'(\xi)}{g'(\xi)}$$

**解题分析**（P?(双向思路)）：

**Step 1：化简待证式**

$$\frac{f(b)-f(a)}{g(b)-g(a)} - \frac{f'(\xi)}{g'(\xi)} = 0$$

交叉相乘：

$$[f(b)-f(a)]g'(\xi) - [g(b)-g(a)]f'(\xi) = 0$$

**Step 2：逆向构造（简单化处理）**

观察结构联想到**柯西中值定理**，关键是将微分式写为差分形式：

$$[g(b)-g(x)]f(x) - [f(b)-f(x)]g(x) = C$$

**Step 3：构造辅助函数**

令

$$F(x) = [f(x)-f(a)][g(b)-g(x)]$$

**Step 4：验证 Rolle 定理条件**

- $F(x)$ 在 $[a,b]$ 上连续
- $F(x)$ 在 $(a,b)$ 内可导
- $F(a) = 0$，$F(b) = 0$

由 Rolle 定理，存在 $\xi \in (a,b)$，使得 $F'(\xi) = 0$

**Step 5：计算导数**

$$F'(x) = f'(x)[g(b)-g(x)] - [f(x)-f(a)]g'(x)$$

令 $x = \xi$：

$$f'(\xi)[g(b)-g(\xi)] - [f(\xi)-f(a)]g'(\xi) = 0$$

整理得：

$$\frac{f(b)-f(a)}{g(b)-g(a)} = \frac{f'(\xi)}{g'(\xi)}$$

$\blacksquare$


## 4. 常见错误

### ❌ 错误一：辅助函数构造错误

> **错误**：直接令 $F(x) = \frac{f(x)}{g(x)}$，无法利用已知条件。

> **正确**：根据化简后的结构 $F(x) = [f(x)-f(a)][g(b)-g(x)]$ 构造。

### ❌ 错误二：忽略连续性条件

> **错误**：不验证 $F(a) = F(b) = 0$ 就直接使用 Rolle 定理。

> **正确**：必须显式计算并验证端点条件。

### ❌ 错误三：恒等变形方向错误

> **错误**：将 $f'(\xi)g(\xi) - f(\xi)g'(\xi) = 0$ 直接写成 $\left[\frac{f(x)}{g(x)}\right]'$ 的形式，忘记链式法则。

> **正确**：注意 $[\frac{f}{g}]' = \frac{f'g - fg'}{g^2}$，需额外处理 $g^2$ 项。

### ❌ 错误四：平移变换计算失误

> **错误**：在平移变换中漏项，如 $[f(x)-e^x]' = f'(x)e^x + f(x) - e^x$ 写成 $f'(x)e^x - e^x$。

> **正确**：使用莱布尼茨公式仔细计算每一项。

## 6. 方法论总结

```
简单化处理技巧解题流程

┌─────────────────────────────────────┐
│  1. 观察待证等式/不等式              │
├─────────────────────────────────────┤
│  2. 逆向化简（移项/乘除）            │
│     使右端为 0，化为 □' = 0 形式     │
├─────────────────────────────────────┤
│  3. 选择策略                        │
│     ├─ 简单式 → 直接化简            │
│     ├─ 高阶导 → 升辈/降辈           │
│     ├─ 特定结构 → 平移变换          │
│     └─ 复杂等式 → 恒等变形          │
├─────────────────────────────────────┤
│  4. 构造辅助函数 F(x)                │
├─────────────────────────────────────┤
│  5. 验证定理条件（连续/可导/端点）   │
├─────────────────────────────────────┤
│  6. 应用中值定理得证                 │
└─────────────────────────────────────┘
```
