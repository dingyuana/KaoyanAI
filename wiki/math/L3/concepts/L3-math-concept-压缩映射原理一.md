## 1. 概念定义

### 压缩映射原理（原理一）

**定义**：对于数列 $\{x_n\}$，若存在常数 $k$ 满足 $0 < k < 1$，使得

$$|x_{n+1} - a| \leq k|x_n - a|, \quad n = 1, 2, \ldots$$

则数列 $\{x_n\}$ 收敛于 $a$。

> **核心思想**：每一项与极限的差距都被一个严格小于1的常数 $k$ 所"压缩"。

### 压缩映射原理（原理二）

**定义**：对于数列 $\{x_n\}$，若满足递推关系 $x_{n+1} = f(x_n)$，其中：
- $f(x)$ 可导
- $a$ 是 $f(x) = x$ 的唯一解
- 对任意 $x \in \mathbb{R}$，有 $|f'(x)| \leq k < 1$

则 $\{x_n\}$ 收敛于 $a$。


## 2. 核心公式

### 原理一的证明核心

$$\boxed{|x_n - a| \leq k^n |x_1 - a|}$$

由递推不等式 $|x_{n+1} - a| \leq k|x_n - a|$ 可得：

$$|x_n - a| \leq k^n |x_1 - a|$$

由于 $0 < k < 1$，故 $\lim\limits_{n \to \infty} k^n = 0$。

### 原理二的核心不等式

由拉格朗日中值定理：

$$\boxed{|x_{n+1} - a| = |f(x_n) - f(a)| = |f'(\xi)||x_n - a| \leq k|x_n - a|}$$

其中 $\xi$ 介于 $x_n$ 与 $a$ 之间。


## 3. 典型例题

### 例题：递推数列的收敛性证明

> **题目**：设 $x_1 = 1$，$x_{n+1} = \sqrt{4 + 3x_n}$（$n = 1, 2, \ldots$），证明数列 $\{x_n\}$ 收敛，并求 $\lim\limits_{n \to \infty} x_n$。

**解答**：

**第一步**：化归经典形式

令 $f(x) = \sqrt{4 + 3x}$（$x > 0$），则 $f(x_{n}) = x_{n+1}$。

**第二步**：求不动点

解方程 $x = \sqrt{4 + 3x}$，得 $x^2 - 3x - 4 = 0$，解得 $x = 4$（舍去负根）。

**第三步**：验证压缩条件

$$f'(x) = \frac{3}{2\sqrt{4 + 3x}}$$

在 $x = 4$ 处：

$$|f'(4)| = \frac{3}{2\sqrt{16}} = \frac{3}{8} < 1$$

由于 $f'(x)$ 连续，对于任意 $\varepsilon > 0$，存在邻域使 $|f'(x)| \leq \frac{1}{2} < 1$。

**第四步**：夹逼估计

由拉格朗日中值定理：

$$|x_{n+1} - 4| = |f(x_n) - f(4)| = |f'(\xi)||x_n - 4|$$

其中 $\xi$ 介于 $x_n$ 与 $4$ 之间。从而：

$$|x_n - 4| \leq \left(\frac{1}{2}\right)^n |x_1 - 4| = \frac{3}{2^n}$$

**第五步**：取极限

由于 $\lim\limits_{n \to \infty} \frac{3}{2^n} = 0$，故：

$$\lim_{n \to \infty} |x_n - 4| = 0 \implies \lim_{n \to \infty} x_n = 4$$


## 4. 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|----------|----------|----------|
| 忽略唯一性 | 直接使用 $|f'(x)| \leq k$ 而不验证 $a$ 是唯一不动点 | 必须先证明 $f(x) = x$ 的解唯一 |
| $k$ 的范围错误 | 取 $k = 1$ | 必须满足 $0 < k < 1$ |
| 导数界估计不当 | 对整个实数域直接估计 $|f'(x)| \leq k$ | 注意导数的取值范围，必要时分段讨论 |
| 遗漏证明过程 | 直接写"由压缩映射原理可得" | 必须写出完整的证明过程 |
| 不验证收敛性前提 | 直接假设 $x_n$ 有界 | 先验证有界性，再使用原理 |
