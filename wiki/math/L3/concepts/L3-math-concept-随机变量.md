# 随机变量

## 概念定义

随机变量（Random Variable）是从随机试验的样本空间到实数的映射，即定义在样本空间上的实值函数，用 $X, Y, Z$ 等大写字母表示。它将随机试验的每一种可能结果赋予一个数值，从而可以用微积分等数学工具研究随机现象。


## 核心公式

### 1. 分布函数的定义

$$F(x) = P(X \leq x), \quad -\infty < x < +\infty$$

**性质：**
- $0 \leq F(x) \leq 1$
- 单调非递减：若 $x_1 < x_2$，则 $F(x_1) \leq F(x_2)$
- 右连续：$F(x+0) = F(x)$
- $\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$

### 2. 离散型随机变量

**概率分布律：**

$$P(X = x_k) = p_k, \quad k = 1, 2, 3, \cdots$$

满足 $p_k \geq 0$，$\sum_k p_k = 1$

**分布函数：**

$$F(x) = \sum_{x_k \leq x} p_k$$

### 3. 连续型随机变量

**概率密度函数 $f(x)$：**

$$F(x) = \int_{-\infty}^{x} f(t)\,dt$$

**性质：**

$$f(x) \geq 0, \quad \int_{-\infty}^{+\infty} f(x)\,dx = 1$$

$$P(a < X \leq b) = \int_a^b f(x)\,dx = F(b) - F(a)$$


## 典型例题

### 例题一：离散型随机变量的分布函数

**题目：** 设随机变量 $X$ 的分布律为：

| $X$ | $-1$ | $0$ | $1$ | $2$ |
| $P$ | $0.2$ | $0.3$ | $0.4$ | $0.1$ |

求 $X$ 的分布函数 $F(x)$。

**解答：**

根据分布函数的定义，分段讨论：

$$F(x) = P(X \leq x) = \begin{cases} 0, & x < -1 \\ 0.2, & -1 \leq x < 0 \\ 0.2 + 0.3 = 0.5, & 0 \leq x < 1 \\ 0.5 + 0.4 = 0.9, & 1 \leq x < 2 \\ 0.9 + 0.1 = 1, & x \geq 2 \end{cases}$$

**考点分析：** 离散型随机变量分布函数的计算，理解分布函数是概率的累加。


### 例题二：连续型随机变量的概率计算

**题目：** 设随机变量 $X$ 的概率密度为：

$$f(x) = \begin{cases} kx, & 0 \leq x < 2 \\ 0, & \text{其他} \end{cases}$$

求：（1）常数 $k$；（2）$P(0.5 < X < 1.5)$；（3）分布函数 $F(x)$。

**解答：**

（1）由 $\int_{-\infty}^{+\infty} f(x)\,dx = 1$：

$$\int_0^2 kx\,dx = k \cdot \frac{x^2}{2}\Big|_0^2 = 2k = 1 \Rightarrow k = \frac{1}{2}$$

（2）

$$P(0.5 < X < 1.5) = \int_{0.5}^{1.5} \frac{1}{2}x\,dx = \frac{1}{2} \cdot \frac{x^2}{2}\Big|_{0.5}^{1.5} = \frac{1}{4}(1.5^2 - 0.5^2) = \frac{1}{4}(2.25 - 0.25) = 0.5$$

（3）分布函数：

$$F(x) = \begin{cases} 0, & x < 0 \\ \int_0^x \frac{1}{2}t\,dt = \frac{x^2}{4}, & 0 \leq x < 2 \\ 1, & x \geq 2 \end{cases}$$

**考点分析：** 连续型随机变量的概率密度函数性质，利用积分求概率。


## 常见错误

### ❌ 错误一：混淆离散与连续型随机变量

| 离散型 | 连续型 |
| 用分布律 $P(X = x_k)$ | 用概率密度 $f(x)$ |
| $P(X = a) > 0$ 可能成立 | $P(X = a) = 0$（任意单点概率为0） |
| 用求和 $\sum$ | 用积分 $\int$ |

### ❌ 错误二：分布函数右连续性

**常见错误：** 写成左连续的分布函数

**正确理解：** 分布函数 $F(x)$ 是右连续的，即 $F(x) = F(x+0)$。对于离散型随机变量，在离散点处取值为"小于等于"的累加。

### ❌ 错误三：概率密度函数的理解

**常见错误：** 将 $f(x)$ 误认为概率

**正确理解：** $f(x)$ 不是概率，$f(x)dx$ 才是概率微元。必须满足 $f(x) \geq 0$ 且 $\int_{-\infty}^{+\infty} f(x)\,dx = 1$。

### ❌ 错误四：分段点处概率计算

**常见错误：** 计算 $P(a < X < b)$ 时忽略区间端点

**正确理解：** 对于连续型，$P(a < X < b) = P(a < X \leq b) = P(a \leq X < b)$，端点不影响结果。
