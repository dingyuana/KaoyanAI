# 驻点的定义与求法


**元数据**
- **章节**：2026 张宇高数 18讲(OCR)
- **难度**：★★☆☆☆
- **分类**：一元函数微分学应用


## 一、概念定义

### 驻点的定义

设函数 $f(x)$ 在点 $x_0$ 的某邻域内有定义，若 $f'(x_0) = 0$，则称点 $x_0$ 为函数 $f(x)$ 的**驻点**（临界点）。

> **注意**：驻点只是**候选极值点**，不一定是极值点。例如 $f(x) = x^3$ 在 $x = 0$ 处 $f'(0) = 0$，但 $x = 0$ 不是极值点。

### 驻点与极值点的关系

```
┌─────────────────────────────────────────────┐
│  极值点 ⟹ 不一定是驻点（如不可导点）         │
│  驻点   ⟹ 不一定是极值点（可能是拐点等）      │
│  可导极值点 ⟹ 一定是驻点                      │
└─────────────────────────────────────────────┘
```


## 二、核心公式

### 1. 驻点的定义条件

$$
f'(x_0) = 0
$$

### 2. 第一充分条件（判断极值）

设 $f(x)$ 在 $x_0$ 处连续，在 $x_0$ 的去心邻域内可导：

| 条件 | 结论 |
| $f'(x) > 0$（左侧），$f'(x) < 0$（右侧） | $x_0$ 为**极大值点** |
| $f'(x) < 0$（左侧），$f'(x) > 0$（右侧） | $x_0$ 为**极小值点** |
| $f'(x)$ 同号 | $x_0$ **不是极值点** |

### 3. 第二充分条件

设 $f'(x_0) = 0$，$f''(x_0)$ 存在：

| 条件 | 结论 |
| $f''(x_0) < 0$ | $x_0$ 为**极大值点** |
| $f''(x_0) > 0$ | $x_0$ 为**极小值点** |
| $f''(x_0) = 0$ | 方法失效，需用其他方法 |

### 4. 求最值的步骤

设 $f(x)$ 在闭区间 $[a, b]$ 上连续：

1. **求导**：$f'(x) = 0$ → 求出所有驻点
2. **不可导点**：找出导数不存在的点
3. **端点**：计算 $f(a)$、$f(b)$
4. **比较**：比较所有驻点、不可导点、端点的函数值

$$
\text{最大值} = \max\{f(a), f(x_0), f(b)\}
$$
$$
\text{最小值} = \min\{f(a), f(x_0), f(b)\}
$$


## 三、典型例题

### 例5.9（张宇高数18讲）

设 $f'(x)$ 在区间 $[0, 4]$ 上连续，曲线 $y = f'(x)$ 与直线 $x = 0$，$x = 4$，$y = 0$ 围成如图所示的三个区域，其面积分别为 $S_1 = 3$，$S_2 = 4$，$S_3 = 2$，且 $f(0) = 1$，则 $f(x)$ 在 $[0, 4]$ 上的最大值与最小值分别为（　）。

$$
\text{选项：} \quad \text{(A) } 2, -3 \quad \text{(B) } 4, -3 \quad \text{(C) } 2, -2 \quad \text{(D) } 4, -2
$$

**图示**（由题意可得 $f'(x)$ 的正负）：

```
y
↑
3│    ┌───┐
 │    │ S₁│
2│    └───┘
 │ ┌───────┐
1│ │   S₂  │
 │ └───────┘
0├─┴────┬───┴────→ x
 0      1    3    4
```

**解题步骤**：

**第一步**：由图可知 $f'(1) = f'(3) = 0$，即 $x = 1$ 和 $x = 3$ 为驻点。

**第二步**：利用定积分求函数值：
$$
f(1) = f(0) + \int_0^1 f'(x)\,dx = 1 - S_1 = 1 - 3 = -2
$$
$$
f(3) = f(1) + \int_1^3 f'(x)\,dx = -2 + S_2 = -2 + 4 = 2
$$
$$
f(4) = f(3) + \int_3^4 f'(x)\,dx = 2 - S_3 = 2 - 2 = 0
$$

**第三步**：比较端点与驻点处的函数值：
$$
f(0) = 1,\quad f(1) = -2,\quad f(3) = 2,\quad f(4) = 0
$$

**结论**：最大值为 $2$，最小值为 $-2$。

> **答案**：$\boxed{\text{(C) } 2, -2}$


## 四、常见错误

### ❌ 错误1：误认为驻点必为极值点

> **错误**：认为 $f'(x_0) = 0$ 则 $x_0$ 必为极值点。

**正确理解**：驻点只是**候选点**，需用充分条件进一步判断。例如 $y = x^3$ 在 $x = 0$ 处为驻点但非极值。

### ❌ 错误2：忽略不可导点

> **错误**：只考虑 $f'(x) = 0$ 的点，忽略导数不存在的点。

**正确理解**：不可导点也可能成为极值点，例如 $y = |x|$ 在 $x = 0$ 处。

### ❌ 错误3：闭区间最值忽略端点

> **错误**：最值一定在驻点处取得。

**正确理解**：闭区间上的连续函数，最值可能在**端点**处取得。

### ❌ 错误4：符号判断错误

> **错误**：对 $\int_0^1 f'(x)dx$ 的符号判断错误。

**正确理解**：由图可知 $f'(x) < 0$（在 $0$ 到 $1$ 之间），故 $\int_0^1 f'(x)dx = -S_1$。


## 五、关联知识点

| 知识点 | 说明 |
| **极值与极值点** | 驻点是极值的必要条件（可导时） |
| **最值定理** | 闭区间连续函数必取得最大最小值 |
| **单调性与导数** | $f'(x) > 0 \Rightarrow f(x)$ 单调递增 |
| **凹凸性与二阶导** | $f''(x) > 0 \Rightarrow$ 下凸 |
| **拐点** | $f''(x) = 0$ 或不存在的点 |
| **泰勒公式** | 在驻点处展开研究函数性态 |


## 六、思维导图

```
一元函数微分学应用
    │
    ├── 极值问题
    │       ├── 极值点
    │       │       ├── 驻点 (f'(x)=0)
    │       │       └── 不可导点
    │       │
    │       └── 判定方法
    │               ├── 第一充分条件
    │               ├── 第二充分条件
    │               └── 第三充分条件
    │
    └── 最值问题
            ├── 开区间 → 极值点
            └── 闭区间 → 极值点 + 端点
```


> **记忆口诀**：
> 驻点求导令为零，极值判断看符号；
> 最值不忘比较端，不可导点也候选。
