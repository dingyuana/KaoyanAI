## 1. 概念定义

### 1.1 导数的两种表述

**点导数 $f'(x_0)$**：指函数在 $x_0$ 点处的导数，表示该点的瞬时变化率，需要用**定义**或**极限**计算。

**导函数 $f'(x)$**：指用求导法则求出的导数表达式，是关于 $x$ 的函数。

> **关键区别**：$f'(x)$ 在 $x_0$ 处无定义，并不意味着 $f'(x_0)$ 不存在！

### 1.2 绝对值函数可导性

对于形如 $|x - x_0|g(x)$ 的函数在 $x_0$ 处的可导性，核心在于判断 $g(x_0)$ 是否为零。


## 2. 核心公式

### 2.1 绝对值函数求导公式

设 $g(x)$ 在 $x_0$ 处可导，则：

$$\frac{d}{dx}|x - x_0|g(x)\bigg|_{x=x_0} = \begin{cases} \text{可导} & \text{若 } g(x_0) = 0 \\ \text{不可导} & \text{若 } g(x_0) \neq 0 \end{cases}$$

**几何理解**：绝对值函数在零点处产生"尖点"，只有当另一个函数在该点也为零时，尖点才能被"磨平"。

### 2.2 乘积可导性判定

设 $F(x) = f(x)g(x)$，$f(x)$ 在 $x_0$ 处连续但不可导，$g(x)$ 在 $x_0$ 处可导：

$$F(x) \text{ 在 } x_0 \text{ 处可导} \iff g(x_0) = 0$$

### 2.3 一阶泰勒公式（微分）

当 $f'(x_0)$ 存在时：

$$\boxed{f(x) - f(x_0) = f'(x_0)\Delta x + o(\Delta x) \quad (\Delta x \to 0)}$$

或微分形式：

$$\boxed{df(x) = f'(x_0)dx = f'(x_0)\Delta x}$$

### 2.4 无穷小记号

若 $\lim\limits_{x \to x_0} f(x) = 0$，则称 $f(x)$ 是 $x \to x_0$ 时的**无穷小量**，记作：

$$f(x) = o(1), \quad x \to x_0$$


## 3. 典型例题

### 例3.1（张宇高数18讲）

> 设 $f(x) = 2^x - x^2 + o(x-1)$，$x \to 1$，且 $f'(1) = a$，则 $a = \underline{\hspace{1cm}}$。

**解析**

由一阶泰勒公式：

$$f(x) - f(1) = f'(1)(x-1) + o(x-1)$$

与已知条件 $f(x) = 2 - x^2 + o(x-1)$ 对比：

- 令 $x = 1$ 得 $f(1) = 2 - 1 = 1$
- 故 $f(x) = 1 + f'(1)(x-1) + o(x-1) = 2 - x^2 + o(x-1)$

取 $x \to 1$，对比一次项系数：

$$f'(1) = -2x\bigg|_{x=1} = -2$$

**答案**：$\boxed{a = -2}$


## 4. 常见错误

| 错误类型 | 说明 | 正确做法 |
|----------|------|----------|
| 混淆 $f'(x_0)$ 与 $f'(x)$ | 误认为 $f'(x)$ 无定义则 $f'(x_0)$ 不存在 | 用导数定义重新计算 |
| 忽略绝对值零点 | 未判断 $g(x_0) = 0$ 是否成立 | 单独验证 $g(x_0)$ 的值 |
| 泰勒展开阶数错误 | 忘记 $o(\Delta x)$ 的存在 | 明确一阶展开包含高阶无穷小 |
| 极限计算跳步 | 直接代入数值而忽略极限过程 | 严格使用极限四则运算法则 |


## 5. 关联知识点

| 知识点 | 关联说明 |
|--------|----------|
| **分段函数的可导性** | 分段点处需用导数定义判断 |
| **导数定义** | $\displaystyle f'(x_0) = \lim_{\Delta x \to 0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$ |
| **高阶无穷小** | $o(x^n)$ 的运算规则 |
| **洛必达法则** | $\frac{0}{0}$ 型极限的求解 |
| **函数连续性** | 可导的必要条件：函数必须连续 |
