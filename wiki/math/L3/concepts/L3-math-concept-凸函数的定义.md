# 凸函数的定义

> **章节**：2026 张宇高数 18讲 - 第5讲 一元函数微分学的应用(一)——几何应用
> **难度**：★★☆☆☆


## 1. 概念定义

### 1.1 几何定义（割线法）

设 $f(x)$ 在区间 $I$ 上有定义，对任意 $x_1, x_2 \in I$：

| 名称 | 不等式条件 | 几何特征 |
| **凹的** | $f\!\left(\dfrac{x_1+x_2}{2}\right) < \dfrac{f(x_1)+f(x_2)}{2}$ | 弧段位于弦的**上方** |
| **凸的** | $f\!\left(\dfrac{x_1+x_2}{2}\right) > \dfrac{f(x_1)+f(x_2)}{2}$ | 弧段位于弦的**下方** |

> **记忆口诀**："凹上凸下"——凹函数图像向上凹，凸函数图像向下凸。

### 1.2 分析定义（切线法）

设 $f(x)$ 在 $[a,b]$ 上连续，在 $(a,b)$ 内可导，若对任意 $x, x_0 \in (a,b)$（$x \neq x_0$）：

$$f(x) > f(x_0) + f'(x_0)(x - x_0) \quad \text{则图形是凹的}$$

$$f(x) < f(x_0) + f'(x_0)(x - x_0) \quad \text{则图形是凸的}$$

### 1.3 拐点定义

> **拐点**：连续曲线的凹弧与凸弧的**分界点**称为该曲线的拐点。


## 2. 核心公式

### 2.1 凹函数判别（第二充分条件）

$$f''(x) > 0 \ \Longleftrightarrow \ f(x) \text{ 在 } (a,b) \text{ 内为凹}$$

$$f''(x) < 0 \ \Longleftrightarrow \ f(x) \text{ 在 } (a,b) \text{ 内为凸}$$

### 2.2 极值点与拐点的导数特征

| 概念 | 导数特征 | 充要条件 |
| **极值点** | $f'(x)$ 有零点 | $f'(x) \geq 0$ 或 $f'(x) \leq 0$（不变号） |
| **拐点** | $f''(x)$ 有零点 | $f''(x) \geq 0$ 或 $f''(x) \leq 0$（不变号） |

> **等价表述体系**：
> - 有极值点 $\Longleftrightarrow$ $f'(x)$ 有零点
> - 无极值点 $\Longleftrightarrow$ $f'(x)$ 不变号（$\geq 0$ 或 $\leq 0$）
> - 有拐点 $\Longleftrightarrow$ $f''(x)$ 有零点

### 2.3 曲率公式（仅数学一、二）

若 $f(x)$ 在点 $P(x_0, y_0)$ 处曲率圆方程为 $(x-a)^2 + (y-b)^2 = r^2$，则：

$$y'\Big|_{x=x_0} = f'(x_0), \qquad y''\Big|_{x=x_0} = f''(x_0)$$


## 3. 典型例题

### 例题：判断函数凹凸性并求拐点

> 判断 $f(x) = x^3 - 3x^2 + 2$ 的凹凸区间，并求其拐点。

**解：**

**第一步**：求一阶、二阶导数
$$f'(x) = 3x^2 - 6x = 3x(x-2)$$
$$f''(x) = 6x - 6 = 6(x-1)$$

**第二步**：令 $f''(x) = 0$，得 $x = 1$

**第三步**：列表分析

| 区间 | $(-\infty, 1)$ | $x = 1$ | $(1, +\infty)$ |
| $f''(x)$ | $<$ 0 | 0 | $>$ 0 |
| 凹凸性 | **凸** | 拐点 | **凹** |

**第四步**：计算拐点坐标
$$f(1) = 1 - 3 + 2 = 0$$

**结论**：
- 凹区间：$(1, +\infty)$
- 凸区间：$(-\infty, 1)$
- 拐点：$(1, 0)$


## 4. 常见错误

| 序号 | 错误类型 | 正确理解 |
| ❌ | 混淆"凹"与"凸"的中文含义 | "凹"对应 $f'' > 0$（上凹），"凸"对应 $f'' < 0$（下凸） |
| ❌ | 极值点处 $f'(x) = 0$ 但 $f''(x) \neq 0$ | 极值点只需 $f'(x) = 0$，二阶导数不影响 |
| ❌ | 认为拐点处 $f''(x) = 0$ | 拐点处 $f''(x)$ 可为零或不存在，关键是凹凸性改变 |
| ❌ | 忽略二阶导数不存在的点 | $f''(x)$ 不存在的点也可能是拐点，需单独讨论 |
| ❌ | 拐点写成"$(x_0, 0)$" | 拐点是**点**，需写完整坐标 $(x_0, f(x_0))$ |


## 5. 关联知识点

| 序号 | 关联知识点 | 关系说明 |
| 1 | **极值与最值** | 与极值点类似，拐点是函数性态的重要特征点 |
| 2 | **函数作图** | 利用凹凸性、拐点可准确描绘函数图像 |
| 3 | **中值定理** | 凹函数的割线斜率递增，凸函数递减 |
| 4 | **Jensen不等式** | 凹函数满足 $f(\lambda x_1 + (1-\lambda)x_2) \leq \lambda f(x_1) + (1-\lambda)f(x_2)$ |
| 5 | **曲率与曲率圆** | 曲率公式 $K = \dfrac{|y''|}{(1+y'^2)^{3/2}}$ |


> **复习提示**：牢记"凹上凸下"的记忆口诀，熟练掌握利用 $f''(x)$ 符号判断凹凸性的方法。
