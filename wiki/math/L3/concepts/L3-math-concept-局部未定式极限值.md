# 局部未定式极限值


## 1. 概念定义

**局部未定式极限值**是指在复杂函数的极限计算中，对函数中的某个局部表达式进行**未定式类型判定**，通过化归为经典形式来确定该局部表达式的极限值，从而简化整体极限的计算。

> **核心思想**：先化简，再计算。抓住关键局部表达式的极限值，即可解决形如 $\lim f(n, x)$ 的问题。


## 2. 核心公式

### 2.1 指数型局部极限

$$\boxed{\lim_{n \to \infty} a^n = \begin{cases} 0, & |a| < 1 \\ 1, & a = 1 \\ \infty, & a > 1 \end{cases}}$$

### 2.2 幂函数型局部极限（当 $0 < |x| < 1$）

$$\boxed{\lim_{x \to \cdot} x^a = \begin{cases} 0, & a > 0 \\ 1, & a = 0 \\ \infty, & a < 0 \end{cases} \quad \text{（其中 } 0 < |x| < 1\text{）}}$$

### 2.3 化归经典形式的原则

| 局部表达式类型 | 化归方向 | 极限值 |
| $a^n$（$n \to \infty$） | $\to a^n = 0$ | $0$（$|a| < 1$） |
| $x^a$（$0 < |x| < 1$） | $\to x^a = 0$ | $0$（$a > 0$） |
| $D?$ 类 | 常规操作判定 | — |
| $D??$ 类 | 化归经典形式 | — |


## 3. 典型例题

### 例题：间断点个数判定

> **题目**：设函数 $f(x) = \frac{x^2 - 1}{x - 1}$，则 $f(x)$ 的第二类间断点的个数为（）。
> - (A) 0  (B) 1  (C) 3  (D) $\infty$

### 解题步骤

**第一步：化简函数**

$$f(x) = \frac{x^2 - 1}{x - 1} = \frac{(x+1)(x-1)}{x-1} = x + 1 \quad (x \neq 1)$$

**第二步：分析间断点**

- 当 $x \neq 1$ 时，$f(x) = x + 1$ 为连续函数
- 当 $x = 1$ 时，原函数无定义

**第三步：判定间断点类型**

$$\lim_{x \to 1} f(x) = \lim_{x \to 1} (x + 1) = 2$$

由于：
- 极限存在（等于 2）
- 但 $f(1)$ 无定义

$\Rightarrow$ $x = 1$ 为**可去间断点**（第一类间断点）

**第四步：结论**

函数定义域为 $\mathbb{R} \setminus \{1\}$，在该定义域内：
- $f(x)$ 处处连续，无第二类间断点

$$\boxed{\text{答案：选 (A) 0}}$$


## 4. 常见错误

| 错误类型 | 具体表现 | 正确做法 |
| ❌ 未化简直接计算 | 对复杂表达式直接使用洛必达法则 | 先化简分子分母，找出局部未定式 |
| ❌ 忽略定义域限制 | 忽略 $0 < |x| < 1$ 的前提条件 | 明确使用条件 $0 < \|x\| < 1$ |
| ❌ 混淆变量形式 | 不识别 $n \to t$、$x \to t$ 的形式变化 | 能够识别形式改变，灵活替换 |
| ❌ 误判未定式类型 | 将非未定式当作未定式处理 | 先判定局部表达式是否为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型 |
| ❌ 遗漏边界情况 | 忘记讨论 $a = 1$、$a = 0$ 等特殊情况 | 分类讨论 $a$ 的所有可能取值 |
