# 概率论与数理统计-第23讲

**来源：** 概率论与数理统计第23讲

```markdown
# 概率论与数理统计-第23讲：多维随机变量及其分布

## 核心概念定义
多维随机变量及其分布是概率论中研究多个随机变量同时取值规律的理论。主要包括离散型问题和连续型问题，涉及边缘分布、条件分布、概率计算及反问题，以及与独立性的关系。

## 核心公式
```latex
\begin{align*}
P\{max\{X,Y\}=2, min\{X,Y\}=1\} &= P\{max\{X,Y\}=2\}P\{min\{X,Y\}=1\} \\
Cov(X,Y) &= E(XY) - EX \cdot EY
\end{align*}
```

## 典型例题
**例4.1** 设二维随机变量$(X,Y)$的概率分布为：

| Y | X |
|---|---|
| -1 | 1 |
| 0 | 0.1 |
| 1 | 0.1 |
| 2 | b |
| 0 | 0.1 |

若事件$\{max\{X,Y\}=2\}$与事件$\{min\{X,Y\}=1\}$相互独立，则$Cov(X,Y)=(\quad)$。

**解** 应选(B)。

由题意，得
$$
P\{max\{X,Y\}=2, min\{X,Y\}=1\} = P\{max\{X,Y\}=2\}P\{min\{X,Y\}=1\},
$$
$$
P\{max\{X,Y\}=2\} = b + 0.1, P\{min\{X,Y\}=1\} = 0.1 + 0.1 = 0.2,
$$
$$
P\{max\{X,Y\}=2, min\{X,Y\}=1\} = 0.1,
$$
故$0.2(b + 0.1) = 0.1$，解得$b = 0.4$。又$a + b = 1 - 0.4 = 0.6$，故$a = 0.2$。

$$
Cov(X,Y) = E(XY) - EX \cdot EY = -0.1 - 0.8 + 0.1 + 0.2 - (-0.6 + 0.4) \cdot (0.2 + 1) = -0.36.
$$

## 常见错误
1. 忽略事件独立性条件，错误地计算概率。
2. 错误地计算边缘分布和条件分布。
3. 在计算协方差时，错误地使用公式。
