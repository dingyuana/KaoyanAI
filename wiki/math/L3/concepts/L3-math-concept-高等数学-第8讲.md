# 高等数学-第8讲：一元函数积分学的概念与性质

## 核心概念定义
一元函数积分学是研究函数在某一区间上的积分运算及其性质的数学分支。它包括不定积分和定积分两部分，其中不定积分是寻找原函数的过程，而定积分则是计算函数在一定区间上的累积效应。

## 核心公式
```latex
\[
\int f(x) \, dx = F(x) + C
\]
\[
\int_a^b f(x) \, dx = F(b) - F(a)
\]
```

## 典型例题
**例题**：计算函数 \( f(x) = x^2 \) 在区间 \([1, 3]\) 上的定积分。

**解答**：
```latex
\[
\int_1^3 x^2 \, dx = \left[ \frac{x^3}{3} \right]_1^3 = \frac{3^3}{3} - \frac{1^3}{3} = 9 - \frac{1}{3} = \frac{26}{3}
\]
```

## 常见错误
1. 忽略积分常数 \(C\)。
2. 在计算定积分时，忘记将积分上下限代入原函数。
3. 在进行不定积分时，错误地应用了积分公式。
4. 在处理变限积分时，未能正确处理积分限的函数关系。
