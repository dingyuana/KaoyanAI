# 一阶导数型辅助函数的构造


## 概念定义

**一阶导数型辅助函数**是指在证明微分中值定理相关命题时，通过对原函数进行代数变形或指数因子修饰，构造出的新函数 $F(x)$，使其导数恰好呈现目标形式，从而将原命题转化为**Rolle定理**或**Lagrange中值定理**的直接应用。

> **核心思想**：通过**恒等变形** + **指数法**（或**乘积构造法**）将复杂表达式化归为 $F'(x) = 0$ 的经典形式。


## 核心公式

### 类型一：$f(x) + xf'(x)$ 型

见到 $f(x) + xf'(x)$，令：
$$F(x) = x \cdot f(x)$$

则：
$$F'(x) = f(x) + x f'(x)$$


### 类型二：$f''(x)f(x) - [f'(x)]^2$ 型（$f(x) \neq 0$）

见到 $f''(x)f(x) - [f'(x)]^2$，令：
$$F(x) = \frac{f'(x)}{f(x)}$$

则：
$$F'(x) = \frac{f''(x)f(x) - [f'(x)]^2}{[f(x)]^2}$$


### 类型三：$f''(x) - f(x)$ 型（$f(x) > 0$）

见到 $f''(x) - f(x)$，令：
$$F(x) = \ln f(x)$$

则：
$$F'(x) = \frac{f'(x)}{f(x)}, \quad F''(x) = \frac{f''(x)f(x) - [f'(x)]^2}{[f(x)]^2}$$


### 类型四：祖孙三代传承法（化归经典形式）

**适用场景**：欲证结论形如 $f''(\xi) = f(\xi)$ 或 $f'(\xi) = \int_{\xi}^{\xi} f(t)\,dt$（辈分不对应）

**操作步骤**：
1. 作**恒等变形**：$a - c = (a - b) + (b - c)$
2. 补齐辈分，将原式化为差的形式
3. 乘以 $e^{-x}$ 因子还原

**公式**：
$$\boxed{F'(x) = [f''(x) - f(x)]e^{-x} + [f'(x) - f(x)]e^{-x} = e^{-x}[f''(x) - f(x) + f'(x) - f(x)]}$$

即：
$$F(x) = [f'(x) - f(x)]e^{-x}$$


## 典型例题

### 例题

设 $f(x)$ 在 $[0,1]$ 上二阶可导，且 $f(0) = f(1) = 0$，证明：存在 $\xi \in (0,1)$，使得

$$f''(\xi) = 2f(\xi)$$


### 解答

**第一步：恒等变形（补齐辈分）**

将待证结论变形为：
$$f''(\xi) - f(\xi) = f''(\xi) - f'(\xi) + f'(\xi) - f(\xi)$$

**第二步：构造辅助函数**

令：
$$F(x) = [f'(x) - f(x)]e^{-x}$$

**第三步：验证条件**

$$F'(x) = [f''(x) - f(x)]e^{-x} + [f'(x) - f(x)](-e^{-x}) = [f''(x) - 2f(x) + f'(x) - f(x)]e^{-x}$$

注意到 $F(0) = [f'(0) - f(0)] = f'(0)$，$F(1) = [f'(1) - f(1)]e^{-1} = f'(1)e^{-1}$

由 $f(0) = f(1) = 0$ 可知 $F(0) = F(1) \cdot e$（需要额外分析）

**第四步：应用Rolle定理**

（此处略去细节，核心是利用 $F'(x) = e^{-x}[f''(x) - f(x) + f'(x) - f(x)]$ 化简）


## 常见错误

| 序号 | 错误类型 | 正确做法 |
| 1 | **忽略定义域条件** | 使用类型二时必须说明 $f(x) \neq 0$；使用类型三时需 $f(x) > 0$ |
| 2 | **指数因子选错** | $f'' - f$ 型应乘 $e^{-x}$；$f' + f$ 型应乘 $e^{x}$ |
| 3 | **恒等变形不到位** | 必须确保"祖孙三代"各辈分齐全，即 $f''(\xi) = f(\xi)$ 需拆为 $f'' - f = (f'' - f') + (f' - f)$ |
| 4 | **忘记验证端点** | 构造 $F(x)$ 后必须验证 $F(a) = F(b)$ 或 $F'(a) = F'(b)$ |
| 5 | **混淆辅助函数形式** | $F(x) = xf(x)$ 和 $F(x) = f(x)/x$ 的适用场景不同 |


## 关联知识点

1. **Rolle定理**：辅助函数构造的最终归宿
2. **Lagrange中值定理**：直接构造 $F(x) = f(x) - kx$
3. **Cauchy中值定理**：多元辅助函数的构造
4. **二阶导数型辅助函数**：进一步延伸
5. **积分型辅助函数**：将积分表达式转化为微分形式


> **记忆口诀**：看见 $f + xf'$，直接 $F = xf$；看见 $f''f - (f')^2$，考虑 $F = f'/f$；看见 $f'' - f$，指数 $e^{-x}$ 来化归。
