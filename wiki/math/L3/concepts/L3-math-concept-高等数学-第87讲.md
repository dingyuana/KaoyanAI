# 高等数学-第87讲：一元函数积分学的应用(三)——物理应用与经济应用

## 核心概念定义
一元函数积分学在物理和经济领域中的应用，主要涉及功、静水压力和引力等概念。功是指力在物体上所做的功，静水压力是水对物体表面的压力，引力是物体间的相互吸引力。

## 核心公式
```latex
W = \int_{a}^{b} p g A(x) \, dx
```
```latex
dW = p g x A(x) \, dx
```
```latex
P = p g [f(x) - h(x)] \, dx
```
```latex
dP = p g [f(x) - h(x)] \, dx
```
```latex
F = \frac{G m \mu}{(a - x)^2}
```

## 典型例题
**例12.3** 半径为 \(a\) 的半球形水池蓄满了水，水的比重为1，现将水抽干，至少做功多少？求 \(a\)。

**解**：将水看作是一层一层抽出来的。任取一个与池面距离为 \(h\) 的小薄层，厚度为 \(dh\)，它的重量为 \(\pi(a^2 - h^2)dh\)。把这层水（微元）抽到池面所做的功是 \(dW = \pi(a^2 - h^2)hdh\)，所以抽干水所做的功至少为 \(W = \int_{0}^{a} \pi(a^2 - h^2)hdh = 2\pi a^3\)。故 \(a = 2\)。

**例12.4** 一闸门的上部是一个宽为2m、高为 \(H\) m 的矩形，下部由 \(y = x^2\) 与 \(y = 1\) 围成。当闸门上边缘与水面在一个平面时，其上部所受水压力与下部所受水压力之比为 5:4，求上部的高度 \(H\)。

**解**：闸门上部所受水压力为 \(R = \int_{0}^{H} p g (H + 1 - y) \, dy = p g H^2\)。闸门下部所受水压力为 \(B = \int_{0}^{H} p g (H + 1 - \sqrt{y}) \, dy = \frac{p g H^2}{2}\)。由 \(B = \frac{4}{5}R\)，得 \(3H^2 - 5H - 2 = 0\)，解得 \(H = 2\)。

## 常见错误
1. 忽略微元厚度 \(dx\) 或 \(dh\)。
2. 错误计算微元面积 \(A(x)\) 或 \(f(x) - h(x)\)。
3. 错误计算微元重量或压力。
4. 忽略积分区间。
5. 错误应用公式。
