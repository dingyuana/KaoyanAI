# 概率论与数理统计-第31讲：多维随机变量函数的分布

## 核心概念定义
多维随机变量函数的分布是指给定一个多维随机变量，研究其函数的分布情况。在概率论与数理统计中，研究多维随机变量函数的分布对于理解随机现象和进行数据分析具有重要意义。

## 核心公式
```latex
P\{Z < z\} = \int_{-\infty}^{z} f_{X,Y}(x, y) \, dx \, dy
```

## 典型例题
**例题**：已知随机变量 \(X\) 与 \(Y\) 相互独立，\(Y\) 服从参数为 1 的指数分布，记 \(V = \begin{cases} 
2 & \text{if } X \leq Y \\
-1 & \text{if } X > 2Y 
\end{cases}\)，求 \((U, V)\) 的分布律。

**解答**：由已知，\(P\{U = 0\} = 4 + 3e^{-3}\)，\(P\{V = 0\} = 1 + 3e^{-3}\)。则有
\[ P\{U = 1\} = 1 - P\{U = 0\} = 4 - 4e^{-3} \]
\[ P\{V = 1\} = 1 - P\{V = 0\} = 3 - 3e^{-3} \]
又 \(P\{U = 0, V = 1\} = P\{X < Y, X \geq 2Y\} = 0\)，所以 \((U, V)\) 的分布律为：

| U | V | P |
|---|---|---|
| 0 | 0 | 4 + 3e^{-3} |
| 0 | 1 | 4 + 3e^{-3} |
| 1 | 0 | 4 - 4e^{-3} |
| 1 | 1 | 3 - 3e^{-3} |

## 常见错误
1. 忽略随机变量之间的独立性。
2. 错误地应用分布函数或概率密度函数。
3. 在计算分布律时，未正确处理边界条件。
