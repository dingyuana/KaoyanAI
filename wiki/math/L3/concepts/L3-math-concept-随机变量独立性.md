# 随机变量独立性


**章节**：2026 张宇概率论 9讲(OCR)  
**难度**：★★☆☆☆  
**必考点**：⭐⭐⭐


## 1. 概念定义

### 随机变量独立性

设 $X$ 和 $Y$ 是两个随机变量，若对于任意实数 $a,b$，事件 $\{X \leq a\}$ 与 $\{Y \leq b\}$ 相互独立，即：

$$P(X \leq a, Y \leq b) = P(X \leq a) \cdot P(Y \leq b)$$

则称 **随机变量 $X$ 与 $Y$ 相互独立**。

### 关键性质

- **离散型 + 连续型混合**：当 $X$ 是离散型随机变量，$Y$ 是连续型随机变量时，利用**全概率公式**处理涉及两者的概率计算
- **独立性可分离**：若 $X$ 与 $Y$ 独立，则 $P(X \in A, Y \in B) = P(X \in A) \cdot P(Y \in B)$


## 2. 核心公式

### 全概率公式（离散-连续混合型）

当 $X$ 与 $Y$ 独立，且 $X$ 为离散型（取值 $\{x_i\}$），$Y$ 为连续型时：

$$P(X < Y) = \sum_i P(X = x_i) \cdot P(Y > x_i)$$

### 独立性的概率分离公式

$$P(X < Y, X = x_k) = P(X = x_k) \cdot P(Y > x_k)$$

### 概率单调性

$$P(AB) \leq P(A) \leq P(A \cup B) \leq P(A) + P(B)$$


## 3. 典型例题

### 例1.4（离散型与连续型混合）

> 已知随机变量 $X$ 与 $Y$ 相互独立，$X$ 服从 $0$—$1$ 分布（$P(X=0) = \frac{1}{4}$，$P(X=1) = \frac{3}{4}$），$Y$ 服从参数为 $1$ 的指数分布。记 $U = \begin{cases} 0, & X < Y \\ 1, & X \geq Y \end{cases}$，$V = \begin{cases} 0, & X < 2Y \\ 1, & X \geq 2Y \end{cases}$。  
> 求 $P(U=0)$ 及 $P(V=0)$。

### 【解】

#### 求 $P(U=0)$

由全概率公式（化归经典形式）：

$$P(U=0) = P(X < Y) = \sum_{k=0}^{1} P(X < Y, X = k)$$

利用独立性分离：

$$= P(X = 0) \cdot P(Y > 0) + P(X = 1) \cdot P(Y > 1)$$

计算各部分：

$$P(Y > y) = \int_y^{+\infty} e^{-t} \, dt = e^{-y}$$

因此：

$$P(U=0) = \frac{1}{4} \cdot P(Y > 0) + \frac{3}{4} \cdot P(Y > 1)$$
$$= \frac{1}{4} \cdot 1 + \frac{3}{4} \cdot e^{-1} = \frac{1}{4} + \frac{3}{4e}$$

#### 求 $P(V=0)$

$$P(V=0) = P(X < 2Y) = \sum_{k=0}^{1} P(X < 2Y, X = k)$$

$$= P(X = 0) \cdot P(Y > 0) + P(X = 1) \cdot P\!\left(Y > \frac{1}{2}\right)$$

$$= \frac{1}{4} \cdot 1 + \frac{3}{4} \cdot e^{-\frac{1}{2}} = \frac{1}{4} + \frac{3}{4\sqrt{e}}$$

### 【答案】

$$\boxed{P(U=0) = \frac{1}{4} + \frac{3}{4e}, \qquad P(V=0) = \frac{1}{4} + \frac{3}{4\sqrt{e}}}$$


## 4. 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| **独立性误用** | 直接写 $P(X<Y) = P(X) \cdot P(Y)$ | 离散型无法直接乘，应条件分解 |
| **分布函数混淆** | 忘记 $P(Y > y) = e^{-y}$ 是尾概率 | 指数分布的分布函数 $F(y) = 1 - e^{-y}$，故 $P(Y > y) = e^{-y}$ |
| **单调性漏用** | 在不等式证明题中直接跳步 | 明确 $AB \leq B$，$AC \leq A$，$BC \leq C$ 的包含关系 |
| **全集分解不完整** | 漏掉 $P(ABC)$ 项 | $P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$ |


## 5. 关联知识点

### 知识图谱

```
随机变量独立性
├── 事件独立性
│   └── P(AB) = P(A)·P(B)
├── 全概率公式
│   └── 离散-连续混合分解
├── 贝叶斯公式
│   └── 条件概率的逆运算
├── 概率单调性
│   ├── 0 ≤ P(A) ≤ 1
│   ├── A ⊆ B ⇒ P(A) ≤ P(B)
│   └── P(AB) ≤ P(A) ≤ P(A∪B) ≤ P(A)+P(B)
└── 常见分布
    ├── 0-1分布（离散型）
    └── 指数分布（连续型）
```

### 相关定理

- **Bonferroni 不等式**：$P(AB) + P(AC) + P(BC) \leq P(A) + P(B) + P(C)$
- **布尔不等式**：$P(A \cup B) \leq P(A) + P(B)$
- **包含-排斥原理**：$P(A \cup B \cup C) = \sum P(A) - \sum P(AB) + P(ABC)$


## 6. 方法论总结

### 处理独立性问题的标准流程

```
1. 识别随机变量类型（离散/连续）
2. 根据独立性条件分离概率
3. 利用全概率公式分解事件
4. 计算各分支概率并求和
```

### 适用题型

- ✅ 混合型随机变量函数的概率计算
- ✅ 独立性条件下的期望/方差计算
- ✅ 不等式概率证明


**关键字**：独立性、全概率公式、离散连续混合、概率单调性、指数分布
