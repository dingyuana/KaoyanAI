# 极限 $\lim x_n$ 的求法

## 元数据

| 属性 | 内容 |

## 1. 概念定义

**数列极限的求法**是指在已知数列 $\{x_n\}$ 的递推关系 $x_{n+1} = f(x_n)$ 或其他形式时，求解 $\lim\limits_{n\to\infty} x_n$ 的值。

### 核心方法

- **单调有界准则**：若数列 $\{x_n\}$ 单调递增且有上界，则收敛；单调递减且有下界，则收敛。
- **方程法**：设 $\lim x_n = a$，代入递推关系解方程 $a = f(a)$。


## 2. 核心公式

### 单调有界准则

$$
\text{若 } x_{n+1} \geq x_n \text{ 且 } x_n \leq M \Rightarrow \lim_{n\to\infty} x_n \text{ 存在}
$$

$$
\text{若 } x_{n+1} \leq x_n \text{ 且 } x_n \geq m \Rightarrow \lim_{n\to\infty} x_n \text{ 存在}
$$

### 极限方程

已知 $x_{n+1} = f(x_n)$，设 $\lim\limits_{n\to\infty} x_n = a$，则：

$$
a = f(a)
$$

### 递推形式

$$
x_{n+1} = f(x_n) \quad \Longrightarrow \quad \lim_{n\to\infty} x_n = a \text{ 满足 } a = f(a)
$$


## 3. 典型例题

### 例题

> 设数列 $\{x_n\}$ 满足 $x_{n+1} = x_n^2 - x_n + 1$，且 $0 < x_1 < 1$，求 $\lim\limits_{n\to\infty} x_n$。

### 解题步骤

**第一步：证明收敛性**

由题意可知 $x_{n+1} - x_n = x_n(x_n - 1) \leq 0$，且 $x_n > 0$，故数列单调递减且有下界，**收敛**。

**第二步：设极限并求解**

设 $\lim\limits_{n\to\infty} x_n = a$，则：

$$
a = a^2 - a + 1
$$

整理得：

$$
a^2 - 2a + 1 = 0 \quad \Rightarrow \quad (a-1)^2 = 0
$$

解得：

$$
\boxed{a = 1}
$$


## 4. 常见错误

| 错误类型 | 说明 | 正确做法 |
|----------|------|----------|
| **忽略单调性证明** | 直接设极限求解，未证明数列收敛 | 必须先用单调有界准则证明极限存在 |
| **遗漏初值范围** | 未考虑 $x_1$ 的取值对敛散性的影响 | 需分情况讨论 $x_1$ 的不同取值 |
| **解方程漏解** | $a = f(a)$ 可能有多解，需结合实际范围筛选 | 结合 $x_n$ 的有界性确定正确解 |
| **误用极限性质** | 在未证明收敛前使用 $\lim(x_{n+1} - x_n) = \lim x_{n+1} - \lim x_n$ | 必须先证明极限存在 |


## 5. 关联知识点

| 知识点 | 说明 |
|--------|------|
| **单调有界准则** | 判断数列极限存在性的基本定理 |
| **夹逼定理** | 用于求极限的另一种方法 |
| **函数极限与数列极限的关系** | Heine定理：$\lim_{x\to x_0} f(x) = A \Leftrightarrow$ 对任意 $x_n \to x_0$，有 $f(x_n) \to A$ |
| **递推数列的收敛速度** | 区分收敛与发散的速度特征 |
| **不动点理论** | $a = f(a)$ 的解即为函数 $f$ 的不动点 |
