# 高等数学-第56讲：一元函数微积分的应用（二）

## 核心概念定义

1. **最值定理**：如果在区间(a,b)内函数F(x)有最小值m，则在(a,b)内F(x)≥m，且除这些最小值点外，均有F(x)>m。对于最大值M，有类似的结论。
2. **凹凸性**：如果对于任意的x∈I，F''(x)>0，则函数F(x)在区间I上为凸函数；如果F''(x)<0，则F(x)为凹函数。
3. **中值定理**：包括拉格朗日中值定理和柯西中值定理，用于证明函数在区间上的性质。
4. **泰勒公式**：用于近似计算函数值，特别是带有拉格朗日余项的泰勒公式。

## 核心公式

```latex
\begin{align*}
&\text{拉格朗日中值定理：} \quad F(b) - F(a) = F'(\xi)(b - a) \\
&\text{柯西中值定理：} \quad \frac{F(b) - F(a)}{G(b) - G(a)} = \frac{F'(\xi)}{G'(\xi)} \\
&\text{泰勒公式：} \quad F(x) = F(x_0) + F'(x_0)(x - x_0) + \frac{F''(\xi)}{2!}(x - x_0)^2
\end{align*}
```

## 常见错误

1. 忽略函数的连续性和可导性条件。
2. 错误应用中值定理，如区间选择不当或导数不存在。
3. 在使用泰勒公式时，忽略余项的存在。
4. 在证明单调性时，未正确使用拉格朗日中值定理或柯西中值定理。
