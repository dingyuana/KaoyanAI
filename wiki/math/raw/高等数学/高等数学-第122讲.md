# 高等数学-第122讲：无穷级数

## 核心概念定义
无穷级数是数学分析中研究的一种数列的极限形式，由一系列数按照一定的次序排列并求和得到。无穷级数的敛散性是研究其和是否存在的性质。

## 核心公式
```latex
\sum_{n=1}^{\infty} a_n = \lim_{n \to \infty} \sum_{k=1}^{n} a_k
```

## 典型例题
**例16.20** 设\( a \)为正数，若级数\( \sum_{n=1}^{\infty} \frac{1}{n^a} \)收敛，而\( \sum_{n=1}^{\infty} \frac{1}{n^{a+2}} \)发散，则\( a \)的取值范围是？

**解**：应选(A) \( 0 < a \leq 2 \)。

**例16.21** 设数列\( \{a_n\} \)收敛，且\( \lim_{n \to \infty} a_n = a \)（\( a > 0 \)），判别级数\( \sum_{n=1}^{\infty} \frac{a}{n^2} \)的敛散性。

**解**：由题设可知，对任意的\( \epsilon > 0 \)，存在正整数\( N \)，当\( n > N \)时，有\( |a_n - a| < \epsilon \)恒成立，故\( a_n > 0 \)。

因此当\( n \to \infty \)时，

\[ \lim_{n \to \infty} \frac{a}{n^2} = 0 \]

由于级数\( \sum_{n=1}^{\infty} \frac{1}{n^2} \)收敛，所以级数\( \sum_{n=1}^{\infty} \frac{a}{n^2} \)收敛。

## 常见错误
1. 忽视级数敛散性的定义，错误地判断级数的敛散性。
2. 在使用比值判别法时，未正确计算极限值。
3. 在讨论级数的敛散性时，未考虑数列的极限性质。
