# 高等数学-第143讲：三重积分的直角坐标系积分法

## 核心概念定义
三重积分的直角坐标系积分法是多元函数积分学中的一种方法，用于计算空间区域上的积分。它包括两种主要方法：先一后二法和先二后一法。

## 核心公式
```latex
\int\int\int_{D} f(x, y, z) \, dV
```

## 典型例题
**例题**：设锥面 $\Sigma$ 的顶点是 $A(0,1,1)$，准线是 $x^2+y^2=1$，$M(x,y,0)$，$\Sigma$ 与平面 $z=0$ 所围成的锥体 $\Omega$。

1. 求直线 $L$ 和 $\Sigma$ 的方程；
2. 求 $\Omega$ 的形心坐标。

**解答**：
1. 直线 $L$ 的方程为 $x = \frac{1}{2}y + \frac{1}{2}$，锥面 $\Sigma$ 的方程为 $x^2 + (y - z)^2 = (1 - z)^2$。
2. $\Omega$ 的形心坐标为 $(0, \frac{1}{3}, \frac{1}{2})$。

## 常见错误
1. 忘记将三重积分转换为累次积分；
2. 在计算累次积分时，积分限错误；
3. 在计算积分时，积分顺序错误；
4. 忽略对称性，导致计算复杂。
