# 未定式判定方法


**章节**：2026 张宇高数 18讲(OCR)  
**章节编号**：第1讲 函数极限与连续  
**难度**：★★☆☆☆  
**标签**：极限计算、未定式、局部判定


## 1. 概念定义

### 1.1 未定式

当分子与分母（或其他部分）同时趋于零、同时趋于无穷大，或呈现出其他**不确定的组合形式**时，极限结果**无法直接判断**，这类极限称为**未定式**。

### 1.2 常见未定式类型

| 类型 | 形式 | 说明 |
| $\dfrac{0}{0}$ 型 | $\dfrac{0}{0}$ | 分子分母同趋于零 |
| $\dfrac{\infty}{\infty}$ 型 | $\dfrac{\infty}{\infty}$ | 分子分母同趋于无穷 |
| $0 \cdot \infty$ 型 | $0 \cdot \infty$ | 零与无穷的乘积 |
| $\infty - \infty$ 型 | $\infty - \infty$ | 两个无穷的差 |
| $0^0$ 型 | $0^0$ | 零的零次方 |
| $\infty^0$ 型 | $\infty^0$ | 无穷的零次方 |
| $1^\infty$ 型 | $1^\infty$ | 底数趋于1，指数趋于无穷 |

### 1.3 局部未定式判定

对于复杂表达式中的局部部分，需要单独判定其极限类型：

> **核心思想**：$D?$（常规操作）$+$ $D??$（化归经典形式）

即：先判断局部表达式是否属于未定式，再将其转化为经典形式求解。


## 2. 核心公式

### 2.1 常用极限结果

$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

$$\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}$$

$$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e$$

$$\lim_{x \to 0^+} x^x = 1$$

$$\lim_{x \to 0} \frac{\ln(1+x)}{x} = 1$$

$$\lim_{x \to 0} \frac{e^x - 1}{x} = 1$$

### 2.2 局部表达式极限速记

$$a^x - 1 \sim x \ln a \quad (x \to 0)$$

$$\log_a(1+x) \sim \frac{x}{\ln a} \quad (x \to 0)$$

$$(1+x)^\alpha - 1 \sim \alpha x \quad (x \to 0)$$

### 2.3 重要等价关系

当 $x \to 0$ 时：

$$\sin x \sim x \sim \tan x \sim \arcsin x \sim \arctan x$$

$$1 - \cos x \sim \frac{1}{2}x^2$$

$$e^x - 1 \sim x \sim \ln(1+x)$$


## 3. 典型例题

### 例题

> 设 $f(x) = \dfrac{x^2 - 1}{x^2 - 3x + 2}$，则 $f(x)$ 的第二类间断点的个数为（ ）
> 
> **(A)** 0 **(B)** 1 **(C)** 3 **(D)** $\infty$

### 解

**分析思路**：第二类间断点指在该点处至少有一个单侧极限为无穷或振荡不存在。

**步骤 1**：化简函数

$$f(x) = \frac{x^2 - 1}{x^2 - 3x + 2} = \frac{(x-1)(x+1)}{(x-1)(x-2)}$$

**步骤 2**：确定定义域

当 $x \neq 1$ 时：

$$f(x) = \frac{x+1}{x-2}$$

**步骤 3**：找出可疑点

- $x = 1$：分子分母同为零，化简后 $\displaystyle\lim_{x \to 1} f(x) = \frac{2}{-1} = -2$，**可去间断点**
- $x = 2$：分母为零，分子 $2+1=3 \neq 0$

**步骤 4**：判断 $x = 2$ 的类型

$$\lim_{x \to 2^+} f(x) = +\infty, \quad \lim_{x \to 2^-} f(x) = -\infty$$

极限不存在（趋于无穷），故 $x = 2$ 为**第二类间断点（无穷间断点）**。

**答案**：**(B) 1**


## 4. 常见错误

| 错误类型 | 错误示例 | 正确做法 |
| **直接代入法** | 直接把 $x = 0$ 代入 $\dfrac{0}{0}$ 型表达式 | 先化简（因式分解、等价无穷小替换），再计算 |
| **忽略局部未定式** | 未判断局部是否属于未定式，直接使用洛必达 | 对复杂表达式进行**局部未定式判定** |
| **等价无穷小滥用** | $x \to \infty$ 时错误使用 $e^x - 1 \sim x$ | 等价无穷小替换仅在 $x \to 0$ 时有效 |
| **洛必达滥用** | 对非未定式使用洛必达法则 | 洛必达只适用于 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$ 型 |
| **忽略定义域** | 未考虑函数定义域就进行化简 | 化简前先明确函数的定义域 |
| **符号识别错误** | 将 $t \to +\infty$ 与 $n \to \infty$ 混淆 | 注意变量形式的改变，保持等价替换 |

### 💡 记忆口诀

> **化简先行，判定紧随；局部分析，整体把握；等价替换，洛必达辅。**
