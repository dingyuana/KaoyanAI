# 高等数学-第59讲：一元函数微分学的应用（三）——物理应用与经济应用

## 核心概念定义
一元函数微分学在物理和经济领域的应用，主要涉及温度变化、边际分析、弹性分析等概念。其中，物理应用涉及温度随时间的变化，经济应用则涉及边际成本、边际收益、边际利润和需求弹性等经济指标的计算。

## 核心公式
```latex
T(t) = Ce^{kt} + 20
```
```latex
C'(q) \approx \frac{C(q+1) - C(q)}{1}
```
```latex
R'(q) = Q(p) + pQ'(p)
```
```latex
L'(q) = R'(q) - C'(q)
```
```latex
e(p) = \frac{p}{Q(p)} \cdot \frac{dQ(p)}{dp}
```

## 典型例题
**物理应用例题**：
已知某物体的温度随时间变化的函数为 \( T(t) = Ce^{kt} + 20 \)，其中 \( k > 0 \)。若初始温度 \( T(0) = 120 \)℃，经过 30 分钟后温度降至 30℃，求常数 \( k \) 和 \( C \) 的值。

**经济应用例题**：
设某商品的成本函数为 \( C(q) = 100 + 2q \)，收益函数为 \( R(q) = 4q - q^2 \)，求边际成本、边际收益和边际利润。

## 常见错误
1. 忽略物理应用中温度随时间变化的指数函数形式。
2. 在计算边际成本、边际收益和边际利润时，未正确应用微分定义。
3. 在计算需求弹性时，未正确应用弹性公式。
4. 在经济应用中，未正确区分边际成本、边际收益和边际利润的概念。
