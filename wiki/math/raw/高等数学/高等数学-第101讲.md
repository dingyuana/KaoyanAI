# 高等数学-第101讲：多元函数极值学

## 核心概念定义
多元函数极值学是研究多元函数在定义域内取得局部最大值或最小值的问题。与一元函数不同，多元函数的极值点可能不是最值点，且可能存在多个极大值或极小值。

## 核心公式
```latex
f(x,y) = 3(x^2 + y^2) - x^3
\frac{\partial f}{\partial x} = 6x - 3x^2
\frac{\partial f}{\partial y} = 6y
\Delta = AC - B^2
```

## 典型例题
### 例13.25
求函数 \( f(x,y) = 3(x^2 + y^2) - x^3 \) 的极值。

**解：**
因为 \( f(x,y) = 3(x^2 + y^2) - x^3 \)，所以
\[ \frac{\partial f}{\partial x} = 6x - 3x^2, \quad \frac{\partial f}{\partial y} = 6y \]
令 \(\frac{\partial f}{\partial x} = 0\) 解得驻点 \((0,0)\) 和 \((2,0)\)。又 \( f_{xx} = 6 - 6x, f_{xy} = 0, f_{yy} = 6 \)。

在点 \((0,0)\) 处，\( A = f_{xx}(0,0) = 6, B = f_{xy}(0,0) = 0, C = f_{yy}(0,0) = 6 \)，所以
\[ \Delta = AC - B^2 = 36 > 0, \text{且} A = 6 > 0, \]
故 \( f(0,0) = 0 \) 是函数 \( f(x,y) \) 的极小值。

在点 \((2,0)\) 处，\( A = f_{xx}(2,0) = -6, B = f_{xy}(2,0) = 0, C = f_{yy}(2,0) = 6 \)，所以
\[ \Delta = AC - B^2 = -36 < 0, \]
故驻点 \((2,0)\) 不是函数 \( f(x,y) \) 的极值点。

综上可知，函数 \( f(x,y) \) 只有一个极值点，且极小值为 \( f(0,0) = 0 \)。

### 例13.26
设 \( f(x,y) = (y - x^2)(y - 2x^2) \)，\( k \) 为任意常数，则 \( f(x,kax) \) 在 \( x = 0 \) 处取极小值，点 \( (0,0) \) 是 \( f(x,y) \) 的极小值点。

**解：**
当 \( y = kx \) 时，\( f(x,kax) = (kx - x^2)(kx - 2x^2) = k^2x^2 - 3k^3x^2 + 2x^4 \)。

当 \( x \to 0 \) 时，显然 \( f \) 的正负取决于 \( k^2x^2 \)，而当 \( k \neq 0 \) 时，\( k^2x^2 > 0 \)；当 \( k = 0 \) 时，\( f = 2x^4 > 0 \)。故 \( x = 0 \) 是 \( f(x,kax) \) 的极小值点。

如图所示，在任何以 \( (0,0) \) 为圆心，\( \delta > 0 \) 为半径的圆内，均有：在 \( D \) 内，\( f(x,y) > 0 \)；在 \( D? \) 内，\( f(x,y) < 0 \)。故点 \( (0,0) \) 不是 \( f(x,y) \) 的极小值点。

## 常见错误
1. 忽略多元函数极值点的存在性条件，如连续性。
2. 误判极值点与最值点的区别。
3. 忽略参数对极值的影响。
