# 二阶导数正与局部曲线凹的关系

## 概念定义

### 曲线凹凸性

设函数 $f(x)$ 在区间 $I$ 上连续，若对任意 $x_0 \in I$，存在 $\delta > 0$，使得当 $x \in (x_0 - \delta, x_0 + \delta)$ 时，曲线 $y = f(x)$ 位于该点切线的**上方**，则称曲线在 $x_0$ 处是**凹**的。

### 二阶导数与凹凸性

> **定理（充分条件）**：若 $f(x)$ 在 $x_0$ 的某邻域内二阶可导，且 $f''(x)$ 在 $x_0$ 处**连续**，则：
> - $f''(x_0) > 0 \Rightarrow$ 曲线在 $x_0$ 的某邻域内是**凹**的
> - $f''(x_0) < 0 \Rightarrow$ 曲线在 $x_0$ 的某邻域内是**凸**的

> **关键点**：二阶导数必须**连续**，才能保证局部定号性。

### 局部凹凸性判定

$$\boxed{f''(x_0) > 0 \text{ 且 } f''(x) \text{ 在 } x_0 \text{ 处连续} \Longrightarrow f(x) \text{ 在 } x_0 \text{ 的某邻域内是凹的}}$$


## 典型例题

### 例题（选自2026张宇高数18讲）

**题目**：判断以下说法正误

| 选项 | 说法 |
| (A) | 若 $f'(x_0) > 0$，则 $f(x)$ 在 $x_0$ 的某邻域内单调增加 |
| (B) | 若 $f'(x_0) > 0$，则 $f(x)$ 在 $x_0$ 的某邻域内单调增加 |
| (C) | 若 $f''(x_0) > 0$，则曲线 $f(x)$ 在 $x_0$ 的某邻域内是凹的 |
| (D) | 若 $f''(x_0) > 0$，则曲线 $f(x)$ 在 $x_0$ 的某邻域内是凹的 |

**答案**：选 **(B)**

**解析**：

- **选项(A)错误**：$f'(x_0) = 0$ 时也可能单调增加。例如 $f(x) = x^3$，$x_0 = 0$，有 $f'(0) = 0$，但在 $x = 0$ 的邻域内单调增加。

- **选项(B)正确**：因为 $f(x)$ 在 $x_0$ 处**二阶可导**，所以 $f'(x)$ 在 $x_0$ 处**连续**，由局部保号性：
  故 $f(x)$ 在 $x_0$ 的某邻域内单调增加。

- **选项(C)错误**：$f''(x_0) = 0$ 时也可能局部凹。例如 $f(x) = x^4$，$x_0 = 0$，有 $f''(0) = 0$，但曲线在 $x = 0$ 的邻域内是凹的。

- **选项(D)错误**：**仅 $f''(x_0) > 0$ 不足以判定局部凹性**。一点附近的凹凸性不能由该点二阶导数的正负确定，除非 $f''(x)$ 在该点还**连续**，使其在该点附近均有二阶导数的定号结论。


## 常见错误

| 错误类型 | 错误表述 | 正确理解 |
| ❌ 混淆充分条件 | $f''(x_0) > 0 \Rightarrow$ 局部凹 | 必须加上 $f''(x)$ **连续**的条件 |
| ❌ 忽略连续性要求 | 一点处二阶导数正 $\Rightarrow$ 邻域内凹 | 需要二阶导数在邻域内**定号** |
| ❌ 误用极限定理 | $f''(x_0) > 0 \Rightarrow \lim f''(x) > 0$ | 二阶导数未必连续，极限不存在 |
| ✅ 正确推理 | $f''(x_0) > 0$ 且 $f''$ 连续 $\Rightarrow$ 局部凹 | 连续 $\Rightarrow$ 局部保号 $\Rightarrow$ 局部凹凸 |


## 关联知识点

| 知识点 | 关联说明 |
| **局部保号性** | 一阶导数连续 $\Rightarrow$ 局部保号 $\Rightarrow$ 局部单调 |
| **一阶导数与单调性** | $f'(x) > 0 \Rightarrow$ 局部单调增加（需导数连续） |
| **极值点判别** | $f'(x_0) = 0,\ f''(x_0) > 0 \Rightarrow$ 极小值点 |
| **凹凸区间** | $f''(x) > 0 \Leftrightarrow$ 曲线在区间上下凹 |
| **拐点** | $f''(x_0) = 0$ 且符号变化 $\Rightarrow$ 拐点 |


## 总结口诀

> **一点二导看邻域，连续才是保证书。**
> **导数正负定单调，二阶正负定凹凸。**
> **二阶导数若不连，局部性质推不出。**
