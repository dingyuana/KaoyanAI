# 高等数学-第141讲：多元函数积分学-轮换对称性

## 核心概念定义
在多元函数积分学中，轮换对称性指的是在直角坐标系下，若将变量x与y对调，积分区域Ω不变，则三重积分的值保持不变。这种对称性可以简化积分的计算。

## 核心公式
```latex
\int_{\Omega} f(x, y, z) \, dV = \int_{\Omega} f(y, x, z) \, dV
```

## 典型例题
**例题1：** 设Ω是由平面x+y+z=1与三个坐标平面所围成的空间区域，计算积分 $\int_{\Omega} (x+2y+3z) \, dV$。

**解：** 由于Ω关于xOy平面轮换对称，故有 $\int_{\Omega} x \, dV = \int_{\Omega} y \, dV = \int_{\Omega} z \, dV = 0$。因此，原积分可简化为：
```latex
\int_{\Omega} (x+2y+3z) \, dV = \int_{\Omega} 2y \, dV = 2 \int_{\Omega} y \, dV = 0
```

**例题2：** 计算积分 $\int_{\Omega} (2+y^3) \, dV$，其中Ω是由球面 $x^2+y^2+z^2 \leq 1$ 和锥面 $z = \sqrt{x^2+y^2}$ 所围成的空间区域。

**解：** 由于Ω关于xOy平面轮换对称，故有 $\int_{\Omega} x \, dV = \int_{\Omega} y \, dV = 0$。因此，原积分可简化为：
```latex
\int_{\Omega} (2+y^3) \, dV = \int_{\Omega} 2 \, dV + \int_{\Omega} y^3 \, dV = 2 \int_{\Omega} dV + \int_{\Omega} y^3 \, dV
```
其中，$\int_{\Omega} dV$ 可通过柱坐标系或直角坐标系计算。

## 常见错误
1. 忽略轮换对称性，导致积分计算错误。
2. 在应用轮换对称性时，未正确处理积分区域Ω的对称性。
3. 在计算积分时，未正确处理变量的轮换关系。
