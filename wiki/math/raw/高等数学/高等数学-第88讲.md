# 高等数学-第88讲：一元函数积分学的应用(三)——物理应用与经济应用

## 核心概念定义
一元函数积分学在物理和经济领域中的应用，主要涉及利用积分计算物理量（如引力、流量）和经济量（如成本、收益、利润）。

## 核心公式
```latex
F_x = \int_{0}^{1} \frac{Gp}{(1+y^2)^{3/2}} dy
```
```latex
Q = \int_{0}^{1} 10(1-r^2) \cdot 2\pi r dr
```
```latex
C(Q) = \int_{0}^{Q} C'(t) dt + C_0
```
```latex
R(Q) = \int_{0}^{Q} R'(t) dt
```
```latex
L(Q) = R(Q) - C(Q)
```

## 典型例题
**例12.5**：设沿y轴上的区间[0,1]放置一长度为1且线密度为p的均匀细杆，在x轴上x=1处有一单位质点，则该细杆对此质点的引力沿x轴正向的分力为多少？

**解**：利用引力公式计算，得到引力沿x轴正向的分力为 \( F_x = \int_{0}^{1} \frac{Gp}{(1+y^2)^{3/2}} dy \)。

**例12.6**：水从一根底面半径为1cm的圆柱形管道中流出，距离管道中心r cm处的水的流动速度为 \( 10(1-r^2) \) cm/s。问水是以多大流量流过管道的？

**解**：利用流量公式计算，得到水流过管道的流量为 \( Q = \int_{0}^{1} 10(1-r^2) \cdot 2\pi r dr \)。

## 常见错误
1. 忽略微元法在物理应用中的重要性。
2. 在计算流量时，未考虑管道截面积的变化。
3. 在求解经济应用题时，未正确使用积分和微分运算。
