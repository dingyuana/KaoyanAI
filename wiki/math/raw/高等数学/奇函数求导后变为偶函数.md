# 奇函数求导后变为偶函数


## 1. 概念定义

### 奇函数
若函数 $f(x)$ 满足 $f(-x) = -f(x)$，则称 $f(x)$ 为**奇函数**。

### 偶函数
若函数 $f(x)$ 满足 $f(-x) = f(x)$，则称 $f(x)$ 为**偶函数**。

### 核心定理
> **奇函数在其定义域内求导后，导函数必为偶函数。**


## 2. 核心公式

### 基本求导奇偶性规律

| 原函数 $f(x)$ 的奇偶性 | 导函数 $f'(x)$ 的奇偶性 |
| 奇函数 | **偶函数** |
| 偶函数 | **奇函数** |
| 周期函数 | 仍为周期函数 |

### 数学推导

设 $f(x)$ 为奇函数，则 $f(-x) = -f(x)$。

对等式两边求导：

$$\frac{d}{dx}f(-x) = \frac{d}{dx}[-f(x)]$$

左边链式法则：$-f'(-x) = -f'(x)$

即 $f'(-x) = f'(x)$，故 $f'(x)$ 为**偶函数**。


## 3. 典型例题

### 例题（张宇高数 18讲）

> 设 $f(x) = 2^x + 1$，$x \in \mathbb{R}$，则 $f^{(n)}(0) =$ \_\_\_

### 解法

**分析**：观察研究对象 $f^{(n)}(0)$，即 $n$ 阶导数在 $x=0$ 处的值。

**步骤 1**：拆分函数
$$f(x) = 2^x + 1 = 2^x + 2 = g(x) + 2$$

其中 $g(x) = 2^x + 1$，令 $h(x) = 2$，则 $f(x) = g(x) + h(x)$。

**步骤 2**：判断奇偶性
$$g(-x) = 2^{-x} + 1 = \frac{1}{2^x} + 1 \neq -g(x)$$

注意到 $f(x) = 2^x + 1$ 既不是奇函数也不是偶函数。

**正确拆分**：
$$f(x) = 2^x + 1 = (2^x + 1 - 2) + 2 = \underbrace{(2^x - 1)}_{\text{奇函数}} + \underbrace{2}_{\text{偶函数}}$$

设 $g(x) = 2^x - 1$，则 $g(-x) = 2^{-x} - 1 = \frac{1 - 2^x}{2^x} = -(2^x - 1) = -g(x)$，故 $g(x)$ 为**奇函数**。

**步骤 3**：利用奇函数性质
$$f^{(n)}(x) = g^{(n)}(x) + 0$$

由于 $g(x)$ 为奇函数，$g^{(n)}(x)$ 的奇偶性随 $n$ 变化：
- $n$ 为奇数：$g^{(n)}(x)$ 为偶函数
- $n$ 为偶数：$g^{(n)}(x)$ 为奇函数

特别地，**奇函数的高阶导数仍为奇函数**。

**步骤 4**：求值
$$f^{(n)}(0) = g^{(n)}(0) = 0$$

> **答案**：$\boxed{0}$


## 4. 常见错误

### ❌ 错误一：混淆高阶导数的奇偶性

| 导数阶数 | 奇函数 $g(x)$ 的导数奇偶性 |
| 一阶导 $g'(x)$ | 偶函数 |
| 二阶导 $g''(x)$ | 奇函数 |
| 三阶导 $g'''(x)$ | 偶函数 |
| **$n$ 阶导 $g^{(n)}(x)$** | **取决于 $n$ 的奇偶** |

### ❌ 错误二：认为所有函数求导都改变奇偶性

**正确规律**：
- 奇函数求导 → 偶函数 ✓
- 偶函数求导 → 奇函数 ✓

但常数函数求导为 0，既是奇函数也是偶函数。

### ❌ 错误三：例题中函数拆分错误

在例题中，$f(x) = 2^x + 1$ **不是**奇函数，需正确拆分出奇函数部分后再利用性质。


## 5. 关联知识点

| 知识点 | 说明 |
| **奇偶函数的定义** | $f(-x) = \pm f(x)$ |
| **链式法则** | 推导奇偶性变化的核心工具 |
| **常见奇函数** | $x^3$、$\sin x$、$\tan x$、$e^x - e^{-x}$ |
| **常见偶函数** | $x^2$、$\cos x$、$e^x + e^{-x}$ |
| **周期函数求导** | 周期函数的导数仍为同周期的周期函数 |
| **高阶导数的莱布尼茨公式** | 乘积函数的高阶导数计算 |


## 📋 总结

> **核心口诀**：奇变偶，偶变奇；求导一次，奇偶交替。

**易记结论**：
- 奇函数 $f(x)$ 的 **一阶导** 为偶函数
- 奇函数 $f(x)$ 的 **$n$ 阶导**：$n$ 偶 $\to$ 偶，$n$ 奇 $\to$ 奇
