# 概率论与数理统计-第30讲：多维随机变量函数的分布

## 核心概念定义
多维随机变量函数的分布是指对于多维随机变量，研究其函数的分布情况。

## 核心公式
```latex
F(x,y) = P\{X_1 \leq x, X_2 \leq y\}
```

## 典型例题
### 例5.7
(1) 求二维随机变量(X,Y)的分布函数，结果用标准正态分布函数φ(x)表示；
(2) 证明随机变量Y服从标准正态分布。

### 解答
(1) 记(X,Y)的分布函数为F(x,y)，则对任意实数x和y，都有
\[ F(x,y) = P\{X_1 \leq x, X_2 \leq y\} \]

通过化归经典形式，可以得到
\[ F(x,y) = P\{X_1 \leq x, X_2 \leq y\} = P\{X_1 \leq x, X_2 \leq y | X_2 = 0\}P\{X_2 = 0\} + P\{X_1 \leq x, X_2 \leq y | X_2 = 1\}P\{X_2 = 1\} \]

由于X_1和X_2相互独立，所以
\[ F(x,y) = P\{X_1 \leq x\}P\{X_2 \leq y\} = \Phi(x)\Phi(y) \]

(2) 由(1)知，Y的分布函数为
\[ F_Y(y) = \lim_{x \to \infty} F(x,y) = \Phi(y) \]

所以Y服从标准正态分布。

## 常见错误
1. 忽略随机变量之间的独立性；
2. 错误地使用分布函数的极限；
3. 在计算分布函数时，未正确处理条件概率。
