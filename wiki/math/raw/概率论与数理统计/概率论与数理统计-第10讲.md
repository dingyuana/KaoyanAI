# 概率论与数理统计-第10讲：随机事件和概率

## 核心概念定义
随机事件是指在随机试验中可能出现也可能不出现的事件。概率是描述随机事件发生可能性的度量。

## 核心公式
```latex
P(A \cup B) = P(A) + P(B) - P(A \cap B)
P(A \cap B) = P(A) + P(B) - P(A \cup B)
P(A \mid B) = \frac{P(A \cap B)}{P(B)}
```

## 典型例题
**例1.1** 在1~100的整数中随机地取一个数，则取到的整数既不能被2整除，又不能被3整除的概率为多少？

**解** 设A为事件“取到的数能被2整除”，B为事件“取到的数能被3整除”，则
```latex
P(A \cup B) = 1 - P(A \cap B) = 1 - \left(\frac{50}{100} + \frac{33}{100} - \frac{16}{100}\right) = \frac{1}{10}
```

**例1.2** 设A,B,C为三个随机事件，且$P(A) = P(B) = P(C) = \frac{1}{4}, P(AB) = 0, P(AC) = P(BC) = \frac{1}{2}$，则A,B,C中恰有一个事件发生的概率为多少？

**解** 应选(D)。
```latex
P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC) = \frac{1}{4} + \frac{1}{4} + \frac{1}{4} - 0 - \frac{1}{2} - \frac{1}{2} + 0 = \frac{1}{4}
```

## 常见错误
1. 忽略事件之间的独立性。
2. 错误地应用概率公式。
3. 在计算概率时，未考虑事件之间的互斥性。
