# 概率论与数理统计-第43讲：统计量及其分布

## 核心概念定义
- 统计量：从样本数据中计算得到的用于估计总体参数的量。
- 抽样分布：统计量的分布称为抽样分布，描述了统计量在多次抽样中的概率分布。

## 核心公式
```latex
\begin{align*}
E(X) &= E(\bar{X}) = \mu \\
D(X) &= D(\bar{X}) = \sigma^2 \\
E(S^2) &= D(S^2) = \sigma^2
\end{align*}
```

## 典型例题
### 例8.1
设随机变量X的概率密度为$f(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}$，其他为0，则X的三阶中心矩$E[(X - E(X))^3] = ?$

**解**：应选(B) 0。

### 例8.2
设$X_1, X_2, \ldots, X_n$（$n > 2$）为独立同分布的随机变量，且均服从正态分布$N(0,1)$，记$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$，$Y = \frac{1}{n} \sum_{i=1}^n (X_i - X_j)$，$j = 1, 2, \ldots, n$，则与$\bar{X}$的协方差$Cov(Y, \bar{X}) = ?$

**解**：应填$\frac{1}{n-1}$。

## 常见错误
1. 忽略样本均值的期望等于总体均值。
2. 忽略样本方差的期望等于总体方差。
3. 错误计算正态分布的上分位数。
4. 错误计算卡方分布的上分位数。
