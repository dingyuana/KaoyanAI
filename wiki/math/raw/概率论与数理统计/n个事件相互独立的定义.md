# n个事件相互独立的定义


**章节**：2026 张宇概率论 9讲(OCR)

**难度**：★★☆☆☆

**标签**：概率论 | 随机事件 | 独立性


## 1. 概念定义

### 1.1 两个事件的独立性

设 $A$、$B$ 为两个事件：

| 关系类型 | 定义条件 |
|---------|---------|
| **相互独立** | $P(AB) = P(A)P(B)$ |
| **相互有利** | $P(AB) > P(A)P(B)$ |
| **相互抑止** | $P(AB) < P(A)P(B)$ |

### 1.2 n个事件的相互独立

设 $A_1, A_2, \ldots, A_n$ 为 $n$ 个事件（$n \geq 2$），如果对其中**任意有限个事件** $A_{i_1}, A_{i_2}, \ldots, A_{i_k}$，都有：

$$P(A_{i_1}A_{i_2}\cdots A_{i_k}) = P(A_{i_1})P(A_{i_2})\cdots P(A_{i_k})$$

则称这 $n$ 个事件**相互独立**。

### 1.3 三个事件的特殊情形（常考）

设 $A_1, A_2, A_3$ 为三个事件，若**同时满足**以下四式，则称三者**相互独立**：

| 编号 | 公式 |
|-----|------|
| ① | $P(A_1A_2) = P(A_1)P(A_2)$ |
| ② | $P(A_1A_3) = P(A_1)P(A_3)$ |
| ③ | $P(A_2A_3) = P(A_2)P(A_3)$ |
| ④ | $P(A_1A_2A_3) = P(A_1)P(A_2)P(A_3)$ |

> ⚠️ **注意**：若只满足①、②、③（仅**两两独立**），则不能称三者相互独立。


## 2. 核心公式

### 2.1 独立事件积的概率

若 $A_1, A_2, \ldots, A_n$ 相互独立，则：

$$\boxed{P(A_1A_2\cdots A_n) = P(A_1)P(A_2)\cdots P(A_n)}$$

### 2.2 独立事件并的概率（重要结论）

若 $A_1, A_2, \ldots, A_n$ 相互独立，则：

$$\boxed{P(A_1 \cup A_2 \cup \cdots \cup A_n) = 1 - P(\overline{A_1})P(\overline{A_2})\cdots P(\overline{A_n}) = 1 - \prod_{i=1}^{n}[1-P(A_i)]}$$

### 2.3 对立事件独立性（重要性质）

> **性质**：将相互独立的事件组中的任何几个事件换成各自的对立事件，所得的新事件组仍相互独立。


## 3. 典型例题

### 例题：验证三个事件的独立性

**题目**：设 $P(A) = 0.5$，$P(B) = 0.5$，$P(C) = 0.25$，已知：
- $P(AB) = 0.25$
- $P(AC) = 0.125$
- $P(BC) = 0.125$
- $P(ABC) = 0.125$

判断 $A$、$B$、$C$ 是否**两两独立**？是否**相互独立**？

**解答**：

**Step 1：验证两两独立**

$$P(A)P(B) = 0.5 \times 0.5 = 0.25 = P(AB) \quad \checkmark$$

$$P(A)P(C) = 0.5 \times 0.25 = 0.125 = P(AC) \quad \checkmark$$

$$P(B)P(C) = 0.5 \times 0.25 = 0.125 = P(BC) \quad \checkmark$$

✅ **结论**：$A$、$B$、$C$ **两两独立**。


**Step 2：验证完全独立**

$$P(A)P(B)P(C) = 0.5 \times 0.5 \times 0.25 = 0.0625$$

$$P(ABC) = 0.125 \neq 0.0625$$

❌ **结论**：$A$、$B$、$C$ **不相互独立**。


**Step 3：计算 $P(A \cup B \cup C)$**

由独立性公式：

$$P(A \cup B \cup C) = 1 - P(\bar{A})P(\bar{B})P(\bar{C})$$

$$= 1 - 0.5 \times 0.5 \times 0.75 = 1 - 0.1875 = 0.8125$$


## 4. 常见错误

| 序号 | 错误类型 | 错误描述 | 正确做法 |
|-----|---------|---------|---------|
| 1 | **混淆独立性层次** | 误认为"两两独立"等价于"相互独立" | 相互独立需满足所有组合条件，包括三事件交集积 |
| 2 | **遗漏验证条件** | 只验证部分条件就下结论 | 必须逐一验证所有公式 |
| 3 | **独立性与互斥混淆** | 认为 $P(AB) = 0$ 即独立 | $P(AB) = 0$ 且 $P(A)P(B) > 0$ 时，反而是"抑止"关系 |
| 4 | **并概率公式误用** | 错误使用 $P(A \cup B) = P(A) + P(B)$ | 独立时应用 $1 - P(\bar{A})P(\bar{B})$ |
| 5 | **忽视前提条件** | 在未确认独立的情况下使用积公式 | 必须先验证独立性条件 |


## 5. 关联知识点

```
n个事件相互独立
    │
    ├──→ 条件概率
    │        P(A|B) = P(AB)/P(B)
    │
    ├──→ 乘法公式
    │        P(AB) = P(A)P(B|A)
    │
    ├──→ 全概率公式
    │        P(B) = ΣP(Aᵢ)P(B|Aᵢ)
    │
    ├──→ 贝叶斯公式
    │        P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / ΣP(Aⱼ)P(B|Aⱼ)
    │
    └──→ max/min 事件概率
             P(max{X,Y} ≤ a)
             P(min{X,Y} ≥ a)
```


## 📝 总结

> **核心要点**：
> 1. **独立**的核心判断标准是 $P(AB) = P(A)P(B)$
> 2. **n个事件独立**需验证**任意有限组合**的积公式
> 3. **两两独立 ≠ 相互独立**（三个事件时需额外验证积公式）
> 4. 独立事件组的**对立事件组仍独立**
