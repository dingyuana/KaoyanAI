# 图的遍历与拓扑排序算法

## 适用场景

图的遍历是解决图相关问题的基础。BFS 适合求最短路径（无权图），DFS 适合检测回路和拓扑排序。

## 方法步骤

### Step 1: 广度优先搜索（BFS）

**特点**：使用队列，按层次访问，类似树的层序遍历。

**步骤**：
1. 访问起始顶点 $v$ 并标记，$v$ 入队
2. 队列非空时循环：
   - 队头顶点出队
   - 访问该顶点的所有未被访问的邻接点，标记并入队

```c
void BFS(Graph G, int v) {
    visit(v);
    visited[v] = true;
    EnQueue(Q, v);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, v);
        for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
            if (!visited[w]) {
                visit(w);
                visited[w] = true;
                EnQueue(Q, w);
            }
    }
}
```

**时间复杂度**：邻接表 $O(N+E)$，邻接矩阵 $O(N^2)$

### Step 2: 深度优先搜索（DFS）

**特点**：使用栈（递归），优先深入，类似树的先序遍历。

**步骤**：
1. 访问起始顶点 $v$ 并标记
2. 从 $v$ 的第一个未被访问的邻接点出发继续 DFS
3. 当不能再深入时，回溯

```c
void DFS(Graph G, int v) {
    visit(v);
    visited[v] = true;
    for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
        if (!visited[w])
            DFS(G, w);
}
```

**时间复杂度**：邻接表 $O(N+E)$，邻接矩阵 $O(N^2)$

### Step 3: BFS 求无权图最短路径

因为 BFS 按路径长度递增的顺序访问顶点，所以首次到达目标顶点时即为最短路径。

```c
void BFS_MinDist(Graph G, int u) {
    // d[i] 记录从 u 到 i 的最短路径长度
    for (int i = 0; i < G.vexnum; i++) d[i] = INF;
    visited[u] = true; d[u] = 0;
    EnQueue(Q, u);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, u);
        for (int w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w))
            if (!visited[w]) {
                visited[w] = true;
                d[w] = d[u] + 1;
                EnQueue(Q, w);
            }
    }
}
```

### Step 4: 拓扑排序

**适用**：有向无环图（DAG）的顶点线性排序。

**步骤**：
1. 从图中选择一个入度为0的顶点输出
2. 从图中删除该顶点及其所有出边
3. 重复1和2，直到所有顶点输出
4. 如果还有顶点未输出，说明图中有环

### Step 5: 关键路径（AOE网）

- 求最早发生时间（从前向后）
- 求最迟发生时间（从后向前）
- 关键路径 = 最早时间=最迟时间的活动
- 关键路径上的活动时间之和 = 整个工程的工期

## 注意事项

1. BFS 用队列，DFS 用栈（递归）
2. 对于非连通图，一次 BFS/DFS 只能访问一个连通分量
3. 拓扑排序可检测有向图中是否存在环
4. 关键路径可能不只一条
