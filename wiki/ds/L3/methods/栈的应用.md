# 栈的应用

## 适用场景

栈的应用主要分为三类：括号匹配、表达式求值和递归转换。考研中重点考察前两种。

## 方法步骤

### 应用1：括号匹配

**场景**：检查表达式中的括号是否成对匹配。

**步骤**：
1. 创建一个空栈
2. 从左到右扫描表达式
3. 遇到左括号（`(`、`[`、`{`）时，压入栈
4. 遇到右括号时：
   - 如果栈为空，匹配失败
   - 弹出栈顶元素，检查是否与当前右括号匹配
   - 如果不匹配，失败
5. 扫描结束后，栈为空则匹配成功，否则失败

```c
bool BracketCheck(char str[], int n) {
    SqStack S;
    InitStack(S);
    for (int i = 0; i < n; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{')
            Push(S, str[i]);
        else {
            if (StackEmpty(S)) return false;
            char top;
            Pop(S, top);
            if (str[i] == ')' && top != '(') return false;
            if (str[i] == ']' && top != '[') return false;
            if (str[i] == '}' && top != '{') return false;
        }
    }
    return StackEmpty(S);
}
```

### 应用2：表达式求值

#### 中缀转后缀（逆波兰）
1. 遇到操作数直接输出
2. 遇到左括号压入栈
3. 遇到右括号，弹出栈中运算符直到左括号
4. 遇到运算符，弹出栈中优先级≥当前运算符的所有运算符，然后将当前运算符压栈
5. 扫描结束后，弹出栈中所有运算符

#### 后缀表达式求值
1. 遇到操作数压栈
2. 遇到运算符，弹出两个操作数运算，结果压栈
3. 扫描结束后，栈中唯一元素即为结果

### 应用3：栈在递归中的应用

递归调用时，系统用栈保存返回地址和局部变量。递归深度受栈空间限制。

## 示例

### 示例1：括号匹配
**题目**：判断 `{[()]()}` 是否匹配。

**解题**：
1. `{` 入栈 → 栈：`{`
2. `[` 入栈 → 栈：`{ [`
3. `(` 入栈 → 栈：`{ [ (`
4. `)` 匹配栈顶 `(` → 弹出 `(` → 栈：`{ [`
5. `]` 匹配栈顶 `[` → 弹出 `[` → 栈：`{`
6. `(` 入栈 → 栈：`{ (`
7. `)` 匹配栈顶 `(` → 弹出 `(` → 栈：`{`
8. `}` 匹配栈顶 `{` → 弹出 `{` → 栈：空
9. 扫描结束，栈空 → 匹配成功

### 示例2：中缀转后缀
中缀 `A + B * C - D` → 后缀 `A B C * + D -`

## 注意事项

1. 括号匹配的栈中只存左括号，右括号用来匹配
2. 中缀转后缀运算符的优先级比较是关键
3. 递归转换为非递归通常需要自己模拟栈
