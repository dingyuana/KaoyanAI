# 串的模式匹配算法

## 适用场景

模式匹配（定位操作）：在主串 $S$ 中找子串 $T$（模式串）第一次出现的位置。考研中主要考察 BF 和 KMP 两种算法。

## 方法步骤

### 算法1：BF算法（暴力匹配）

**步骤**：
1. 主串指针 $i$ 和模式串指针 $j$ 都从1开始
2. 若 $S[i] == T[j]$，$i++,\ j++$
3. 若 $S[i] \neq T[j]$，$i = i - j + 2$（回溯），$j = 1$
4. 若 $j > T.length$，匹配成功，返回 $i - T.length$
5. 若 $i > S.length$，匹配失败

```c
int Index_BF(String S, String T) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) {
            ++i; ++j;
        } else {
            i = i - j + 2;
            j = 1;
        }
    }
    if (j > T.length) return i - T.length;
    else return 0;
}
```

**时间复杂度**：$O(m \times n)$

### 算法2：KMP算法

**步骤**：
1. 计算模式串 $T$ 的 next 数组
2. 主串指针 $i$ 和模式串指针 $j$ 都从1开始
3. 若 $j=0$ 或 $S[i] == T[j]$，$i++,\ j++$
4. 若 $S[i] \neq T[j]$，$j = next[j]$（$i$ 不回溯）
5. 若 $j > T.length$，匹配成功

```c
void get_next(String T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            ++i; ++j;
            next[i] = j;
        } else {
            j = next[j];
        }
    }
}
```

**时间复杂度**：$O(m + n)$

### 算法3：KMP优化（nextval数组）

在 next 数组基础上，如果 $T[next[j]] == T[j]$，则 $nextval[j] = nextval[next[j]]$，进一步减少无用比较。

## 示例

### 示例1：BF算法模拟
**主串**：`ababcabcacbab`，**模式串**：`abcac`

第一趟：
- `a`=`a` → `b`=`b` → `a`≠`c` → 回溯
- 比较3次，失败

...（最终匹配成功，位置6）

### 示例2：计算 next 数组
**模式串**：`abaabc`
- `next[1] = 0`
- `next[2] = 1`
- `next[3] = 1`（"ab"无相同前后缀）
- `next[4] = 2`（"aba"中"a"=前缀"a"）
- `next[5] = 2`（"abaa"中"a"=前缀"a"）
- `next[6] = 3`（"abaab"中"ab"=前缀"ab"）

## 注意事项

1. KMP 算法的核心是**主串指针不回溯**
2. next 数组只与模式串有关，与主串无关
3. 字符串索引通常从1开始（本约定），从0开始需调整算法
4. BF 算法简单但效率低，KMP 高效但复杂

## 失效情况

KMP 算法在模式串无重复字符时，与 BF 算法效率相同（仍需比对但 $i$ 不回溯）。
