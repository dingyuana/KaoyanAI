# 折半查找算法

## 适用场景

折半查找（二分查找）适用于**有序的顺序表**，用于在有序序列中快速定位目标元素。

## 方法步骤

### Step 1: 确定数据结构

折半查找要求：
1. 数据元素**有序**（递增或递减）
2. 采用**顺序存储**（顺序表）

### Step 2: 算法实现

```c
typedef struct {
    ElemType *elem;  // 动态数组基址
    int TableLen;    // 表的长度
} SSTable;

int Binary_Search(SSTable L, ElemType key) {
    int low = 0, high = L.TableLen - 1;
    int mid;
    while (low <= high) {
        mid = (low + high) / 2;  // 取中间位置
        if (L.elem[mid] == key)
            return mid;           // 查找成功
        else if (L.elem[mid] > key)
            high = mid - 1;       // 左边查找
        else
            low = mid + 1;        // 右边查找
    }
    return -1;  // 查找失败
}
```

### Step 3: 判定树分析

折半查找的过程可以用二叉树（判定树）表示：
- 树的根节点对应中间元素
- 左子树对应左半部分
- 右子树对应右半部分

**折半查找的判定树一定是平衡二叉树**（或接近平衡）。

### 复杂度分析

| 指标 | 值 |
|------|-----|
| 平均查找长度 | $O(\log n)$ |
| 最坏情况比较次数 | $\lceil \log_2(n+1) \rceil$ |
| 空间复杂度 | $O(1)$ |

## 示例

### 示例1：折半查找过程

**有序表**：{7, 10, 13, 16, 19, 29, 32, 33, 37, 41, 43}
**查找 key = 13**

1. low=0, high=10, mid=5 → elem[5]=29, 29>13 → high=4
2. low=0, high=4, mid=2 → elem[2]=13, 13==13 → 返回2

比较2次，找到。

### 示例2：查找失败

**查找 key = 11**
1. low=0, high=10, mid=5 → 29>11 → high=4
2. low=0, high=4, mid=2 → 13>11 → high=1
3. low=0, high=1, mid=0 → 7<11 → low=1
4. low=1, high=1, mid=1 → 10<11 → low=2
5. low=2 > high=1 → 查找失败，返回-1

## 注意事项

1. **折半查找仅适用于有序的顺序表** — 链表不行（无法 $O(1)$ 访问中间元素）
2. 判定树是平衡的，查找效率稳定在 $O(\log n)$
3. 查找失败时的比较次数可通过判定树中的失败节点分析
4. 折半插入排序中的"折半"指的是查找插入位置时使用折半查找

## 失效情况

以下情况不适合使用折半查找：
- 链表存储（只能顺序存取）→ 用顺序查找
- 无序数据 → 先排序再查找（如频繁查找可先排序）
- 频繁插入删除的数据集 → 用二叉排序树
