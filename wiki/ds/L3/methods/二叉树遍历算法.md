# 二叉树遍历算法

## 适用场景

二叉树遍历是树结构中最基本的操作，用于访问树中所有节点。考研中涉及：
- 根据遍历序列确定二叉树
- 遍历的递归和非递归实现
- 线索化二叉树的遍历

## 方法步骤

### Step 1: 理解四种遍历方式

| 遍历方式 | 访问顺序 | 递归实现 |
|---------|---------|---------|
| 前序 | 根 → 左 → 右 | 先访问根，再递归左子树，再递归右子树 |
| 中序 | 左 → 根 → 右 | 先递归左子树，再访问根，再递归右子树 |
| 后序 | 左 → 右 → 根 | 先递归左子树，再递归右子树，再访问根 |
| 层序 | 从上至下，从左至右 | 使用队列实现 |

### Step 2: 递归实现

#### 前序遍历
```c
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);          // 访问根节点
        PreOrder(T->lchild); // 递归左子树
        PreOrder(T->rchild); // 递归右子树
    }
}
```

#### 中序遍历
```c
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);
        InOrder(T->rchild);
    }
}
```

#### 后序遍历
```c
void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        visit(T);
    }
}
```

### Step 3: 非递归实现（使用栈）

#### 中序非递归遍历
```c
void InOrder2(BiTree T) {
    SqStack S;
    InitStack(S);
    BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {          // 一直向左走
            Push(S, p);
            p = p->lchild;
        } else {          // 左子树为空，弹出并访问，再转向右子树
            Pop(S, p);
            visit(p);
            p = p->rchild;
        }
    }
}
```

### Step 4: 层序遍历（使用队列）
```c
void LevelOrder(BiTree T) {
    LinkQueue Q;
    InitQueue(Q);
    BiTree p;
    EnQueue(Q, T);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);
        visit(p);
        if (p->lchild != NULL) EnQueue(Q, p->lchild);
        if (p->rchild != NULL) EnQueue(Q, p->rchild);
    }
}
```

### Step 5: 根据遍历序列确定二叉树

| 已知条件 | 能否唯一确定 |
|---------|------------|
| 前序 + 中序 | ✔️ 可以 |
| 后序 + 中序 | ✔️ 可以 |
| 层序 + 中序 | ✔️ 可以 |
| 前序 + 后序 | ❌ 不行 |

**步骤**：
1. 前序/后序确定根节点
2. 中序确定左右子树
3. 递归重复

## 示例

### 示例：根据先序和中序确定二叉树
**先序**：3 1 2 5 4 6
**中序**：1 2 3 4 5 6

1. 先序第一个3是根
2. 中序中3左边 {1,2} 是左子树，右边 {4,5,6} 是右子树
3. 左子树先序 {1,2} + 中序 {1,2} → 1是根，2是右孩子
4. 右子树先序 {5,4,6} + 中序 {4,5,6} → 5是根，4是左孩子，6是右孩子

## 注意事项

1. 前序+后序**不能唯一确定**二叉树
2. 前序序列和中序序列的关系相当于以前序序列为入栈次序，以中序序列为出栈次序
3. 后序遍历可以找到 $m$ 到 $n$ 之间的路径（其中 $m$ 是 $n$ 的祖先）
4. 当先序与后序相反时，二叉树高度 = 节点数（每层只有一个节点）
