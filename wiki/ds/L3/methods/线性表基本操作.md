# 线性表基本操作

## 适用场景

线性表是数据结构中最基本的结构。以下方法适用于考研中涉及线性表的所有操作题：
- 顺序表的插入、删除、查找
- 链表的创建、插入、删除、查找、逆置、合并

## 方法步骤

### Step 1: 确定存储结构
先判断题目使用的是**顺序存储**（顺序表）还是**链式存储**（链表），不同存储结构下操作方法完全不同。

### Step 2: 顺序表的基本操作

#### 插入操作
```c
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1) return false;
    if (L.length >= MaxSize) return false;
    for (int j = L.length; j >= i; j--)
        L.data[j] = L.data[j - 1];
    L.data[i - 1] = e;
    L.length++;
    return true;
}
```
- 时间复杂度：$O(n)$
- 平均移动元素数：$n/2$

#### 删除操作
```c
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    for (int j = i; j < L.length; j++)
        L.data[j - 1] = L.data[j];
    L.length--;
    return true;
}
```
- 时间复杂度：$O(n)$

#### 按值查找
```c
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++)
        if (L.data[i] == e) return i + 1;
    return 0;
}
```
- 时间复杂度：$O(n)$

### Step 3: 链表的基本操作

#### 头插法建立单链表
```c
void HeadInsert(LinkList &L, ElemType arr[], int n) {
    L = (LinkList)malloc(sizeof(LNode));
    L->next = NULL;
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode*)malloc(sizeof(LNode));
        s->data = arr[i];
        s->next = L->next;
        L->next = s;
    }
}
```

#### 尾插法建立单链表
```c
void TailInsert(LinkList &L, ElemType arr[], int n) {
    L = (LinkList)malloc(sizeof(LNode));
    LNode *r = L;
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode*)malloc(sizeof(LNode));
        s->data = arr[i];
        r->next = s;
        r = s;
    }
    r->next = NULL;
}
```

#### 插入操作
```c
// 在 p 节点之后插入 s
s->next = p->next;
p->next = s;
```

#### 删除操作
```c
// 删除 p 的后继节点 q
q = p->next;
p->next = q->next;
free(q);
```

## 示例

### 示例1：顺序表合并
**题目**：将两个有序顺序表合并为一个有序顺序表。

**解题**：
```c
bool Merge(SqList A, SqList B, SqList &C) {
    if (A.length + B.length > MaxSize) return false;
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length) {
        if (A.data[i] <= B.data[j])
            C.data[k++] = A.data[i++];
        else
            C.data[k++] = B.data[j++];
    }
    while (i < A.length) C.data[k++] = A.data[i++];
    while (j < B.length) C.data[k++] = B.data[j++];
    C.length = k;
    return true;
}
```

### 示例2：单链表逆置
**解题**：用头插法重新建立链表即可。
```c
void Reverse(LinkList &L) {
    LNode *p = L->next, *r;
    L->next = NULL;
    while (p != NULL) {
        r = p->next;
        p->next = L->next;
        L->next = p;
        p = r;
    }
}
```

## 注意事项

1. 链表操作中**先连后断** — 插入时先让新节点指向后继，再让前驱指向新节点
2. 顺序表插入删除注意元素移动方向
3. 链表操作注意避免断链（丢失后续节点地址）
4. 头插法会逆序，尾插法保持顺序

## 失效情况

以下情况不适合使用标准方法：
- 单链表中已知插入位置的前驱节点时可以直接插入
- 顺序表在末尾插入无需移动元素（$O(1)$）
- 双链表的插入删除需额外修改 prior 指针
