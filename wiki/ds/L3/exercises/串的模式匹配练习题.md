# 串的模式匹配练习题

## 题目列表

### 题目1：BF算法的时间复杂度分析
**来源**：408常考题型
**难度**：简单
**考点**：BF暴力匹配算法

**题目**：
设主串 S="ababcabcacbab"，模式串 T="abcac"。使用 BF（朴素模式匹配）算法最多需要比较多少次？

**解析**：
BF 算法最坏情况下的时间复杂度为 $O(m \times n)$，其中 $m$ 为主串长度，$n$ 为模式串长度。

本题中：
- 主串 S 长度 $m = 13$
- 模式串 T 长度 $n = 5$

最坏情况下需要比较 $m \times n = 13 \times 5 = 65$ 次。

**答案**：最多需要比较 65 次

**关键点**：BF 算法最坏情况时间复杂度为 $O(mn)$

### 题目2：KMP算法 next 数组计算
**来源**：408真题改编
**难度**：中等
**考点**：KMP next 数组

**题目**：
已知模式串 T="abaabc"，请计算该模式串的 next 数组值。

**解析**：
next 数组定义：
- next[1] = 0（约定）
- next[2] = 1（只有一个字符，前缀为空）
- next[j] = k，表示当模式串中第 j 个字符与主串失配时，模式串应滑到第 k 个位置继续比较

计算过程：
| j | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| T[j] | a | b | a | a | b | c |
| 最大相同前缀后缀长度 | 0 | 0 | 1 | 2 | 1 | 0 |
| next[j] | 0 | 1 | 1 | 2 | 3 | 1 |

- j=3：T[1]=a = T[3]=a，最长相同前后缀为"a"，长度为1，所以 next[3]=1+? 但这里应该是 1+0=1...实际上 next[3] = 1（根据最长前后缀长度+1）
- j=4：T[1..2]="ab" ≠ T[2..3]="ba"，最长相同前后缀为0，所以 next[4]=1
- j=5：T[1..2]="ab" = T[4..5]="ab"，最长相同前后缀为"ab"，长度为2，所以 next[5]=3
- j=6：T[1]="a" ≠ T[6]="c"，最长相同前后缀为0，所以 next[6]=1

重新计算：
- next[1] = 0
- next[2] = 1
- next[3]：T[1]=a = T[3]=a，所以 next[3] = 2
- next[4]：T[1..2]="ab" ≠ T[2..3]="ba"，T[1]=a = T[4]=a，所以 next[4] = 2
- next[5]：T[1..3]="aba" = T[3..5]="abc"？不，next[5]要看 T[1..4] 中前缀后缀是否相同
  - T[1..4]="abaa"，前后缀："a"相同，所以 next[5] = 2
- next[6]：T[1..5]="abaab"，T[1..2]="ab" = T[4..5]="ab"，所以 next[6] = 3

**答案**：next = [0, 1, 2, 2, 2, 3]（下标从1开始）

**关键点**：next 数组表示失配后模式串应跳转到的位置

### 题目3：KMP算法匹配过程
**来源**：408真题
**难度**：中等
**考点**：KMP匹配过程

**题目**：
设主串 S="ababaabab"，模式串 T="abab"。使用 KMP 算法进行匹配，给出匹配过程。

**解析**：
1. 先计算 T 的 next 数组：
   - T="abab"，next = [0, 1, 1, 2]

2. 匹配过程：
   - 第1次：S[1..4]="abab" = T[1..4]，匹配成功！位置为1

实际上我们来看 KMP 的特点：
- i 指针不回溯
- j 根据 next 数组跳转

**答案**：匹配成功，起始位置为1

**关键点**：KMP 的核心是 i 指针不回溯，利用已匹配信息

### 题目4：BF与KMP算法对比
**来源**：408选择题
**难度**：简单
**考点**：两种算法的特点和区别

**题目**：
以下关于模式匹配算法的描述中，错误的是：

A. BF算法最坏情况下时间复杂度为 O(m×n)
B. KMP算法最坏情况下时间复杂度为 O(m×n)
C. KMP算法的空间复杂度为 O(n)（用于存储next数组）
D. BF算法的主串指针在匹配成功前不会减小

**解析**：
A✅ BF算法最坏情况下需要比较 m×n 次
B❌ KMP算法最坏情况下时间复杂度为 O(m+n)
C✅ next数组需要 O(n) 空间
D✅ 主串指针 i 只增不减

**答案**：B

**关键点**：KMP 的时间复杂度是线性的，关键在于 next 数组的利用

### 题目5：KMP算法 nextval 数组
**来源**：408真题
**难度**：困难
**考点**：nextval数组改进

**题目**：
已知模式串 T="aaaab"，求其 nextval 数组（对 next 数组的改进）。

**解析**：
1. 先求 next 数组：
   - T[1..5]="aaaab"
   - next[1]=0, next[2]=1, next[3]=2, next[4]=3, next[5]=4

2. 再求 nextval 数组：
   - nextval[1] = 0（恒为0）
   - nextval[2]：T[2]=a，T[next[2]]=T[1]=a，T[2]==T[1]，所以 nextval[2] = nextval[1] = 0
   - nextval[3]：T[3]=a，T[next[3]]=T[2]=a，T[3]==T[2]，所以 nextval[3] = nextval[2] = 0
   - nextval[4]：T[4]=a，T[next[4]]=T[3]=a，T[4]==T[3]，所以 nextval[4] = nextval[3] = 0
   - nextval[5]：T[5]=b，T[next[5]]=T[4]=a，T[5]≠T[4]，所以 nextval[5] = next[5] = 4

**答案**：nextval = [0, 0, 0, 0, 4]

**关键点**：nextval 的作用是避免模式串中相同字符的无效比较

### 题目6：KMP算法在失配时的移动次数
**来源**：408常考题型
**难度**：困难
**考点**：KMP效率分析

**题目**：
主串 S 长度为 1000，模式串 T 长度为 6。使用 KMP 算法，在最好情况和最坏情况下各需要比较多少次？

**解析**：
- 最好情况：每次模式串第一个字符就失配，需要比较6次，共比较 1000 次（主串每个位置都比较到第一个字符）
- 最坏情况：类似BF，但KMP会跳过一些无效比较

**答案**：
- 最好情况：约 1000 次（O(m+n)）
- 最坏情况：约 1005 次

**关键点**：KMP的最坏情况仍为线性时间
