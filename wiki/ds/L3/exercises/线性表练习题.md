## 题目列表

### 题目1：顺序表插入操作的平均移动次数
**来源**：408常考题型
**难度**：简单
**考点**：顺序表的插入操作

**题目**：
在一个长度为 $n$ 的顺序表中，向第 $i$ 个元素（$1 \leq i \leq n+1$）之前插入一个新元素时需要移动多少个元素？平均移动次数是多少？

**解析**：
1. 在第 $i$ 个位置插入，需要移动 $n-i+1$ 个元素
2. 平均移动次数：$\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}$

**答案**：平均移动 $\frac{n}{2}$ 个元素

**关键点**：顺序表插入操作的时间复杂度为 $O(n)$

### 题目2：判断链表是否有环
**来源**：408真题改编
**难度**：中等
**考点**：链表操作

**题目**：
设计一个算法判断单链表是否有环（即链表的尾节点指向了前面某个节点）。

**解析**：
使用**快慢指针**法：
1. 快指针 `fast` 每次走两步，慢指针 `slow` 每次走一步
2. 如果 `fast == slow`，说明有环
3. 如果 `fast` 或 `fast->next` 为 NULL，说明无环

```c
bool HasCycle(LinkList L) {
    LNode *fast = L->next, *slow = L->next;
    while (fast != NULL && fast->next != NULL) {
        fast = fast->next->next;
        slow = slow->next;
        if (fast == slow) return true;
    }
    return false;
}
```

**答案**：使用快慢指针法

**关键点**：快指针每次两步，慢指针每次一步

### 题目3：两个有序链表合并
**来源**：408常考算法设计题
**难度**：中等
**考点**：链表的合并

**题目**：
将两个递增的有序单链表合并为一个递减的有序单链表，要求使用原链表的节点空间。

**解析**：
1. 使用头插法（头插法可使结果逆序）
2. 同时遍历两个链表，将较小的节点摘下，用头插法插入新链表

**答案**：利用头插法+归并思想

**关键点**：头插法自然产生逆序结果

### 题目4：顺序表与链表的比较
**来源**：408选择题
**难度**：简单
**考点**：线性表存储结构比较

**题目**：
以下关于顺序表和链表的描述中，错误的是：
A. 顺序表支持随机存取，链表只支持顺序存取
B. 顺序表的存储密度高于链表
C. 链表的插入和删除操作不需要移动元素
D. 链表的空间利用率高于顺序表

**解析**：
A✅ 顺序表通过首地址可直接计算元素位置（$O(1)$），链表需遍历（$O(n)$）
B✅ 顺序表只存数据，链表需额外存指针
C✅ 链表只需修改指针
D❌ 链表的指针域占用额外空间，空间利用率并不高于顺序表

**答案**：D

**关键点**：链表的指针占用额外空间，顺序表更省空间
