# 栈与队列练习题

## 题目列表

### 题目1：出栈序列的卡特兰数
**来源**：408常考题型
**难度**：中等
**考点**：栈的数学性质

**题目**：
$n$ 个不同元素进栈，出栈元素共有多少种不同的排列？

**解析**：
出栈序列的不同排列个数为卡特兰数：
$$
\frac{1}{n+1}C_{2n}^{n}
$$
例如 $n=3$ 时，有 $\frac{1}{4} \times 20 = 5$ 种出栈序列。

**答案**：$\frac{1}{n+1}C_{2n}^{n}$

**关键点**：卡特兰数公式

### 题目2：循环队列判空判满
**来源**：408选择题
**难度**：简单
**考点**：循环队列

**题目**：
若用牺牲一个存储单元的方式来区分循环队列的空和满，则队满的条件是：
A. Q.front == Q.rear
B. Q.front == (Q.rear+1) % MaxSize
C. (Q.front+1) % MaxSize == Q.rear
D. Q.rear == MaxSize

**解析**：
牺牲一个存储单元时：
- 队空：`Q.front == Q.rear`
- 队满：`(Q.rear + 1) % MaxSize == Q.front`

**答案**：B

**关键点**：循环队列三个要素：初始值、队空条件、队满条件

### 题目3：栈在括号匹配中的应用
**来源**：408算法设计题
**难度**：中等
**考点**：栈的应用

**题目**：
设计算法检查一个字符串中的括号是否匹配。括号包括圆括号 `()`、方括号 `[]` 和花括号 `{}`。

**解析**：
```c
bool BracketCheck(char str[], int n) {
    SqStack S;
    InitStack(S);
    for (int i = 0; i < n; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{')
            Push(S, str[i]);
        else if (str[i] == ')' || str[i] == ']' || str[i] == '}') {
            if (StackEmpty(S)) return false;
            char top;
            Pop(S, top);
            if (str[i] == ')' && top != '(') return false;
            if (str[i] == ']' && top != '[') return false;
            if (str[i] == '}' && top != '{') return false;
        }
    }
    return StackEmpty(S);
}
```

**答案**：利用栈进行括号匹配

**关键点**：左括号入栈，右括号匹配栈顶

### 题目4：循环队列入队出队过程
**来源**：408常考计算题
**难度**：简单
**考点**：循环队列操作

**题目**：
设循环队列的容量为 8（0~7），初始时 Q.front = Q.rear = 0。
依次执行以下操作后，Q.front 和 Q.rear 的值分别是多少？
操作序列：a入队、b入队、c入队、出队1次、d入队、e入队、出队1次、f入队

**解析**：
1. 初始：front=0, rear=0
2. a入队：rear=1
3. b入队：rear=2
4. c入队：rear=3
5. 出队：front=1
6. d入队：rear=4
7. e入队：rear=5
8. 出队：front=2
9. f入队：rear=6

**答案**：front=2, rear=6

**关键点**：入队 rear 增加，出队 front 增加
