# 树与二叉树练习题

## 题目列表

### 题目1：二叉树叶子节点与度为2的节点关系
**来源**：408真题
**难度**：简单
**考点**：二叉树的性质

**题目**：
一棵有 $n$ 个节点的二叉树中，叶子节点数为 $n_0$，度为2的节点数为 $n_2$，则 $n_0$ 与 $n_2$ 的关系是什么？

**解析**：
根据二叉树的性质：$n_0 = n_2 + 1$
证明：总节点数 $n = n_0 + n_1 + n_2$，总度数 $= 0 \times n_0 + 1 \times n_1 + 2 \times n_2 = n_1 + 2n_2$
又因为总节点数 = 总度数 + 1（根节点无入边）
所以 $n_0 + n_1 + n_2 = n_1 + 2n_2 + 1$
解得 $n_0 = n_2 + 1$

**答案**：$n_0 = n_2 + 1$

**关键点**：这个性质对一切非空二叉树成立

### 题目2：根据遍历序列确定二叉树
**来源**：408真题
**难度**：中等
**考点**：二叉树遍历

**题目**：
已知一棵二叉树的前序遍历序列为 $A \ B \ D \ E \ C \ F$，中序遍历序列为 $D \ B \ E \ A \ F \ C$，请画出这棵二叉树。

**解析**：
1. 前序第一个 $A$ 是根节点
2. 中序中 $A$ 左边 $\{D,B,E\}$ 是左子树，右边 $\{F,C\}$ 是右子树
3. 左子树的前序 $\{B,D,E\}$，中序 $\{D,B,E\}$ → $B$ 是根，$D$ 是左孩子，$E$ 是右孩子
4. 右子树的前序 $\{C,F\}$，中序 $\{F,C\}$ → $C$ 是根，$F$ 是左孩子

**答案**：
```
    A
   / \
  B   C
 / \ /
D  E F
```

**关键点**：前序确定根，中序划分左右子树

### 题目3：哈夫曼树的WPL计算
**来源**：408选择题
**难度**：中等
**考点**：哈夫曼树

**题目**：
已知字符集 $\{a,b,c,d,e\}$ 的出现频率分别为 $\{9, 8, 5, 3, 1\}$，构造哈夫曼树并计算 WPL。

**解析**：
1. 排序：1, 3, 5, 8, 9
2. 合并1+3=4 → {4, 5, 8, 9}
3. 合并4+5=9 → {8, 9, 9}
4. 合并8+9=17 → {9, 17}
5. 合并9+17=26
6. WPL = (1+3)×4 + 5×3 + 8×2 + 9×2 = 16 + 15 + 16 + 18 = 65

**答案**：WPL = 65，哈夫曼树共有 $2 \times 5 - 1 = 9$ 个节点

**关键点**：每次取最小两个值合并

### 题目4：完全二叉树节点数计算
**来源**：408选择题
**难度**：简单
**考点**：完全二叉树

**题目**：
一棵完全二叉树有 768 个节点，求叶子节点数。

**解析**：
最后一个非叶子节点编号 = $\lfloor n/2 \rfloor = 384$
叶子节点数 = $n - \lfloor n/2 \rfloor = 768 - 384 = 384$

**答案**：384个叶子节点

**关键点**：完全二叉树叶子节点数 = $n - \lfloor n/2 \rfloor$

1. $n_0 = n_2 + 1$ 是二叉树最核心的性质，必须熟记

3. 哈夫曼树的构造和WPL计算是常考内容
4. 完全二叉树的编号特性要掌握
