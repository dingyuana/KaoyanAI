# 排序练习题

## 题目列表

### 题目1：排序算法的稳定性判断
**来源**：408选择题
**难度**：简单
**考点**：排序稳定性

**题目**：
以下排序算法中，哪些是稳定的？
A. 快速排序
B. 简单选择排序
C. 归并排序
D. 希尔排序
E. 冒泡排序
F. 堆排序

**解析**：
稳定的排序算法：归并排序、冒泡排序、直接插入排序、基数排序
不稳定的排序算法：快速排序、简单选择排序、堆排序、希尔排序

**答案**：C（归并排序）、E（冒泡排序）

**关键点**：记忆口诀：快选希堆 = 不稳定

### 题目2：快速排序每趟结果
**来源**：408真题
**难度**：中等
**考点**：快速排序

**题目**：
对序列 $\{50, 16, 32, 79, 63, 24, 18, 45\}$ 进行快速排序（以第一个元素为pivot），写出第一趟排序后的结果。

**解析**：
选取 pivot = 50
```
初始：   50  16  32  79  63  24  18  45
从右向左：45<50 → {45}  16  32  79  63  24  18 { }
从左向右：45 { } 16  32  79  63  24  18  50
从右向左：45  16  32 { } 79  63  24  18  50
          ...
最终：   45  16  32  24  18  [50]  79  63
```

**答案**：45, 16, 32, 24, 18, 50, 79, 63

**关键点**：快速排序每趟确定一个元素的最终位置

### 题目3：堆排序建堆过程
**来源**：408真题
**难度**：中等
**考点**：堆排序

**题目**：
对序列 $\{15, 7, 22, 3, 13, 9, 18\}$ 建立大顶堆，写出建堆后的序列。

**解析**：
1. 原始序列对应完全二叉树：
```
       15
     /    \
    7      22
   / \    / \
  3  13  9  18
```
2. 从最后一个非叶子节点开始调整
3. 7 < max(3,13) → 7与13交换
4. 15 < max(13,22) → 15与22交换
5. 15 < max(13,18) → 15与18交换

建堆后：22, 13, 18, 3, 7, 9, 15

**答案**：22, 13, 18, 3, 7, 9, 15

**关键点**：建堆从最后一个非叶子节点开始，自底向上调整

### 题目4：排序算法时间复杂度对比
**来源**：408选择题
**难度**：简单
**考点**：排序算法对比

**题目**：
下列排序算法中，平均时间复杂度为 $O(n\log n)$ 的是：
A. 直接插入排序
B. 冒泡排序
C. 简单选择排序
D. 归并排序

**解析**：
- 直接插入排序：$O(n^2)$
- 冒泡排序：$O(n^2)$
- 简单选择排序：$O(n^2)$
- **归并排序：$O(n\log n)$**

此外，快速排序和堆排序的平均时间复杂度也是 $O(n\log n)$。

**答案**：D

**关键点**：归并、快排、堆排的时间复杂度都是 $O(n\log n)$
