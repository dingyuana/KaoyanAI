# 图练习题

## 题目列表

### 题目1：图的度数之和与边数的关系
**来源**：408选择题
**难度**：简单
**考点**：图的基本概念

**题目**：
若无向图 $G$ 有 15 条边，且各顶点度数之和为 30，则该图有几个顶点？（每个顶点的度数均为 2）

**解析**：无向图的总度数 = 2 × 边数，所以 30 = 2 × 15 ✓
若每个顶点度数均为 2，则顶点数 = 30/2 = 15

**答案**：15个顶点

**关键点**：无向图总度数 = $2e$，有向图总入度 = 总出度 = $e$

### 题目2：图的遍历序列
**来源**：408真题
**难度**：中等
**考点**：BFS和DFS

**题目**：
已知图的邻接表如下：
```
0: → 1 → 2 → 3
1: → 0 → 4
2: → 0 → 4
3: → 0 → 4
4: → 1 → 2 → 3
```
写出从顶点0出发的DFS和BFS遍历序列（邻接点按顺序访问）。

**解析**：
DFS（深度优先）：0 → 1 → 4 → 2 → 3
（0→1→4→2后，4的邻接点还有3未访问，3访问后回溯）

BFS（广度优先）：0 → 1 → 2 → 3 → 4
（0→1→2→3的所有邻接点，4是1的邻接点）

**答案**：DFS: 0,1,4,2,3；BFS: 0,1,2,3,4

**关键点**：DFS用栈思想（递归），BFS用队列思想

### 题目3：最小生成树计算
**来源**：408计算题
**难度**：中等
**考点**：Prim和Kruskal算法

**题目**：
带权无向图有顶点 $\{A,B,C,D,E\}$，边和权值如下：
$AB=3, AC=5, AD=6, BC=4, BD=2, BE=7, CD=8, CE=1, DE=9$
求最小生成树的权值和。

**解析**：
**Kruskal算法**（按权值递增）：
1. CE=1 选 ✓
2. BD=2 选 ✓
3. AB=3 选 ✓
4. BC=4 选 ✓（与BD、AB已连通）
5. AC=5 形成回路，跳过
6. AD=6 选 ✓（连接A-D，所有顶点已连通）

权值和 = 1+2+3+4+6 = 16

**答案**：16

**关键点**：Kruskal按权值递增选择不形成回路的边

### 题目4：拓扑排序
**来源**：408选择题
**难度**：中等
**考点**：拓扑排序

**题目**：
下列哪种图可以进行拓扑排序？拓扑排序的输出结果是否唯一？
A. 有向无环图
B. 有向图
C. 无向图
D. 连通图

**解析**：
- 拓扑排序只适用于**有向无环图（DAG）**
- 如果图中存在环，则无法进行拓扑排序
- 拓扑排序结果不唯一（通常有多个合法序列）

**答案**：A；不唯一

**关键点**：拓扑排序可检测有向图中是否存在环

## 学习建议

1. 掌握图的基本性质：度数、边数、连通性
2. 熟练掌握 BFS 和 DFS 的遍历过程和序列
3. 最小生成树的两种算法（Prim 邻接矩阵 $O(V^2)$，Kruskal 邻接表 $O(E\log E)$）要会手动模拟
4. 拓扑排序的关键是找到入度为0的顶点
