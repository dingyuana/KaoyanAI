# 串的基本概念

## 形式化定义

> 引用自 [[RAW-ds-4串-4.1]]：

**串（字符串）**：由零个或多个字符组成的有限序列。

| 术语 | 说明 |
|------|------|
| **子串** | 串中任意多个连续的字符组成的子序列 |
| **主串** | 包含子串的串 |
| **位置** | 某个字符在串中的序号 |
| **空格串** | 由一个或多个空格组成的串（不是空串） |
| **空串** | 零个字符的串 |

## 存储结构

### 定长顺序存储表示

```c
#define MAXLEN 255
typedef struct {
    char ch[MAXLEN];
    int length;
} SString;
```

### 堆分配存储表示

```c
typedef struct {
    char *ch;
    int length;
} HString;
```

### 块链存储表示

- 类似于线性表的链式存储结构
- 采用链表方式存储串值，其中节点称为"块"
- 最后一个节点占不满时用 `#` 填充

## 基本操作

| 操作 | 说明 |
|------|------|
| `StrAssign(&T, chars)` | 赋值操作 |
| `StrCopy(&T, S)` | 复制操作 |
| `StrEmpty(S)` | 判空操作 |
| `StrCompare(S, T)` | 比较操作 |
| `StrLength(S)` | 求串长 |
| `SubString(&Sub, S, pos, len)` | 求子串 |
| `Concat(&T, S1, S2)` | 串联接 |
| `Index(S, T)` | 定位操作（模式匹配） |
| `ClearString(&S)` | 清空操作 |

## 核心要点

1. 空串与空格串不同：空串长度为0，空格串长度≥1
2. 串的逻辑结构是线性表，每个元素是一个字符
3. 子串的位置从主串的第一个字符开始计数

## 常见考法

### 考法1：串的存储结构选择
- 定长顺序存储：简单但长度受限
- 堆分配存储：灵活，长度可动态变化
- 块链存储：适合大量插入操作

### 考法2：串的基本操作实现
- 串的比较：按字典序比较字符
- 串的连接：注意目标空间是否足够

## 注意事项

1. 串和线性表的区别：串的操作对象是字符，且子串必须是连续的
2. 串的索引通常从1开始（KMP算法约定）
3. 堆分配存储需要手动管理内存释放
