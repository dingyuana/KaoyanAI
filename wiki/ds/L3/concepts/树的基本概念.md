# 树的基本概念

## 形式化定义

> 引用自 [[RAW-ds-5树与二叉树-5.1.1]]：

**树**：树是一种数据结构，它是由 $n$（$n \geq 0$）个有限节点组成一个具有层次关系的集合。

### 树的基本术语

| 术语 | 说明 |
|------|------|
| **根节点** | 树中唯一的没有前驱的节点 |
| **叶子节点** | 度为0的节点 |
| **分支节点** | 度不为0的节点 |
| **节点度** | 一个节点拥有的子树个数 |
| **树的度** | 树中各节点度的最大值 |
| **孩子/双亲** | 节点的子树的根称为该节点的孩子，反之称为双亲 |
| **兄弟** | 同一双亲的孩子之间互为兄弟 |
| **层次** | 根为第1层，其孩子为第2层，依次类推 |
| **深度/高度** | 树中节点的最大层数 |
| **森林** | 互不相交的树的集合 |

### 树的性质

> 引用自 [[RAW-ds-5树与二叉树-5.1.3]]：

1. 树中的节点数等于所有节点的度数加1
2. 度为 $m$ 的树中第 $i$ 层上最多有 $m^{i-1}$ 个节点
3. 高度为 $h$ 的 $m$ 叉树最多有 $(m^h - 1)/(m - 1)$ 个节点
4. 具有 $n$ 个节点的 $m$ 叉树的最小高度为 $\lceil \log_m(n(m-1)+1) \rceil$

### 树的存储结构

| 存储方式 | 说明 |
|---------|------|
| **双亲表示法** | 每个节点存储其双亲的位置 |
| **孩子表示法** | 每个节点存储其所有孩子 |
| **孩子兄弟表示法** | 每个节点存储第一个孩子和右兄弟 |

## 核心要点

1. 树的**度** = 所有节点度的最大值
2. 树是**递归定义**的数据结构
3. 树的深度从根开始计数（根为第1层）

## 常见考法

### 考法1：计算树中的节点数
**解题步骤**：
1. 总节点数 = 各节点度数之和 + 1
2. 叶子节点数 = 总节点数 - 分支节点数

### 考法2：m叉树的最大节点数
- 高度为 $h$ 的 $m$ 叉树最多有 $\frac{m^h-1}{m-1}$ 个节点

## 注意事项

1. 树的深度和高度通常是同一个概念
2. 树中节点数 = 所有节点度数之和 + 1 是基本公式
3. 树的存储结构有双亲、孩子、孩子兄弟三种表示法
