# 图的基本概念

## 形式化定义

> 引用自 [[RAW-ds-6图-6.1]]：

**图**：图由顶点集 $V$ 和边集 $E$ 组成，记为 $G = (V, E)$。

### 常见术语

| 术语 | 定义 |
|------|------|
| **无向图** | 全部由无向边构成的图 |
| **有向图** | 全部由有向边构成的图 |
| **简单图** | 不存在重复边，不存在顶点到自身的边 |
| **多重图** | 两个顶点之间的边数大于1 |
| **完全图** | 完全无向图边数 $\frac{n(n-1)}{2}$，完全有向图边数 $n(n-1)$ |
| **连通图** | 图中任意两个顶点都是连通的（无向图） |
| **强连通图** | 图中任何一对顶点都是强连通的（有向图） |
| **生成树** | 包含图中全部顶点的一个极小连通子图 |
| **稀疏图/稠密图** | 边少的为稀疏图，边多的为稠密图 |

### 常考结论

> 引用自 [[RAW-ds-6图-6.1]]：

- 无向图边数 $\times 2$ = 各顶点度数之和
- 有向图边数 = 各顶点的入度之和 = 各顶点的出度之和
- 一个连通图的生成树是一个极小连通子图，是无环的
- 连通无向图边数至少 $n-1$
- 强连通有向图边数至少 $n$

## 核心要点

1. **度数和边数的关系**：无向图 $2e = \sum \text{degree}$，有向图 $e = \sum \text{indegree} = \sum \text{outdegree}$
2. **连通 vs 强连通**：连通针对无向图，强连通针对有向图
3. **生成树**是极小连通子图（$n-1$ 条边）

## 常见考法

### 考法1：计算图的边数或度数
**解题步骤**：
1. 无向图：边数 $\times 2$ = 各顶点度数之和
2. 有向图：边数 = 入度和 = 出度和

### 考法2：判断连通性
- $n$ 个顶点的连通无向图至少 $n-1$ 条边
- $n$ 个顶点的强连通有向图至少 $n$ 条边

1. 完全图是简单图的一种特殊形式
2. 连通分量是无向图的极大连通子图
3. 强连通分量是有向图的极大连通子图
