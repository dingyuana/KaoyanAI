# 双链表

## 形式化定义

> 引用自 [[RAW-ds-2线性表-2.3.3]]：

**双链表**：在单链表的基础上，每个节点增加一个指向其前驱节点的指针域，形成两个不同方向的链。

### 节点定义

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

## 基本操作

### 插入操作

在节点 `p` 之后插入节点 `s`：

```c
s->next = p->next;
s->prior = p;
if (p->next != NULL)
    p->next->prior = s;
p->next = s;
```

### 删除操作

删除节点 `p` 的后继节点 `q`：

```c
p->next = q->next;
if (q->next != NULL)
    q->next->prior = p;
free(q);
```

## 核心要点

1. **双向遍历**：可从任一节点向前或向后遍历
2. **插入/删除更方便**：无需像单链表那样需知道前驱节点
3. **空间开销更大**：每个节点多一个指针域

## 常见考法

### 考法1：双链表插入操作的指针修改顺序
**解题步骤**：
1. 先处理 `s->next` 和 `s->prior`
2. 再处理 `p->next->prior`（如果存在）
3. 最后修改 `p->next`

### 考法2：双链表与单链表的对比
- 单链表：只能向后遍历，删除需知道前驱节点
- 双链表：可双向遍历，删除操作更灵活

## 注意事项

1. 双链表插入删除时，注意处理边界情况（如 p 是尾节点时 p->next 为 NULL）
2. 双链表插入比单链表多一个指针的修改
