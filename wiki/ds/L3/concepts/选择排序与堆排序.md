# 选择排序与堆排序

## 简单选择排序

### 形式化定义

> 引用自 [[RAW-ds-8排序-8.4]]：

**原理**：每一趟从待排序的数据元素中选择最小（或最大）的一个元素作为首元素，直到所有元素排完为止。

**平均时间复杂度**：$O(n^2)$
**空间复杂度**：$O(1)$
**稳定性**：不稳定

### 代码实现
```c
void SelectSort(int arr[], int n) {
    int i, j, min, temp;
    for (i = 0; i < n - 1; i++) {
        min = i;
        for (j = i + 1; j < n; j++)
            if (arr[j] < arr[min]) min = j;
        if (min != i) {
            temp = arr[i];
            arr[i] = arr[min];
            arr[min] = temp;
        }
    }
}
```

## 堆排序

### 形式化定义

**堆**：具有特殊性质的完全二叉树。
- **大顶堆**：$arr[i] \geq arr[2i+1] \land arr[i] \geq arr[2i+2]$（根最大）
- **小顶堆**：$arr[i] \leq arr[2i+1] \land arr[i] \leq arr[2i+2]$（根最小）

**堆排序基本思想**：
1. 将无序序列构建成一个堆（升序用大顶堆，降序用小顶堆）
2. 将堆顶元素与末尾元素交换，将最大元素"沉"到数组末端
3. 重新调整结构，使其满足堆定义
4. 反复执行调整+交换，直到整个序列有序

**平均时间复杂度**：$O(n \log n)$
**空间复杂度**：$O(1)$
**稳定性**：不稳定

### 建堆过程
> 引用自 [[RAW-ds-8排序-8.4]]：

从序列末尾开始向前遍历，检查每个节点是否满足堆性质。

### 堆的调整规则
- 建大堆：如果某节点值更小，把它两个子节点中更大的一个与该节点置换
- 建小堆：如果某节点值更大，把它两个子节点中更小的一个与该节点置换

## 核心要点

1. **堆排序**是选择排序的改进，利用堆结构实现 $O(\log n)$ 的选择
2. **堆排序是不稳定的**
3. 建堆时间复杂度 $O(n)$，每次调整 $O(\log n)$

## 常见考法

### 考法1：堆排序的建堆过程
**解题步骤**：
1. 按数据序列的层次遍历得到完全二叉树
2. 从最后一个非叶子节点开始向上调整
3. 检查是否满足大顶堆/小顶堆性质

### 考法2：堆的插入和删除
- 插入：将元素放到末尾，向上调整
- 删除：用末尾元素替换堆顶，向下调整

## 注意事项

1. 堆排序建堆和排序是两回事，注意区分
2. 堆排序不稳定是因为堆顶元素与末尾元素交换
3. 如果题说明是"筛选法"或"对序列进行堆排序"，先用层次遍历得完全二叉树再建堆
