# 图的存储结构

## 形式化定义

> 引用自 [[RAW-ds-6图-6.2]]：

图的存储方法主要有四种：邻接矩阵、邻接表、十字链表、邻接多重表。

## 四种存储方式对比

| 存储方式 | 适用图类型 | 空间复杂度 | 特点 |
|---------|-----------|-----------|------|
| **邻接矩阵** | 有向/无向 | $O(n^2)$ | 唯一表示，可随机判断边是否存在 |
| **邻接表** | 有向/无向 | $O(n+e)$ | 不唯一，省空间 |
| **十字链表** | 有向图 | $O(n+e)$ | 易求入度和出度 |
| **邻接多重表** | 无向图 | $O(n+e)$ | 易删除边操作 |

### 常考结论

> 引用自 [[RAW-ds-6图-6.2]]：

- 求有向图节点的入度，必须遍历整个邻接表
- 有向图邻接表中，删除某个顶点的所有边的时间复杂度为 $O(n+e)$
- 一个图的邻接矩阵表示唯一，邻接表表示不唯一

## 图的基本操作

| 操作 | 说明 |
|------|------|
| `Adjacent(G, x, y)` | 判断是否存在边 |
| `Neighbors(G, x)` | 列出与结点x邻接的边 |
| `InsertVertex(G, x)` | 插入顶点x |
| `DeleteVertex(G, x)` | 删除顶点x |
| `AddEdge(G, x, y)` | 添加边 |
| `RemoveEdge(G, x, y)` | 删除边 |
| `NextNeighbor(G, x, y)` | 返回x的下一个邻接点 |

## 核心要点

1. **邻接矩阵唯一**，**邻接表不唯一**（因为链表中节点顺序可变）
2. 稠密图用邻接矩阵，稀疏图用邻接表
3. 十字链表针对有向图，邻接多重表针对无向图

## 常见考法

### 考法1：选择合适的存储结构
- 稠密图：邻接矩阵
- 稀疏图：邻接表
- 需要快速判断边是否存在：邻接矩阵
- 需要分别统计入度和出度：十字链表

### 考法2：邻接表求入度的时间复杂度
**解题步骤**：
1. 邻接表只记录了出边信息
2. 求入度需遍历整个邻接表，时间复杂度 $O(n+e)$

## 注意事项

1. 邻接矩阵表示唯一，但可能浪费空间（对稀疏图）
2. 用邻接表求有向图入度时需遍历所有顶点
3. 图的存储结构决定了图算法的时间复杂度
