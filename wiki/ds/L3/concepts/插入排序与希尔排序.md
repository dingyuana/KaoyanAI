# 插入排序与希尔排序

## 直接插入排序

### 形式化定义

> 引用自 [[RAW-ds-8排序-8.2]]：

**原理**：某节点前是排好序的，节点后是未排序的。未排序数据从后向前一一比较大小并交换数据，边比较边移动元素。

**平均时间复杂度**：$O(n^2)$
**最好情况**：$O(n)$（已有序）
**最坏情况**：$O(n^2)$（逆序）
**空间复杂度**：$O(1)$
**稳定性**：稳定

### 代码实现
```c
void InsertSort(int arr[], int n) {
    int i, j, temp;
    for (i = 1; i < n; i++) {
        temp = arr[i];
        for (j = i - 1; j >= 0 && arr[j] > temp; j--)
            arr[j + 1] = arr[j];
        arr[j + 1] = temp;
    }
}
```

## 折半插入排序

**原理**：先折半查找出元素的待插入位置，然后统一移动待插入位置后的所有元素。

**平均时间复杂度**：$O(n^2)$
**稳定性**：稳定

## 希尔排序

### 形式化定义

**原理**：先将整个待排序序列按增量分割成若干子序列，每个子序列分别进行直接插入排序，然后不断减小增量大小，直到序列有序。

**平均时间复杂度**：$O(n \log_2 n)$
**空间复杂度**：$O(1)$
**稳定性**：不稳定

### 代码实现
```c
void ShellSort(int arr[], int n) {
    int i, j, temp, gap;
    for (gap = n / 2; gap > 0; gap /= 2) {
        for (i = gap; i < n; i++) {
            temp = arr[i];
            for (j = i - gap; j >= 0 && arr[j] > temp; j -= gap)
                arr[j + gap] = arr[j];
            arr[j + gap] = temp;
        }
    }
}
```

## 核心要点

1. **直接插入排序**：稳定，适合基本有序的数据
2. **希尔排序**：不稳定，是插入排序的改进，通过增量分组提高效率
3. 直接插入排序的最好情况是 $O(n)$（已排序）

## 注意事项

1. 直接插入排序是稳定的，希尔排序是不稳定的
2. 希尔排序的增量序列选择影响算法效率
3. 直接插入排序适合数据量小或基本有序的场景
