# 散列表

## 形式化定义

> 引用自 [[RAW-ds-7查找-7.5]]：

**散列表（哈希表）**：根据关键字直接进行访问的数据结构，通过散列函数将关键字映射到表中的位置。

### 两项基本工作
1. **计算位置**：构造散列函数确定关键词存储位置
2. **解决冲突**：应用某种策略解决多个关键词位置相同的问题

### 装填因子

> 引用自 [[RAW-ds-7查找-散列表相关概念]]：

$$
\alpha = \frac{\text{表中记录数} n}{\text{散列表长度} m}
$$

- 散列查找的平均查找长度与装填因子有关，与表长无关
- **冲突是不可避免的**，与装填因子无关
- 冲突发生的概率与装填因子密切相关

### 散列函数构造方法

| 方法 | 说明 |
|------|------|
| 直接定址法 | $H(key) = a \times key + b$ |
| 除留余数法 | $H(key) = key \bmod p$，$p$ 取不大于表长的质数 |
| 数字分析法 | 分析关键字分布，取分布均匀的几位 |
| 平方取中法 | 取关键字的平方值的中间几位 |

### 处理冲突的方法

| 方法 | 说明 |
|------|------|
| **开放地址法** | 一旦冲突，寻找下一个空位（线性探测、平方探测、双散列） |
| **拉链法（链地址法）** | 同义词存储在同一链表中 |

**线性探测法**容易产生"一次聚集"（堆积），因为探测的是相邻单元。

**拉链法**基本不会产生物理意义上的"堆积"。

## 核心要点

1. **ASL 与装填因子有关**，与表长无关
2. 冲突可减少但不可避免
3. 线性探测易产生堆积，拉链法不会
4. **为提高查找效率**：设计冲突少的散列函数 + 处理冲突时避免堆积

## 常见考法

### 考法1：计算平均查找长度 ASL
**解题步骤**：
1. 确定散列函数和冲突处理方法
2. 逐个插入关键字，计算每个关键字查找成功/失败时的比较次数
3. 取平均值

### 考法2：线性探测与拉链法的比较
- 线性探测：易产生堆积，ASL 随堆积增大
- 拉链法：无堆积，开销稳定

## 注意事项

1. 装填因子 $\alpha$ 是固有属性
2. 冲突不可避免，但可通过好的散列函数和处理方法减少影响
3. 拉链法处理冲突时不产生堆积现象
