# 线索二叉树

## 形式化定义

> 引用自 [[RAW-ds-5树与二叉树-5.3.2]]：

**线索二叉树**：在二叉树的链式存储中，利用 $n$ 个节点的 $n+1$ 个空指针域存储指向其前驱或后继节点的指针，这些指针称为"线索"。

### 节点结构

```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;  // 线索标志位
} ThreadNode, *ThreadTree;
```

**标志位含义**：
- `ltag = 0`：`lchild` 指向左孩子；`ltag = 1`：`lchild` 指向前驱
- `rtag = 0`：`rchild` 指向右孩子；`rtag = 1`：`rchild` 指向后继

### 中序线索化过程

通过中序遍历二叉树，在遍历过程中将空指针改为线索。

### 常考结论

> 引用自 [[RAW-ds-5树与二叉树-线索二叉树基本概念和常考点]]：

- 线索二叉树仍然是一种物理结构（存储结构）
- 线索二叉树是一种二叉树的一种存储方式
- 中序线索二叉树可以方便地找到指定节点的前驱和后继

## 核心要点

1. **$n$ 个节点的二叉树有 $n+1$ 个空指针域** — 线索化利用的就是这些空指针
2. **线索化实际上是对二叉树的一次遍历过程**
3. 线索二叉树方便了遍历操作，无需递归或栈

## 常见考法

### 考法1：判断某节点的前驱和后继
**解题步骤**：
1. 看左右标志位 `ltag` 和 `rtag`
2. 如果 `ltag=1`：`lchild` 指向前驱
3. 如果 `rtag=1`：`rchild` 指向后继

### 考法2：中序线索化后的遍历
**解题步骤**：
1. 找到中序遍历的第一个节点（最左下节点）
2. 利用后继线索逐个访问后继节点

## 注意事项

1. 线索化是在遍历过程中进行的，不同遍历顺序产生不同的线索二叉树
2. 前序线索二叉树找前驱、后序线索二叉树找后继较复杂
3. 线索二叉树是存储结构，不是逻辑结构
