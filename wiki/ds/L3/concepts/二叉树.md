# 二叉树

## 形式化定义

> 引用自 [[RAW-ds-5树与二叉树-二叉树的定义]]：

**二叉树**：每个节点最多有两个子树（左子树和右子树）的树结构。二叉树可以是空集，根可以有空的左子树或右子树。

### 五种基本形态
1. 空二叉树
2. 只有一个根节点
3. 根节点只有左子树
4. 根节点只有右子树
5. 根节点既有左子树又有右子树

### 特殊二叉树

| 类型 | 定义 |
|------|------|
| **满二叉树** | 一棵深度为 $k$ 且含有 $2^k-1$ 个节点的二叉树 |
| **完全二叉树** | 深度为 $k$ 的 $n$ 个节点的二叉树，每个节点都与深度为 $k$ 的满二叉树中编号 $1 \sim n$ 的节点一一对应 |

### 二叉树的性质

> 引用自 [[RAW-ds-5树与二叉树-二叉树的性质]]：

1. 非空二叉树上叶子节点数等于度为2的节点数加1：$n_0 = n_2 + 1$
2. 非空二叉树上第 $k$ 层最多有 $2^{k-1}$ 个节点
3. 深度为 $h$ 的二叉树最多有 $2^h-1$ 个节点
4. 具有 $n$ 个节点的完全二叉树深度为 $\lceil \log_2(n+1) \rceil$

## 存储结构

### 顺序存储

```c
typedef struct {
    ElemType data[MaxSize];
    int length;
} SqBiTree;
```

适合满二叉树和完全二叉树，普通二叉树会造成空间浪费。

### 链式存储

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

最常用的存储方式，每个节点包含数据域和两个指针域。

## 遍历方法

| 遍历方式 | 访问顺序 |
|---------|---------|
| 前序遍历 | 根节点 → 左子树 → 右子树 |
| 中序遍历 | 左子树 → 根节点 → 右子树 |
| 后序遍历 | 左子树 → 右子树 → 根节点 |
| 层序遍历 | 从上至下，从左至右 |

## 核心要点

1. $n_0 = n_2 + 1$ 是二叉树最重要的性质
2. 完全二叉树适合顺序存储，普通二叉树适合链式存储
3. 前序+中序、后序+中序、层序+中序都可以唯一确定二叉树，前序+后序不行

## 常见考法

### 考法1：利用 $n_0 = n_2 + 1$ 计算节点数
**解题步骤**：
1. 已知叶子节点数 $n_0$，可求出度为2的节点数 $n_2 = n_0 - 1$
2. 总节点数 $n = n_0 + n_1 + n_2$

### 考法2：根据遍历序列确定二叉树
- 前序确定根，中序确定左右子树
- 后序确定根，中序确定左右子树

### 考法3：前序与后序相反时
- 二叉树高度 = 节点数（每层只有一个节点）

## 注意事项

1. 二叉树的左右子树是有顺序的，不能随意交换
2. 完全二叉树适合用数组存储（顺序存储）
3. 二叉树的节点不一定都有两个孩子（可以为空）
