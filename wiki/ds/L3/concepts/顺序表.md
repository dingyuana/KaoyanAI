# 顺序表

## 形式化定义

> 引用自 [[RAW-ds-2线性表-2.2.1]]：

**顺序表**：用一组地址连续的存储单元依次存储线性表中的数据元素，从而使得逻辑上相邻的两个元素在物理位置上也相邻。

### 特点
- 表中元素的**逻辑顺序与其物理顺序相同**
- **随机访问**：通过首地址和元素序号能在 $O(1)$ 时间内找到指定的元素
- **存储密度高**：每个节点只存储数据元素
- 插入和删除需要移动大量元素

## 存储结构

### 静态分配

```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;
```

数组的大小和空间事先已经固定，一旦空间占满会产生溢出。

### 动态分配

```c
#define InitSize 100
typedef struct {
    ElemType *data;  // 动态数组指针
    int MaxSize, length;
} SeqList;
```

空间在程序执行过程中通过动态存储分配语句分配，空间占满时可开辟更大的存储空间替换原有空间。

### 动态分配语句

```c
// C语言
L.data = (ElemType*)malloc(sizeof(ElemType) * InitSize);

// C++语言
L.data = new ElemType[InitSize];
```

## 基本操作

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按值查找 | $O(n)$ | 需遍历比较 |
| 按位查找 | $O(1)$ | 随机存取 |
| 插入 | $O(n)$ | 需移动后续元素 |
| 删除 | $O(n)$ | 需移动后续元素 |

## 核心要点

1. **随机存取**：$O(1)$ 时间访问任意位置元素 — 这是顺序表最大的优势
2. **插入/删除代价高**：平均需要移动一半的元素
3. **存储密度高**：只存数据，不存指针

## 常见考法

### 考法1：顺序表的插入操作中移动元素的次数
**解题步骤**：
1. 在位置 $i$ 插入，需移动 $n-i+1$ 个元素
2. 平均移动次数为 $n/2$

### 考法2：顺序表与链表的比较
**解题步骤**：
1. 存取方式：顺序表随机存取 vs 链表顺序存取
2. 插入删除：顺序表 $O(n)$ 需移动 vs 链表 $O(1)$ 只改指针

## 注意事项

1. 静态分配空间固定，动态分配可扩容
2. 顺序表逻辑上相邻的元素物理上也相邻
3. 动态分配不是链式存储，仍然是顺序存储结构
