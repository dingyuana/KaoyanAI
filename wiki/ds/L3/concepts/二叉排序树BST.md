# 二叉排序树BST

## 形式化定义

> 引用自 [[RAW-ds-7查找-7.3.1]]：

**二叉排序树（BST）**：一棵二叉树，或者为空，或者满足：
1. 左子树上所有节点的关键字均小于根节点的关键字
2. 右子树上所有节点的关键字均大于根节点的关键字
3. 左、右子树也分别是二叉排序树

### 常考结论

> 引用自 [[RAW-ds-7查找-二叉排序树常考结论]]：

1. 当叶子节点全部在相邻的两层时，深度最小。理想情况为满二叉树：$h = \lceil \log_2 n + 1 \rceil$
2. 当输入序列是有序序列时，构造的 BST 是一支单支树，查找最多需比较 $n$ 次
3. **按中序遍历 BST 得到的序列是一个有序序列**（升序）
4. BST 中关键字值最大的节点右指针一定为空

## 基本操作

### 查找
```c
BSTNode *BST_Search(BiTree T, ElemType key) {
    while (T != NULL && key != T->data) {
        if (key < T->data)
            T = T->lchild;
        else
            T = T->rchild;
    }
    return T;
}
```
时间复杂度：平均 $O(\log n)$，最坏 $O(n)$

### 插入
- 若树为空，新节点作为根节点
- 若树非空，与根节点比较，递归插入左或右子树
- 插入的节点一定是叶子节点

## 核心要点

1. **中序遍历有序** — BST 的核心性质
2. **查找效率**：平衡时 $O(\log n)$，单支树时退化为 $O(n)$
3. 插入的节点总是叶子节点

## 常见考法

### 考法1：给定序列构造 BST
**解题步骤**：
1. 第一个元素为根
2. 后续元素与根比较，小的放左子树，大的放右子树
3. 递归进行

### 考法2：BST 的删除操作
- 叶子节点：直接删除
- 只有一棵子树：用子树替代
- 有两棵子树：用右子树最小节点或左子树最大节点替代

## 注意事项

1. BST 中不允许有两个相同关键字的节点
2. 最坏情况下 BST 退化为单支树，查找效率 $O(n)$
3. 中序遍历 BST 得到的序列是递增有序序列
