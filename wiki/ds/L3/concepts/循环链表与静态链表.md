# 循环链表与静态链表

## 循环链表

### 形式化定义

> 引用自 [[RAW-ds-2线性表-2.3.4]]：

**循环链表**：将单链表或双链表的最后一个节点的指针域由 NULL 改为指向头结点（或第一个节点），形成一个环。

### 循环单链表

- 最后一个节点的 `next` 指针指向头结点（带头结点）或第一个节点（不带头结点）
- 从任一节点出发都能遍历整个链表

### 循环双链表

- 头结点的 `prior` 指针指向尾节点
- 尾节点的 `next` 指针指向头结点

### 常考结论

> 引用自 [[RAW-ds-2线性表-循环链表常考结论]]：

- 在循环单链表中，删除第一个元素的时间复杂度为 $O(1)$
- 带尾指针的循环单链表，合并两个链表的时间复杂度为 $O(1)$

## 静态链表

### 形式化定义

> 引用自 [[RAW-ds-2线性表-2.3.5]]：

**静态链表**：借助数组来描述线性表的链式存储结构，节点由数据域和游标（指针）组成。

### 结构描述

```c
#define MaxSize 50
typedef struct {
    ElemType data;
    int next;  // 游标
} SLinkList[MaxSize];
```

### 特点
- 需要预先分配较大的连续空间
- 插入和删除不需要移动元素，只需修改游标
- 失去了顺序表随机存取的优点

## 核心要点

1. **循环链表**：尾节点指向头结点，判空条件为 `L->next == L`
2. **静态链表**：数组 + 游标实现链式结构，游标 -1 表示表尾
3. 静态链表也属于链式存储，不是顺序存储

## 常见考法

### 考法1：循环链表判空条件
- 带头结点的循环单链表判空：`L->next == L`
- 循环双链表判空：`L->next == L && L->prior == L`

### 考法2：静态链表的本质
- 静态链表用数组实现，但逻辑结构是链式的
- 查找仍需 $O(n)$ 顺着游标遍历

- **前置知识**：[单链表](L3-ds-concept-单链表.md)、[双链表](L3-ds-concept-双链表.md)
- **同层对比**：[顺序表](L3-ds-concept-顺序表.md)

## 注意事项

1. 循环链表的判空条件与普通链表不同
2. 静态链表的游标（数组下标）不是真正的指针，但功能类似
3. 循环链表合并时，带尾指针的操作更方便
