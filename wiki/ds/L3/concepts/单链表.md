# 单链表

## 形式化定义

> 引用自 [[RAW-ds-2线性表-2.3.1]]：

**单链表**：线性表的链式存储，通过一组任意的存储单元来存储线性表中的数据元素，通过"链"建立起数据元素之间的逻辑关系。

### 特点
- 通过指针建立数据元素之间的逻辑关系
- **插入和删除操作不需要移动元素**，只需要修改指针
- **失去顺序表可随机存取的优点**，只能顺序存取

## 存储结构

### 节点定义

```c
typedef struct LNode {
    ElemType data;           // 数据域
    struct LNode *next;      // 指针域
} LNode, *LinkList;
```

### 头结点与头指针

| 概念 | 说明 |
|------|------|
| **头指针** | 始终指向链表的第一个节点 |
| **头结点** | 带头结点链表的第一个节点，通常不存储信息 |

### 引入头结点的优点

1. 插入和删除算法统一，不再需要判断是否在第一个元素之前操作
2. 空表和非空表的处理统一，空表时头指针指向头节点

## 基本操作

### 按序号查找
```c
LNode *GetElem(LinkList L, int i) {
    int j = 1;
    LNode *p = L->next;
    if (i == 0) return L;
    if (i < 1) return NULL;
    while (p && j < i) {
        p = p->next;
        j++;
    }
    return p;
}
```

### 按值查找
```c
LNode *LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;
    while (p && p->data != e)
        p = p->next;
    return p;
}
```

### 插入操作
```c
p = GetElem(L, i-1);
s->next = p->next;
p->next = s;
```

### 删除操作
```c
p = GetElem(L, i-1);
q = p->next;
p->next = q->next;
free(q);
```

### 头插法建立单链表
```c
s->next = L->next;
L->next = s;  // 新节点插入到头结点之后
```

### 尾插法建立单链表
```c
r->next = s;
r = s;  // r始终指向尾节点
```

## 核心要点

1. **顺序存取**：查找第 $i$ 个元素需要 $O(n)$ 时间
2. **插入删除高效**：已知位置时只需 $O(1)$ 时间修改指针
3. **头插法建表使数据逆序**，尾插法保持原序

## 常见考法

### 考法1：单链表插入/删除时指针修改顺序
**解题步骤**：
1. 插入时，先连后断（先让新节点指向后继节点，再让前驱节点指向新节点）
2. 删除时，先记录要删除的节点，再修改指针跳过它，最后 free

### 考法2：头插法的应用（链表逆置）
**解题步骤**：
1. 将原链表依次取出，用头插法插入新链表
2. 得到的链表即为原链表的逆序

## 注意事项

1. 头结点不是必须的，但推荐使用以统一操作
2. 链表操作中，p->next 的值随指针 p 的变化而变化
3. 注意区分带头结点和不带头结点的链表操作差异
