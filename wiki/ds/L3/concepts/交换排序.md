# 交换排序

## 冒泡排序

### 形式化定义

> 引用自 [[RAW-ds-8排序-8.3]]：

**原理**：
1. 比较相邻的元素，如果第一个比第二个大，就交换
2. 对每一对相邻元素做同样的工作，直到最后一对
3. 最后的元素会是最大的数
4. 重复以上步骤，直到排序完成

**平均时间复杂度**：$O(n^2)$
**最好情况**：$O(n)$（已有序）
**空间复杂度**：$O(1)$
**稳定性**：稳定

### 代码实现
```c
void BubbleSort(int arr[], int n) {
    int i, j, temp;
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

## 快速排序

### 形式化定义

**原理**（分治策略）：
1. 选择基准元素（pivot）
2. 将序列分割成两部分，左边 < pivot，右边 > pivot
3. 递归地对左右两部分进行快速排序

**平均时间复杂度**：$O(n \log n)$
**最坏情况**：$O(n^2)$（已有序）
**空间复杂度**：$O(\log n)$（递归栈）
**稳定性**：不稳定

### 代码实现
```c
int Partition(int arr[], int low, int high) {
    int pivot = arr[low];
    while (low < high) {
        while (low < high && arr[high] >= pivot) high--;
        arr[low] = arr[high];
        while (low < high && arr[low] <= pivot) low++;
        arr[high] = arr[low];
    }
    arr[low] = pivot;
    return low;
}

void QuickSort(int arr[], int low, int high) {
    if (low < high) {
        int pivotPos = Partition(arr, low, high);
        QuickSort(arr, low, pivotPos - 1);
        QuickSort(arr, pivotPos + 1, high);
    }
}
```

## 核心要点

1. **冒泡排序**：每趟确定一个最大元素，稳定
2. **快速排序**：基于分治，平均最快的内排序
3. 快速排序的空间复杂度 $O(\log n)$ 来自递归调用栈

## 常见考法

### 考法1：快速排序的 pivot 选择影响
- 选择第一个元素为 pivot：已有序时退化为 $O(n^2)$
- 优化：三数取中法

### 考法2：快速排序每趟结果
**解题步骤**：
1. 选取 pivot（通常选第一个元素）
2. 从两端向中间扫描交换
3. 确定 pivot 的最终位置

## 注意事项

1. 快速排序最坏情况 $O(n^2)$ 当每次选的 pivot 都是最小值或最大值
2. 快速排序是不稳定的（元素交换可能改变相对顺序）
3. 快速排序的平均性能优于归并排序和堆排序
