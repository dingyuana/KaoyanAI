# 栈

## 形式化定义

> 引用自 [[RAW-ds-3栈队列和数组-3.1.1]]：

**栈**：只允许在一端进行插入或删除操作的线性表，是一种操作受限的线性表。

| 术语 | 说明 |
|------|------|
| **栈顶** | 允许进行插入删除操作的一端 |
| **栈底** | 固定的，不允许进行插入删除的一端 |
| **操作特性** | 后进先出（LIFO, Last In First Out） |

**数学性质**：$n$ 个不同元素进栈，出栈元素的不同排列的个数为卡特兰数：
$$
\frac{1}{n+1}C_{2n}^{n}
$$

## 存储结构

### 顺序栈

```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int top;  // 栈顶指针
} SqStack;
```

**基本操作**：| 操作 | 说明 |
|------|------|
| `InitStack(&S)` | 初始化栈，S.top = -1 |
| `StackEmpty(S)` | 判栈空，返回 S.top == -1 |
| `Push(&S, x)` | 进栈，S.data[++S.top] = x |
| `Pop(&S, &x)` | 出栈，x = S.data[S.top--] |
| `GetTop(S, &x)` | 读栈顶元素，x = S.data[S.top] |

### 共享栈

```c
typedef struct {
    ElemType data[MaxSize];
    int top0;  // 0号栈栈顶指针
    int top1;  // 1号栈栈顶指针
} ShStack;
```

两个栈共享同一段存储空间，top0 = -1 时 0 号栈为空，top1 = MaxSize 时 1 号栈为空。判满条件为 `top0 + 1 == top1`。

### 链栈

采用单链表实现，头指针作为栈顶指针，所有操作在表头进行。

## 基本操作复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 进栈 | $O(1)$ |
| 出栈 | $O(1)$ |
| 读取栈顶 | $O(1)$ |
| 判空 | $O(1)$ |

## 核心要点

1. **后进先出**是栈的核心特性
2. 卡特兰数用于计算 $n$ 个元素进栈的出栈序列数
3. 共享栈能更有效地利用存储空间，两个栈从两端向中间增长

## 常见考法

### 考法1：判断出栈序列的合法性
**解题步骤**：
1. 模拟进栈和出栈过程
2. 使用卡特兰数公式计算可能的排列数

### 考法2：共享栈判满条件
- 当 `top0 + 1 == top1` 时，共享栈满

## 注意事项

1. 栈也是一种线性表，只是操作受限（只在一端操作）
2. 栈的数学性质（卡特兰数）常考选择题
3. 共享栈判空：top0 = -1 且 top1 = MaxSize 时两个栈都为空
