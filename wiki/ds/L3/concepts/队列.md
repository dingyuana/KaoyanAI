# 队列

## 形式化定义

> 引用自 [[RAW-ds-3栈队列和数组-3.2.1]]：

**队列**：操作受限的线性表，只允许在一端插入（队尾），在另一端删除（队头）。

| 术语 | 说明 |
|------|------|
| **队头** | 允许删除的一端 |
| **队尾** | 允许插入的一端 |
| **操作特性** | 先进先出（FIFO, First In First Out） |

## 存储结构

### 顺序队列

```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int front, rear;  // 队头指针和队尾指针
} SqQueue;
```

**假溢出问题**：`rear == MaxSize` 时队列不一定是满的（前面可能有空位）。

### 循环队列

为解决假溢出，将顺序队列视为环形空间。

```c
// 循环队列判空：Q.front == Q.rear
// 循环队列入队：Q.rear = (Q.rear + 1) % MaxSize
// 循环队列出队：Q.front = (Q.front + 1) % MaxSize
```

**区分队空和队满的三种方法**：
1. 牺牲一个存储单元：队满条件 `(Q.rear + 1) % MaxSize == Q.front`
2. 增加 `size` 字段记录元素个数
3. 增加 `tag` 字段标记最近操作类型

### 链式队列

```c
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;

typedef struct {
    LinkNode *front, *rear;  // 队头队尾指针
} LinkQueue;
```

## 基本操作

| 操作 | 说明 |
|------|------|
| `InitQueue(&Q)` | 初始化队列，Q.front = Q.rear = 0 |
| `QueueEmpty(Q)` | 判队空，返回 Q.front == Q.rear |
| `EnQueue(&Q, x)` | 入队，Q.rear = (Q.rear+1)%MaxSize |
| `DeQueue(&Q, &x)` | 出队，Q.front = (Q.front+1)%MaxSize |
| `GetHead(Q, &x)` | 读队头元素 |

## 双端队列

> 引用自 [[RAW-ds-3栈队列和数组-3.2.4]]：

双端队列允许两端都可以进行插入和删除操作，是栈和队列的推广。

## 核心要点

1. **先进先出**是队列的核心特性（与栈相反）
2. **循环队列**解决了顺序队列的假溢出问题
3. 链式队列不会溢出，适合无法预估队列长度的场景

## 常见考法

### 考法1：循环队列中元素个数的计算
**公式**：元素个数 = `(Q.rear - Q.front + MaxSize) % MaxSize`

### 考法2：区分队空和队满
**解题步骤**：
1. 牺牲一个单元法：`(Q.rear+1) % MaxSize == Q.front` 表示队满
2. 增加 `size` 法：`size == MaxSize` 表示队满

## 注意事项

1. 循环队列的判空条件为 `Q.front == Q.rear`，但队满也可能是此条件（需用其他方式区分）
2. 链式队列中，rear 指针始终指向尾节点
3. 双端队列可以模拟栈（两端都禁止一端操作时）和普通队列（一端仅插入，另一端仅删除）
