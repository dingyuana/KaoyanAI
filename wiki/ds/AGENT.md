# AGENT.md - 数据结构学科 AI 约束

> 本文件定义AI在操作数据结构知识库时的行为规范和约束条件。
> 通用约束请参阅 `../WIKI_SCHEMA.md`。

---

## 一、AI 操作原则

### 1.1 知识生成规则

1. **忠实原文**：L1 层不得修改、总结、纠错原文内容
2. **三层架构**：严格遵循 L1→L2→L3 的知识加工流程
3. **类型分离**：概念、方法、习题必须分离到对应目录
4. **格式统一**：严格遵循 SCHEMA.md 定义的格式规范

### 1.2 算法描述规范

1. **伪代码优先**：算法描述优先使用伪代码
2. **复杂度必含**：每个算法必须标注时间复杂度和空间复杂度
3. **代码语言**：优先使用 C/C++ 实现示例

### 1.3 数据结构表示

1. **逻辑结构**：描述数据元素之间的逻辑关系
2. **存储结构**：描述数据在计算机中的存储方式
3. **基本操作**：描述接口定义和操作实现

---

## 二、L1 处理规则

### 2.1 Chunk 拆分标准

- 一个数据结构定义 = 一个 Chunk
- 一个算法 = 一个 Chunk
- 一道例题 = 一个 Chunk
- 一个图示说明 = 一个 Chunk

### 2.2 锚点生成规则

```
RAW-ds-{章节名}-{序号}
示例：RAW-ds-5树与二叉树-P001-C01
```

---

## 三、L3 生成规则

### 3.1 概念文档

- 必须包含：形式化定义、逻辑结构、存储结构、基本操作
- 可选包含：典型应用、关联知识点

### 3.2 方法文档

- 必须包含：适用场景、算法步骤、示例、复杂度分析
- 可选包含：失效情况、替代方法

### 3.3 习题文档

- 必须包含：题目、解析、答案
- 可选包含：考点分析、关键点

---

## 四、禁止行为

1. ❌ 不得在 L1 层修改原文内容
2. ❌ 不得将不同题型混为一个 Chunk
3. ❌ 不得省略算法复杂度分析
4. ❌ 不得将概念和方法混在同一文档
5. ❌ 不得跨章节引用不存在的锚点
