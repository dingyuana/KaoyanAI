# 内存管理概念

## 形式化定义

> 引用自 RAW-os-3内存管理-3.1.1：

**内存管理**是操作系统对内存的划分和动态分配。其目的是更好地支持多道程序并发执行、方便用户、提高内存利用率。

## 直观解释

内存管理就是操作系统当"房东"：把有限的内存空间合理分配给各个进程（租客），确保每个租客有自己的空间不互相干扰，并在空间不够时想办法"扩容"（虚拟内存）。

## 核心要点

### 1. 内存管理的功能

1. **内存空间的分配与回收**：为进程分配内存空间，回收释放的空间
2. **地址转换**：将逻辑地址转换为物理地址
3. **内存空间的扩充**：虚拟内存技术
4. **存储保护**：确保每个进程有独立的内存空间

### 2. 逻辑地址 vs 物理地址

| 概念 | 定义 |
|------|------|
| **逻辑地址** | 从0号单元开始编址，不同进程可以有相同的逻辑地址 |
| **物理地址** | 内存中物理单元的集合，是地址转换的最终地址 |
| **地址重定位** | 将逻辑地址转换为物理地址的过程 |

### 3. 程序的链接与装入

| 阶段 | 说明 | 分类 |
|------|------|------|
| **编译** | 将源代码编译成目标模块 | - |
| **链接** | 将目标模块和库函数链接成装入模块 | 静态链接、动态链接、运行时动态链接 |
| **装入** | 将装入模块装入内存运行 | 静态装入、可重定位装入、动态重定位装入 |

### 4. 内存保护方法

| 方法 | 说明 |
|------|------|
| **上下限寄存器** | 设置一对上下限寄存器，判断地址是否越界 |
| **重定位+界地址寄存器** | 重定位寄存器（基地址，用于"加"），界地址寄存器（逻辑最大值，用于"比"） |

**公式**：逻辑地址 + 重定位寄存器的值 = 物理地址

### 5. 进程的内存映像

进程在内存中的组成要素：代码段、数据段（全局变量）、堆（动态分配）、栈（局部变量、函数调用）、PCB。

## 常见考法

### 考法1：地址转换
**题目**：程序执行时，CPU访问的地址是逻辑地址还是物理地址？

**解析**：程序运行时，CPU看到和使用的是**逻辑地址**。CPU发出逻辑地址，由MMU（内存管理单元）将其转换为物理地址后访问内存。

### 考法2：内存保护
**题目**：重定位寄存器和界地址寄存器分别用于？

**解析**：重定位寄存器存最小的物理地址（基地址），用于加法运算；界地址寄存器存逻辑地址的最大值，用于比较是否越界。

## 注意事项

1. 不同进程的相同逻辑地址映射到内存中不同位置
2. 纯代码（可重入代码）可以共享，不属于临界资源
3. 内存共享通过段共享、共享内存、内存映射文件实现
