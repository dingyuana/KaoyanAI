# 分页存储管理

## 形式化定义

> 引用自 RAW-os-3内存管理-3.1.3：

**分页存储管理**将进程的逻辑地址空间划分为大小相等的**页**（Page），将物理内存空间划分为与页大小相等的**页框/页帧**（Page Frame）。通过**页表**实现逻辑地址到物理地址的映射。

## 直观解释

分页就好比把一本书（进程）拆成很多页（逻辑页），图书馆（内存）有许多空位（页框）。书的每一页可以放在图书馆的任意空位，通过"索引表"（页表）可以快速找到每页在哪。

## 核心要点

### 1. 基本概念

| 概念 | 说明 |
|------|------|
| **页（页面）** | 逻辑地址空间的划分单位 |
| **页框（页帧）** | 物理地址空间的划分单位 |
| **页表** | 记录逻辑页号与物理页框号的映射关系 |
| **页面大小** | 一般4KB（由系统决定） |

### 2. 地址变换

#### 基本地址变换
```
逻辑地址 → 切分为 [页号 | 页内偏移量]
                    ↓
              查询页表 → 物理页框号
                    ↓
物理地址 = 物理页框号 × 页面大小 + 页内偏移量
```

#### 具有快表（TLB）的地址变换
1. CPU给出逻辑地址，先查询TLB（快表）
2. TLB命中：直接获得物理页框号（1次内存访问）
3. TLB未命中：查询内存中的页表（2次内存访问）
4. 同时更新TLB

### 3. 特点

| 优点 | 缺点 |
|------|------|
| 无外部碎片 | 有内部碎片（平均每个进程半页的碎片） |
| 离散分配，内存利用率高 | 页表占用内存空间大 |
| 易于管理 | 多级页表增加了时间开销 |

### 4. 多级页表

为解决页表过大的问题，采用多级页表：
- **一级页表**：覆盖全部虚拟地址空间
- **二级页表**：在需要时创建，避免存储无用的页表项
- **页表寄存器**：存放一级页表起始物理地址

## 常见考法

### 考法1：地址转换计算
**题目**：某计算机页面大小为4KB（4096B），逻辑地址为8192（十进制），页表项中对应页框号为3，求物理地址。

**解析**：
- 页号 = 8192 ÷ 4096 = 2
- 页内偏移量 = 8192 mod 4096 = 0
- 物理地址 = 3 × 4096 + 0 = 12288

### 考法2：TLB命中与未命中
**题目**：引入TLB后，一次地址访问需要几次内存访问？

**解析**：TLB命中时：1次（TLB在CPU芯片中，不访问内存）。TLB未命中时：2次（先查内存中的页表，再访问目标物理内存地址）。

## 注意事项

1. 分页是**系统行为**，对用户透明
2. 快表（TLB）位于CPU芯片中，是**相联存储器**
3. MMU（内存管理单元）完成地址转换和TLB访问
4. 分页没有外部碎片，但有内部碎片
