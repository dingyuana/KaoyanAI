# 进程调度

## 形式化定义

> 引用自 RAW-os-2进程与线程-2.2.1：

**调度**是从就绪队列中选择一个进程/线程，分配CPU使其运行的过程。调度的目标是提高CPU利用率、系统吞吐量，并保证公平性和响应时间。

## 直观解释

调度就像图书馆只有一个座位，管理员（调度器）决定谁先坐（运行）、谁排队等（就绪）。管理员需要考虑谁等得最久、谁很快就能做完、谁最紧急等因素。

## 核心要点

### 1. 调度层次

| 调度类型 | 发生位置 | 频率 | 说明 |
|----------|----------|------|------|
| **高级调度（作业调度）** | 外存→内存 | 低 | 决定哪些作业调入内存 |
| **中级调度（内存调度）** | 内存↔外存 | 中 | 实现进程对换 |
| **低级调度（进程调度）** | CPU分配 | 最高 | 选择就绪进程占用CPU |

### 2. 调度方式

| 方式 | 说明 | 特点 |
|------|------|------|
| **非抢占式** | 进程获得CPU后运行直到完成或阻塞 | 实现简单，响应时间差 |
| **抢占式** | 进程可被更高优先级的进程中断 | 响应好，但开销大 |

### 3. 调度常用指标

| 指标 | 定义 |
|------|------|
| **CPU利用率** | CPU忙碌时间/总时间 |
| **系统吞吐量** | 单位时间内完成的作业数 |
| **周转时间** | 作业完成时间 - 作业提交时间 |
| **平均周转时间** | 各作业周转时间之和/作业数 |
| **带权周转时间** | 周转时间/实际运行时间 |
| **等待时间** | 进程在就绪队列中等待的时间总和 |
| **响应时间** | 作业提交到首次运行的时间间隔 |

### 4. 调度算法一览

| 算法 | 抢占性 | 特点 |
|------|--------|------|
| FCFS | 非抢占 | 公平，利于长作业 |
| SJF | 可抢占 | 平均等待时间最少，长作业可能饥饿 |
| 高响应比优先 | 非抢占 | 兼顾长短作业，无饥饿 |
| 时间片轮转 | 抢占 | 分时系统，响应好 |
| 优先级调度 | 可抢占/非抢占 | 分静态优先级和动态优先级 |
| 多级反馈队列 | 抢占 | 综合性能好，通用性强 |

## 常见考法

### 考法1：调度指标计算
**题目**：有3个作业A(8:00到达，运行1h)、B(8:10到达，运行0.5h)、C(8:20到达，运行0.2h)，采用FCFS调度，求平均周转时间。

**解析**：
- A完成时间：9:00，周转时间=1h
- B完成时间：9:30，周转时间=1h20min
- C完成时间：9:42，周转时间=1h22min
- 平均周转时间=(1+1.33+1.37)/3≈1.23h

### 考法2：调度层次区分
**题目**：从就绪队列中选择进程分配CPU属于什么调度？

A. 高级调度 B. 中级调度 C. 低级调度 D. 作业调度

**解析**：低级调度（进程调度）就是从就绪队列选进程分配CPU。高级调度=作业调度，中级调度=内存调度。

**答案**：C

## 注意事项

1. 低级调度（进程调度）是最基本的调度，频率最高
2. 周转时间 = 完成时间 - 提交时间
3. 带权周转时间 = 周转时间/运行时间（值越接近1越好）
