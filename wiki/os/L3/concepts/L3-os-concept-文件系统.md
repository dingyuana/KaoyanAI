# 文件系统

## 形式化定义

> 引用自 RAW-os-4文件管理-4.1.1：

**文件**是以硬盘为载体的存储在计算机上的信息集合，是用户输入输出的基本单位。**文件系统**是操作系统中负责管理和存储文件信息的功能模块。

## 直观解释

文件系统就像图书馆的管理系统：每本书（文件）有编号、位置、借阅权限等信息（元数据），书架（磁盘）上的书按照一定规则摆放（存储结构），读者（用户/程序）通过书名或编号（文件名/路径）找到想要的书。

## 核心要点

### 1. 文件的属性（元数据）

| 属性 | 说明 |
|------|------|
| 文件名 | 用户识别的符号名称 |
| 类型 | 文件格式（.txt, .exe等） |
| 位置 | 文件在外存中的存放位置 |
| 大小 | 文件当前大小 |
| 保护 | 访问权限控制 |
| 创建者/所有者 | 文件的创建者和归属用户 |
| 创建时间/修改时间 | 时间戳信息 |

### 2. 文件系统层次结构

| 层次 | 功能 |
|------|------|
| **I/O控制** | 读写磁盘物理块，设备驱动程序 |
| **基本文件系统** | 发送通用命令，管理内存缓冲区 |
| **文件组织模块** | 组织文件的逻辑块和物理块映射，管理空闲空间 |
| **逻辑文件系统** | 管理元数据、目录结构、文件保护 |

### 3. 文件控制块（FCB）

FCB是文件存在的标志，包含文件的基本信息。多个FCB构成**文件目录**。

### 4. 虚拟文件系统（VFS）

VFS为不同文件系统提供统一接口，使用户无需关心底层文件系统的实现差异。

### 5. 文件操作

| 操作 | 说明 |
|------|------|
| 创建 | 在目录中创建FCB，分配磁盘空间 |
| 打开 | 将FCB从外存复制到内存打开文件表 |
| 读/写 | 通过文件指针读写数据 |
| 关闭 | 删除内存中的FCB副本 |
| 删除 | 释放文件占用的磁盘空间 |

## 常见考法

### 考法1：文件打开操作
**题目**：文件"打开"操作的主要目的是什么？

**解析**：将FCB从外存复制到内存中的打开文件表，建立用户与文件的联系，加快后续文件访问速度。

### 考法2：VFS的作用
**题目**：虚拟文件系统（VFS）的主要作用是什么？

**解析**：VFS为不同文件系统（如ext4、NTFS、FAT32）提供统一的编程接口，屏蔽底层差异。用户程序通过VFS接口访问文件，无需关心具体文件系统的实现。

## 注意事项

1. 文件是**用户**视角的数据组织方式
2. 文件系统在磁盘中的结构包括：MBR、引导块、超级块、空闲空间管理、inode、根目录等
3. 打开文件表分为系统级和进程级两级
