# 进程

## 形式化定义

> 引用自 RAW-os-2进程与线程-2.1.1：

**进程**是程序的一次执行过程，是系统进行**资源分配和调度的一个独立单位**。引入进程的目的是使多道程序并发执行，提高资源利用率和系统吞吐量。

## 直观解释

进程就是一个"正在运行的程序实例"。程序是存储在磁盘上的静态代码，进程是程序在内存中"活起来"的动态执行过程。每个进程都有独立的资源（地址空间、打开的文件等），就像一个独立的"工作间"。

## 核心要点

### 1. 进程的特征

| 特征 | 说明 |
|------|------|
| **动态性** | 进程有生命周期（创建→运行→终止） |
| **并发性** | 多个进程可并发执行 |
| **独立性** | 进程是资源分配和调度的独立单位 |
| **异步性** | 进程以不可预知的速度推进 |

### 2. 进程控制块（PCB）

PCB是进程存在的唯一标识，包含：
- 进程标识符（PID）
- 处理器状态信息（通用寄存器、PC、PSW等）
- 进程调度信息（状态、优先级等）
- 进程控制信息（程序和数据地址、资源清单等）

### 3. 五状态模型

```
         ┌─────────────────────────────────────┐
         │          创建 → 就绪 ←── 阻塞       │
         │          ↓         ↕       ↑        │
         │         运行 ─────→ 终止             │
         └─────────────────────────────────────┘
```

| 状态 | 说明 |
|------|------|
| **运行态** | 进程正在CPU上运行 |
| **就绪态** | 进程已具备运行条件，等待CPU |
| **阻塞态** | 进程因等待某事件而暂停 |
| **创建态** | 进程正在被创建 |
| **终止态** | 进程正在被撤销 |

### 4. 状态转换

| 转换 | 触发条件 |
|------|----------|
| 就绪→运行 | 进程被调度程序选中 |
| 运行→就绪 | 时间片到、被高优先级进程抢占 |
| 运行→阻塞 | 等待资源（如I/O请求） |
| 阻塞→就绪 | 资源获得（如I/O完成） |

## 常见考法

### 考法1：进程基本特征
**题目**：下列哪个不是进程的特征？
A. 动态性 B. 共享性 C. 并发性 D. 异步性

**解析**：共享性是操作系统的特征，不是进程的特征。进程的特征是动态性、并发性、独立性、异步性。

**答案**：B

### 考法2：状态转换
**题目**：进程从运行态变为阻塞态的原因是什么？

**解析**：进程请求某种资源（如I/O设备）但资源暂时不可用，进程被阻塞等待。注意：时间片到会导致运行态→就绪态，不是阻塞态。

## 注意事项

1. PCB是进程存在的**唯一标志**，系统通过PCB感知进程的存在
2. 进程是**资源分配**的基本单位，线程是**调度**的基本单位
3. 运行→就绪（主动放弃或被动剥夺），运行→阻塞（主动或因资源不足）
