# 文件物理结构

## 形式化定义

> 引用自 RAW-os-4文件管理-4.1.5：

**文件物理结构**研究文件数据在物理存储设备（主要是磁盘）上是如何分布和组织的。文件的存储方式直接决定了文件支持的访问方式（顺序/随机）和空间利用率。

## 直观解释

文件物理结构就是文件在磁盘上的"摆放方式"：是连续放在一起（顺序存储）、用指针串起来（链表存储）、还是用索引表管理（索引存储）。不同的方式影响文件访问速度和空间利用。

## 核心要点

### 1. 文件存储方式

| 方式 | 说明 | 访问 | 优缺点 |
|------|------|------|--------|
| **顺序分配** | 连续存放，类似数组 | 可随机访问 | 简单但产生外部碎片，文件扩展难 |
| **隐式链接** | 数据块通过指针链接 | 只能顺序访问 | 消除碎片，可动态扩展，但无法随机访问 |
| **显式链接** | 指针放在FAT（文件分配表）中 | 可随机访问 | FAT表在内存，查表快 |
| **索引分配** | 使用索引数据块存放指针列表 | 可随机访问 | 支持直接访问，多级索引支持大文件 |

### 2. 文件分配表（FAT）

FAT是显式链接方式的核心数据结构：
- 放在内存中的链接表
- 每个表项对应一个磁盘块
- 表项内容为下一个块的块号（形成链）
- 支持随机访问（查一次FAT即可定位）

### 3. Unix inode结构（多级索引）

Unix/Linux使用多级索引结构：

| 索引类型 | 适用场景 |
|----------|----------|
| **直接索引**（10个直接块） | 小文件（≤10块） |
| **一级间接索引** | 中等文件 |
| **二级间接索引** | 大文件 |
| **三级间接索引** | 超大文件 |

### 4. 存储空间管理

| 方法 | 说明 |
|------|------|
| **空闲表法** | 记录所有连续空闲块 |
| **空闲链表法** | 空闲块链接成链表 |
| **位示图法** | 用二进制位表示磁盘块的空闲状态 |
| **成组链接法** | 分组管理空闲块，Unix系统常用 |

## 常见考法

### 考法1：文件存储方式特点
**题目**：某文件采用隐式链接存储，要访问第i块需要？

**解析**：隐式链接只能顺序访问，要访问第i块必须从文件头开始顺序读取到第i块，共需i次磁盘I/O。

### 考法2：多级索引计算
**题目**：Unix系统一个inode有10个直接块，每个磁盘块大小为1KB，每个磁盘块号占4B，则一级间接索引可管理多大文件？

**解析**：
- 一个磁盘块可存放的地址数 = 1KB/4B = 256个
- 一级间接索引可管理 256 × 1KB = 256KB
- 加上10个直接块：10KB + 256KB = 266KB

## 注意事项

1. 隐式链接无法随机访问，显式链接可随机访问
2. FAT表在**内存**中，查表快但占用内存
3. 磁盘空间管理常用**位示图法**和**成组链接法**
4. 文件在磁带上是连续存储，在磁盘上通常不采用连续存储
