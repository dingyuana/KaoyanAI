# 磁盘

## 形式化定义

> 引用自 RAW-os-5输入输出管理-5.3.1：

**磁盘**是一种直接存取的存储设备，由多个盘片组成。磁盘表面划分为磁道、扇区，多个磁道组成柱面。磁盘的最小读写单位是**扇区**（按块存取）。

## 直观解释

磁盘就像一个"旋转的唱片柜"：唱片（盘片）在转，唱针（磁头）前后移动寻找音轨（磁道），找到后等唱片转到目标位置（扇区）就能读写了。找磁道位置（寻道）是最费时的部分。

## 核心要点

### 1. 磁盘物理结构

| 术语 | 说明 |
|------|------|
| **磁道** | 盘面上的同心圆轨道 |
| **扇区** | 磁道上的最小存储单位（通常512B或1KB） |
| **柱面** | 所有盘片中相同位置的磁道组成的圆柱 |
| **簇** | 一组扇区，磁盘空间分配的基本单位 |

### 2. 磁盘物理地址

物理地址格式：（柱面号，盘面号，扇区号）

读写步骤：
1. 根据柱面号移动磁臂（寻道）
2. 激活指定盘面对应的磁头
3. 等待磁盘旋转，扇区到磁头下（旋转延迟）
4. 读写数据（传输）

### 3. 一次磁盘读写的时间

| 时间 | 公式 | 说明 |
|------|------|------|
| **寻道时间 Ts** | Ts = s + m × n | 启动磁臂+移动磁头到目标磁道，**一般最长** |
| **旋转延迟 Tr** | Tr = 1/(2r) | 磁头定位到目标扇区，平均转半圈 |
| **传输时间 Tt** | Tt = b/(r×N) | 读写数据时间 |
| **总时间 Ta** | Ta = Ts + Tr + Tt | 总访问时间 |

- s: 启动磁臂时间，m: 每跨越一个磁道时间，n: 跨越磁道数
- r: 磁盘转速，b: 读写字节数，N: 每磁道字节数

### 4. 固态硬盘（SSD）

| 对比 | 传统磁盘（HDD） | 固态硬盘（SSD） |
|------|----------------|-----------------|
| 介质 | 磁性盘片 | 闪存芯片 |
| 访问方式 | 顺序/随机（随机访问慢） | 随机访问快 |
| 寻道时间 | 有（主要耗时） | 无（电子存储） |
| 可靠性 | 机械结构易损坏 | 无机械结构更可靠 |

## 常见考法

### 考法1：磁盘访问时间计算
**题目**：某磁盘转速为7200转/分钟，平均寻道时间为5ms，求平均访问时间。

**解析**：
- 旋转延迟 = 1/(2r) = 1/(2×7200/60) = 1/(2×120) = 1/240 ≈ 4.17ms
- 注意：转速7200r/min = 120r/s
- 平均访问时间 ≈ 5 + 4.17 + 传输时间

### 考法2：物理地址定位
**题目**：某磁盘有8个盘面（0-7），200个柱面（0-199），每个磁道有64个扇区。逻辑块号1000对应的物理地址是？

**解析**：每个柱面有 8×64 = 512 个扇区。
- 柱面号 = 1000/512 = 1（整数除法）
- 柱面内偏移 = 1000 mod 512 = 488
- 盘面号 = 488/64 = 7，扇区号 = 488 mod 64 = 40
- 物理地址：(1, 7, 40)

## 注意事项

1. 磁盘存储器的最小读写单位为1个**扇区**
2. 寻道时间是磁盘访问最耗时的部分
3. 操作系统只能优化**寻道时间**，无法优化旋转延迟和传输时间
4. 大多数OS以**簇**（一组扇区）为单位进行空间分配
