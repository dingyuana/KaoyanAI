# 进程同步与互斥

## 形式化定义

> 引用自 RAW-os-2进程与线程-2.3.1：

**同步**：进程A应在进程B之前执行（直接制约关系），体现进程间的协作。
**互斥**：进程A和进程B不能在同一时刻执行（间接制约关系），体现对临界资源的竞争访问。

## 直观解释

**同步**像接力赛：A跑完才能把接力棒交给B（有先后顺序）。
**互斥**像厕所门锁：一个人进去用厕所，其他人在外面等（不能同时使用）。

## 核心要点

### 1. 关键概念

| 概念 | 定义 |
|------|------|
| **临界资源** | 一次仅允许一个进程使用的资源（如打印机、共享变量、队列） |
| **共享资源** | 可被多个进程同时使用的资源（如可重入代码、磁盘） |
| **临界区** | 访问临界资源的那段代码 |
| **进程异步性** | 进程以不可预知的速度推进 |

### 2. 同步机制遵循的准则

| 准则 | 说明 |
|------|------|
| **空闲让进** | 临界区空闲时，应允许一个进程进入 |
| **忙则等待** | 临界区正被访问时，其他进程必须等待 |
| **有限等待** | 等待进入临界区的进程不能在有限时间内进入时，应让出CPU |
| **让权等待** | 当进程不能进入临界区时，应立即释放CPU（防止忙等） |

### 3. 实现临界区互斥的方法

| 方法 | 特点 | 缺点 |
|------|------|------|
| 软件方法（Peterson算法等） | 纯软件实现 | 复杂，现代OS不常用 |
| 硬件方法（关中断、TS指令） | 简单有效 | 关中断权限高，TS指令可能忙等 |
| 信号量（PV操作） | 最常用，灵活 | 需掌握PV操作 | 
| 互斥锁 | 简单 | 适用于单处理器 |

## 常见考法

### 考法1：同步与互斥的区分
**题目**：多个进程对共享变量的访问必须互斥，这属于什么制约关系？

A. 同步 B. 互斥 C. 既同步又互斥 D. 无关

**解析**：共享变量是临界资源，只能互斥访问，属于间接制约关系（互斥）。

**答案**：B

### 考法2：临界区概念
**题目**：关于临界区，下列说法正确的是？

A. 多个进程不能同时进入临界区
B. 临界区是指进程中访问临界资源的代码段
C. 临界区是一种临界资源
D. 对不同临界资源的访问不能放入同一个临界区

**解析**：
A ✗：如果访问的是不同的临界资源，可以同时进入
B ✓：临界区是代码段
C ✗：临界区是代码段，临界资源是资源
D ✗：如果临界资源不同，互不干扰

**答案**：B

## 注意事项

1. 同步=直接制约（协作关系），互斥=间接制约（竞争关系）
2. 前三个准则（空闲让进、忙则等待、有限等待）必须满足
3. 临界区是**代码段**，不是资源
