# 操作系统概述知识点总结

## 适用场景

操作系统概述是408的高频考点，主要包括：
- 操作系统的基本概念和功能
- 中断和异常的处理机制
- 系统调用的实现
- 处理器的运行机制

## 核心知识点

### 1. 操作系统的基本概念

#### 操作系统的定义
操作系统（OS）是计算机系统中最基本的系统软件，它管理计算机的硬件和软件资源，为用户提供服务。

#### 操作系统的功能

| 功能 | 说明 |
|------|------|
| 处理机管理 | 进程控制、进程同步、进程通信、调度 |
| 存储器管理 | 内存分配、地址映射、内存保护、虚拟内存 |
| 设备管理 | 缓冲管理、设备分配、设备处理 |
| 文件管理 | 文件存储空间管理、目录管理、文件读写 |
| 提供用户接口 | 命令接口、程序接口、图形接口 |

### 2. 中断与异常

#### 中断的类型

| 类型 | 产生原因 | 处理方式 |
|------|---------|---------|
| 硬件中断（外中断） | I/O设备、外部事件 | 异步，CPU被硬件打断 |
| 软件中断（内中断） | 异常、故障、陷入 | 同步，当前指令引起 |

#### 中断处理过程

1. **中断请求**：外设发出中断请求
2. **中断响应**：CPU检查中断，保存现场
3. **中断判优**：多个中断时选择优先级最高的
4. **中断向量**：根据中断类型找到中断处理程序入口
5. **中断处理**：执行中断服务程序
6. **恢复现场**：恢复被打断进程的状态

### 3. 系统调用

#### 系统调用的特点
- 运行在**核心态**（特权模式）
- 通过**软中断**（如INT 0x80）或**访管指令**实现
- 提供操作系统服务的接口

#### 系统调用与普通函数调用的区别

| 区别 | 系统调用 | 函数调用 |
|------|---------|---------|
| 执行模式 | 核心态 | 用户态 |
| 切换 | 可能涉及状态切换 | 通常用户态内 |
| 访问资源 | 可访问受保护资源 | 受限 |

### 4. 处理器运行机制

#### 特权指令与非特权指令
- **特权指令**：只能在内核态执行（I/O、设置时钟等）
- **非特权指令**：用户态和核心态都可执行

#### CPU状态转换
- **用户态→核心态**：中断、异常、系统调用
- **核心态→用户态**：修改程序状态字（PSW）

## 常见考点

1. **中断和异常的区别**：异步vs同步
2. **系统调用的实现**：通过中断或异常进入内核
3. **用户态和核心态的区分**：通过PSW标志位
4. **操作系统是资源管理器**：合理分配资源、提高利用率

## 注意事项

1. **中断是异步的**：与CPU当前执行的指令无关
2. **异常是同步的**：由当前指令引起
3. **系统调用是主动的**：用户程序请求操作系统服务
4. **特权指令只能在核心态执行**：这是CPU的硬件保证
