# I/O管理知识点总结

## 适用场景

I/O管理是408操作系统的常考内容，包括：
- I/O设备的分类
- I/O软件的层次结构
- I/O控制方式（程序查询、中断、DMA、通道）
- SPOOLing技术
- 缓冲区管理

## I/O软件层次

### 层次结构

| 层次 | 功能 | 主要组成 |
|------|------|---------|
| 用户层I/O软件 | 提供用户接口 | 系统调用、库函数 |
| 设备独立性软件 | 逻辑I/O、统一命名 | 设备分配、缓冲区管理 |
| 设备驱动程序 | 物理I/O、控制设备 | 具体设备控制器 |
| 中断处理程序 | 处理I/O完成中断 | 中断服务例程 |
| 硬件 | 执行I/O操作 | 设备控制器、设备 |

### 各层的主要功能

1. **用户层I/O软件**：将用户请求翻译成系统调用
2. **设备独立性软件**：实现设备保护、缓冲区管理
3. **设备驱动程序**：向设备控制器发送命令
4. **中断处理程序**：I/O完成后唤醒等待进程

## I/O控制方式

### 方式对比

| 方式 | CPU介入程度 | 数据传输单位 | 特点 |
|------|------------|-------------|------|
| 程序查询方式 | 高（轮询） | 字 | CPU全程参与，效率低 |
| 中断方式 | 中 | 字/块 | CPU响应中断后处理 |
| DMA方式 | 低 | 块 | DMA控制器负责 |
| 通道方式 | 很低 | 一组块 | 独立处理I/O |

### DMA（直接存储器访问）

**DMA控制器组成**：
- 设备选择器
- 主存地址寄存器
- 数据计数器
- 数据缓冲寄存器
- 命令/状态寄存器

**DMA工作过程**：
1. CPU给DMA控制器设置参数
2. DMA请求总线使用权
3. DMA控制数据传输
4. 传输完成后中断通知CPU

## SPOOLing技术

### 什么是SPOOLing
SPOOLing = Simultaneous Peripheral Operations On-Line（外围设备联机操作）

### SPOOLing系统组成

```
                    ┌─────────┐
                    │  输入井  │
                    └────┬────┘
                         │
┌──────┐            ┌────▼────┐            ┌──────┐
│ 输入设备 │ ───────→ │ 输入缓冲区 │ ───────→ │ 作业控制卡  │
└──────┘            └─────────┘            └──────┘
                                                 │
                                                 ▼
┌──────┐            ┌─────────┐            ┌──────┐
│ 输出设备 │ ←─────── │ 输出缓冲区 │ ←─────── │ 输出井   │
└──────┘            └─────────┘            └──────┘
```

### SPOOLing的特点

1. **提高I/O速度**：将独占设备改为共享设备
2. **实现虚拟设备**：将一台物理设备虚拟为多台逻辑设备
3. **使独占设备变为可共享**：多个进程可同时使用

## 缓冲区管理

### 缓冲区类型

| 类型 | 特点 | 应用 |
|------|------|------|
| 单缓冲区 | 一个缓冲区 | 简单场景 |
| 双缓冲区 | 两个缓冲区 | 生产者-消费者 |
| 循环缓冲区 | 多个缓冲区组成环 | 效率较高 |
| 缓冲池 | 通用缓冲区池 | 通用I/O |

### 缓冲区的作用

1. **缓和CPU与I/O设备速度不匹配**
2. **减少中断次数**
3. **提高并行性**
4. **改善性能**

## 设备分配

### 设备分配算法

| 算法 | 说明 | 优缺点 |
|------|------|-------|
| 先来先服务(FCFS) | 按请求顺序分配 | 公平简单 |
| 优先级高者优先 | 高优先级先分配 | 可能低优先级饥饿 |
| 静态分配 | 进程运行前分配 | 利用率低 |
| 动态分配 | 运行时分配 | 利用率高 |

### 设备独立性

- 应用程序使用逻辑设备名
- 由操作系统转换为物理设备
- 便于程序移植和设备替换

## 学习建议

1. **理解I/O层次结构**：每层负责什么
2. **区分不同I/O控制方式**：DMA效率最高
3. **掌握SPOOLing的三个特点**：虚拟设备、提高效率
4. **理解缓冲区的作用**：速度匹配、减少中断
