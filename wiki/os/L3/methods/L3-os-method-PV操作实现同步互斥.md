# PV操作实现同步与互斥

## 适用场景

当多个并发进程需要访问临界资源（互斥）或有执行顺序约束（同步）时，使用信号量和PV操作实现进程间的协调。

## 方法步骤

### 第一步：分析同步互斥关系

1. 找出所有**临界资源**（共享变量、缓冲区、设备等）
2. 找出进程之间的**同步关系**（谁必须在谁之前执行，或缓冲区满/空条件）
3. 找出进程之间的**互斥关系**（哪些进程不能同时访问同一临界资源）

### 第二步：定义信号量

| 信号量类型 | 初值 | 用途 |
|-----------|------|------|
| **互斥信号量（mutex）** | 1 | 保护临界区互斥访问 |
| **同步信号量（empty/full）** | 可用资源数量 | 描述资源数量或同步条件 |

### 第三步：应用PV操作

#### 互斥模式
```
P(mutex);    // 进入区：申请
访问临界资源;  // 临界区
V(mutex);    // 退出区：释放
```

#### 同步模式
```
// 在前操作之后执行V(sync)
// 在后操作之前执行P(sync)
```

## 示例

### 示例1：进程互斥访问共享变量

**问题**：两个进程P1和P2共享变量count，需要互斥访问。

**解法**：
```c
semaphore mutex = 1;

// 进程P1
P(mutex);
count++;
V(mutex);

// 进程P2
P(mutex);
count--;
V(mutex);
```

### 示例2：进程同步（前驱关系）

**问题**：进程P1计算x+y，P2打印结果，必须P1先执行，P2后执行。

**解法**：
```c
semaphore sync = 0;

// 进程P1
result = x + y;
V(sync);  // 通知P2可以执行

// 进程P2
P(sync);  // 等待P1完成
print(result);
```

### 示例3：生产者-消费者抽象

**问题**：一个生产者进程向缓冲区放数据，一个消费者进程从缓冲区取数据，缓冲区大小为n。

**解法**：
```c
semaphore mutex = 1;  // 互斥访问缓冲区
semaphore empty = n;  // 空闲缓冲区数量
semaphore full = 0;   // 已填满缓冲区数量

// 生产者
while (1) {
    produce(item);
    P(empty);    // 申请空闲缓冲区
    P(mutex);    // 互斥访问缓冲区
    put(item);
    V(mutex);    // 释放互斥
    V(full);     // 增加已填满数量
}

// 消费者
while (1) {
    P(full);     // 申请已填满缓冲区
    P(mutex);    // 互斥访问缓冲区
    item = get();
    V(mutex);    // 释放互斥
    V(empty);    // 增加空闲缓冲区
    consume(item);
}
```

## 注意事项

1. **P和V必须成对出现**，缺少P无法保证互斥，缺少V会死锁
2. 多个P操作时，注意**顺序**：通常先同步后互斥（先P(empty)后P(mutex)），防止死锁
3. 信号量初值通常为：互斥=1，资源=N，同步=0

## 失效情况

- 单CPU系统：PV操作本身是原子的（通过关中断实现）
- 多CPU系统：PV操作需要硬件支持的原子指令（如TSL/XCHG）

替代方法：互斥锁（简单互斥场景）、管程（高级语言支持的同步机制）
