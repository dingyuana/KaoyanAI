### 题目1：操作系统特征
**来源**：408真题
**难度**：简单
**考点**：操作系统的四个基本特征

**题目**：
操作系统的四个基本特征是并发、共享、虚拟和异步。请解释每个特征的含义，并说明并发与并行的区别。

**解析**：
1. **并发**：两个或多个事件在同一时间间隔内发生（宏观上同时，微观上交替执行）
2. **共享**：系统中的资源可供多个并发执行的进程共同使用
3. **虚拟**：将一个物理实体映射为多个逻辑实体（如虚拟内存、虚拟处理器）
4. **异步**：进程的执行不是一贯到底的，走走停停，推进速度不可预知

**并发 vs 并行**：
- 并发：逻辑上的同时，宏观并行微观交替，单核即可实现
- 并行：物理上的同时，多核同时执行多个指令

### 题目2：系统调用
**来源**：408真题
**难度**：简单
**考点**：系统调用的执行过程

**题目**：
用户程序使用 `read()` 系统调用从文件读取数据时，CPU 的状态如何变化？简述从用户态到核心态的切换过程。

**解析**：
1. 用户程序执行 `read()` 库函数 → 仍在用户态
2. 库函数将系统调用号和参数放入指定寄存器
3. 执行 `trap`（访管）指令 → 触发中断，CPU 从用户态切换为核心态
4. 操作系统根据系统调用号查找系统调用表，执行对应的内核函数
5. 内核完成文件读取操作，将数据复制到用户缓冲区
6. 执行 `return-from-trap` 指令 → CPU 从核心态返回用户态
7. 用户程序继续执行

**关键点**：`trap` 指令是实现用户态→核心态切换的唯一途径

**答案**：用户态→trap指令→核心态→内核处理→返回用户态

### 题目3：中断分类
**来源**：408真题
**难度**：中等
**考点**：内中断与外中断的区别

**题目**：
下列事件中，哪些属于内中断（异常），哪些属于外中断（中断）？请分类并说明理由。
(1) 除零错误  (2) 时钟中断  (3) 缺页中断  (4) I/O 设备中断  (5) 系统调用  (6) 越界访问

**解析**：

| 事件 | 类型 | 理由 |
|------|------|------|
| 除零错误 | 内中断（故障） | CPU 内部执行指令产生 |
| 时钟中断 | 外中断 | CPU 外部设备产生 |
| 缺页中断 | 内中断（故障） | CPU 执行指令时 MMU 触发 |
| I/O 设备中断 | 外中断 | 外部设备通过中断控制器发出 |
| 系统调用 | 内中断（陷阱） | CPU 主动执行 trap 指令 |
| 越界访问 | 内中断（故障） | CPU 执行指令时检测到 |
