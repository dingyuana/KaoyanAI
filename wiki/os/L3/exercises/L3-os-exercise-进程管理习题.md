# 进程管理习题

## 题目列表

### 题目1：调度算法计算
**来源**：408真题
**难度**：中等
**考点**：FCFS、SJF、RR 调度算法

**题目**：
进程到达时间和 CPU 突发时间如下表：

| 进程 | 到达时间 | 突发时间 |
|------|---------|---------|
| P1 | 0 | 7 |
| P2 | 2 | 4 |
| P3 | 4 | 1 |
| P4 | 5 | 4 |

分别使用 FCFS、SJF（非抢占）、RR（时间片=2）三种算法，计算平均周转时间和平均等待时间。

**解析**：

**FCFS**：
| 进程 | 到达 | 开始 | 完成 | 周转 | 等待 |
|------|------|------|------|------|------|
| P1 | 0 | 0 | 7 | 7 | 0 |
| P2 | 2 | 7 | 11 | 9 | 7 |
| P3 | 4 | 11 | 12 | 8 | 11 |
| P4 | 5 | 12 | 16 | 11 | 12 |
平均周转 = (7+9+8+11)/4 = 8.75
平均等待 = (0+7+11+12)/4 = 7.5

**SJF（非抢占）**：
| 进程 | 到达 | 开始 | 完成 | 周转 | 等待 |
|------|------|------|------|------|------|
| P1 | 0 | 0 | 7 | 7 | 0 |
| P3 | 4 | 7 | 8 | 4 | 7 |
| P2 | 2 | 8 | 12 | 10 | 8 |
| P4 | 5 | 12 | 16 | 11 | 12 |
平均周转 = (7+10+4+11)/4 = 8.0
平均等待 = (0+8+7+12)/4 = 6.75

**RR（时间片=2）**：
执行顺序：P1(0-2), P2(2-4), P1(4-6), P3(6-7), P2(7-9), P4(9-11), P1(11-12), P4(12-14)
| 进程 | 完成 | 周转 | 等待 |
|------|------|------|------|
| P1 | 12 | 12 | 5 |
| P2 | 9 | 7 | 3 |
| P3 | 7 | 3 | 2 |
| P4 | 14 | 9 | 5 |
平均周转 = (12+7+3+9)/4 = 7.75
平均等待 = (5+3+2+5)/4 = 3.75

**答案**：FCFS: 8.75/7.5, SJF: 8.0/6.75, RR: 7.75/3.75

### 题目2：银行家算法
**来源**：408真题
**难度**：困难
**考点**：死锁避免、安全序列

**题目**：
系统中有 5 个进程 P0~P4，3 类资源 A(10), B(5), C(7)。当前状态如下：

| 进程 | Allocation | Max | Available |
|------|-----------|-----|-----------|
| P0 | (0,1,0) | (7,5,3) | (3,3,2) |
| P1 | (2,0,0) | (3,2,2) | |
| P2 | (3,0,2) | (9,0,2) | |
| P3 | (2,1,1) | (2,2,2) | |
| P4 | (0,0,2) | (4,3,3) | |

(1) 计算 Need 矩阵
(2) 当前状态是否安全？给出安全序列
(3) P1 请求 (1,0,2)，能否分配？

**解析**：
(1) Need = Max - Allocation

| 进程 | Need |
|------|------|
| P0 | (7,4,3) |
| P1 | (1,2,2) |
| P2 | (6,0,0) |
| P3 | (0,1,1) |
| P4 | (4,3,1) |

(2) Available = (3,3,2)
- P1: Need(1,2,2) ≤ Available(3,3,2) → 满足，P1 完成后 Available=(5,3,2)
- P3: Need(0,1,1) ≤ Available(5,3,2) → 满足，P3 完成后 Available=(7,4,3)
- P4: Need(4,3,1) ≤ Available(7,4,3) → 满足，P4 完成后 Available=(7,4,5)
- P2: Need(6,0,0) ≤ Available(7,4,5) → 满足，P2 完成后 Available=(10,4,7)
- P0: Need(7,4,3) ≤ Available(10,4,7) → 满足
安全序列：P1 → P3 → P4 → P2 → P0 ✅

(3) P1 请求 Request(1,0,2)
检查：Request ≤ Need? (1,0,2) ≤ (1,2,2) ✅
检查：Request ≤ Available? (1,0,2) ≤ (3,3,2) ✅
假设分配：Available=(2,3,0), Allocation(P1)=(3,0,2), Need(P1)=(0,2,0)
检查安全性：P1 可直接满足 → 安全
可以分配 ✅

**答案**：安全序列 P1→P3→P4→P2→P0，可以分配
