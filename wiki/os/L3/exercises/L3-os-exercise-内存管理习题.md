# 内存管理习题

## 题目列表

### 题目1：动态分区分配
**来源**：408真题
**难度**：中等
**考点**：首次适应、最佳适应、最差适应算法

**题目**：
内存空闲分区按地址从小到大为：50KB、120KB、80KB、200KB、60KB。依次请求 100KB、50KB、150KB、30KB 的作业。分别采用首次适应、最佳适应和最差适应算法，哪个能满足所有请求？

**解析**：

**首次适应（FF）**：
- 请求100KB：从低地址找第一个≥100KB的空闲块 → 120KB (剩20KB)
  空闲：50KB, 20KB, 80KB, 200KB, 60KB
- 请求50KB：50KB 正好 → 分配
  空闲：20KB, 80KB, 200KB, 60KB
- 请求150KB：200KB ≥ 150KB → 分配 (剩50KB)
  空闲：20KB, 80KB, 50KB, 60KB
- 请求30KB：20KB < 30KB, 80KB ≥ 30KB → 分配 (剩50KB)
  所有请求满足 ✅

**最佳适应（BF）**：
- 请求100KB：找到最小≥100KB的空闲块 → 120KB (剩20KB)
  空闲：50KB, 20KB, 80KB, 200KB, 60KB
- 请求50KB：50KB 正好 → 分配
  空闲：20KB, 80KB, 200KB, 60KB
- 请求150KB：200KB ≥ 150KB → 分配 (剩50KB)
  空闲：20KB, 80KB, 50KB, 60KB
- 请求30KB：20KB < 30KB, 50KB ≥ 30KB → 分配 (剩20KB)
  所有请求满足 ✅

**最差适应（WF）**：
- 请求100KB：找最大空闲块 → 200KB (剩100KB)
  空闲：50KB, 120KB, 80KB, 100KB, 60KB
- 请求50KB：120KB ≥ 50KB → 分配 (剩70KB)
  空闲：50KB, 70KB, 80KB, 100KB, 60KB
- 请求150KB：最大100KB < 150KB → 无法分配 ❌

**答案**：首次适应和最佳适应可满足所有请求，最差适应失败

### 题目2：分页系统地址转换
**来源**：408真题
**难度**：中等
**考点**：逻辑地址到物理地址的转换

**题目**：
某分页系统，页面大小为 4KB，页表如下：

| 逻辑页号 | 物理块号 |
|---------|---------|
| 0 | 3 |
| 1 | 5 |
| 2 | 8 |
| 3 | 1 |

逻辑地址为 0x2A5F，求对应的物理地址。

**解析**：
页面大小 4KB = $2^{12}$B，所以页内偏移占 12 位

0x2A5F = 0010 1010 0101 1111B
- 页号 P = 0x2A5F >> 12 = 0x2 = 2
- 页内偏移 W = 0x2A5F & 0xFFF = 0xA5F

查页表：页号 2 → 物理块号 8
物理地址 = 块号 × 页大小 + 偏移 = 8 × 4096 + 0xA5F
= 0x8000 + 0xA5F = 0x8A5F

**答案**：物理地址 = 0x8A5F

### 题目3：分段系统地址转换
**来源**：408真题
**难度**：简单
**考点**：分段地址转换

**题目**：
某分段系统，段表如下：

| 段号 | 段基址 | 段长 |
|------|--------|------|
| 0 | 1000 | 800 |
| 1 | 3000 | 500 |
| 2 | 5000 | 1000 |

逻辑地址 (1, 400) 和 (2, 1200) 能否转换为物理地址？若能，写出物理地址。

**解析**：
(1) 段号 1，段内偏移 400
段 1 的段长 = 500，偏移 400 < 500 → 合法
物理地址 = 基址 + 偏移 = 3000 + 400 = 3400 ✅

(2) 段号 2，段内偏移 1200
段 2 的段长 = 1000，偏移 1200 > 1000 → 越界 ❌
触发段保护异常，无法转换

**答案**：(1,400) → 3400，地址合法；(2,1200) 越界，不合法
