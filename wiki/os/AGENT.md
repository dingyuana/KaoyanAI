# AGENT.md - 操作系统学科 AI 约束

> 本文件定义AI在操作操作系统知识库时的行为规范和约束条件。
> 通用约束请参阅 `../WIKI_SCHEMA.md`。

---

## 一、AI 操作原则

### 1.1 知识生成规则

1. **忠实原文**：L1 层不得修改、总结、纠错原文内容
2. **三层架构**：严格遵循 L1→L2→L3 的知识加工流程
3. **类型分离**：概念、方法、习题必须分离到对应目录
4. **格式统一**：严格遵循 SCHEMA.md 定义的格式规范

### 1.2 算法与机制描述规范

1. **PV操作规范**：信号量操作必须使用标准P/V记号
2. **状态转换**：进程状态转换必须标明触发条件
3. **伪代码优先**：算法描述优先使用伪代码

### 1.3 策略描述规范

1. **策略名称**：使用标准中文译名或英文原名
2. **比较维度**：从公平性、效率、实现难度等维度比较
3. **场景适配**：说明各策略适用的场景

---

## 二、L1 处理规则

### 2.1 Chunk 拆分标准

- 一个系统概念 = 一个 Chunk
- 一个算法/策略 = 一个 Chunk
- 一个状态转换图 = 一个 Chunk
- 一道例题 = 一个 Chunk

### 2.2 锚点生成规则

```
RAW-os-{章节名}-{序号}
示例：RAW-os-2进程与线程-P001-C01
```

---

## 三、L3 生成规则

### 3.1 概念文档

- 必须包含：形式化定义、状态模型、核心机制
- 可选包含：典型应用、关联知识点

### 3.2 方法文档

- 必须包含：适用场景、算法步骤、示例
- 可选包含：策略比较、失效情况

### 3.3 习题文档

- 必须包含：题目、解析、答案
- 可选包含：PV操作设计、考点分析

---

## 四、禁止行为

1. ❌ 不得在 L1 层修改原文内容
2. ❌ 不得将PV操作序列拆分
3. ❌ 不得省略状态转换图的触发条件
4. ❌ 不得将概念和算法混在同一文档
5. ❌ 不得修改题目的原始条件
