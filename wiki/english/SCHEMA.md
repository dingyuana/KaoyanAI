## 三、L1 分块原则（英语特色）

### 3.1 基础规则

1. **完整性**：一篇文章、一道题目、一个语法点不得跨 Chunk
2. **唯一ID**：每个 Chunk 分配永久锚点 ID，学科前缀为 `english`
3. **不改原文**：保留原文所有文字和标点，不总结、不纠错

### 3.2 英语特色规则

- **文章完整**：每篇阅读文章（含题目和选项）作为一个 Chunk
- **长难句独立**：翻译题中的每个长难句作为一个 Chunk
- **范文独立**：每篇写作范文作为一个 Chunk
- **词汇单元化**：同义词群、形近词群作为一个 Chunk

### 3.3 命名规范

```
{学科}_{模块}_{标题}.md
示例：english_阅读_2010Text1.md、english_翻译_长难句精讲.md
```

## 四、L3 文档格式（英语特色）

### 4.1 Frontmatter

```yaml
---
id: L3-english-concept-虚拟语气
title: 虚拟语气
subject: english
type: concept
level: 3
tags: [语法, 虚拟语气, 长难句]
related:
  - L3-english-method-语法填空解题技巧.md
  - L3-english-exercise-虚拟语气练习题.md
source_anchors:
  - RAW-english-考研语法-P023-C07
created: 2026-05-09
---
```

### 4.2 正文结构（概念类）

1. 定义说明（引用自 L1 原文）
2. 用法规则（结构公式/变化规律）
3. 考研考点（历年常考方式）
4. 易混对比（与其他结构的区别）
5. 真题例句（带出处和翻译）

### 4.3 英语格式规范

- 例句使用 `> ` 引用格式
- 中文翻译紧跟英文原文，使用 `//` 分隔
- 生词标注：`**word** [词性] 释义`
- 长难句分析使用编号列表逐层拆解

## 五、习题分离规则

### 5.1 习题识别标准

满足以下任一条件即为习题：
- 包含标准题型指令（Choose、Read the passage、Translate）
- 带有编号的题目（如 21.、22.、Part A）
- 来自历年真题（带年份、题号）
- 写作题目（含题目要求和提示）

### 5.2 习题分类

| 分类 | 说明 |
|------|------|
| 选择题 | 完形填空、阅读理解的客观题 |
| 翻译题 | 英译中翻译题 |
| 写作题 | 应用文、图画/图表作文 |
