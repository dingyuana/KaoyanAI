# 极值点的判断方法y00且y00为极大值点

来源: 

# 极值点的判断方法

**章节**：2026 张宇高数 18讲(OCR)  
**难度**：★★☆☆☆  
**标签**：一元函数微分学 | 极值问题 | 二阶导数应用


## 📖 概念定义

**极值点**是指函数在某点邻域内取得最大值或最小值的点。

**极大值点判断定理（第二充分条件）**  
设函数 $f(x)$ 在点 $x_0$ 处**二阶可导**，且满足：
$$f'(x_0) = 0$$

- 若 $f''(x_0) < 0$，则 $x_0$ 为**极大值点**
- 若 $f''(x_0) > 0$，则 $x_0$ 为**极小值点**
- 若 $f''(x_0) = 0$，则方法失效，需用其他方法判断

> **注意**：使用该方法前，必须先验证 $f'(x_0) = 0$。


## 📐 核心公式

### 极值点判断公式

$$\boxed{f'(x_0) = 0 \quad \text{且} \quad \begin{cases} f''(x_0) < 0 & \Rightarrow \text{极大值点} \\ f''(x_0) > 0 & \Rightarrow \text{极小值点} \end{cases}}$$

### 隐函数求导步骤（极值问题常用）

$$F(x, y) = 0$$

1. **一阶导**：对 $x$ 求导 → 解出 $y'$
2. **二阶导**：对 $y'$ 表达式再求 $x$ 导数 → 解出 $y''$


## 📝 典型例题

### 例4.7（隐函数极值问题）

**已知**可导函数 $y = y(x)$ 满足
$$ae^x + y^2 + y - \ln(1+x)\cos y + b = 0$$
且 $y(0) = 0$，$y'(0) = 0$。

**(1) 求 $a, b$ 的值；**  
**(2) 判断 $x = 0$ 是否为 $y(x)$ 的极值点。**


### 【解】

**(1) 求 $a, b$：**

由 $y(0) = 0$ 代入原方程：
$$a \cdot e^0 + 0^2 + 0 - \ln 1 \cdot \cos 0 + b = 0$$
$$\Rightarrow a + b = 0 \quad \cdots(1)$$

对原方程两边关于 $x$ 求导：
$$ae^x + 2yy' + y' - \frac{1}{1+x}\cos y + \ln(1+x)(-\sin y)\cdot y' = 0$$

将 $x = 0$，$y(0) = 0$，$y'(0) = 0$ 代入：
$$a - 1 = 0 \Rightarrow a = 1$$

由 $(1)$ 得：$b = -1$。


**(2) 判断 $x = 0$ 的极值性：**

由 $y'(x) = 0$ 的等式（将 $a = 1$ 代入）：
$$e^x + 2yy' + y' - \frac{1}{1+x}\cos y + \ln(1+x)(-\sin y)\cdot y' = 0$$

再对 $x$ 求导：
$$e^x + 2(y')^2 + 2yy'' + y'' + \frac{1}{(1+x)^2}\cos y - \frac{1}{1+x}\sin y \cdot y' + \cdots = 0$$

将 $x = 0$，$y(0) = 0$，$y'(0) = 0$ 代入：
$$1 + 0 + 0 + y''(0) + 1 - 0 = 0$$

$$\Rightarrow y''(0) = -2 < 0$$


### ✅ 结论

因为 $y'(0) = 0$ 且 $y''(0) = -2 < 0$，

$$\boxed{x = 0 \text{ 为 } y(x) \text{ 的极大值点}}$$


## ⚠️ 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| **忽略一阶导为零** | 直接计算 $f''(0)$ 就判断 | 必须先验证 $f'(x_0) = 0$ |
| **二阶导计算错误** | 隐函数求导漏项 | 仔细逐项求导，注意复合函数求导 |
| **代入顺序错误** | 先代入二阶导表达式再求导 | 应先求导再代入数值 |
| **$f''(x_0) = 0$ 时误判** | 认为极值点不存在 | 此时第二充分条件失效，需用**高阶导数**或**定义法**判断 |
| **忘记检验充分条件** | 未说明函数二阶可导 | 需确保 $f''(x_0)$ 存在且连续 |


## 🔗 关联知识点

| 知识点 | 说明 |
|-------|------|
| **导数的定义** | $f'(x_0) = \lim\limits_{\Delta x \to 0} \dfrac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$ |
| **隐函数求导** | $F(x,y) = 0 \Rightarrow \dfrac{dy}{dx} = -\dfrac{F_x}{F_y}$ |
| **参数方程求导** | $\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$，$\dfrac{d^2y}{dx^2} = \dfrac{d}{dt}\left(\dfrac{dy}{dx}\right) \bigg/ \dfrac{dx}{dt}$ |
| **极值的定义** | $f(x_0)$ 为极值的必要条件和充分条件 |
| **洛必达法则** | 求导困难时可用定义法配合极限计算 |
