# 概率论与数理统计-第29讲：多维随机变量函数的分布

## 核心概念定义
多维随机变量函数的分布是指给定多维随机变量时，其函数的分布情况。主要研究随机变量经过函数变换后的概率分布。

## 核心公式
```latex
F_Z(z) = P\{|U| \leq z\} = P\{-z \leq U \leq z\} = F_Z(2) - F_Z(-z)
```

## 典型例题
**例5.5** 设随机变量 \(X \sim U(1,2)\)，在 \(X=x\) 的条件下，\(Y\) 的条件分布为 \(E(x)\)，则 \(D(XY) = ( )\)。

(A) 1
(B) 2
(C) x
(D) 2x

**解** 应选 (A)。

**例5.6** 设总体 \(X\) 服从 \([0,\theta]\) 上的均匀分布，\(\theta\) 为正常数，\(X_1, X_2, X_3\) 是取自 \(X\) 的一个样本，求 \(Y = \max\{X_1, X_2, X_3\}\)，\(Z = \min\{X_1, X_2, X_3\}\) 的分布函数和概率密度。

## 常见错误
1. 忽略随机变量函数的独立性。
2. 错误地应用分布函数和概率密度公式。
3. 在计算分布函数和概率密度时，未考虑随机变量的边界值。
