# 对数型辅助函数的构造

## 元数据

- **章节**：2026 张宇高数 18讲(OCR)
- **难度**：★★☆☆☆
- **标签**：辅助函数构造 | 对数型 | 微分中值定理


## 1. 概念定义

对数型辅助函数构造法是证明微分中值定理相关命题的重要技巧。当待证结论中出现关于 $f(x)$ 与 $f'(x)$ 的特定组合时，构造形如 $F(x) = \ln f(x)$ 的辅助函数，可以将乘法关系转化为加法关系，从而简化问题。

**核心思想**：利用对数的性质
$$\ln(ab) = \ln a + \ln b, \quad \ln\frac{a}{b} = \ln a - \ln b$$
将导数的乘积形式转化为导数的和差形式，便于应用 Lagrange 中值定理或 Cauchy 中值定理。


## 2. 核心公式

### 2.1 基本对数型构造

| 序号 | 条件 | 辅助函数构造 | 备注 |
| ① | 见到 $f'(x)f(x) - [f'(x)]^2$，且 $f(x) \neq 0$ | $F(x) = \ln f(x)$ | 即 $\ln f(x)$ 求导 |

### 2.2 导数关系式

$$[\ln f(x)]' = \frac{f'(x)}{f(x)}$$

$$[\ln f(x)]'' = \frac{f''(x)f(x) - [f'(x)]^2}{[f(x)]^2}$$

### 2.3 祖孙三代传承法（恒等变形）

**适用场景**：欲证"差辈分"结论，如：
- $f''(\xi) = f(\xi)$
- $f'(\xi) = \displaystyle\int_\xi^\eta f(t)\,dt$

**核心思想**：利用 $a - c = a - b + b - c$ 进行恒等变形，补齐"辈分"。


## 3. 典型例题

### 例题：证明 $f''(\xi) = f(\xi)$

**题目**：设 $f(x)$ 在 $[a,b]$ 上二阶可导，且 $f(a) = f(b) = 0$，证明：存在 $\xi \in (a,b)$，使得 $f''(\xi) = f(\xi)$。

**证明思路**：

**第一步：恒等变形**
$$f''(\xi) - f(\xi) = 0$$
在 $f''(\xi)$ 与 $f(\xi)$ 之间补入 $f'(\xi)$，利用 $a - c = a - b + b - c$：
$$f''(\xi) - f'(\xi) + f'(\xi) - f(\xi) = 0$$

**第二步：构造辅助函数**
$$F'(x) = [f''(x) - f'(x)]e^x + [f'(x) - f(x)]e^x = [f'(x) - f(x)]e^x$$

验证：$F(x) = [f'(x) - f(x)]e^x$，则
$$F'(x) = [f''(x) - f'(x)]e^x + [f'(x) - f(x)]e^x = [f''(x) - f(x)]e^x$$

**第三步：验证边界条件**
$$F(a) = [f'(a) - f(a)]e^a = f'(a)e^a$$
$$F(b) = [f'(b) - f(b)]e^b = f'(b)e^b$$

**第四步：应用中值定理**
由 $f(a) = f(b) = 0$，需要额外条件 $F(a) = F(b)$ 或结合罗尔定理完成证明。

（此处略去详细计算，核心是构造 $F(x) = [f'(x) - f(x)]e^{-x}$ 可直接使用）


## 4. 常见错误

| 序号 | 错误类型 | 正确做法 |
| ① | **忽略定义域条件** | 构造 $F(x) = \ln f(x)$ 时，必须确保 $f(x) > 0$（严格正） |
| ② | **混淆 $f'(x)f(x)$ 与 $f''(x)f(x) - [f'(x)]^2$** | 前者是 $[\ln f(x)]' \cdot f(x)$，后者才是 $[\ln f(x)]''$ 的分子 |
| ③ | **恒等变形不彻底** | "祖孙三代"法要求每一步变形都要保持等价，不能遗漏项 |
| ④ | **忘记回代验证** | 构造 $F(x)$ 后，必须验证 $F'(x)$ 是否确实等于目标表达式 |
| ⑤ | **忽视 $e^x$ 因子** | 在祖孙三代法中，常需乘以 $e^x$ 或 $e^{-x}$ 使表达式闭合 |


## 5. 关联知识点

| 关联知识点 | 说明 |
| **拉格朗日中值定理** | 对数型构造常用于生成 $(e^x F(x))'$ 形式的表达式 |
| **柯西中值定理** | 当出现两个函数比值的导数时，考虑比值形式 |
| **罗尔定理** | 构造 $F'(x) = 0$ 的形式，寻找 $F(\xi) = 0$ |
| **泰勒公式** | 二阶导数关系可与泰勒展开结合 |
| **辅助函数构造通法** | 观察待证结论结构，逆向构造 |
