# 高等数学-第39讲：一元函数微分学的计算

## 核心概念定义
一元函数微分学的计算主要研究一元函数的导数和微分，包括导数的定义、求导法则、高阶导数等。通过微分，可以研究函数的变化率，解决实际问题。

## 核心公式
```latex
y''(0) = (-1)^{2n+1}(2n+1)!
y''(0) = -2 \times 1 \times 0 = 0
y''(0) = -4 \times 3 \times 0 = 0
\ldots
y^{(2n)}(0) = 0
```

## 典型例题
**例4.5** 设函数 \( y = f(x) \) 由 \( y = \sqrt[3]{x^2} \) 所确定，则在 \( (-2, 2) \) 内 \( f'(0) \) 的值是多少？

**解**：\( f'(0) \) 的值不存在。

**例4.6** 设 \( f(x) = 2x^3 + 1, x \in \mathbb{R} \)，则 \( f''(0) \) 的值是多少？

**解**：\( f''(0) = 0 \)。

## 常见错误
1. 忽略函数的连续性条件。
2. 混淆导数和微分。
3. 错误应用求导法则。
4. 忽略高阶导数的计算规则。
