# 反函数求导法则

## 1. 概念定义

**反函数求导法则**：若函数 $y = f(x)$ 在区间 $I$ 上单调、可导，且 $f'(x) \neq 0$，则存在反函数 $x = \varphi(y)$，其导数满足：

$$\varphi'(y) = \frac{1}{f'(x)}$$

核心思想：**反函数的导数等于原函数导数的倒数**。


## 2. 核心公式

### 2.1 一阶导数

$$\boxed{\varphi'(y) = \frac{dx}{dy} = \frac{1}{\frac{dy}{dx}} = \frac{1}{f'(x)}}$$

> **注意**：求导时需将 $x$ 视为 $y$ 的函数。

### 2.2 二阶导数

$$\boxed{\varphi''(y) = -\frac{f''(x)}{[f'(x)]^3}}$$

其中 $x = \varphi(y)$，推导过程如下：

$$\varphi''(y) = \frac{d}{dy}\left[\frac{1}{f'(x)}\right] = \frac{d}{dx}\left[\frac{1}{f'(x)}\right] \cdot \frac{dx}{dy} = \frac{-f''(x)}{[f'(x)]^2} \cdot \frac{1}{f'(x)} = -\frac{f''(x)}{[f'(x)]^3}$$


## 3. 典型例题

### 例题

已知函数 $f(x) = e^x + 2x + 1$，设 $g(y)$ 与 $f(x)$ 互为反函数，则 $g''(2) = \, ?$

**选项**：  
(A) $-1$ (B) $-3$ (C) $-\dfrac{1}{27}$ (D) $-\dfrac{7}{8}$

### 解析

**Step 1：判断单调性并求关键点**

$$f(x) = e^x + 2x + 1 \quad \Rightarrow \quad f'(x) = e^x + 2 > 0$$

函数单调递增，反函数存在。

由 $f(0) = e^0 + 0 + 1 = 2$，得 $g(2) = 0$。


**Step 2：计算一阶导数**

$$f'(x) = e^x + 2$$

反函数一阶导数：

$$g'(y) = \frac{1}{f'(x)} = \frac{1}{e^x + 2}$$

其中 $x = g(y)$。


**Step 3：计算二阶导数（核心步骤）**

$$g''(y) = \frac{d}{dy}\left[\frac{1}{e^x + 2}\right]$$

对 $y$ 求导时，先对 $x$ 求导，再乘以 $\dfrac{dx}{dy}$：

$$g''(y) = \frac{-e^x}{(e^x + 2)^2} \cdot \frac{1}{e^x + 2} = -\frac{e^x}{(e^x + 2)^3}$$


**Step 4：代入数值**

当 $y = 2$ 时，$x = g(2) = 0$：

$$g''(2) = -\frac{e^0}{(e^0 + 2)^3} = -\frac{1}{(1+2)^3} = -\frac{1}{27}$$


**答案**：$\boxed{\text{(C)}\ -\dfrac{1}{27}}$


## 4. 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| **混淆变量** | 直接对 $y$ 求导时写成 $g''(y) = -\dfrac{e^y}{(e^y+2)^3}$ | 注意 $x$ 是 $y$ 的函数，需用链式法则 |
| **漏乘链式因子** | $g''(y) = \dfrac{-e^x}{(e^x+2)^2}$ | 必须乘以 $\dfrac{dx}{dy} = \dfrac{1}{e^x+2}$ |
| **记错公式** | 二阶导数写成 $-\dfrac{f''(x)}{[f'(x)]^2}$ | 分母应为 $[f'(x)]^3$ |
| **变量替换错误** | 求 $g''(2)$ 时直接代入 $y=2$ 到 $e^y$ | 应先将 $y=2$ 转为 $x=g(2)$，再计算 |


## 5. 关联知识点

```
反函数求导法则
├── 复合函数求导法则（链式法则）
├── 隐函数求导法则
├── 参数方程求导
└── 高阶导数计算
```

- **复合函数求导**：反函数二阶导数的推导本质是链式法则的应用
- **隐函数求导**：两者都涉及对中间变量的求导转换
- **可逆性条件**：$f'(x) \neq 0$ 是反函数存在且可导的必要条件


> **记忆口诀**：反函数导，导数倒数；二阶导数，负号别忘，分母立方。
