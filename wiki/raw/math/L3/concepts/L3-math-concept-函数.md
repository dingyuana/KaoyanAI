# 函数

## 概念定义

**函数**是高等数学最基本的概念之一，表示两个数集之间的一种对应关系。设 $D$ 为非空实数集合，若对于 $D$ 中的每一个数 $x$，按照某种法则 $f$，都有唯一确定的实数 $y$ 与之对应，则称 $y = f(x)$ 为定义在 $D$ 上的函数，其中 $D$ 称为函数的定义域。


## 核心公式

### 一、函数的基本性质

| 性质 | 定义 | 表达式 |
| **单调性** | 若 $x_1 < x_2$ 时，$f(x_1) < f(x_2)$ | $f(x)$ 单调递增 |
| **奇偶性** | $f(-x) = f(x)$ 或 $f(-x) = -f(x)$ | 偶函数 / 奇函数 |
| **周期性** | 存在 $T \neq 0$，使 $f(x+T) = f(x)$ | 最小正周期 $T$ |
| **有界性** | 存在 $M > 0$，使 $|f(x)| \leq M$ | 有界函数 |

### 二、反函数

若 $y = f(x)$ 在定义域上单调，则其反函数为：

$$x = f^{-1}(y)$$

**性质**：$f^{-1}[f(x)] = x$，$f[f^{-1}(y)] = y$

### 三、复合函数

设 $y = f(u)$，$u = g(x)$，则复合函数为：

$$y = f[g(x)]$$

### 四、基本初等函数

| 函数类型 | 表达式 | 定义域 |
| 幂函数 | $y = x^\alpha$ | $\alpha$ 决定 |
| 指数函数 | $y = a^x \quad (a > 0, a \neq 1)$ | $(-\infty, +\infty)$ |
| 对数函数 | $y = \log_a x \quad (a > 0, a \neq 1)$ | $(0, +\infty)$ |
| 三角函数 | $\sin x, \cos x, \tan x, \cot x$ | 分段定义 |
| 反三角函数 | $\arcsin x, \arccos x, \arctan x$ | $[-1,1]$ 或 $(-\infty,+\infty)$ |

### 五、常用恒等式

- $\sin^2 x + \cos^2 x = 1$
- $1 + \tan^2 x = \sec^2 x$
- $\ln(ab) = \ln a + \ln b$
- $a^{\log_a b} = b$
- $e^{\ln x} = x$


## 典型例题

### 例题一：求函数定义域

**题目**：求函数 $f(x) = \dfrac{\sqrt{x-1}}{\ln(2-x)}$ 的定义域。

**解答**：

由分母不为零：$\ln(2-x) \neq 0 \Rightarrow 2-x \neq 1 \Rightarrow x \neq 1$

由被开方数非负：$x - 1 \geq 0 \Rightarrow x \geq 1$

由对数定义：$2 - x > 0 \Rightarrow x < 2$

综上，取交集：$x \in [1, 2)$ 且 $x \neq 1$

$$\therefore \text{定义域为：} (1, 2)$$

**考点分析**：定义域的求解是高频考点，需同时满足根号、对数、分式三方面约束。


### 例题二：复合函数与函数性质

**题目**：设 $f(x) = \begin{cases} x^2 + 1, & x \leq 0 \\ 2x, & x > 0 \end{cases}$，求 $f[f(-1)]$。

**解答**：

第一步：计算 $f(-1)$

由于 $-1 \leq 0$，代入第一段：$f(-1) = (-1)^2 + 1 = 2$

第二步：计算 $f(2)$

由于 $2 > 0$，代入第二段：$f(2) = 2 \times 2 = 4$

$$\therefore f[f(-1)] = 4$$

**考点分析**：分段函数的复合运算，需判断每次运算中自变量所属的区间。


## 常见错误

| 序号 | 易错点 | 正确理解 |
| 1 | **忽略定义域** | 求函数表达式时必须注明定义域，如 $f(x) = \sqrt{x}$ 的定义域是 $[0, +\infty)$ |
| 2 | **反函数符号混淆** | $f^{-1}(x)$ 表示反函数，不是 $\dfrac{1}{f(x)}$ |
| 3 | **复合函数定义域** | $f[g(x)]$ 的定义域是 $g(x)$ 的值域落在 $f$ 定义域内的 $x$ 的集合 |
| 4 | **对数函数定义域** | $\ln x$ 的定义域是 $x > 0$，而非 $x \geq 0$ |
| 5 | **符号判断错误** | 奇函数满足 $f(-x) = -f(x)$，偶函数满足 $f(-x) = f(x)$ |
