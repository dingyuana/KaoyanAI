# 相互独立事件的定义

> **元数据**
> - **章节**：2026 张宇概率论 9讲(OCR)
> - **难度**：★★☆☆☆


## 1. 概念定义

### 1.1 两个事件的相互独立

设 $A$、$B$ 为两个事件：

| 关系类型 | 定义条件 | 含义 |
| **相互独立** | $P(AB) = P(A)P(B)$ | 两事件无关联 |
| **相互有利** | $P(AB) > P(A)P(B)$ | 两事件倾向于同时发生 |
| **相互抑止** | $P(AB) < P(A)P(B)$ | 两事件倾向于不同时发生 |

### 1.2 n 个事件的相互独立

设 $A_1, A_2, \ldots, A_n$（$n \geq 2$）为 $n$ 个事件，如果对其中**任意有限个**事件 $A_{i_1}, A_{i_2}, \ldots, A_{i_k}$，有

$$P(A_{i_1} A_{i_2} \cdots A_{i_k}) = P(A_{i_1})P(A_{i_2})\cdots P(A_{i_k})$$

则称这 $n$ 个事件**相互独立**。

### 1.3 n = 3 时的判定（常考）

设 $A_1, A_2, A_3$ 为三个事件，需**同时满足**以下四个等式：

$$
\begin{cases}
P(A_1 A_2) = P(A_1)P(A_2) & \text{①} \\
P(A_1 A_3) = P(A_1)P(A_3) & \text{②} \\
P(A_2 A_3) = P(A_2)P(A_3) & \text{③} \\
P(A_1 A_2 A_3) = P(A_1)P(A_2)P(A_3) & \text{④}
\end{cases}
$$

- **满足①、②、③** → 称为**两两独立**
- **同时满足①、②、③、④** → 称为**相互独立**

> ⚠️ **注意**：两两独立 $\neq$ 相互独立！④式是区分两者的关键。


## 2. 核心公式

### 2.1 独立事件的乘法公式

若 $A_1, A_2, \ldots, A_n$ **相互独立**，则：

$$\boxed{P(A_1 A_2 \cdots A_n) = P(A_1) \cdot P(A_2) \cdot \cdots \cdot P(A_n)}$$

### 2.2 n 个独立事件至少发生一个的概率

若 $A_1, A_2, \ldots, A_n$ **相互独立**，则：

$$\boxed{P(A_1 \cup A_2 \cup \cdots \cup A_n) = 1 - \prod_{i=1}^{n}[1 - P(A_i)]}$$

### 2.3 对立事件的独立性（重要性质）

> **定理**：将相互独立的事件组中的**任何几个事件**换成各自的对立事件，所得的新事件组**仍相互独立**。

特别地：
$$A \text{ 与 } B \text{ 独立} \Longleftrightarrow A \text{ 与 } \bar{B} \text{ 独立} \Longleftrightarrow \bar{A} \text{ 与 } B \text{ 独立} \Longleftrightarrow \bar{A} \text{ 与 } \bar{B} \text{ 独立}$$


## 3. 典型例题

### 【例题】

> 设 $P(A) = 0.4$，$P(B) = 0.3$，$P(A \cup B) = 0.6$，判断 $A$ 与 $B$ 的关系。

**【解答】**

**法一：计算 $P(AB)$**
$$P(A \cup B) = P(A) + P(B) - P(AB)$$
$$0.6 = 0.4 + 0.3 - P(AB)$$
$$P(AB) = 0.1$$

**法二：比较 $P(AB)$ 与 $P(A)P(B)$**
$$P(A)P(B) = 0.4 \times 0.3 = 0.12$$

因为 $P(AB) = 0.1 < 0.12 = P(A)P(B)$，所以：

$$\boxed{A \text{ 与 } B \text{ 相互抑止}}$$


## 4. 常见错误

| # | 错误类型 | 正确理解 |
| 1 | **混淆"互斥"与"独立"** | 互斥：$P(AB) = 0$；独立：$P(AB) = P(A)P(B)$。两者无必然关系 |
| 2 | **两两独立 ≠ 相互独立** | 三个事件两两独立，不能推出三者相互独立，还需验证积事件的概率公式 |
| 3 | **忽略④式** | 判断三个事件相互独立时，必须验证 $P(A_1 A_2 A_3) = P(A_1)P(A_2)P(A_3)$ |
| 4 | **错误使用加法公式** | $P(A \cup B) = P(A) + P(B) - P(AB)$，独立时才能简化为 $P(A) + P(B)$（仅限互斥情形） |
| 5 | **对立事件独立判断** | $A$ 与 $B$ 独立，则 $A$ 与 $\bar{B}$ 也独立；$\bar{A}$ 与 $\bar{B}$ 也独立 |
