# 随机试验

## 概念定义

**随机试验**是指在相同条件下可以重复进行，但每次试验前无法确定其结果，具有**事先不确定性**的试验过程。

> 随机试验是概率论的研究对象，是一切概率统计理论的基石。


## 核心特征

随机试验必须同时满足以下 **三个特征**：

| 特征 | 说明 |
| **可重复性** | 在相同条件下可以重复进行多次 |
| **可知性** | 试验的所有可能结果是已知的 |
| **不确定性** | 每次试验前无法预知会出现哪个结果 |


## 典型例题

### 例题 1：判断是否为随机试验

**题目**：判断下列试验是否为随机试验：
- (1) 投掷一枚均匀硬币，观察正面朝上还是反面朝上
- (2) 抛掷一枚骰子，观察出现的点数
- (3) 测量某人的身高
- (4) 从10件产品中任取3件，观察次品数

**解答**：

| 试验 | 是否随机试验 | 理由 |
| (1) 投硬币 | ✅ 是 | 可重复进行；结果只有两种且可知；每次结果不确定 |
| (2) 抛骰子 | ✅ 是 | 可重复进行；结果在{1,2,3,4,5,6}中可知；每次结果不确定 |
| (3) 测身高 | ⚠️ 需分情况 | 若对同一人重复测量，一般是确定性的；若对不同人随机抽取测量，则是随机试验 |
| (4) 取产品 | ✅ 是 | 可重复进行；结果{0,1,2,3}可知；每次结果不确定 |

**考点分析**：随机试验三特征（可重复性、可知性、不确定性）的识别与判断。


### 例题 2：描述随机试验的样本空间

**题目**：描述下列随机试验的样本空间 $\Omega$：
- (1) 抛两枚硬币
- (2) 记录某路口一小时内通过的车辆数

**解答**：

**(1)** 抛两枚硬币的样本空间为：
$$\Omega_1 = \{HH, HT, TH, TT\}$$
其中 $H$ 表示正面，$T$ 表示反面。

**(2)** 一小时内通过的车辆数（假设最多不超过 $N$ 辆）：
$$\Omega_2 = \{0, 1, 2, \ldots, N\}$$
或写作 $\Omega_2 = \{0, 1, 2, \ldots\}$

**考点分析**：样本空间的概念、随机试验结果的列举方法。


## 常见错误

| 错误类型 | 错误示例 | 正确理解 |
| 混淆随机试验与随机现象 | "天气变化是随机试验" | 天气变化是**随机现象**，只有当设计好观测规则后才构成随机试验 |
| 忽视可重复性 | "太阳从东方升起"不是随机试验 | 该现象不可重复（每天都发生），不满足随机试验条件 |
| 误判可知性 | 声称试验结果完全未知 | 即使单个结果不确定，但**所有可能结果的集合**必须是已知的 |
| 混淆确定性与随机性 | "明天是否下雨"是确定事件 | 这里的"是否下雨"在观测前不确定，是典型的随机试验 |


## 关联知识点

### 前置依赖
- **无**（随机试验是概率论的逻辑起点）

### 同类关联

| 知识点 | 关系说明 |
| **随机事件** | 随机试验的某个结果或结果集合 |
| **样本空间** | 随机试验所有可能结果的全体 |
| **随机变量** | 定义在随机试验样本空间上的函数 |
| **概率** | 描述随机试验中各事件发生的可能性大小 |

### 知识脉络

```
随机试验 → 样本空间 → 随机事件 → 事件的概率
           ↓
      随机变量 → 分布函数 → 数字特征
```


## 补充说明

1. **随机试验的"相同条件"**：指试验的基本条件保持不变，但允许随机因素存在
2. **随机试验 vs 随机现象**：随机现象是客观存在的，随机试验是人为定义的观测过程
3. **确定性试验**：结果唯一确定的试验（如自由落体）不属于随机试验
