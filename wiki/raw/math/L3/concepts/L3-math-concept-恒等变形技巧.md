# 恒等变形技巧


**章节**：2026 张宇高数 18讲(OCR)  
**难度**：★★☆☆☆


## 1. 概念定义

恒等变形技巧是高等数学中处理**极限计算**的重要方法，其核心思想是：

> **化归经典形式** —— 将复杂的表达式通过代数恒等变形，转化为已知极限结果的"经典形式"（如 $e$、$\ln(1+x)$、$(1+u)^v$ 等）

### 核心原则

| 原则 | 说明 |
|------|------|
| **合零为整** | 将 $f(x) - ax$ 等差式转化为乘除形式 |
| **识别经典** | 识别 $\frac{e^x-1}{x}$、$\frac{\ln(1+x)}{x}$ 等经典极限结构 |
| **等价替换** | 利用泰勒展开或等价无穷小简化计算 |


## 2. 核心公式

### 2.1 经典极限形式

$$\lim_{x \to 0} \frac{e^x - 1}{x} = 1$$

$$\lim_{x \to 0} \frac{\ln(1+x)}{x} = 1$$

$$\lim_{x \to 0} (1+x)^{\frac{1}{x}} = e$$

### 2.2 常用恒等变形

$$\boxed{a^n - b^n = (a-b)(a^{n-1} + a^{n-2}b + \cdots + b^{n-1})}$$

$$\boxed{e^x - e^{\sqrt{x}} = e^{\sqrt{x}}(e^{x-\sqrt{x}} - 1)}$$

$$\boxed{1 + x - \sqrt{1+2x} = \frac{x^2}{1+x+\sqrt{1+2x}}}$$


## 3. 典型例题

### 例题：利用恒等变形求极限

**题目**：计算 $\lim\limits_{x \to 3} \dfrac{x + x^3 - 3x^2}{\ln(3+x-x^2)}$

**解题步骤**：

**Step 1：分子因式分解**

$$x + x^3 - 3x^2 = x(1 + x^2 - 3x) = x(x-1)(x-3)$$

**Step 2：分母化简**

令 $t = x - 3$，则 $x = t + 3$

$$3 + x - x^2 = 3 + (t+3) - (t+3)^2 = 3 + t + 3 - (t^2+6t+9) = -t^2 - 5t$$

**Step 3：化归经典形式**

$$\ln(3+x-x^2) = \ln[1 + (x+x^3-3x^2)]$$

当 $x \to 3$ 时，$x + x^3 - 3x^2 \to 0$，可用 $\ln(1+u) \sim u$

**Step 4：代入计算**

$$\lim_{x \to 3} \frac{x + x^3 - 3x^2}{\ln(3+x-x^2)} = \lim_{x \to 3} \frac{x + x^3 - 3x^2}{x + x^3 - 3x^2} = \boxed{1}$$


## 4. 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|----------|----------|----------|
| **生搬硬套等价无穷小** | 在 $\frac{e^x-1}{x}$ 中令 $x=1$ 得 $0$ | 等价无穷小替换要求 $x \to 0$ |
| **恒等变形不彻底** | $\lim\limits_{x\to 0}\frac{e^x-1}{x}$ 直接写 $=1$ | 需明确分子分母同阶 |
| **忽略定义域** | $\ln(1+x) \sim x$ 用于 $x < -1$ | 仅在 $x > -1$ 时成立 |
| **指数处理错误** | $e^x - e^{\sqrt{x}}$ 直接相减 | 应提取公因子 $e^{\sqrt{x}}$ |


## 5. 关联知识点

- **第一章：函数极限与连续**
  - 等价无穷小替换
  - 泰勒公式

- **指数与对数**
  - $e$ 的定义：$\lim\limits_{n\to\infty}(1+\frac{1}{n})^n = e$
  - 对数恒等式：$\ln(ab) = \ln a + \ln b$

- **因式分解**
  - 立方差/立方和公式
  - 有理化技巧


## 6. 方法论总结

```
恒等变形解题流程：
┌─────────────────────────────────────┐
│  1. 观察分子分母结构                  │
│         ↓                           │
│  2. 尝试因式分解或提取公因子          │
│         ↓                           │
│  3. 识别经典极限形式                  │
│         ↓                           │
│  4. 化归为 (e^x-1)/x 或 ln(1+x)/x   │
│         ↓                           │
│  5. 代入经典极限结果                  │
└─────────────────────────────────────┘
```


> **记忆口诀**：恒等变形贵在"整"，化归经典思路清；等价替换要注意，$x\to 0$ 是前提。
