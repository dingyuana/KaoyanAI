# 概率论与数理统计-第33讲：数字特征

## 核心概念定义
数字特征是描述随机变量分布的重要统计量，包括数学期望、方差、协方差等。数学期望是随机变量取值的加权平均，方差是随机变量取值与其期望之差的平方的期望。

## 核心公式
```latex
E(X) = \int_{-\infty}^{\infty} x f(x) \, dx
D(X) = E[(X - E(X))^2]
Cov(X, Y) = E[(X - E(X))(Y - E(Y))]
```

## 典型例题
**例6.2** 设随机变量 \(X, Y\) 独立同分布于 \(N(0,1)\)，求 \(E(\max\{X, Y\})\) 和 \(E(\min\{X, Y\})\)。

**解** 由题设，\(X - Y \sim N(0,2)\)，且 \(\max\{X, Y\} = \frac{X + Y + 2X - Y}{2}\)，故
\[ E(\max\{X, Y\}) = E\left(\frac{X + Y + 2X - Y}{2}\right) = E(X) + E(Y) + E(X) - E(Y) = 2E(X) \]
同理，\(E(\min\{X, Y\}) = E(X) - E(Y)\)。

**注** 因 \(\max\{X, Y\} + \min\{X, Y\} = X + Y\)，故 \(E(\min\{X, Y\}) = 0\)。

**例6.3** 设随机变量 \(X\) 服从参数为 \(\lambda\) 的指数分布，\(Y = [X]\)，\(Z = \{X\}\) 分别是 \(X\) 的整数部分和小数部分。求 \(E(Y)\) 和 \(E(Z)\)。

**解** 由例3.3可知 \(Y + 1\) 服从参数为 \(1 - e^{-1}\) 的几何分布，则
\[ E(Y + 1) = \frac{1}{1 - e^{-1}} = 1 - e^{-1} \]
由题意，有
\[ E(Y) = E(Y + 1) - 1 = e^{-1} - 1 \]
\[ X = Y + Z \]
\[ E(Z) = E(X) - E(Y) \]

## 常见错误
1. 忽略随机变量的独立性。
2. 错误地计算数学期望和方差。
3. 忽略随机变量的分布类型。
