# 高等数学-第137讲

## 核心概念定义
多元函数微分学的预备知识主要涉及多元函数的泰勒展开、空间曲线的切线与法平面、空间曲面的切平面与法线等概念。

## 核心公式
```latex
f(x,y) = f(0,0) + xf_x'(0,0) + yf_y'(0,0) + \frac{1}{2}x^2f_{xx}''(0,0) + \frac{1}{2}y^2f_{yy}''(0,0) + \frac{1}{2}xyf_{xy}''(0,0) + o(x^2 + y^2)
```

## 典型例题
**例17.4** 设 \( f(x,y) = \cos(x) \) 在点 \( (0,0) \) 处的二次泰勒多项式为 \( a + bx^2 + cy^2 \)，则 \( ( \) \).
(A) \( a=1, b=-2, c=2 \)
(B) \( a=1, b=2, c=-2 \)
(C) \( a=-1, b=-2, c=2 \)
(D) \( a=-1, b=2, c=-2 \)

**解** 应选 (A).

由题得 \( f(0,0) = 1, f_x'(0,0) = 0, f_y'(0,0) = 0, f_{xx}''(0,0) = -1, f_{yy}''(0,0) = 0, f_{xy}''(0,0) = 0 \).

\( f(x,y) = f(0,0) + xf_x'(0,0) + yf_y'(0,0) + \frac{1}{2}x^2f_{xx}''(0,0) + \frac{1}{2}y^2f_{yy}''(0,0) + \frac{1}{2}xyf_{xy}''(0,0) + o(x^2 + y^2) \)

得 \( \cos(x) = 1 - x^2 + 2y^2 + o(x^2 + y^2) \)，故 \( a=1, b=-2, c=2 \).

## 常见错误
1. 忽略泰勒展开的二次项。
2. 错误计算偏导数。
3. 错误应用切线与法平面的公式。
