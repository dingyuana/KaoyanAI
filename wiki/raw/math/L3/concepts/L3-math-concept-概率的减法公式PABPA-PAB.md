## 1. 概念定义

### 1.1 加法公式

**加法公式**用于计算两个或多个事件并集的概率，核心思想是：
> 将各事件概率相加，再减去重复计数的交集部分。

### 1.2 减法公式

**减法公式**用于计算两个事件的差事件的概率：
> 事件 A 发生而 B 不发生的概率，等于 A 的概率减去 A、B 同时发生的概率。

### 1.3 互斥思想

当事件之间互斥（互不相容）时，并集概率简化为各概率之和：

$$P(A_1 \cup A_2 \cup \cdots \cup A_n) = P(A_1) + P(A_2) + \cdots + P(A_n) \quad (A_i \text{ 两两互斥})$$


## 2. 核心公式

### 2.1 基本公式

**减法公式（差事件）：**
$$P(A - B) = P(AB) = P(A) - P(AB)$$

> 其中 $AB$ 表示 A 与 B 的差事件，即「A 发生且 B 不发生」。

**两个事件的加法公式：**
$$P(A \cup B) = P(A) + P(B) - P(AB)$$

**三个事件的加法公式：**
$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(BC) - P(AC) + P(ABC)$$

### 2.2 互斥思想相关公式

**① 集合分解（任一事件可分解为互斥部分）：**
$$A = (A - B_1) \cup (A - B_2) \cup \cdots \cup (A - B_n) \cup (A \cap B_1 \cap B_2 \cap \cdots \cap B_n)$$

**② 完备事件组分解：**
若 $B_1, B_2, \ldots, B_n$ 为完备事件组，则：
$$A = AB_1 \cup AB_2 \cup \cdots \cup AB_n$$

从而：
$$P(A) = P(AB_1) + P(AB_2) + \cdots + P(AB_n)$$


## 3. 典型例题

### 例题

> 设 $A, B, C$ 为三个随机事件，且
> $$P(A) = P(B) = P(C) = \frac{1}{4}, \quad P(AB) = 0, \quad P(AC) = P(BC) = \frac{1}{8}$$
> 则 $A, B, C$ 中**恰有一个事件发生**的概率为（ ）
> 
> (A) $\frac{1}{4}$ $\quad$ (B) $\frac{1}{2}$ $\quad$ (C) $\frac{1}{12}$ $\quad$ (D) $\frac{5}{12}$

### 解法

**步骤 1：写出「恰有一个发生」的概率表达式**

恰有一个事件发生 = $AB \cup ABC \cup ABC$，注意这里用的是差事件表示。

$$P(\text{恰有一个发生}) = P(AB) + P(ABC) + P(ABC)$$

**步骤 2：利用减法公式转化**

由 $P(AB) = P(A) - P(ABC)$：
$$P(AB) = P(A) - P(ABC) = \frac{1}{4} - P(ABC)$$

同理：
$$P(ABC) = P(B) - P(ABC) = \frac{1}{4} - P(ABC)$$
$$P(ABC) = P(C) - P(ABC) = \frac{1}{4} - P(ABC)$$

**步骤 3：计算 $P(ABC)$**

由 $P(AB) = 0$ 且 $P(AB) = P(A) - P(ABC)$：
$$0 = \frac{1}{4} - P(ABC) \implies P(ABC) = \frac{1}{4}$$

**步骤 4：代入计算**

$$P(\text{恰有一个发生}) = \left(\frac{1}{4} - \frac{1}{4}\right) + \left(\frac{1}{4} - \frac{1}{4}\right) + \left(\frac{1}{4} - \frac{1}{4}\right) = 0 + 0 + \frac{1}{4} = \frac{1}{4}$$

**答案：** $\boxed{\text{选 (A)}}$


## 4. 常见错误

| 序号 | 错误类型 | 错误示例 | 正确做法 |
| 1 | **混淆记号** | 混淆 $AB$（积事件）与 $A-B$（差事件）的含义 | 明确 $AB = A - B$ 是「A 发生且 B 不发生」 |
| 2 | **重复扣减** | 三个事件加法公式漏项或多项 | 记住口诀：「相加减相交，加回去」 |
| 3 | **忽视互斥条件** | 对互斥事件仍使用一般加法公式 | 互斥时直接相加，无需减交集 |
| 4 | **遗漏完备事件组分解** | 不会将复杂事件拆分为互斥的子事件 | 熟练掌握 $A = \bigcup\limits_{i=1}^{n} AB_i$ 的分解技巧 |
| 5 | **符号书写错误** | 将 $P(A-B)$ 写成 $P(AB)$ | 注意：减法公式中 $P(AB)$ 表示差事件，不是积事件 |
