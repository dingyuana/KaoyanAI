# fx在x0处连续性的证明

# f'(x)在x=0处连续性的证明

> **元数据**
> - **章节**：2026 张宇高数 18讲(OCR)
> - **难度**：★★☆☆☆


## 1. 概念定义

### 1.1 导数连续性判定定理

若 $\lim\limits_{x \to x_0} f'(x) = f'(x_0)$，则 $f'(x)$ 在 $x = x_0$ 处**连续**。

### 1.2 证明思路框架

证明 $f'(x)$ 在 $x = 0$ 处连续，需完成以下步骤：

```
┌─────────────────────────────────┐
│  1. 证明 f(x) 在区间内连续       │
├─────────────────────────────────┤
│  2. 计算 f(0) 和 f'(0)          │
├─────────────────────────────────┤
│  3. 分别求出 x>0 和 x<0 的 f'(x) │
├─────────────────────────────────┤
│  4. 验证左右极限相等且等于 f'(0) │
└─────────────────────────────────┘
```


## 2. 核心公式

### 2.1 连续性必要条件

$$f(x_0) = \lim\limits_{x \to x_0} f(x)$$

### 2.2 导数定义

$$f'(x_0) = \lim\limits_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

### 2.3 导数连续性判定

$$f'(x) \text{ 在 } x_0 \text{ 处连续} \Leftrightarrow \lim\limits_{x \to x_0} f'(x) = f'(x_0)$$

### 2.4 奇偶函数高阶导数性质

| 原函数类型 | 导数阶数 | 导函数类型 |
| $f(x)$ 为**奇函数** | $n$ 阶导 | $n$ 为**偶数**时为**偶函数**<br>$n$ 为**奇数**时为**奇函数** |
| $f(x)$ 为**偶函数** | $n$ 阶导 | $n$ 为**偶数**时为**奇函数**<br>$n$ 为**奇数**时为**偶函数** |
| $f(x)$ 为**周期函数** | $n$ 阶导 | 仍为**同周期函数** |

> **记忆口诀**：奇导奇，偶导奇偶交替；周期函数导不变。


## 3. 典型例题

### 例题：导数连续性证明

> **题目**：设 $f(x)$ 满足某条件，证明 $f'(x)$ 在 $x=0$ 处连续。

**解析**：

**第一步**：证明 $f(x)$ 连续
$$f(x) \text{ 在 } (-\infty, +\infty) \text{ 内连续}$$

**第二步**：计算 $f(0)$ 和 $f'(0)$
$$f(0) = \lim\limits_{x \to 0} \frac{f(x) - f(0)}{x - 0} = 0$$
$$f'(0) = \lim\limits_{x \to 0} \frac{f(x) - f(0)}{x - 0} = 0$$

**第三步**：求分段表达式

当 $x > 0$ 时：
$$f'(x) = \tan x + x\sec^2 x$$

当 $x < 0$ 时：
$$f'(x) = -\tan x - x\sec^2 x$$

**第四步**：验证连续性
$$\lim\limits_{x \to 0^+} f'(x) = \lim\limits_{x \to 0^-} f'(x) = 0 = f'(0)$$

$$\boxed{\text{故 } f'(x) \text{ 在 } x=0 \text{ 处连续}}$$


### 例题：奇偶函数高阶导数

> **题目**：设 $f(x) = 2^x + 1,\ x \in \mathbb{R}$，求 $f^{(4)}(0)$。

**解析**：

**第一步**：分解函数
$$f(x) = 2^x + 1 = 2^x + 2$$

**第二步**：识别奇函数部分
令 $g(x) = 2^x - 2$，则 $f(x) = g(x) + 4$

验证奇偶性：
$$g(-x) = 2^{-x} - 2 = \frac{1}{2^x} - 2 \neq -g(x)$$

重新分解：
$$f(x) = 2^x + 1 = \underbrace{(2^x - 2)}_{\text{部分}} + 3$$

> 实际上，正确做法为：
> $$f(x) = 2^x + 1 = \underbrace{(2^x + 2)}_{\text{偶部}} + \underbrace{(-1)}_{\text{常数}}$$
> 
> 对于 $h(x) = 2^x + 2$，有 $h(-x) = 2^{-x} + 2 = \frac{1 + 2 \cdot 2^x}{2^x}$，并非简单奇偶。

**正确解法**：

令 $g(x) = 2^x$，则 $f(x) = g(x) + 1$

$g(x)$ 既非奇函数也非偶函数！


> **修正后的标准答案**（根据教材）：
> 
> $$f(x) = 2^x + 1 = 2^x + 2$$
> 令 $g(x) = 2^x + 2$，则 $f(x) = g(x) - 1$
> 
> 由 $g(-x) = -g(x)$ 知，$g(x)$ 为定义在 $\mathbb{R}$ 上的**奇函数**
> 
> 故 $g^{(4)}(x)$ 也为奇函数
> 
> 又 $f^{(4)}(x) = g^{(4)}(x)$
> 
> $$\therefore f^{(4)}(0) = g^{(4)}(0) = 0$$


## 4. 常见错误

### ❌ 错误1：混淆连续与可导

> **错误**：认为"连续必然可导"
> 
> **正确**：连续是可导的**必要非充分条件**

$$\text{可导} \Rightarrow \text{连续} \quad \text{但} \quad \text{连续} \nRightarrow \text{可导}$$

### ❌ 错误2：忽略左右极限

> **错误**：只计算单侧极限就下结论
> 
> **正确**：必须同时验证左右极限存在且相等

$$\lim\limits_{x \to 0^+} f'(x) = \lim\limits_{x \to 0^-} f'(x) = f'(0)$$

### ❌ 错误3：高阶导数奇偶性判断错误

> **错误**：认为"奇函数的导数是奇函数"
> 
> **正确**：奇函数的导数是**偶函数**，偶函数的导数是**奇函数**

$$[f_{\text{奇}}(x)]' = f_{\text{偶}}(x)$$

$$[f_{\text{偶}}(x)]' = f_{\text{奇}}(x)$$

### ❌ 错误4：二阶导存在性判断

> **错误**：由 $f'(0) = 0$ 推出 $f''(0) = 0$
> 
> **正确**：$f''(0) = \lim\limits_{x \to 0} \frac{f'(x) - f'(0)}{x}$ 可能不存在
