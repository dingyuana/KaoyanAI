# 相似理论

## 概念定义

**相似（Similar）**：设 \(A,B\in\mathbb{R}^{n\times n}\)，若存在可逆矩阵 \(P\) 使得  
\[
B = P^{-1}AP,
\]
则称 **\(A\) 与 \(B\) 相似**，记作 \(A\sim B\)。相似变换本质上是同一线性变换在不同基下的矩阵表示。

**相似对角化（Similar Diagonalization）**：如果存在可逆矩阵 \(P\)（或正交矩阵 \(Q\)）使得  
\[
P^{-1}AP = \Lambda \quad (\text{或 } Q^{T}AQ = \Lambda)
\]
其中 \(\Lambda\) 为对角矩阵，则称 **\(A\) 可相似对角化**。此时 \(A\) 的特征值恰好位于 \(\Lambda\) 的对角线上。

> **三向解题法**（盯住目标 → 常规操作 → 化归经典形式）是处理相似理论问题的通用思路：先明确要证的相似关系，再利用已知的特征值/特征向量结构，最后把问题化归为“求可逆矩阵 \(P\) 使 \(P^{-1}AP\) 为已知对角矩阵”。


## 核心公式

- **相似的定义**  
  \[
  A\sim B \iff \exists P\in GL_n(\mathbb{R}),\; B=P^{-1}AP.
  \]

- **可对角化的充要条件**（几何重数 = 代数重数）  
  \[
  A\sim\Lambda \iff \dim E_{\lambda_i}=m_i,\;\forall\lambda_i\in\sigma(A),
  \]
  其中 \(E_{\lambda_i}=\ker(A-\lambda_i I)\)，\(m_i\) 为特征值 \(\lambda_i\) 的代数重数。

- **实对称矩阵的正交相似对角化**  
  \[
  A=A^{T}\;\Longrightarrow\;\exists Q\;(Q^{T}Q=I),\; Q^{T}AQ=\operatorname{diag}(\lambda_1,\dots,\lambda_n).
  \]

- **相似不变量**（若 \(A\sim B\)）  
  \[
  \det A=\det B,\qquad \operatorname{tr}A=\operatorname{tr}B,\qquad \operatorname{rank}A=\operatorname{rank}B,
  \]
  \[
  \sigma(A)=\sigma(B),\qquad \chi_A(\lambda)=\chi_B(\lambda).
  \]

- **相似矩阵的多项式保持**  
  \[
  A\sim B \;\Longrightarrow\; f(A)\sim f(B),\quad \forall f\in\mathbb{R}[x].
  \]

- **正交矩阵的性质**  
  \[
  Q^{T}Q=I\;\Longleftrightarrow\; Q^{-1}=Q^{T},\qquad |\det Q| = 1.
  \]
  实特征值只能取 \(\pm1\)。


## 判定条件

### 1. 充要条件

1. **\(A\) 有 \(n\) 个线性无关的特征向量**  
   \[
   \iff A\sim\Lambda.
   \]
2. **几何重数等于代数重数**  
   \[
   n_i=n-\operatorname{rank}(\lambda_i E-A)\;\;(=m_i),\quad\forall\lambda_i.
   \]

### 2. 充分条件

| 条件 | 结论 |
|------|------|
| \(A\) 为[[实对称矩阵]] | \(A\sim\Lambda\)（存在正交矩阵） |
| \(A\) 有 \(n\) 个互不相同的特征值 | \(A\sim\Lambda\) |
| \(A^{k}=E\)（\(k\in\mathbb{N}\)） | \(A\sim\Lambda\) |
| \(A^{2}-(k_1+k_2)A+k_1k_2E=0\)，且 \(k_1\neq k_2\) | \(A\sim\Lambda\) |
| \(\operatorname{rank}(A)=1\) 且 \(\operatorname{tr}(A)\neq0\) | \(A\sim\Lambda\) |

### 3. 必要条件

- 若 \(A\sim\Lambda\)，则  
  \[
  \operatorname{rank}(A)=\#\{\lambda_i\neq0\},
  \]
  即非零特征值的个数（计重数）。

### 4. 否定条件（不可对角化）

- **\(A\neq0\) 且 \(A^{k}=0\)（\(k>1\)）** → 不可相似对角化。  
- **\(A\) 的所有特征值均为同一个数 \(\lambda\)，但 \(A\neq\lambda E\)** → 不可相似对角化。


## 非对称矩阵与实对称矩阵的异同

| 项目 | 非对称矩阵 \(A\) | 实对称矩阵 \(A\) |
|------|-------------------|-------------------|
| 是否可正交相似对角化 | 只能在可逆矩阵 \(P\) 下对角化，**不存在**正交矩阵 | 必存在正交矩阵 \(Q\) 使得 \(Q^{T}AQ=\Lambda\) |
| 特征向量的正交性 | 不同特征值的特征向量 **不一定** 正交 | 不同特征值的特征向量 **必正交**（可通过施密特正交化） |
| 相似对角化手段 | \(P^{-1}AP=\Lambda\) | \(Q^{T}AQ=\Lambda\)（\(Q\) 为正交） |

> **要点**：若题目要求“正交相似”，必须先判断矩阵是否为实对称；否则只能使用一般的可逆相似变换。


## 典型例题

### 例 8.1 相似对角化与列变换

**题目**  
设 \(A\) 为 3 阶矩阵，\(P=[\alpha_1,\alpha_2,\alpha_3]\) 为可逆矩阵，满足  
\[
P^{-1}AP=\Lambda=\begin{pmatrix}2&0&0\\0&2&0\\0&0&1\end{pmatrix}.
\]  
令  
\[
Q=[\alpha_1+\alpha_2,\;\alpha_2,\;\alpha_3],
\]  
求 \(Q^{-1}AQ\)。

**解答**  

1. **矩阵分解**  
   \[
   Q=P\,S,\qquad 
   S=\begin{pmatrix}1&0&0\\1&1&0\\0&0&1\end{pmatrix}.
   \]

2. **利用相似变换的可乘性**  
   \[
   Q^{-1}AQ = S^{-1}P^{-1}AP\,S
            = S^{-1}\Lambda S.
   \]

3. **计算 \(S^{-1}\Lambda S\)**  

   - 先算 \(\Lambda S\)：  
     \[
     \Lambda S=
     \begin{pmatrix}
     2&0&0\\0&2&0\\0&0&1
     \end{pmatrix}
     \begin{pmatrix}
     1&0&0\\1&1&0\\0&0&1
     \end{pmatrix}
     =
     \begin{pmatrix}
     2&0&0\\2&2&0\\0&0&1
     \end{pmatrix}.
     \]
   - 再算 \(S^{-1}\Lambda S\)：因为 \(\Lambda\) 的前两个对角元相等（均为 2），\(S\) 与 \(\Lambda\) 可交换，  
     \[
     S^{-1}\Lambda S = \Lambda.
     \]

4. **结论**  

   \[
   Q^{-1}AQ = \Lambda = \begin{pmatrix}2&0&0\\0&2&0\\0&0&1\end{pmatrix}.
   \]

> 因此答案为 **\(\begin{pmatrix}2&0&0\\0&2&0\\0&0&1\end{pmatrix}\)**（选项 B）。


## 常见错误

1. **误以为“特征值互异”是可对角化的必要条件**  
   - 实对称矩阵即使特征值有重根，只要几何重数等于代数重数仍可对角化。  
   - *纠正*：只能把它当作**充分条件**。

2. **混淆“相似”与“正交相似”**  
   - 正交矩阵只能在[[实对称矩阵]]的情形下保证 \(Q^{T}AQ\) 为对角矩阵。  
   - *纠正*：若题目未说明“正交”，只能使用普通可逆矩阵 \(P\)。

3. **在求 \(P^{-1}AP\) 时忘记对 \(P\) 做相应的列/行变换**  
   - 例 8.1 中的 \(Q\) 实际上是 \(P\) 左乘一个初等列变换矩阵 \(S\)。  
   - *纠正*：先把变换矩阵写成 \(Q=PS\)，再代入相似公式。

4. **忽视非零特征值与秩的关系**  
   - 必要条件 \(\operatorname{rank}(A)=\#\{\lambda_i\neq0\}\) 常被忘记，导致误判可对角化。  
   - *纠正*：先用秩快速排除不可能的情形。

5. **对 \(A^{k}=E\) 或 \(A^{2}=cA+dE\) 条件的误用**  
   - 这些条件仅在**所有特征值满足相同多项式**时才是充分条件。  
   - *纠正*：检验是否所有特征值都满足 \(f(\lambda)=0\)。

## 小结

相似理论是线性代数核心概念之一，涉及 **相似矩阵的判别、可对角化的充分必要条件、以及实对称矩阵的正交相似**。掌握以下关键点：

1. **相似定义** 与 **不变量**（行列式、迹、秩、特征值）是判断相似的基础。  
2. **可对角化的判定**（几何重数＝代数重数）以及常见的 **充分条件**（互异特征值、实对称等）。  
3. **正交矩阵** 在实对称矩阵中的特殊作用——提供 **正交相似**。  
4. **三向解题法**：盯住目标 → 常规操作 → 化归经典形式，是解决相似相关题目的通用框架。  

熟练运用上述工具，能够快速、准确地处理 **相似对角化、矩阵幂次计算、特征向量正交化** 等典型问题。
