# 高等数学-第112讲：微分方程

## 核心概念定义
微分方程是描述函数及其导数之间关系的方程。高阶常系数线性微分方程是其中一类，其一般形式为 \( y^{(n)} + p_{n-1}(x)y^{(n-1)} + \ldots + p_1(x)y' + p_0(x)y = f(x) \)。

## 核心公式
```latex
y^{(n)} + p_{n-1}(x)y^{(n-1)} + \ldots + p_1(x)y' + p_0(x)y = f(x)
```

## 典型例题
**例15.7** 求解微分方程 \( xy'' + x(y')^2 - yy' = 0 \)。

**解**：原方程化为 \( x(y')' - yy^3 = 0 \)。两端同时乘以 \( \frac{1}{y^3} \)，得 \( x\left(\frac{y'}{y^3}\right)' = 0 \)，即 \( \left(\frac{y'}{y^3}\right) = C_1 \)，所以 \( y' = C_1y^3 \)。分离变量后，解得 \( \frac{1}{y^2} = C_2x^2 + C_3 \)，式中 \( C_2, C_3 \) 为任意常数。

## 常见错误
1. 忽略微分方程的阶数。
2. 在求解微分方程时，未正确处理齐次方程和特解。
3. 在求解欧拉方程时，未正确进行变量替换。
