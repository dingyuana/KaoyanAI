# 高等数学-第65讲：一元函数积分学的概念与性质

## 核心概念定义
一元函数积分学是研究函数在某一区间上的积分运算及其性质的数学分支。它包括定积分和反常积分，其中定积分是反常积分的特例。

## 核心公式
```latex
\int_a^b f(x) \, dx = F(b) - F(a) \quad \text{(牛顿-莱布尼茨公式)}
\int_0^\infty \frac{1}{x^p} \, dx = \begin{cases} 
\frac{1}{1-p} & \text{if } 0 < p < 1 \\
\text{divergent} & \text{if } p \geq 1 
\end{cases}
```

## 典型例题
**例8.6** 设常数 \( p > 0, q > 0 \)，若 \(\int_0^1 x^p \, dx\) 收敛，则 \( ( ) \)。
(A) \( 0 < p < 1, 0 < q < 2 \)
(B) \( p > 1, 1 < q < 2 \)
(C) \( 0 < p < 1, 0 < q < 1 \)
(D) \( p > 1, 0 < q < 1 \)
【解】应选(A)。

**例8.7** 设 \( p \) 为常数，若反常积分 \(\int_0^1 x^p (1-x)^q \ln x \, dx\) 收敛，则 \( ( ) \)。
(A) \( p < -1 \)
(B) \( -1 < p \leq 0 \)
(C) \( 0 \leq p < 1 \)
(D) \( p > 1 \)
【解】应选(B)。

## 常见错误
1. 忽视积分区间的端点值，导致错误地判断积分的敛散性。
2. 在换元积分时，未正确处理新变量与原变量的关系，导致计算错误。
3. 在应用积分公式时，未注意公式的适用条件，导致错误地应用公式。
