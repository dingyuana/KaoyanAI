# 法线在y轴上的截距


**章节**：2026 张宇高数 18讲(OCR)  
**难度**：★★☆☆☆


## 1. 概念定义

设曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处的切线方程为：

$$Y - f(x_0) = f'(x_0)(X - x_0)$$

**法线在 $y$ 轴上的截距** = 令切线方程中 $X = 0$ 时，对应的 $Y$ 值。

即切线与 $y$ 轴交点的纵坐标。


## 2. 核心公式

切线方程，令 $X = 0$ 代入：

$$Y_{\text{截距}} - f(x_0) = f'(x_0)(0 - x_0)$$

$$\boxed{b = f(x_0) - x_0 \cdot f'(x_0)}$$

其中 $b$ 为法线（切线）在 $y$ 轴上的截距。


## 3. 典型例题

**例题**：已知 $f(x) = x^2 + 1$，求曲线在点 $(1, 2)$ 处的切线在 $y$ 轴上的截距。

**解**：
1. 求导数：$f'(x) = 2x$
2. 计算 $f'(1) = 2$
3. 切线方程：$Y - 2 = 2(X - 1)$，即 $Y = 2X$
4. 令 $X = 0$：$Y = 0$

$$\therefore \text{在 } y \text{ 轴上的截距 } b = 0$$


## 4. 常见错误

| 错误类型 | 正确做法 |
|---------|---------|
| 混淆"截距"与"截距绝对值" | 截距有正负号，需带符号计算 |
| 将 $x$ 轴截距公式误用于 $y$ 轴 | $x$ 轴截距令 $Y = 0$，$y$ 轴截距令 $X = 0$ |
| 求法线方程而非切线方程 | 截距问题默认针对切线，除非特别说明 |
| 计算时代入错误的点坐标 | 截距公式中的 $x_0$ 必须是切点横坐标 |
