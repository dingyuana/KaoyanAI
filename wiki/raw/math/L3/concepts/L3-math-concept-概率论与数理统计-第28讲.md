# 概率论与数理统计-第28讲：多维随机变量函数的分布

## 核心概念定义
多维随机变量函数的分布是指给定一个多维随机变量，研究其函数的分布情况。通过换元法，可以将复杂的多维随机变量函数的分布转化为更简单的形式。

## 核心公式
```latex
f_{U,V}(u,v) = f_{X,Y}[x(u,v), y(u,v)] \cdot |J|, \quad J = \left| \frac{\partial (x,y)}{\partial (u,v)} \right|
```

## 典型例题
**例5.2** 设随机变量 \(X, Y\) 相互独立，且均服从参数为 \(\lambda\) 的指数分布，令 \(Z = |X - Y|\)，则下列随机变量中与 \(Z\) 同分布的是：

(A) \(X + Y\)

(B) \(X^2 + Y\)

(C) \(2X\)

(D) \(X\)

**解** 应选 (D)。

**例5.3** 设 \((X, Y) \sim f(x, y) = \begin{cases} 8, & 0 < x < 1, 0 < y < 1 \\ 0, & \text{其他} \end{cases}\)，记 \(Z = X - Y\)。

(1) 求 \(Z\) 的概率密度 \(f_Z(z)\)；
(2) 求 \(P\{Z < 0\}\)。

**解** (1) 令 \(u = x - y\)，则 \(y = x - u\)，\(x = u + y\)。根据换元法，有：

\[ f_Z(z) = \begin{cases} 2z, & 0 < z < 1 \\ 1 - 2z, & 1 < z < 2 \\ 0, & \text{其他} \end{cases} \]

(2) 由于 \(P\{Z < 0\} = P\{X - Y < 0\} = P\{X < Y\} = 0\)，故 \(P\{Z < 0\} = 0\)。

## 常见错误
1. 忘记考虑反函数的存在性；
2. 换元时，未正确计算雅可比行列式；
3. 在求解概率密度时，未正确处理边界情况。
