# 压缩映射原理二

## 元数据

- **章节**：2026 张宇高数 18讲(OCR)
- **难度**：★★☆☆☆
- **标签**：数列收敛、迭代法、不动点定理


## 1. 概念定义

**压缩映射原理**是研究数列收敛性的重要工具，其核心思想是：如果数列的相邻两项之差按固定比例缩小，则该数列必收敛。

### 原理一（基本形式）

设数列 $\{x_n\}$，若存在常数 $k$（$0 < k < 1$）和常数 $a$，使得
$$|x_{n+1} - a| \leq k |x_n - a|, \quad n = 1, 2, \ldots$$

则 $\{x_n\}$ **收敛于** $a$。

### 原理二（导数形式）

设数列 $\{x_n\}$ 满足 $x_{n+1} = f(x_n)$，其中：
1. $f(x)$ 可导
2. $a$ 是方程 $f(x) = x$ 的唯一解
3. $|f'(x)| \leq k < 1$（对任意 $x \in \mathbb{R}$）

则 $\{x_n\}$ **收敛于** $a$。


## 2. 核心公式

### 原理一证明中的关键不等式

$$|x_n - a| \leq k^n |x_1 - a|$$

由递推关系反复展开：
$$|x_{n+1} - a| \leq k |x_n - a| \leq k^2 |x_{n-1} - a| \leq \cdots \leq k^n |x_1 - a|$$

### 原理二的核心不等式（拉格朗日中值定理）

$$|x_{n+1} - a| = |f(x_n) - f(a)| = |f'(\xi_n)| \cdot |x_n - a| \leq k |x_n - a|$$

其中 $\xi_n$ 介于 $x_n$ 与 $a$ 之间。

### 例2.1 中的不等式链

对于 $f(x) = \sqrt{4 + 3x}$，$f'(x) = \frac{3}{2\sqrt{4+3x}}$：

$$|x_n - 4| \leq \left(\frac{2}{3}\right)^n |x_1 - 4|$$


## 3. 典型例题

### 例2.1（递推数列极限）

> **题目**：设 $x_1 = 1$，$x_{n+1} = \sqrt{4 + 3x_n}$（$n = 1, 2, \ldots$），证明数列 $\{x_n\}$ 收敛，并求 $\lim\limits_{n \to \infty} x_n$。

**解答**：

**第一步：化归经典形式**

令 $f(x) = \sqrt{4 + 3x}$（$x > 0$），则 $x_{n+1} = f(x_n)$，$f(4) = 4$。

**第二步：验证压缩条件**

$$f'(x) = \frac{3}{2\sqrt{4+3x}} \leq \frac{3}{2\sqrt{4+3 \cdot 0}} = \frac{3}{4} < 1$$

**第三步：建立不等式**

由拉格朗日中值定理：
$$|x_n - 4| = |f(x_{n-1}) - f(4)| = |f'(\xi)| \cdot |x_{n-1} - 4| \leq \frac{3}{4}|x_{n-1} - 4|$$

递推得：
$$|x_n - 4| \leq \left(\frac{3}{4}\right)^{n-1} |x_1 - 4| = 3 \cdot \left(\frac{3}{4}\right)^{n-1}$$

**第四步：求极限**

令 $n \to \infty$，由 $\left(\frac{3}{4}\right)^{n-1} \to 0$：
$$\lim_{n \to \infty} |x_n - 4| = 0$$

故 $\lim\limits_{n \to \infty} x_n = 4$。


## 4. 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 忘记验证唯一解 | 直接假设 $a$ 是 $f(x) = x$ 的解 | 必须先证明 $f(x) = x$ 只有唯一解 $a$ |
| 导数上界取错 | 误认为 $|f'(x)| \leq 1$ 即可 | 必须 $|f'(x)| \leq k < 1$（严格小于1） |
| 忽略初始值影响 | 认为任何初始值都收敛 | 需检查 $|x_1 - a|$ 的范围 |
| 证明过程不写 | 直接使用结论 | 考试中需写出证明过程 |
| 例2.1 中不等式链断裂 | 直接写 $|x_n - 4| \leq k^n$ | 需严格推导每一步，$k = \frac{3}{4}$ |

## 附录：重要不等式变形

1. **基本压缩不等式**：若 $|x_{n+1} - a| \leq k|x_n - a|$，则 $|x_n - a| \leq k^{n-1}|x_1 - a|$

2. **导数控制形式**：$|f(x) - f(y)| = |f'(\xi)||x - y| \leq k|x - y|$

3. **收敛速度估计**：误差上界为 $k^n|x_1 - a|$，收敛速率由 $k$ 决定


> **记忆口诀**：压缩映射真巧妙，比例小于一就好；拉格朗日来帮忙，唯一解后求极限。
