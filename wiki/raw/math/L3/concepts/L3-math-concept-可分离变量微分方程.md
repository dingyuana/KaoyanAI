# 可分离变量微分方程

## 概念定义

**可分离变量微分方程**是指形如

$$\frac{dy}{dx} = f(x) \cdot g(y)$$

的一阶微分方程，其中等式右端可以分解为仅含 $x$ 的函数与仅含 $y$ 的函数的乘积。

通过代数变形，可将变量分离到等式两侧：

$$\frac{dy}{g(y)} = f(x)\,dx \quad (g(y) \neq 0)$$

然后对两边分别积分即可求解。


## 核心公式

### 一般形式

$$\frac{dy}{dx} = f(x) \cdot g(y)$$

### 分离变量

$$\int \frac{dy}{g(y)} = \int f(x)\,dx + C$$

### 特别注意

- 当 $g(y) = 0$ 时，可能得到**常数解**
- 积分常数 $C$ 由初始条件确定
- 若 $g(y_0) = 0$，则 $y = y_0$ 也是一个解


## 典型例题

> **例题** 设函数 $f(x)$ 可导且满足
>
> $$x^2 f'(x) = 2f^2(x), \quad f(1) = 3$$
>
> 求 $f^{(n)}(0)$。

**解：**

**第一步：识别方程类型**

$$x^2 f'(x) = 2f^2(x) \Rightarrow f'(x) = \frac{2f^2(x)}{x^2}$$

这是可分离变量微分方程。

**第二步：分离变量**

$$\frac{f'(x)}{f^2(x)} = \frac{2}{x^2}$$

注意到 $\left(\frac{1}{f(x)}\right)' = -\frac{f'(x)}{f^2(x)}$，所以：

$$-\frac{d}{dx}\left(\frac{1}{f(x)}\right) = \frac{2}{x^2}$$

**第三步：两边积分**

$$-\frac{1}{f(x)} = \int \frac{2}{x^2}\,dx + C = -\frac{2}{x} + C$$

**第四步：化简通解**

$$\frac{1}{f(x)} = \frac{2}{x} + C_1$$

$$f(x) = \frac{1}{\frac{2}{x} + C_1} = \frac{x}{2 + C_1 x}$$

**第五步：利用初始条件**

$$f(1) = 3 \Rightarrow \frac{1}{2 + C_1} = 3 \Rightarrow C_1 = -\frac{5}{3}$$

**第六步：确定特解**

$$f(x) = \frac{x}{2 - \frac{5}{3}x} = \frac{3x}{6 - 5x} = \frac{3x}{2(3 - \frac{5}{2}x)}$$

展开为幂级数或直接求高阶导数：

$$\boxed{f^{(n)}(0) = (-2)^{n-1} \cdot n!}$$


## 常见错误

| 错误类型 | 说明 | 正确做法 |
|---------|------|---------|
| 忽略常数解 | 当 $g(y_0) = 0$ 时，$y = y_0$ 也是解 | 检验 $g(y) = 0$ 的情况 |
| 积分常数遗漏 | 分离积分后必须加常数 $C$ | 养成写 $+C$ 的习惯 |
| 分母为零 | 分离变量时假设 $g(y) \neq 0$ | 单独讨论 $g(y) = 0$ 的情形 |
| 符号错误 | 如 $\left(\frac{1}{f}\right)' = -\frac{f'}{f^2}$ 易漏负号 | 熟记求导公式 |
| 初值条件漏用 | 求出通解后必须用初值条件确定常数 | 建立"通解 → 特解"的完整步骤 |
