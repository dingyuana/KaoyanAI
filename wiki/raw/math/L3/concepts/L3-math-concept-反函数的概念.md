# 反函数的概念


## 1. 概念定义

**反函数** 设函数 $y = f(x)$ 的定义域为 $D$，值域为 $R$。若对于 $R$ 中的每一个 $y$，都有**唯一**的 $x \in D$ 与之对应，满足 $y = f(x)$，则称这样的映射构成的函数 $x = f^{-1}(y)$ 为原函数 $y = f(x)$ 的反函数。

**关键性质**：
- 原函数与反函数关于直线 $y = x$ 对称
- 若 $f(x)$ 在区间上单调，则其反函数必存在
- 互为反函数的两个函数，其定义域与值域互换


## 2. 核心公式

| 公式 | 说明 |
|------|------|
| $f^{-1}(f(x)) = x$ | 反函数复合性质 |
| $f(f^{-1}(y)) = y$ | 逆运算性质 |
| $[f^{-1}(y)]' = \dfrac{1}{f'(x)}$，其中 $y = f(x)$ | 反函数求导公式 |
| $b = a + 1$（若 $f(x) = ax + b$） | 线性函数反函数关系 |


## 3. 典型例题

### 例题：求反函数的渐近线

> **题目**：设 $g(x)$ 是函数 $f(x) = 2\ln(3-x)$ 的反函数，则曲线 $y = g(x)$ 的渐近线方程为 $\underline{\quad\quad}$。

**【解题步骤】**

**第一步：求反函数**
由 $y = 2\ln(3-x)$，得：
$$2y = \ln(3-x) \Rightarrow e^{2y} = 3 - x \Rightarrow x = 3 - e^{2y}$$

故 $g(x) = 3 - e^{2x}$（将 $y$ 换回 $x$）

**第二步：求水平渐近线**
$$\lim_{x \to +\infty} g(x) = \lim_{x \to +\infty} (3 - e^{2x}) = -\infty$$
$$\lim_{x \to -\infty} g(x) = \lim_{x \to -\infty} (3 - e^{2x}) = 3$$

$$\boxed{y = 3}$$

**【答案】** $y = 3$（注：题目答案为 $y = \pm 3$ 可能存在印刷问题，实际应为 $y = 3$）


## 4. 常见错误

| 错误类型 | 错误示例 | 正确理解 |
|----------|----------|----------|
| 定义域值域混淆 | 求 $f(x) = e^x$ 的反函数写成 $e^y$ | $f^{-1}(x) = \ln x$（变量名改为 $x$） |
| 忽略单调性条件 | 认为 $y = x^2$ 存在反函数 | 需限定区间，如 $x \geq 0$ 或 $x \leq 0$ |
| 求导公式符号错误 | $[f^{-1}]' = f'$ | $[f^{-1}]' = \dfrac{1}{f'}$ |
| 渐近线漏解 | 只求一侧极限 | 需分别讨论 $x \to +\infty$ 和 $x \to -\infty$ |
