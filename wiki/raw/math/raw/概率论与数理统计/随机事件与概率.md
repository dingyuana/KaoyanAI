# 随机事件与概率

## 概念定义

随机事件与概率是概率论的基础概念。**随机试验**是指在相同条件下可以重复进行，但结果事先不可预测的试验。**样本空间**是随机试验所有可能结果的集合，记作 $\Omega$。**随机事件**是样本空间的子集，记作 $A, B, C$ 等。**概率**是描述随机事件发生可能性大小的数值度量，介于 0 与 1 之间。


## 核心公式

### 1. 概率的公理化定义

设 $P(A)$ 为事件 $A$ 的概率，满足：

$$P(\Omega) = 1, \quad P(\varnothing) = 0$$

$$0 \leq P(A) \leq 1$$

若 $A_1, A_2, \ldots, A_n$ 两两互不相容，则：

$$P(A_1 \cup A_2 \cup \cdots \cup A_n) = \sum_{i=1}^{n} P(A_i)$$

### 2. 概率的基本性质

$$P(\bar{A}) = 1 - P(A)$$

$$P(A - B) = P(A) - P(AB)$$

若 $A \subset B$，则：

$$P(B - A) = P(B) - P(A)$$

有限可加性（互不相容事件）：

$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$

### 3. 条件概率

$$P(B \mid A) = \frac{P(AB)}{P(A)}, \quad P(A) > 0$$

### 4. 乘法公式

$$P(AB) = P(A) \cdot P(B \mid A) = P(B) \cdot P(A \mid B)$$

推广（n个事件）：

$$P(A_1 A_2 \cdots A_n) = P(A_1) \cdot P(A_2 \mid A_1) \cdot P(A_3 \mid A_1 A_2) \cdots P(A_n \mid A_1 \cdots A_{n-1})$$

### 5. 全概率公式

设 $A_1, A_2, \ldots, A_n$ 为样本空间 $\Omega$ 的一个完备事件组（两两互不相容、和为 $\Omega$），则：

$$P(B) = \sum_{i=1}^{n} P(A_i) \cdot P(B \mid A_i)$$

### 6. 贝叶斯公式（逆概率公式）

$$P(A_j \mid B) = \frac{P(A_j) \cdot P(B \mid A_j)}{\sum_{i=1}^{n} P(A_i) \cdot P(B \mid A_i)}, \quad j = 1, 2, \ldots, n$$

### 7. 独立事件的概率

若 $A$ 与 $B$ 相互独立，则：

$$P(AB) = P(A) \cdot P(B)$$

$$P(B \mid A) = P(B), \quad P(A \mid B) = P(A)$$


## 典型例题

### 例题一：古典概型与概率加法公式

> **题目**：袋中有 5 个白球和 3 个黑球，从中不放回地依次取出 2 个球。求：
>
> (1) 两个球都是白球的概率；
>
> (2) 两个球颜色不同的概率。

**解答**：

**(1)** 方法一（古典概型）：

$$P(\text{两个白球}) = \frac{C_5^2}{C_8^2} = \frac{10}{28} = \frac{5}{14}$$

方法二（乘法公式）：

$$P = \frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14}$$

**(2)** 方法一：

$$P(\text{颜色不同}) = \frac{C_5^1 \cdot C_3^1}{C_8^2} = \frac{15}{28}$$

方法二（补事件）：

$$P(\text{颜色不同}) = 1 - P(\text{两个白}) - P(\text{两个黑})$$

$$= 1 - \frac{5}{14} - \frac{C_3^2}{C_8^2} = 1 - \frac{5}{14} - \frac{3}{28} = \frac{15}{28}$$

**考点分析**：本题考查古典概型的计算方法、加法公式与乘法公式的灵活运用，以及补事件的解题技巧。


### 例题二：全概率公式与贝叶斯公式

> **题目**：甲、乙、丙三人向同一目标各射击一次，命中率分别为 $0.4$、$0.5$、$0.7$。已知目标被击中一次，求它是被甲击中的概率。

**解答**：

设事件 $B$：目标被击中一次；事件 $A_1$：甲击中；$A_2$：乙击中；$A_3$：丙击中。

由题意，三人是否击中相互独立，且恰好一人击中的情况为：

$$B = A_1 \bar{A}_2 \bar{A}_3 + \bar{A}_1 A_2 \bar{A}_3 + \bar{A}_1 \bar{A}_2 A_3$$

$$P(A_1) = 0.4, \quad P(A_2) = 0.5, \quad P(A_3) = 0.7$$

$$P(B) = 0.4 \times 0.5 \times 0.3 + 0.6 \times 0.5 \times 0.3 + 0.6 \times 0.5 \times 0.7$$

$$= 0.06 + 0.09 + 0.21 = 0.36$$

由贝叶斯公式：

$$P(A_1 \mid B) = \frac{P(A_1) \cdot P(\bar{A}_2) \cdot P(\bar{A}_3)}{P(B)} = \frac{0.4 \times 0.5 \times 0.3}{0.36} = \frac{0.06}{0.36} = \frac{1}{6}$$

**考点分析**：本题综合考查全概率公式和贝叶斯公式的应用，关键在于正确设定完备事件组并计算各条件概率。


### 例题三：独立事件的判断与计算

> **题目**：设 $A, B$ 为两个随机事件，已知 $P(A) = 0.4$，$P(B \mid A) = 0.5$，$P(A \cup B) = 0.6$。判断 $A$ 与 $B$ 是否相互独立。

**解答**：

由条件概率：

$$P(AB) = P(A) \cdot P(B \mid A) = 0.4 \times 0.5 = 0.2$$

由加法公式：

$$P(A \cup B) = P(A) + P(B) - P(AB)$$

$$0.6 = 0.4 + P(B) - 0.2$$

$$P(B) = 0.4$$

检验独立性：

$$P(A) \cdot P(B) = 0.4 \times 0.4 = 0.16 \neq P(AB) = 0.2$$

因此，$A$ 与 $B$ **不相互独立**。

**考点分析**：本题考查独立性的判定方法，以及条件概率、加法公式的综合运用。


## 常见错误

| 错误类型 | 错误示例 | 正确理解 |
|---------|---------|---------|
| 混淆互斥与独立 | 认为互斥事件一定独立 | 互斥事件若 $P(A) > 0, P(B) > 0$，则 $P(AB) = 0 \neq P(A)P(B)$，必不独立 |
| 遗漏情况 | 使用加法公式时未减去交集 | $P(A \cup B) = P(A) + P(B) - P(AB)$ |
| 条件概率混淆 | $P(B \mid A) = P(B)$ 与 $P(AB) = P(A)P(B)$ 混用 | 前者是独立性定义，后者是等价条件 |
| 全概率公式乱用 | 未验证完备事件组条件 | 必须满足 $A_1, A_2, \ldots, A_n$ 两两互斥且 $\bigcup A_i = \Omega$ |
| 贝叶斯公式分母错误 | 分母写成交叉概率 | 分母应为全概率公式的结果 $P(B)$ |
| 不放回抽样误用放回公式 | 误用 $n$ 次独立重复试验公式 | 不放回抽取各次试验不独立，需用组合数 |
