# 古典概型与几何概型

## 概念定义

### 古典概型

若随机试验的全部可能结果只有有限个（设为 $n$ 个），且每个基本事件发生的可能性相等，则称该随机试验对应的概率模型为**古典概型**。

> 特点：有限性 + 等可能性

### 几何概型

若随机试验的全部可能结果有无穷多个，且每个基本事件发生的可能性相等，此时概率需要通过几何测度（长度、面积、体积）的比值来计算，称该概率模型为**几何概型**。

> 特点：无限性 + 等可能性 + 几何测度


## 核心公式

### 古典概型概率公式

$$P(A) = \frac{\text{事件A包含的基本事件数}}{\text{总的基本事件数}} = \frac{m}{n}$$

### 几何概型概率公式

$$P(A) = \frac{\text{区域A的几何测度}}{\text{整个样本空间的几何测度}} = \frac{\mu(A)}{\mu(\Omega)}$$

其中 $\mu$ 可表示长度、面积或体积。


## 典型例题

### 例题一（古典概型）

**题目**：袋中有 5 个白球和 3 个黑球，从中不放回地依次取出 2 个球，求恰好取到 1 个白球的概率。

**解法**：

方法一：考虑抽取顺序（排列）

总的基本事件数：$A_5^2 + A_3^2 = 5 \times 4 + 3 \times 2 = 26$（第一次白第二次黑 + 第一次黑第二次白）

恰好 1 个白球：第一次白第二次黑 $= 5 \times 3 = 15$，或第一次黑第二次白 $= 3 \times 5 = 15$

$$P = \frac{15 + 15}{26} = \frac{30}{26} = \frac{15}{13}$$

方法二：考虑组合（更常用）

总的基本事件数：$C_8^2 = 28$

恰好 1 个白球：$C_5^1 \cdot C_3^1 = 5 \times 3 = 15$

$$P = \frac{C_5^1 \cdot C_3^1}{C_8^2} = \frac{15}{28}$$

**考点分析**：古典概型的计数方法（排列 vs 组合）、超几何分布雏形


### 例题二（几何概型 - 会面问题）


**解法**：

设 $x$、$y$ 分别为甲、乙到达的时刻（单位：分钟）。

样本空间：$\Omega = \{(x, y) \mid 0 \leq x \leq 60, 0 \leq y \leq 60\}$

此为正方形区域，面积为 $60 \times 60 = 3600$

两人能够会面的条件：$|x - y| \leq 20$

即 $-20 \leq x - y \leq 20$，对应正方形中两条平行直线 $y = x \pm 20$ 之间的区域

阴影部分面积 = 正方形面积 - 两个三角形面积

$$S_{\text{阴影}} = 3600 - 2 \times \frac{1}{2} \times 40 \times 40 = 3600 - 1600 = 2000$$

$$P = \frac{S_{\text{阴影}}}{S_{\Omega}} = \frac{2000}{3600} = \frac{5}{9}$$

**考点分析**：几何概型的平面区域表示、线性规划思想


## 常见错误

| 序号 | 易错点 | 正确做法 |
| 1 | **混淆排列与组合** | 若抽取顺序影响结果（如先后顺序）用排列；顺序不影响则用组合 |
| 2 | **基本事件等可能性未验证** | 使用古典概型公式前，必须确认每个基本事件概率相等 |
| 3 | **几何区域画错** | 仔细审题，正确写出不等式条件，再画图表示 |
| 4 | **几何概型测度选择错误** | 根据题目描述选择长度（1维）、面积（2维）或体积（3维） |
| 5 | **"至少"类问题重复计数** | 用容斥原理或间接法（1 减对立事件概率）避免重复 |
