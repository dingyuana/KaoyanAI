# 概率论与数理统计-第38讲：大数定律与中心极限定理

## 核心概念定义
大数定律描述了在大量重复试验中，随机变量序列的样本均值会逐渐稳定在总体均值附近。中心极限定理则表明，当样本量足够大时，样本均值的分布会趋近于正态分布。

## 核心公式
```latex
\lim_{n \to \infty} P\{|X_n - E(X)| \geq \epsilon\} = 0, \quad n \to \infty
\lim_{n \to \infty} P\{|X_n - X| < \epsilon\} = 1, \quad n \to \infty
```

## 典型例题
**例题**：假设有一系列独立同分布的随机变量序列 \(X_1, X_2, \ldots, X_n\)，其中 \(E(X) = \mu\)，\(D(X) = \sigma^2\)。证明当 \(n\) 趋于无穷大时，样本均值 \(\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i\) 依概率收敛于 \(\mu\)。

**解答**：根据切比雪夫大数定律，有
\[ P\{|X_n - E(X)| \geq \epsilon\} \leq \frac{D(X)}{\epsilon^2} \]
由于 \(D(X) = \sigma^2\)，所以
\[ P\{|X_n - E(X)| \geq \epsilon\} \leq \frac{\sigma^2}{\epsilon^2} \]
当 \(n\) 趋于无穷大时，\(\frac{\sigma^2}{\epsilon^2}\) 趋于 0，因此
\[ \lim_{n \to \infty} P\{|X_n - E(X)| \geq \epsilon\} = 0 \]
即 \(\bar{X}\) 依概率收敛于 \(\mu\)。

## 常见错误
1. 忽略大数定律和中心极限定理的适用条件，如样本量不足或随机变量不独立。
2. 误用切比雪夫不等式，将其应用于非独立随机变量。
3. 在计算概率时，错误地使用极限公式。
