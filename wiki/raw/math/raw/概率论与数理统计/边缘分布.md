# 边缘分布

## 概念定义

边缘分布是指在多维随机变量 $(X_1, X_2, \cdots, X_n)$ 中，单独考虑部分变量的概率分布。它通过将联合分布中其他变量"边缘化"（求和或积分）得到，反映了单个随机变量的概率行为。


## 核心公式

### 1. 边缘分布函数

对于二维随机变量 $(X, Y)$，关于 $X$ 的边缘分布函数：

$$F_X(x) = P(X \leq x) = \lim_{y \to +\infty} F(x, y)$$

关于 $Y$ 的边缘分布函数：

$$F_Y(y) = P(Y \leq y) = \lim_{x \to +\infty} F(x, y)$$

### 2. 离散型边缘分布律

若 $(X, Y)$ 为离散型随机变量，联合分布律为 $P(X=x_i, Y=y_j) = p_{ij}$，则：

$$P_X(X=x_i) = \sum_{j=1}^{\infty} p_{ij}$$

$$P_Y(Y=y_j) = \sum_{i=1}^{\infty} p_{ij}$$

### 3. 连续型边缘密度函数

若 $(X, Y)$ 为连续型随机变量，联合密度为 $f(x, y)$，则：

$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$$

$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$


## 典型例题

### 例题 1：求离散型边缘分布律

设 $(X, Y)$ 的联合分布律为：

| $X \backslash Y$ | $y_1=0$ | $y_2=1$ |
| $x_1=0$ | $0.1$ | $0.2$ |
| $x_2=1$ | $0.3$ | $0.4$ |

**求** $X$ 和 $Y$ 的边缘分布律。

**解答：**

关于 $X$ 的边缘分布律：
$$P(X=0) = 0.1 + 0.2 = 0.3$$
$$P(X=1) = 0.3 + 0.4 = 0.7$$

关于 $Y$ 的边缘分布律：
$$P(Y=0) = 0.1 + 0.3 = 0.4$$
$$P(Y=1) = 0.2 + 0.4 = 0.6$$

**考点分析**：离散型边缘分布律的求解，核心是"行求和"或"列求和"。


### 例题 2：求连续型边缘密度函数

设 $(X, Y)$ 的联合密度函数为：
$$f(x, y) = \begin{cases} 6x^2y, & 0 < x < 1,\ 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

**求** $X$ 和 $Y$ 的边缘密度函数。

**解答：**

关于 $X$ 的边缘密度：
$$f_X(x) = \int_{0}^{1} 6x^2y \, dy = 6x^2 \cdot \frac{y^2}{2}\Big|_{0}^{1} = 3x^2, \quad 0 < x < 1$$

关于 $Y$ 的边缘密度：
$$f_Y(y) = \int_{0}^{1} 6x^2y \, dx = 6y \cdot \frac{x^3}{3}\Big|_{0}^{1} = 2y, \quad 0 < y < 1$$

**考点分析**：连续型边缘密度的求解，需在联合密度定义域上对另一变量积分。


## 常见错误

| 错误类型 | 错误示例 | 正确做法 |
| **积分限错误** | 直接对 $y$ 从 $-\infty$ 到 $+\infty$ 积分 | 必须在联合密度的有效区域内积分 |
| **忽略定义域** | 忘记标注边缘密度的取值范围 | 边缘密度函数需标注 $x$（或 $y$）的定义域 |
| **混淆概念** | 将 $F(x,y)$ 误写为 $f(x,y)$ | 边缘分布函数与边缘密度函数是不同概念 |
| **正态分布漏项** | 二维正态的边缘分布漏掉参数 | 记住：二维正态的边缘分布仍为正态 |

## 扩展应用

### 二维正态分布的边缘分布

若 $(X,Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则：
$$X \sim N(\mu_1, \sigma_1^2), \quad Y \sim N(\mu_2, \sigma_2^2)$$

**重要结论**：二维正态分布的边缘分布与参数 $\rho$ 无关。
