# 高等数学-第90讲：多元函数微分学

## 核心概念定义

多元函数微分学是研究多元函数在一点处局部性质的理论。主要内容包括二元函数的极限、偏导数、全微分等。

## 核心公式

```latex
\lim_{(x,y) \to (x_0, y_0)} f(x, y) = \lim_{x \to x_0} \lim_{y \to y_0} f(x, y)
```

```latex
\frac{\partial f}{\partial x} = \lim_{\Delta x \to 0} \frac{f(x + \Delta x, y) - f(x, y)}{\Delta x}
```

```latex
\frac{\partial f}{\partial y} = \lim_{\Delta y \to 0} \frac{f(x, y + \Delta y) - f(x, y)}{\Delta y}
```

## 典型例题

**例题**：计算极限 $\lim_{(x,y) \to (0,0)} \frac{x^2y}{x^4 + y^2}$。

**解答**：首先，考虑同阶路径法，令 $y = kx$，则原极限变为：

$$
\lim_{x \to 0} \frac{x^2(kx)}{x^4 + (kx)^2} = \lim_{x \to 0} \frac{kx^3}{x^4 + k^2x^2} = \lim_{x \to 0} \frac{k}{x + k^2} = 0
$$

因此，原极限为0。

## 常见错误

1. 忽略二重极限与累次极限的关系。
2. 在计算二重极限时，未考虑特殊路径法。
3. 在计算累次极限时，未先计算二重极限。
4. 在使用夹逼准则时，未正确选择夹逼函数。
