# 高等数学-第117讲：欲分方程

## 核心概念定义
欲分方程，又称曳物线或追踪曲线，描述了当P沿已知路径逃跑时，追踪者Q从某点出发追赶P，Q跑过的路线。

## 核心公式
```latex
\Delta y_n = y_{n+1} - y_n = f(t+1) - f(t)
\Delta^2 y_n = \Delta(\Delta y_n) = \Delta y_{n+1} - 2\Delta y_n + \Delta y_{n-1}
```

## 典型例题
**例题**：差分方程 $y_{n+1} - 2y_n + y_{n-1} = x^0$ 的通解为____。

**解答**：应填 $y_n = C + (x-2)^2$，式中 $C$ 为任意常数。

## 常见错误
1. 忽略齐次差分方程的求解过程。
2. 特解的设定不符合方程形式。
3. 特解的系数计算错误。
