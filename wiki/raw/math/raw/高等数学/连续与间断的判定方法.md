# 连续与间断的判定方法


**章节**：2026 张宇高数 18讲(OCR)  
**难度**：★★☆☆☆  
**标签**：函数极限、连续性、间断点


## 1 概念定义

### 1.1 连续的定义

设函数 $f(x)$ 在点 $x_0$ 的某邻域内有定义，若

$$\lim_{x \to x_0} f(x) = f(x_0)$$

则称 $f(x)$ 在点 $x_0$ 处**连续**。

### 1.2 间断的定义

若函数 $f(x)$ 在点 $x_0$ 处不满足连续的条件，则称 $x_0$ 为 $f(x)$ 的**间断点**。

### 1.3 间断点的四种类型

| 类型 | 定义 | 条件 |
| **可去间断点** | 左右极限存在且相等，但不等于函数值 | $\lim_{x \to x_0^+} f(x) = \lim_{x \to x_0^-} f(x) = a \neq f(x_0)$ |
| **跳跃间断点** | 左右极限都存在但不相等 | $\lim_{x \to x_0^+} f(x) = a,\ \lim_{x \to x_0^-} f(x) = b,\ a \neq b$ |
| **无穷间断点** | 至少有一侧极限为无穷大 | $\lim_{x \to x_0^+} f(x) = \infty$ 或 $\lim_{x \to x_0^-} f(x) = \infty$ |
| **振荡间断点** | 左右极限振荡不存在 | $\lim_{x \to x_0} f(x)$ 振荡不存在 |


## 2 核心公式

### 2.1 连续性判定的三部曲

$$f(x) \text{ 在 } x_0 \text{ 处连续} \Longleftrightarrow \begin{cases} \lim\limits_{x \to x_0^+} f(x) \text{ 存在} \\ \lim\limits_{x \to x_0^-} f(x) \text{ 存在} \\ \lim\limits_{x \to x_0} f(x) = f(x_0) \end{cases}$$

### 2.2 常见无定义点（潜在间断点）

| 序号 | 函数形式 | 潜在间断点 $x_0$ |
| ① | $e^x \to x=0$ 为无定义点 | $x_0 = 0$ |
| ② | $\ln x \to x = \pm 1$ 为无定义点 | $x_0 = -1, 1$ |
| ③ | $\sin x \to x = k\pi\ (k = 0, \pm 1, \cdots)$ 为无定义点 | $x_0 = k\pi$ |
| ④ | $\arctan x \to x = 0$ 为无定义点 | $x_0 = 0$ |
| ⑤ | $\dfrac{1}{x^2 - 1} \to x = \pm 1$ 为无定义点 | $x_0 = -1, 1$ |
| ⑥ | $\dfrac{(x^2 - 1)}{x} \to x = 0, \pm 1$ 为无定义点 | $x_0 = -1, 0, 1$ |
| ⑦ | $[x]$（取整函数）$\to x = n\ (n = 0, \pm 1, \pm 2, \cdots)$ 为分段点 | $x_0 = n$ |
| ⑧ | $\|x - 2\| \to x - 2 = 0$ | $x_0 = 2$ |

### 2.3 取整函数的极限公式

$$\lim_{x \to n^+} [x] = n, \qquad \lim_{x \to n^-} [x] = n - 1$$


## 3 典型例题

### 例题：判断函数 $f(x) = \dfrac{|x|}{x}$ 的连续性与间断点类型

**解：**

**第一步：化简函数并识别潜在间断点**

$$f(x) = \frac{|x|}{x} = \begin{cases} 1, & x > 0 \\ -1, & x < 0 \end{cases}$$

潜在间断点：$x = 0$（分母零点）

**第二步：计算左右极限**

$$\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} 1 = 1$$

$$\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} (-1) = -1$$

**第三步：按定义判定间断点类型**

由于 $\lim_{x \to 0^+} f(x) = 1 \neq \lim_{x \to 0^-} f(x) = -1$，

所以 $x = 0$ 为**跳跃间断点**。


## 4 常见错误

| 序号 | 错误类型 | 正确做法 |
| ❌ | 忽略分母为零的点 | 优先识别**无定义点**和**分段点** |
| ❌ | 忘记对取整函数 $[x]$ 求左右极限 | 注意 $\lim\limits_{x \to n^+} [x] = n$，$\lim\limits_{x \to n^-} [x] = n - 1$ |
| ❌ | 将 $\ln x$ 的定义域误认为 $x > 0$，忘记 $x = -1$ 处无定义 | 牢记 $\ln x$ 定义域为 $x > 0$，但$\ln|x|$ 定义域为 $x \neq 0$ |
| ❌ | 可去间断点和连续混淆 | 可去间断点要求 $\lim f(x)$ 存在但 $\neq f(x_0)$ 或 $f(x_0)$ 无定义 |
| ❌ | 只计算单侧极限就下结论 | 必须同时计算**左右极限**并比较 |

## 6 判定流程图

```
┌─────────────────────────────────────────┐
│           判定连续与间断                  │
└─────────────────────────────────────────┘
                    │
                    ▼
        ┌───────────────────┐
        │ 1. 找出潜在间断点  │
        │  (无定义点/分段点) │
        └───────────────────┘
                    │
                    ▼
        ┌───────────────────┐
        │ 2. 计算左右极限    │
        │  lim⁺f(x), lim⁻f(x)│
        └───────────────────┘
                    │
                    ▼
    ┌───────────────┼───────────────┐
    │               │               │
    ▼               ▼               ▼
lim⁺存在且=lim⁻   lim⁺≠lim⁻      至少一侧∞
    │               │               │
    ▼               ▼               ▼
  函数值?        跳跃间断点     无穷间断点
    │
    ▼
lim=f(x₀)? → 连续
lim≠f(x₀)或f(x₀)无定义 → 可去间断点
```


> **记忆口诀**：间断判定三步走，无定义点先找够；左右极限比大小，类型判断不用愁。
