# 高等数学-第64讲：一元函数积分学的概念与性质

## 核心概念定义
一元函数积分学是研究函数在某一区间上的积分运算及其性质的数学分支。它包括不定积分和定积分，其中定积分可以进一步分为反常积分和常义积分。

## 核心公式
```latex
\int f(x) \, dx = F(x) + C
```
其中，\( F(x) \) 是 \( f(x) \) 的一个原函数，\( C \) 是积分常数。

## 典型例题
**例题**：计算不定积分 \( \int x^3 \, dx \)。

**解答**：
\[ \int x^3 \, dx = \frac{x^4}{4} + C \]

## 常见错误
1. 忘记加上积分常数 \( C \)。
2. 在进行不定积分时，没有正确地找到原函数。
3. 在处理反常积分时，没有正确地判断其敛散性。
4. 在使用比较判敛法时，没有正确地选择比较函数。
5. 在使用绝对值判敛法时，没有正确地处理绝对值。
