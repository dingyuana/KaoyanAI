# 高等数学-第116讲：欲分方程

## 核心概念定义
欲分方程是描述价格P随时间t变化的一类微分方程，其中价格的变化率与过剩需求量成正比，与价格成反比。

## 核心公式
```latex
\frac{dP}{dt} = \frac{14(D-S)}{P}
```

## 典型例题
**例题**：已知商品的初始价格为5元，欲分方程为 $S=12.8P^2-128$ 和 $D=-4.4P^2+130$。求价格P随时间t变化的函数。

**解答**：
1. 建立微分方程：
   \[
   \frac{dP}{dt} = \frac{14(-4.4P^2+130-12.8P^2+128)}{P} = \frac{14(-17.2P^2+258)}{P}
   \]
   化简得：
   \[
   \frac{dP}{dt} = \frac{-244.8P}{P} = -244.8
   \]

2. 通过变量代换 $y = P^2$，求解此方程：
   \[
   \frac{dy}{dt} = 2P\frac{dP}{dt} = -489.6P
   \]
   分离变量并积分：
   \[
   \int \frac{dy}{y} = -489.6 \int dt
   \]
   得到：
   \[
   \ln y = -489.6t + C
   \]
   解得：
   \[
   y = e^{-489.6t + C} = Ce^{-489.6t}
   \]
   由初始条件 $P(0) = 5$，得 $C = 25$，所以：
   \[
   P(t) = \sqrt{25e^{-489.6t}} = 5e^{-244.8t}
   \]

## 常见错误
1. 忘记将 $P^2$ 代入微分方程中。
2. 在积分过程中，忘记将 $P$ 的系数乘以 $dy$。
3. 在求解过程中，忘记考虑初始条件。
