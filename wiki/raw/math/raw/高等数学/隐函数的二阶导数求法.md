# 隐函数的二阶导数求法

## 元数据

- **章节**：2026 张宇高数 18讲(OCR)
- **难度**：★★☆☆☆
- **知识点**：隐函数的二阶导数求法


## 一、概念定义

隐函数的二阶导数求法是指在隐函数 $F(x, y) = 0$ 确定的函数 $y = y(x)$ 中，通过**两次求导**得到 $y''(x)$ 的方法。

### 基本步骤

1. **第一步**：对方程 $F(x, y) = 0$ 两边关于 $x$ 求导，得到一阶导数关系 $G(x, y, y') = 0$
2. **第二步**：再对 $G(x, y, y') = 0$ 关于 $x$ 求导，解出 $y''(x)$

> **核心思想**：链式法则 + 隐函数求导


## 二、核心公式

### 隐函数一阶导数公式

$$F(x, y) = 0 \implies \frac{dy}{dx} = -\frac{F_x}{F_y} \quad (F_y \neq 0)$$

### 隐函数二阶导数公式

对方程两边求二阶导数：

$$\frac{d^2y}{dx^2} = -\frac{F_{xx} \cdot F_y^2 - 2F_{xy} \cdot F_x \cdot F_y + F_{yy} \cdot F_x^2}{F_y^3}$$

### 通用操作步骤

| 步骤 | 操作 | 结果 |
| 1 | $F[x, y(x)] = 0$ 两边对 $x$ 求导 | $G[x, y(x), y'(x)] = 0$ |
| 2 | 从 $G = 0$ 解出 $y'(x)$ | $y'(x) = \varphi(x, y)$ |
| 3 | $G[x, y(x), y'(x)] = 0$ 两边再对 $x$ 求导 | $H[x, y, y', y''(x)] = 0$ |
| 4 | 从 $H = 0$ 解出 $y''(x)$ | $y''(x)$ |


## 三、典型例题

### 例题 4.7

**已知**可导函数 $y = y(x)$ 满足

$$ae^x + y^2 + y - \ln(1+x)\cos y + b = 0$$

且 $y(0) = 0$，`y'(0) = 0`。

**求**：
1. $a, b$ 的值
2. 判断 $x = 0$ 是否为 $y(x)$ 的极值点


### 【解】

#### 第(1)问：求 $a, b$

**由 $y(0) = 0$ 代入原方程**：

$$a \cdot e^0 + 0^2 + 0 - \ln(1+0)\cos 0 + b = 0$$

$$a + b = 0 \quad \cdots (1)$$

**两边对 $x$ 求导**：

$$ae^x + 2yy' + y' - \frac{1}{1+x}\cos y - \ln(1+x)(-\sin y) \cdot y' = 0$$

**代入 $x = 0, y(0) = 0, y'(0) = 0$**：

$$a \cdot 1 + 0 + 0 - \frac{1}{1}\cdot 1 - 0 = 0$$

$$a - 1 = 0 \Rightarrow a = 1$$

**由式(1)**：

$$b = -1$$


#### 第(2)问：判断极值点

**对 $ae^x + 2yy' + y' - \frac{1}{1+x}\cos y - \ln(1+x)(-\sin y) \cdot y' = 0$ 再求导**：

$$ae^x + 2(y')^2 + 2yy'' + y'' + \frac{1}{(1+x)^2}\cos y - \frac{1}{1+x}\sin y \cdot y' - \frac{1}{1+x}\sin y \cdot y' - \ln(1+x)\cos y \cdot (y')^2 - \ln(1+x)(-\sin y) \cdot y'' = 0$$

**代入 $x = 0, y(0) = 0, y'(0) = 0$**：

$$a + 0 + 0 + 0 + 1 - 0 - 0 - 0 - 0 = 0$$

$$a + 1 + y''(0) = 0$$

**代入 $a = 1$**：

$$1 + 1 + y''(0) = 0$$

$$y''(0) = -2 < 0$$


### 【结论】

| 条件 | 判断 |
| $y'(0) = 0$ | ✅ 满足极值点必要条件 |
| $y''(0) = -2 < 0$ | ✅ $x = 0$ 为 $y(x)$ 的**极大值点** |


## 四、常见错误

### ❌ 错误 1：求导时遗漏复合函数

$$\text{对 } \ln(1+x) \text{ 求导时遗漏 } \frac{1}{1+x}$$

**正确做法**：

$$\frac{d}{dx}\ln(1+x) = \frac{1}{1+x}$$

### ❌ 错误 2：遗漏 $y$ 对 $x$ 的依赖

**错误**：$\dfrac{d}{dx}(y^2) = 2y$

**正确**：$\dfrac{d}{dx}(y^2) = 2y \cdot y'$

### ❌ 错误 3：代入数值时机错误

**错误**：在求导前就将 $y(0) = 0$ 代入

**正确**：先求导得到一般表达式，再代入具体数值

### ❌ 错误 4：极值判断符号错误

| 条件 | 结论 |
| $y''(x_0) > 0$ | 极小值点 |
| $y''(x_0) < 0$ | 极大值点 |

```
┌─────────────────────────────────────────────────┐
│  隐函数二阶导数速记                              │
├─────────────────────────────────────────────────┤
│  F(x, y) = 0                                    │
│         ↓  (对x求导)                            │
│  F_x + F_y · y' = 0  →  y' = -F_x/F_y          │
│         ↓  (再对x求导)                          │
│  F_xx + 2F_xy·y' + F_yy·(y')² + F_y·y'' = 0    │
│         ↓  (解出y'')                            │
│  y'' = -(F_xx + 2F_xy·y' + F_yy·(y')²) / F_y  │
└─────────────────────────────────────────────────┘
```
