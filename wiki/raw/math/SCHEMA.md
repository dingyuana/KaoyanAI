## 三、L1 分块原则（数学特色）

### 3.1 基础规则

1. **完整性**：一个定义、一个定理、一道题不得跨 Chunk
2. **唯一ID**：每个 Chunk 分配永久锚点 ID，学科前缀为 `math`
3. **不改原文**：保留所有文字和 LaTeX，不总结、不纠错

### 3.2 数学特色规则

- **公式完整**：LaTeX 公式 `$$...$$` 必须完整，不被截断
- **定理独立**：每个定理（含条件、结论、证明）作为一个 Chunk
- **例题独立**：每个例题（含题目、解答）作为一个 Chunk
- **多公式推导**：如果推导过程连续，中间步骤不得拆分

### 3.3 命名规范

```
{学科}_{章节序号}_{标题}.md
示例：math_01_极限.md、math_02_导数与微分.md
```

## 四、L3 文档格式（数学特色）

### 4.1 Frontmatter

```yaml
---
id: L3-math-concept-极限的概念与性质

  - L3-math-exercise-极限练习题.md
source_anchors:
  - RAW-math-同济高数上-P023-C07

---
```

### 4.2 正文结构（概念类）

1. 形式化定义（引用自 L1 原文）
2. 直观解释（LLM 根据原文生成）
3. 常见考法（解题步骤）
4. 注意事项（易错点）
5. 关联概念（前置/后续）

### 4.3 LaTeX 格式规范

- 行内公式：`$...$`
- 独立公式：`$$...$$`
- 矩阵：`\begin{pmatrix} ... \end{pmatrix}`
- 分段函数：使用 `\begin{cases} ... \end{cases}`
- 数学符号：使用标准 LaTeX 语法

## 五、习题分离规则

### 5.1 习题识别标准

满足以下任一条件即为习题：
- 包含问号或指令动词（求、证明、计算、判断）
- 有编号的例题（如"例1"、"习题2-3"）
- 包含"解答"、"解："等解题过程标记
- 来自试卷或真题（带年份、题号）

### 5.2 习题分类

| 分类 | 说明 |
|------|------|
| 选择题 | 单选/多选 |
| 填空题 | 计算结果填空 |
| 解答题 | 证明/计算题 |
