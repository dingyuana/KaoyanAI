# 指令流水线

## 形式化定义

> 引用自 [[RAW-arch-5中央处理器-5.6]]：

指令流水线是一种指令级并行技术，将指令的执行过程分为多个阶段（如取指、译码、执行、访存、写回），每个阶段由独立的硬件部件处理，不同指令的不同阶段可以重叠执行，从而提高指令吞吐量。

## 工作原理

### 流水线的表示方法

流水线的执行情况可以用**时空图**表示：
- 横轴：时间（时钟周期）
- 纵轴：流水线阶段

| 指令 | 第1周期 | 第2周期 | 第3周期 | 第4周期 | 第5周期 | 第6周期 | 第7周期 |
|------|--------|--------|--------|--------|--------|--------|--------|
| 指令1 | IF | ID | EX | MEM | WB | | |
| 指令2 | | IF | ID | EX | MEM | WB | |
| 指令3 | | | IF | ID | EX | MEM | WB |
| 指令4 | | | | IF | ID | EX | MEM |

### 五级流水线（经典的RISC流水线）

| 阶段 | 英文 | 功能 |
|------|------|------|
| IF | Instruction Fetch | 取指令 |
| ID | Instruction Decode | 指令译码/读寄存器 |
| EX | Execute | 执行/计算地址 |
| MEM | Memory Access | 访存 |
| WB | Write Back | 写回寄存器 |

## 性能指标

### 流水线吞吐率

$$ \text{吞吐率} = \frac{\text{指令条数}}{\text{流水线执行时间}} $$

m段流水线在第m个时钟周期后，每个时钟周期都可完成一条指令。

### 流水线加速比

$$ \text{加速比} = \frac{\text{不使用流水线的所用时间}}{\text{使用流水线所用的时间}} $$

理想情况下，m段流水线的加速比接近于m。

## 高级流水线技术

| 技术 | 描述 |
|------|------|
| **超标量流水线** | 每个时钟周期发射多条指令，硬件有多个执行单元 |
| **超流水线** | 将每个流水线段进一步细分，提高主频 |
| **超长指令字（VLIW）** | 编译器将多条并行指令打包为长指令字 |

## 典型应用场景

- 现代CPU（从ARM到x86）均使用指令流水线技术
- 高性能处理器结合超标量和超流水线技术
