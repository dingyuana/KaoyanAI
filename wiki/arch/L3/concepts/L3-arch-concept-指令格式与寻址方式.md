# 指令的基本格式与数据寻址方式

## 形式化定义

> 引用自 [[RAW-arch-4指令系统-指令概念]] / [[RAW-arch-4指令系统-指令基本格式]] / [[RAW-arch-4指令系统-数据寻址方式]]：

**指令**（机器指令）是指示计算机执行某种操作的命令，是计算机运行的**最小功能单位**。一台计算机所有指令的集合构成该机的**指令系统**（指令集）。

**指令格式**：指令 = 操作码 + 地址码

### 按地址码数量分类
| 类型 | 说明 | 示例 |
|------|------|------|
| 零地址 | 无地址码 | 空操作、堆栈运算 |
| 一地址 | 一个地址码 | OP(A)→A |
| 二地址 | 两个地址码 | (A1)OP(A2)→A1 |
| 三地址 | 三个地址码 | (A1)OP(A2)→A3 |
| 四地址 | 四个地址码 | (A1)OP(A2)→A3，下条指令地址A4 |

### 常见数据寻址方式
| 方式 | 有效地址 | 速度 |
|------|---------|------|
| 隐含寻址 | 程序指定 | 快 |
| 立即寻址 | A即操作数 | 最快 |
| 直接寻址 | EA=A | 快 |
| 间接寻址 | EA=(A) | 慢 |
| 寄存器寻址 | EA=$R_i$ | 快 |
| 寄存器间接寻址 | EA=($R_i$) | 较慢 |
| 基址寻址 | EA=(BR)+A | 支持多道程序 |
| 变址寻址 | EA=(IX)+A | 适合数组处理 |
| 相对寻址 | EA=(PC)+A | 适合程序跳转 |
| 堆栈寻址 | 栈顶指针 | 用于函数调用 |

## 核心要点

1. **速度排序**：立即寻址 > 寄存器寻址 > 直接寻址 > 寄存器间接寻址 > 间接寻址
2. **基址寻址 vs 变址寻址**：
   - 基址：BR内容由OS确定，不可变，用于多道程序和浮动程序
   - 变址：IX内容由用户设定，可变，用于数组处理和循环
3. **相对寻址**：EA = (PC) + A，广泛用于转移指令
4. 指令系统位于硬件和软件的交界面上

## 常见考法

### 考法1：有效地址计算
**题目**：基址寄存器的内容为3000H，指令中的形式地址为100H，求有效地址。
**答案**：EA = 3000H + 100H = 3100H

### 考法2：寻址方式特点
**题目**：哪种寻址方式适合处理数组问题？
**答案**：变址寻址，因为变址寄存器的内容可由用户改变，适合遍历数组元素。

## 注意事项

1. 立即寻址的"立即"指的是操作数直接在指令中，不需要访存
2. 间接寻址需要两次访存（取地址、取数据），速度最慢
3. 相对寻址优点：代码可浮动，适用于程序跳转
