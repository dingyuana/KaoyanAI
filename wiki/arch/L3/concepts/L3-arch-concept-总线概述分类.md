# 总线概述、分类与性能标准

## 形式化定义

> 引用自 [[RAW-arch-6总线-总线概述]] / [[RAW-arch-6总线-总线分类]] / [[RAW-arch-6总线-总线性能标准]]：

**总线**是一组能为多个部件**分时共享**的公共信息传送路线。

**特点**：
- **分时性**：同一时刻只允许有一个部件向总线发送信息；同一时刻只能有一个主设备控制总线传输操作
- **共享性**：总线上可以挂接多个部件

### 总线分类

#### 按功能分类
| 类型 | 功能 |
|------|------|
| 数据总线 | 传输数据信息（双向传输） |
| 地址总线 | 传输地址信息（单向传输，CPU→其他） |
| 控制总线 | 传输控制信号（各方向） |

#### 按数据传输格式
- **并行总线**：同时传输多位数据
- **串行总线**：逐位传输数据

#### 按时序控制方式
- **同步总线**：由统一时钟控制
- **异步总线**：通过应答方式（握手）控制

### 性能标准
- **总线宽度**（位宽）：同时能传输的数据位数
- **总线工作频率**：总线周期的倒数
- **总线带宽**：$带宽 = \frac{\text{总线宽度}}{8} \times \text{工作频率}$（单位：字节/s）
- **总线复用**：信号线在不同时间传输不同信息

## 核心要点

1. **总线带宽公式**：$带宽 = \frac{\text{数据线宽度}}{8} \times \text{工作频率}$（B/s）
2. 数据总线双向，地址总线单向（CPU输出）
3. 同一时刻只有一个发送方，但可以有多个接收方
4. **信号线数** = 地址总线根数 + 数据总线根数 + 控制总线根数

## 常见考法

### 考法1：总线带宽计算
**题目**：32位数据总线，工作频率100MHz，求总线带宽。
**答案**：带宽 = 32/8 × 100M = 4 × 100M = 400MB/s

### 考法2：总线特性
**题目**：总线什么时候需要仲裁？
**答案**：当多个总线主设备同时请求使用总线时，需要通过总线仲裁决定哪个设备获得总线控制权。

## 注意事项

1. 总线带宽是最大理论值，实际传输速率可能更低
2. 总线宽度加倍 ≠ 性能加倍（因其他因素限制）
3. 现代总线多采用并行+串行的混合设计
