# 存储器的层次结构与分类

## 形式化定义

> 引用自 [[RAW-arch-3存储系统-存储器分类]] / [[RAW-arch-3存储系统-多级层次]]：

### 按存储介质分类
- **半导体存储器**：主存、Cache（TTL、MOS）
- **磁表面存储器**：磁盘、磁带
- **光存储器**：光盘
- **固态硬盘（SSD）**：闪存（Flash Memory）

### 按存取方式分类
- **随机存取存储器（RAM）**：读写时间与地址无关（主存、Cache）
- **只读存储器（ROM）**：只能读不能写
- **顺序存取存储器（SAM）**：按顺序存取（磁带）
- **直接存取存储器（DAM）**：先直接定位再顺序读写（磁盘）

### 按在计算机中的作用分类
- **主存**：存放正在执行的程序和数据
- **Cache**：高速缓冲存储器
- **辅存/外存**：大容量、非易失（磁盘、SSD）

### 按信息可保持性分类
- **易失性存储器**（RAM）：断电丢失信息
- **非易失性存储器**（ROM、闪存）：断电不丢失信息

## 多级层次结构

```
寄存器(CPU内部) → Cache → 主存(DRAM) → 辅存(磁盘/SSD)
  速度: 快 → → → → → → → → → → → → → → 慢
  容量: 小 → → → → → → → → → → → → → → 大
  成本: 高 → → → → → → → → → → → → → → 低
```

## 核心要点

1. **存取速度**：寄存器 > Cache > 主存 > 辅存
2. **容量和成本呈反比**：速度越快越贵、容量越小
3. **主存（DRAM）**：易失性，需定期刷新
4. **ROM**：非易失性，用于存放BIOS等固件
5. **SSD**：基于闪存，非易失，速度快于磁盘

## 常见考法

### 考法1：存储器速度排序
**题目**：寄存器、Cache、主存、磁盘的速度排序？
**答案**：寄存器 > Cache > 主存 > 磁盘

### 考法2：RAM与ROM的区别
**题目**：DRAM属于什么类型的存储器？
**答案**：属于易失性半导体随机存取存储器

## 注意事项

1. 寄存器是CPU内部部件，不是主存的一部分
2. 存储系统的层次结构体现了"速度-容量-成本"的权衡
3. 虚拟存储系统是主存和辅存的层次配合
