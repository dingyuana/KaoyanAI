# 硬布线控制器与微程序控制器

## 形式化定义

> 引用自 [[RAW-arch-5中央处理器-硬布线]] / [[RAW-arch-5中央处理器-微程序]] / [[RAW-arch-5中央处理器-控制器对比]]：

**控制器**是CPU的核心部件之一，负责指挥各部件协同工作使程序执行。有两种实现方式：

### 硬布线控制器（组合逻辑控制器）
- 根据指令要求、当前时序及内外部状态，**按时间顺序**发送一系列微操作控制信号
- 由复杂的**组合逻辑门电路**和触发器构成
- 速度快，设计难度大，成本高，不易扩展
- 时序系统复杂
- 用于**RISC**处理器

### 微程序控制器
- 采用**存储逻辑**实现，将微操作信号代码化
- 每条机器指令编写成一个**微程序**，包含若干**微指令**
- 微程序存放在**控制存储器（CM）**中（通常用ROM构成）
- 速度较慢（增加从CM读取微指令的时间）
- 灵活性高、易扩充修改、时序系统简单
- 用于**CISC**处理器

## 微程序控制器的基本结构

| 部件 | 功能 |
|------|------|
| 控制存储器（CM） | 核心部件，存放各指令对应的微程序 |
| 微指令寄存器（μIR） | 存放从CM中取出的微指令 |
| 微地址形成部件 | 产生初始微地址和后继微地址 |
| 微地址寄存器（μMAR/CMAR） | 接收微地址，为CM中取指令做准备 |

## 核心要点

| 对比 | 硬布线控制器 | 微程序控制器 |
|------|-------------|-------------|
| 工作原理 | 组合逻辑输出微操作 | 顺序执行微指令 |
| 速度 | 快 | 慢（多一步CM读取） |
| 设计难度 | 大、成本高 | 小、易扩充 |
| 时序系统 | 复杂 | 简单 |
| 适用 | RISC | CISC |

## 常见考法

### 考法1：控制器类型判断
**题目**：RISC CPU通常采用什么控制器？
**答案**：硬布线（组合逻辑）控制器

### 考法2：微程序执行过程
**题目**：微程序入口地址由什么决定？
**答案**：由机器指令的操作码字段通过微地址形成部件产生。

## 注意事项

1. 控制存储器（CM）属于CPU内部部件，不归主存管理
2. 微程序控制器比硬布线控制器慢，因为需从CM读取微指令
3. 现代CISC处理器常采用微程序+硬布线混合设计
