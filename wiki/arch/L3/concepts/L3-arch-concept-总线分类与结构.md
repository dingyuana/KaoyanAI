# 总线分类与系统总线结构

## 形式化定义

> 引用自 [[RAW-arch-6总线-6.1]]：

总线是一组能为多个部件**分时共享**的公共信息传送路线。分时性指同一时刻只允许有一个部件向总线发送信息；共享性指总线上可以挂接多个部件。

## 总线的分类

### 按功能划分

| 总线类型 | 功能 |
|---------|------|
| **数据总线** | 传输数据信息（双向） |
| **地址总线** | 传输地址信息（单向，CPU→其他） |
| **控制总线** | 传输控制信号（双向） |

### 按时序控制方式划分

| 类型 | 描述 |
|------|------|
| **同步总线** | 由统一时钟信号控制传输 |
| **异步总线** | 通过握手信号协调传输 |

### 按数据传输格式划分

| 类型 | 描述 |
|------|------|
| **并行总线** | 同时传输多位数据（速度快但线多、成本高） |
| **串行总线** | 逐位传输数据（速度慢但线少、成本低） |

## 系统总线的结构

| 结构 | 组成 | 优点 | 缺点 |
|------|------|------|------|
| **单总线结构** | 一条系统总线连接所有部件 | 结构简单、成本低、易于接入新设备 | 带宽低、负载重、不支持并发传送 |
| **双总线结构** | 主存总线 + I/O总线 | 低速I/O从单总线分离，实现存储器总线和I/O总线分离 | 需要增加通道等硬件 |
| **三总线结构** | I/O总线 + 主存总线 + DMA总线 | 提高I/O设备性能，提高系统吞吐量 | 系统工作效率低 |

## 总线特性

- **物理特性**：总线线的数量、类型、连接方式
- **功能特性**：各信号线的功能定义
- **电气特性**：信号的电平、时序、负载能力
- **时间特性**：信号在时间上的配合关系

## 总线设备

- **主设备**：可以申请并获得总线控制权的设备（如CPU）
- **从设备**：只能响应主设备请求的设备（如内存、I/O接口）

## 典型应用场景

- 理解计算机系统各部件之间的互联方式
- 分析不同总线结构对系统性能的影响
- 考研常考：比较单/双/三总线结构的优劣
