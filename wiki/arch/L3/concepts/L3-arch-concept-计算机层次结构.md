# 计算机系统的层次结构

## 形式化定义

> 引用自 [[RAW-arch-1计算机系统概述-1.2.4]]：

计算机系统是一个多层抽象的结构，从底层硬件到高层应用软件，每一层都隐藏了下层的实现细节，为上层提供接口服务。

## 工作原理

计算机系统的层次结构从下到上依次为：

```
应用软件层（应用程序）
    ↑
高级语言层（C/C++/Java等）
    ↑
汇编语言层
    ↑
操作系统层
    ↑
机器语言层（指令系统）
    ↑
微体系结构层（控制层）
    ↑
数字逻辑层（物理硬件）
```

### 三个级别的语言

| 语言级别 | 说明 | 翻译方式 |
|---------|------|---------|
| **高级语言** | 面向程序员，如C、Java | 编译/解释 |
| **汇编语言** | 用助记符表示机器指令 | 汇编 |
| **机器语言** | 二进制代码，CPU直接执行 | 无需翻译 |

### 翻译程序类型

- **编译程序**：将高级语言源程序一次性全部翻译成机器语言目标程序
- **解释程序**：逐条翻译并立即执行高级语言源程序，不产生完整的目标程序
- **汇编程序**：将汇编语言源程序翻译成机器语言程序

## 核心要点

1. **层次越高，抽象程度越高**：高级语言程序员无需了解底层硬件细节
2. **层次间通过接口通信**：每层为上层提供约定的服务接口
3. **指令系统是软硬件交界面**：指令系统是计算机的主要属性，位于硬件和软件的交界面上
4. **程序转换链路**：高级语言 → 汇编语言 → 机器语言 → CPU执行

## 典型应用场景

理解层次结构有助于：
- 区分不同级别的编程语言及其翻译方式
- 理解操作系统在硬件和应用之间的桥梁作用
- 分析程序的执行过程（从源码到机器指令）
