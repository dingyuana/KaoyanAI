# 指令周期

## 形式化定义

> 引用自 [[RAW-arch-5中央处理器-5.2.1]]：

指令周期是指CPU从主存中取出并执行一条指令所需的全部时间。一个指令周期通常由若干个机器周期（CPU周期）组成，一个机器周期包含若干个时钟周期（T周期）。

## 指令周期组成

| 子周期 | 功能 |
|--------|------|
| **取指周期** | 从主存中取出指令并送至IR |
| **间址周期** | 取出操作数的有效地址（寻址方式需要时） |
| **执行周期** | 执行指令规定的操作 |
| **中断周期** | 处理中断请求（有中断时） |

### 不同指令的指令周期

| 指令类型 | 指令周期的组成 | 说明 |
|---------|--------------|------|
| **无条件转移指令JMP X** | 取指周期 + 执行周期 | PC被修改两次：取指结束PC自动加1 + 执行周期PC修改为目标地址 |
| **间接寻址的指令** | 取指周期 + 间址周期 + 执行周期 | 间址周期结束时MDR中为操作数的有效地址EA |
| **有中断请求时** | 取指周期 + 间址周期 + 执行周期 + 中断周期 | 进栈操作将SP-1（堆栈向低地址增长） |

## 关键考点

- **中断采样时机**：CPU在每条指令执行结束前发中断查询信号
- **中断隐指令**：关中断 + 保存断点 + 引出中断服务程序
- **通用寄存器的保护**：由中断服务程序完成
- **中断优先级**：由屏蔽字决定，而不是根据请求先后次序

## 指令执行方案

| 方案 | 描述 |
|------|------|
| **单周期处理器** | 每条指令在一个时钟周期完成，CPI=1 |
| **多周期处理器** | 不同指令用不同数量的时钟周期 |
| **流水线处理器** | 指令重叠执行，提高吞吐量 |

## 典型应用场景

- 理解CPU执行程序的基本流程
- 分析不同指令的执行时间差异
- 为流水线设计提供基础概念
