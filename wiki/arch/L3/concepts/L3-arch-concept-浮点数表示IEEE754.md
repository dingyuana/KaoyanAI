# 浮点数表示与IEEE 754标准

## 形式化定义

> 引用自 [[RAW-arch-2数据表示和运算-浮点数]]：

浮点数由**符号、尾数、基数、指数**四个要素构成：
- 浮点数 = $(-1)^S \times M \times r^E$
- **基数r**（隐含）：二进制为2
- **符号S**：1位，0正1负
- **尾数M**：有效数字，反映浮点数精度
- **阶码E**（指数）：反映浮点数表示范围

**IEEE 754标准**：
- **单精度（float）**：32位 = 1位符号 + 8位阶码 + 23位尾数，偏置值127
- **双精度（double）**：64位 = 1位符号 + 11位阶码 + 52位尾数，偏置值1023
- IEEE 754中尾数用**原码**表示，阶码用**移码**表示

**规格化**：规定尾数的最高数位必须是有效值（1），目的是增加数据表示精度。
- **左规**：尾数算术左移一位，阶码减1
- **右规**：尾数算术右移一位，阶码加1（尾数溢出时）

## 直观解释

定点数能表示的范围有限，浮点数通过类似"科学计数法"的方式（$1.xxx \times 2^{yyy}$），在有限位数内同时扩大表示范围和保持精度。IEEE 754是通用的浮点数标准，所有计算机都遵循。

## 核心要点

1. **单精度范围**：E=1~254，偏移127；最大值 $(2-2^{-23}) \times 2^{127}$
2. **双精度范围**：E=1~2046，偏移1023
3. **规格化要求**：尾数最高位为1，且隐藏（integer bit）
4. **E全0**表示0或非规格化数；**E全1**表示无穷大或NaN
5. **上溢**：超过最大正数；**下溢**：小于最小正数

## 常见考法

### 考法1：浮点数转十进制
**题目**：单精度浮点数 0 10000001 01000000000000000000000 对应的十进制数？
**解题步骤**：
1. 符号S=0，正数
2. 阶码E=10000001B=129D，真值 = 129-127 = 2
3. 尾数M=1.01B（隐藏的1+小数部分）= 1.25D
4. 结果 = $1.25 \times 2^2 = 5.0$
**答案**：5.0

### 考法2：十进制转浮点数
**题目**：将-7.5转为IEEE 754单精度浮点数
**解题步骤**：
1. 符号S=1
2. 7.5 = 111.1B = 1.111B × 2²
3. E = 2+127 = 129 = 10000001B
4. 尾数M = 11100000000000000000000B（隐藏整数位1）
**答案**：1 10000001 11100000000000000000000B

## 注意事项

1. 阶码用移码表示，偏置值为$2^{k-1}-1$（k为阶码位数）
2. 尾数采用原码表示，且整数部分1被隐藏（节省1位精度）
3. 左规和右规的区别要掌握：左规-尾数左移阶码减1，右规-尾数右移阶码加1
