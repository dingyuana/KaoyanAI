# 冯·诺依曼结构

## 形式化定义

> 引用自 [[RAW-arch-1计算机系统概述-1.2.2]]：

冯·诺依曼机由**五大部件**组成：输入设备、输出设备、存储器、运算器、控制器。指令和数据以同等地位存储在存储器中，按地址寻访。指令和数据均以二进制代码表示。

## 工作原理

冯·诺依曼结构的基本工作方式为**控制流驱动方式**，其核心思想可归纳为：

1. **存储程序**：将程序（指令序列）和数据以二进制形式预先存入存储器
2. **程序控制**：计算机自动、连续地从存储器中取出指令并执行
3. **指令结构**：指令 = 操作码 + 地址码，操作码表示操作性质，地址码表示操作数位置
4. **顺序执行**：指令在存储器中按顺序存放，通常顺序执行，特定条件下可跳转

### CPU区分指令和数据的依据
CPU通过**指令周期的不同阶段**区分指令和数据——取指周期取出的是指令，执行周期取出的是数据。数据由指令的地址码给出。

## 现代计算机结构

现代计算机以**存储器为核心**，结构如下：

- **计算机** = 主机 + 输入/输出设备
- **主机** = CPU + 主存
- **CPU** = 运算器 + 控制器
- **运算器核心**：ALU（算术逻辑单元）
- **控制器核心**：CU（控制单元）

### 五大功能部件详述

| 部件 | 核心组成 | 功能 |
|------|---------|------|
| **存储器** | 存储体、MAR、MDR | 存放数据和指令 |
| **运算器** | ALU、ACC、MQ、X | 算术运算和逻辑运算 |
| **控制器** | PC、IR、CU | 指挥各部件执行程序 |
| **输入设备** | 键盘、鼠标等 | 将信息转换为机器可识别的形式 |
| **输出设备** | 显示器、打印机等 | 将结果转换为人类熟悉的形式 |

## 关键参数

- **存储元**：存储二进制的最小电子元件，每个存储元可存1bit
- **存储单元**：每个单元存放一串二进制代码
- **存储字长**：存储单元中二进制代码的位数
- **机器字长**：计算机能一次处理的二进制代码长度
- **MAR位数** = 存储单元个数/地址码长度
- **MDR位数** = 存储字长

## 典型应用场景

冯·诺依曼结构是现代通用计算机的基础架构，几乎所有通用计算机（x86、ARM等）都遵循这一基本结构。早期的冯·诺依曼机以运算器为中心，现代计算机改为以存储器为中心。
