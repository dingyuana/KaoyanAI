# SRAM和DRAM

## 形式化定义

> 引用自 [[RAW-arch-3存储系统-3.2.1]]：

半导体随机存取存储器（RAM）分为静态RAM（SRAM）和动态RAM（DRAM）两种，主要区别在于存储信息的原理和是否需要刷新。

## SRAM与DRAM对比

| 比较项 | SRAM（静态RAM） | DRAM（动态RAM） |
|--------|----------------|----------------|
| **主要用途** | Cache、TLB | 主机内存 |
| **存储信息** | 触发器（双稳态电路） | 电容 |
| **破坏性读出** | 否 | 是 |
| **需要刷新** | 不需要 | 需要（每2ms刷新一次） |
| **送行列地址** | 同时送 | 分两次送 |
| **运行速度** | **快** | 慢 |
| **集成度** | 低 | **高** |
| **存储成本** | 高 | **低** |

## DRAM刷新机制

### 为什么需要刷新？

DRAM使用电容存储信息，电容电荷维持时间短（即使电源不断电，信息也会自动消失），因此每隔一段时间必须刷新。

### 刷新参数

- **刷新周期（再生周期）**：一般取2ms
- **刷新单位**：以行为单位
- **刷新一行的时间** = 一个存取周期
- 一次完整的刷新过程只需要占用一个存储周期

### 三种刷新方式

| 刷新方式 | 描述 | 特点 |
|---------|------|------|
| **集中刷新** | 在2ms内集中安排一段时间依次对所有行刷新 | 存在"死时间"，期间无法访问 |
| **分散刷新** | 每存取一次就刷新一次 | 无"死时间"，但存取周期延长 |
| **异步刷新** | 将刷新操作分散在2ms内均匀完成 | 折中方案，常用 |

### 刷新计算示例

假设：刷新周期2ms，存取周期0.5μs，128×128矩阵芯片：

- 集中刷新：128行 × 0.5μs = 64μs的死时间
- 异步刷新：每2ms/128 ≈ 15.6μs刷新一行
- 分散刷新：存取周期变为2×0.5μs = 1μs

## 地址复用技术

DRAM采用地址复用技术，行地址和列地址分两次送入，以减少地址引脚数量。SRAM则同时送行列地址。

## 典型应用场景

- **SRAM**：CPU Cache、TLB、寄存器
- **DRAM**：计算机主存（内存条）、显存
