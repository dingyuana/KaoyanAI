# DMA方式

## 形式化定义

> 引用自 [[RAW-arch-7输入输出系统-7.3.3]]：

DMA（Direct Memory Access，直接存储器存取）方式是一种由硬件控制存储器与外设之间直接进行数据传送的I/O方式，不需要CPU的干预。数据传输率非常高，适合于高速外设的成组数据传送。

## DMA与中断方式的对比

| 比较项 | DMA方式 | 中断方式 |
|--------|---------|---------|
| **CPU参与程度** | 预处理和后处理后不占用CPU | 需保护和恢复现场 |
| **响应时机** | 每个机器周期结束时都可响应 | 只能在指令执行结束时响应 |
| **传送控制** | 不需要CPU干预，靠硬件传送 | 需要CPU干预，靠程序传送 |
| **数据传输率** | 高 | 低 |
| **适用场景** | 高速外设成组数据传送 | 低速设备、异常事件处理 |
| **优先级** | **DMA请求优先级高于中断请求** | 低于DMA |
| **功能范围** | 仅局限于数据块传送 | 具有对异常事件的处理能力 |

## DMAC（DMA控制器）

### DMAC的功能
1. 接受外设的DMA请求，向CPU发出总线请求
2. 获得总线控制权后，控制数据传送
3. 确定传送数据的起始地址和长度
4. 传送结束时向CPU发出中断请求（后处理）

### DMAC的组成
- 地址寄存器
- 字节计数器
- 控制/状态寄存器
- 数据缓冲寄存器

## DMA的传送过程

1. **预处理**：CPU设置DMAC的传送参数（源地址、目标地址、传送长度、传送方向）
2. **DMA传送**：DMAC获得总线控制权后，直接控制存储器与外设间的数据传送
3. **后处理**：传送结束后，DMAC向CPU发出中断请求，CPU进行后续处理

## 典型应用场景

- 磁盘读写操作
- 高速网卡数据收发
- 图形显示数据传送
