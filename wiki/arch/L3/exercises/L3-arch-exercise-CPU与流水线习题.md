# CPU与指令流水线习题

## 题目列表

### 题目1：流水线性能计算
**来源**：408真题
**难度**：中等
**考点**：流水线吞吐率、加速比

**题目**：
某指令流水线由 5 段组成，各段执行时间分别为 2ns、3ns、1ns、2ns、2ns。连续输入 100 条指令。

(1) 求流水线的吞吐率。
(2) 相对于非流水线（串行执行），求加速比。

**解析**：
(1) 流水线最大段耗时：$\Delta t = \max(2,3,1,2,2) = 3\text{ns}$
第一条指令执行时间：$T_1 = 2+3+1+2+2 = 10\text{ns}$
之后每 3ns 完成一条指令
100 条指令总时间：$T_{100} = 10 + (100-1) \times 3 = 10 + 297 = 307\text{ns}$
吞吐率：$TP = \frac{100}{307} \approx 0.326\text{ 条/ns} = 326\text{ MIPS}$

(2) 非流水线执行 100 条指令：$100 \times 10 = 1000\text{ns}$
加速比：$S = \frac{1000}{307} \approx 3.26$

**答案**：吞吐率 ≈ 326 MIPS，加速比 ≈ 3.26

### 题目2：数据冒险检测
**来源**：408真题
**难度**：中等
**考点**：数据冒险（RAW）、插入气泡

**题目**：
在 5 段流水线（IF, ID, EX, MEM, WB）中，执行以下指令序列：
```
I1: ADD R1, R2, R3    ; R1 ← R2 + R3
I2: SUB R4, R1, R5     ; R4 ← R1 - R5
I3: OR  R6, R1, R7     ; R6 ← R1 OR R7
```

(1) 指出存在的数据冒险类型和位置。
(2) 若不采用转发技术，需要插入多少气泡（停顿周期）？
(3) 若采用转发技术，能否消除所有冒险？

**解析**：
(1) I1 写 R1，I2 读 R1 → RAW 冒险（写后读）
I1 写 R1，I3 读 R1 → RAW 冒险（写后读）

(2) 不采用转发：
- I1 在 WB 阶段（第5个周期）才写入 R1
- I2 的 ID 阶段在第3个周期，那时 R1 还未写回
- 需插入 3 个气泡（I2 推迟到 I1 WB 之后）
- I3 同样需要等待

```
周期: 1  2  3  4  5  6  7  8  9
I1:  IF ID EX MEM WB
I2:     IF ID --- --- ID EX MEM WB  (插3个气泡)
I3:        IF --- --- --- ID EX MEM WB  (再插3个)
```

(3) 采用转发技术：
- EX→EX 转发：I2 的 EX 阶段可直接使用 I1 EX 阶段的结果
- 只需插入 1 个气泡（I2 的 ID 等待 I1 的 EX 完成）
- I3 同样只需 1 个气泡（或通过 MEM→ID 转发消除）

**答案**：(1) RAW冒险，(2) 3个气泡，(3) 转发可减至1个气泡

### 题目3：数据通路分析
**来源**：408真题
**难度**：困难
**考点**：单周期/多周期数据通路

**题目**：
某单周期 CPU 中，执行指令 `LW R1, 100(R2)`（从内存地址 R2+100 读取数据到 R1）。请描述该指令在数据通路中的执行过程，并指出各控制信号的值。

**解析**：
`LW R1, 100(R2)` 的执行过程：

1. **IF 取指**：PC → 指令存储器 → 取出指令
2. **ID 译码**：读出寄存器 R2 的值，符号扩展立即数 100
3. **EX 执行**：ALU 计算地址 = R2 + 100
4. **MEM 访存**：数据存储器读操作，地址为 ALU 计算结果
5. **WB 写回**：将读取的数据写回 R1

控制信号：
- RegDst = 0（写寄存器地址来自 Rt 字段）
- ALUSrc = 1（ALU 第二操作数为立即数）
- MemtoReg = 1（写回数据来自数据存储器）
- RegWrite = 1（写寄存器）
- MemRead = 1（读内存）
- MemWrite = 0（不写内存）
- ALUOp = 00（加法操作）
- Branch = 0（非分支指令）

**答案**：见解析
