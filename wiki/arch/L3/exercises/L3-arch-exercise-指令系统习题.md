# 指令系统习题

## 题目列表

### 题目1：扩展操作码设计
**来源**：408真题
**难度**：困难
**考点**：扩展操作码

**题目**：
假设某机器指令字长16位，包含3种指令格式：二地址、一地址和零地址。已知二地址指令有15条，零地址指令有16条。设扩展操作码为1111，二地址指令格式为：

```
| 操作码(4位) | A1 | A2 |
```

问：一地址指令最多可以有多少条？

**解析**：
1. 二地址指令使用4位操作码，除去1111（二地址末尾标记）和15条指令
   - 实际二地址操作码 = 2^4 - 1 - 15 = 16 - 1 - 15 = 0... 这不对

2. 重新分析：
   - 4位操作码最多16种（0000~1111）
   - 1111用作扩展标记
   - 所以二地址指令最多15条（0000~1110）

3. 扩展方式：
   - 当二地址指令的操作码为1111时，后面8位地址码作为扩展操作码
   - 扩展操作码最多可表示 2^8 = 256 条指令
   - 零地址占用了16条
   - 所以一地址指令 = 256 - 16 = 240 条

**答案**：一地址指令最多有240条

**关键点**：扩展操作码的数目取决于扩展位数，一地址指令的扩展操作码长度是8位

### 题目2：指令格式设计
**来源**：408选择题
**难度**：中等
**考点**：指令格式

**题目**：
某机器字长32位，指令格式如下：

```
| 操作码(8位) | 寻址特征(4位) | 形式地址(20位) |
```

该机器的指令系统采用变长操作码。设地址码长度为24位，则该指令系统最多可以定义多少种不同的操作码？

**解析**：
1. 变长操作码设计中，操作码长度可变
2. 寻址特征4位 + 形式地址20位 = 24位地址码
3. 指令字长32位，剩余8位作为操作码扩展位
4. 最多可以定义 2^8 = 256 种不同的操作码

**答案**：256种

**关键点**：变长操作码设计中，短操作码用于常用指令，长操作码用于扩展

### 题目3：寻址方式
**来源**：408真题
**难度**：简单
**考点**：各种寻址方式

**题目**：
下列寻址方式中，执行速度最快的是：

A. 直接寻址
B. 立即寻址
C. 寄存器间接寻址
D. 相对寻址

**解析**：
A. 直接寻址：需要访问一次内存获取操作数
B. 立即寻址：操作数在指令中，直接取出，速度最快
C. 寄存器间接寻址：需要访问寄存器再访问内存，两次
D. 相对寻址：需要计算有效地址，通常也需要访问内存

**答案**：B

**关键点**：立即寻址的操作数就在指令中，无需访问存储器，速度最快

### 题目4：CISC与RISC对比
**来源**：408选择题
**难度**：简单
**考点**：CISC和RISC

**题目**：
以下关于RISC特点的说法中，错误的是：

A. 指令长度固定，指令格式少
B. 寻址方式少
C. 控制器采用微程序控制方式
D. 指令在单周期内完成

**解析**：
A✅ RISC指令长度固定，指令格式少，减少译码复杂度
B✅ RISC寻址方式简单，通常少于10种
C❌ RISC控制器采用硬布线控制，不是微程序控制
D✅ RISC指令在单周期内完成

**答案**：C

**关键点**：RISC = 硬布线控制器，简化指令集，单周期执行

### 题目5：相对寻址计算
**来源**：408真题改编
**难度**：困难
**考点**：相对寻址

**题目**：
某机器使用相对寻址，指令字长32位，当前PC值为2000H（十六进制），指令中的偏移量为-8（用补码表示）。求该指令的转移目标地址。

**解析**：
1. PC自动增量：相对寻址中，PC已经指向下一条指令
2. 在取指后，PC = 2000H + 4 = 2004H（假设字长32位=4字节）
3. 偏移量 -8 的补码表示...实际上题目直接给出偏移量
4. 转移目标地址 = PC + 偏移量 = 2004H + (-8)
5. -8 的十六进制是 FFFFFFF8H
6. 2004H + FFFFFFF8H = (2004 + FFFFFFF8)H
7. = 2004 - 8 = 1FFCH

**答案**：1FFCH

**关键点**：相对寻址的PC值是下一条指令的地址，偏移量需要带符号扩展

### 题目6：扩展操作码总数验证
**来源**：408真题
**难度**：困难
**考点**：扩展操作码设计

**题目**：
在扩展操作码指令集中，若每个操作码为4位，地址码为12位，指令字长为32位。若二地址指令的操作码有8条，求该指令系统最多能定义多少条指令？

**解析**：
1. 指令字长32位，地址码12位（两个地址共24位）
2. 操作码实际可用位数 = 32 - 24 = 8位
3. 但设计扩展操作码时：
   - 二地址指令：4位固定操作码 = 8条（0000~0111）
   - 扩展位 = 12位（用作一地址或零地址的扩展操作码）
4. 扩展操作码可定义：2^12 = 4096 条（如果全作为一地址指令）
5. 实际总数 = 8 + 4096 = 4104 条

**答案**：最多4104条

**关键点**：扩展操作码设计要考虑固定操作码和扩展位的分配

## 学习建议

1. **熟记各种寻址方式的特点**：立即寻址最快但灵活性差，间接寻址灵活但速度慢
2. **掌握扩展操作码的计算方法**：固定位 + 扩展位 = 总可表示指令数
3. **理解CISC和RISC的区别**：RISC简化指令集，提高执行效率
4. **注意PC自动增量**：相对寻址时PC已经指向下一条指令
5. **多做真题**：扩展操作码设计是408难点
