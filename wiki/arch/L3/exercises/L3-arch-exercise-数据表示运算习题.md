# 数据表示与运算习题

## 题目列表

### 题目1：补码表示范围
**来源**：408经典题型
**难度**：简单
**考点**：补码表示范围

**题目**：
8位补码能表示的最小负数和最大正数分别是多少？short（16位有符号整数）的表示范围是多少？

**解析**：
1. 8位补码范围：$-2^{7} \sim 2^{7}-1 = -128 \sim 127$
2. 16位补码范围：$-2^{15} \sim 2^{15}-1 = -32768 \sim 32767$
3. 原因：正数有0~32767共32768个，负数为-1~-32768共32768个

**答案**：8位补码范围$-128 \sim 127$，short范围$-32768 \sim 32767$

**关键点**：补码比原码多表示一个最小负数

### 题目2：IEEE 754单精度转换
**来源**：408经典题型
**难度**：中等
**考点**：IEEE 754十进制转浮点数

**题目**：
将十进制数 $-15.625$ 转换为IEEE 754单精度浮点数格式（用十六进制表示）。

**解析**：
1. 符号位S = 1（负数）
2. 15.625D = 1111.101B = $1.111101 \times 2^3$
3. 阶码E = 3 + 127 = 130D = 10000010B
4. 尾数M = 11110100000000000000000（23位）
5. 完整二进制：`1 10000010 11110100000000000000000`
6. 十六进制：`C1 7A 00 00` → 0xC17A0000

**答案**：0xC17A0000

**关键点**：注意隐藏整数部分1，阶码加偏置值127

### 题目3：补码加减法运算
**来源**：408经典题型
**难度**：中等
**考点**：补码加减法与溢出判断

**题目**：
已知 $x = -5, y = 3$，用4位补码计算 $x + y$ 和 $x - y$，并判断是否溢出。

**解析**：
1. $x = -5$：原码1101，反码1010，补码1011
2. $y = 3$：补码0011
3. $x + y$：1011 + 0011 = 1110（补码）= -2D
   - 双符号位11（无溢出）
4. $x - y = x + (-y)$：$-y$的补码 = 1101（取反+1）
   - 1011 + 1101 = 1000（补码）= -8D
   - 双符号位10（有溢出！因为$-5-3=-8$，恰好是4位补码的最小值）

**答案**：$x+y=-2$（无溢出），$x-y=-8$（无溢出，恰好在边界）

**关键点**：补码减法化为加法计算，注意溢出判断

### 题目4：浮点数加减运算
**来源**：408经典题型
**难度**：中等
**考点**：浮点数对阶、求和、规格化

**题目**：
两个浮点数 $a=2^{01} \times (-0.1001)_2$，$b=2^{11} \times (+0.1001)_2$，阶码和尾数均用补码表示，求 $a+b$。

**解析**：
1. a的阶码=01（补码）= 1，b的阶码=11（补码）= -1
2. 对阶：较小阶码向较大阶码看齐，b的阶码从-1调整到1
   - b的尾数右移2位：0.001001（补码）
3. 尾数求和：a的尾数1.0111 + b的尾数0.001001 = 1.100101
4. 结果规格化：1.100101已经是规格化形式
5. 结果：$2^{1} \times (-0.011011)_2$

**答案**：$a+b = 2^{1} \times (-0.011011)_2$

**关键点**：对阶小阶向大阶看齐，尾数右移

### 题目5：C语言整数类型转换
**来源**：408真题
**难度**：困难
**考点**：有符号无符号数的转换

**题目**：
在C语言中，int为32位有符号整数，unsigned int为32位无符号整数。若int x = -1，则 (unsigned int)x 的值是多少？

**解析**：
1. $x = -1$ 的32位补码：0xFFFFFFFF
2. 作为无符号数解释：$2^{32} - 1 = 4294967295$
3. 因此 (unsigned int)x = 4294967295

**答案**：4294967295（即0xFFFFFFFF）

**关键点**：有符号数到无符号数的转换是逐位重新解释，位模式不变
