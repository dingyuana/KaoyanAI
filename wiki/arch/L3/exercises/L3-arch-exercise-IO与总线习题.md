# 输入输出系统与总线习题

## 题目列表

### 题目1：中断处理过程
**来源**：408真题
**难度**：中等
**考点**：中断响应、中断处理流程

**题目**：
简述 CPU 响应中断的流程，从硬件自动完成到软件中断服务程序执行，列出关键步骤。

**解析**：
**硬件自动完成（中断隐指令）**：
1. 关中断：CPU 将 IF（中断标志位）置 0，屏蔽后续中断
2. 保存断点：将当前 PC 值（返回地址）压入堆栈
3. 识别中断源：通过中断向量表获取中断服务程序入口地址
4. 转中断服务程序：将入口地址送入 PC

**软件完成（中断服务程序）**：
5. 保护现场：将通用寄存器和状态寄存器压栈
6. 开中断：允许更高优先级中断嵌套
7. 执行中断处理：完成具体的 I/O 操作
8. 关中断：为恢复现场做准备
9. 恢复现场：出栈还原寄存器值
10. 开中断：恢复中断标志
11. 中断返回：从堆栈弹出断点地址到 PC

**答案**：共 11 步，硬件 4 步 + 软件 7 步

### 题目2：DMA 与中断方式对比
**来源**：408真题
**难度**：简单
**考点**：DMA 特点、与中断的区别

**题目**：
比较程序中断方式和 DMA 方式在数据传输时的特点，填写下表：

| 比较项 | 程序中断方式 | DMA 方式 |
|--------|------------|---------|
| 数据传送方式 | | |
| 响应时间 | | |
| 处理异常能力 | | |
| 传送单位 | | |
| 优先级 | | |

**解析**：

| 比较项 | 程序中断方式 | DMA 方式 |
|--------|------------|---------|
| 数据传送方式 | 程序（软件）控制 | 硬件控制（DMA控制器） |
| 响应时间 | 执行完当前指令后响应 | 每个总线周期结束后响应 |
| 处理异常能力 | 可处理复杂异常和错误 | 不处理异常，仅传输数据 |
| 传送单位 | 字节/字 | 数据块 |
| 优先级 | 低于 DMA | 高于中断（DMA 优先级最高） |

**答案**：见上表

### 题目3：总线仲裁
**来源**：408真题
**难度**：中等
**考点**：集中式仲裁方式

**题目**：
某系统有 3 个总线主设备，采用链式查询方式进行总线仲裁。

(1) 画出链式查询的电路结构图。
(2) 若设备 1 优先级最高，设备 3 优先级最低，设备 2 申请总线时，分析仲裁过程。
(3) 链式查询的优缺点各是什么？

**解析**：
(1) 链式查询结构：
```
总线仲裁器 → BG (总线允许) → 设备1 → 设备2 → 设备3
                    ↑ BR (总线请求) ← ← ← ← ← ← ← ← ←
```

(2) 设备 2 申请总线：
1. 设备 2 将 BR 信号置为有效
2. 仲裁器检测到 BR 有效，若总线空闲，将 BG 信号置为有效
3. BG 信号首先到达设备 1
4. 设备 1 未申请总线，将 BG 传递到设备 2
5. 设备 2 收到 BG，获得总线使用权，停止传递 BG
6. 设备 2 开始传输数据

(3) 优点：
- 电路简单，只需少量连线
- 易于扩展，增加设备不影响仲裁器
缺点：
- 优先级固定，无法改变
- 对故障敏感，某个设备故障会导致后续设备无法获得总线
- 响应延迟随设备数量增加而增大

**答案**：见解析
