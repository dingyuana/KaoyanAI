# 计算机系统概述习题

## 题目列表

### 题目1：冯诺依曼机的核心特点
**来源**：408选择题
**难度**：简单
**考点**：冯诺依曼结构

**题目**：
冯诺依曼机的核心特点是：

A. 采用存储程序工作方式
B. 控制器和运算器分离
C. 否定"存储程序"
D. 只有运算器没有控制器

**解析**：
冯诺依曼机的核心特点就是"存储程序"（Stored-program）—— 将指令和数据都以同等地位存放在存储器中，并按地址访问。

A✅ "存储程序"是冯诺依曼机最核心的特点
B❌ 控制器和运算器分离是计算机硬件结构，但不是核心特点
C❌ 冯诺依曼机恰恰是"存储程序"，不是否定
D❌ 计算机必须有控制器

**答案**：A

**关键点**：冯诺依曼机 = 存储程序 + 二进制表示 + 五大部分（运算器、控制器、存储器、输入设备、输出设备）

### 题目2：CPU性能计算
**来源**：408真题
**难度**：中等
**考点**：CPI和CPU执行时间

**题目**：
某计算机系统采用流水线技术，程序中有50%的指令为Load/Store指令，其CPI为4；其他指令的CPI为1。已知机器的时钟周期为2ns，求该计算机的CPI和MIPS。

**解析**：
1. 平均CPI = 各指令CPI × 比例之和
2. 平均CPI = 50% × 4 + 50% × 1 = 2 + 0.5 = 2.5
3. MIPS = f / (CPI × 10^6) = (1/2ns) / (2.5 × 10^6)
4. f = 1/2ns = 500MHz = 0.5 × 10^9 Hz
5. MIPS = 0.5 × 10^9 / (2.5 × 10^6) = 200

**答案**：CPI = 2.5，MIPS = 200

**关键点**：混合CPI = Σ(比例 × CPI)，MIPS = 时钟频率 / (CPI × 10^6)

### 题目3：MIPS与执行时间转换
**来源**：408真题改编
**难度**：中等
**考点**：MIPS、时钟周期、执行时间

**题目**：
某计算机的MIPS为500，程序包含200,000条指令，求该程序的执行时间（假设平均CPI为2）。

**解析**：
1. 由 MIPS = f / (CPI × 10^6) 得：
   - 500 = f / (2 × 10^6)
   - f = 500 × 2 × 10^6 = 10^9 Hz = 1GHz

2. 时钟周期 = 1/f = 1ns

3. 执行时间 = N × CPI × 时钟周期
   = 200,000 × 2 × 1ns = 400,000ns = 0.4ms

**答案**：执行时间为 0.4ms

**关键点**：MIPS → f → 时钟周期 → 执行时间的转换链

### 题目4：吞吐量和响应时间
**来源**：408选择题
**难度**：简单
**考点**：性能指标

**题目**：
以下关于系统性能指标的说法中，正确的是：

A. 响应时间指从作业提交到完成的时间
B. 吞吐量指单位时间内处理的作业数
C. CPU利用率与系统性能无关
D. 主频越高，系统性能一定越好

**解析**：
A✅ 响应时间是系统对请求的响应时间，从提交到完成
B✅ 吞吐量是单位时间内完成的工作量
C❌ CPU利用率与系统性能密切相关，是性能指标之一
D❌ 主频高但CPI大，性能不一定好

**答案**：AB

**关键点**：吞吐量、响应时间、CPI、主频是计算机性能的主要指标

### 题目5：指令分类与CPI
**来源**：408真题
**难度**：困难
**考点**：混合CPI计算

**题目**：
某计算机执行20,000条指令，指令分类如下：
- 算术指令：40%，CPI = 1
- Load指令：20%，CPI = 2
- Store指令：10%，CPI = 2
- 分支指令：15%，CPI = 3
- 其他指令：15%，CPI = 1.5

若CPU主频为600MHz，求该程序的执行时间。

**解析**：
1. 计算平均CPI：
   - 平均CPI = 0.4×1 + 0.2×2 + 0.1×2 + 0.15×3 + 0.15×1.5
   = 0.4 + 0.4 + 0.2 + 0.45 + 0.225 = 1.775

2. 时钟周期 = 1 / 600MHz = 1 / (600 × 10^6) ≈ 1.67ns

3. 执行时间 = 指令数 × 平均CPI × 时钟周期
   = 20,000 × 1.775 × 1.67ns
   = 59,300ns ≈ 59.3μs

**答案**：执行时间约为 59.3μs

**关键点**：加权平均CPI是计算执行时间的关键

## 学习建议

1. **熟记公式**：CPU执行时间 = N × CPI × T，MIPS = f / (CPI × 10^6)
2. **理解各指标关系**：主频、CPI、指令数共同决定执行时间
3. **注意单位换算**：MHz → Hz，μs → ns
4. **区分吞吐量和响应时间**：系统性能的两个不同维度
5. **多做真题**：408特别喜欢出混合CPI的计算题
