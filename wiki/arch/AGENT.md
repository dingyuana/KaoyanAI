# AGENT.md - 计算机组成原理学科 AI 约束

> 本文件定义AI在操作计算机组成原理知识库时的行为规范和约束条件。
> 通用约束请参阅 `../WIKI_SCHEMA.md`。

---

## 一、AI 操作原则

### 1.1 知识生成规则

1. **忠实原文**：L1 层不得修改、总结、纠错原文内容
2. **三层架构**：严格遵循 L1→L2→L3 的知识加工流程
3. **类型分离**：概念、方法、习题必须分离到对应目录
4. **格式统一**：严格遵循 SCHEMA.md 定义的格式规范

### 1.2 硬件描述规范

1. **结构图完整**：描述硬件结构时保持完整性
2. **时序图清晰**：时序描述必须包含状态变化
3. **公式准确**：计算公式必须保持原始形式

### 1.3 数值计算规范

1. **标明进制**：所有数值必须标明进制（B/D/H/O）
2. **单位规范**：使用标准单位（bit、Byte、KB、MB、GB）
3. **保留过程**：计算题保留完整计算过程

---

## 二、L1 处理规则

### 2.1 Chunk 拆分标准

- 一个硬件概念 = 一个 Chunk
- 一个计算公式 = 一个 Chunk
- 一个结构图 = 一个 Chunk
- 一道例题 = 一个 Chunk

### 2.2 锚点生成规则

```
RAW-arch-{章节名}-{序号}
示例：RAW-arch-3存储系统-P001-C01
```

---

## 三、L3 生成规则

### 3.1 概念文档

- 必须包含：形式化定义、硬件结构、工作原理
- 可选包含：技术指标、对比分析

### 3.2 方法文档

- 必须包含：适用场景、计算步骤、示例
- 可选包含：注意事项、常见错误

### 3.3 习题文档

- 必须包含：题目、解析、答案
- 可选包含：考点分析、计算过程

---

## 四、禁止行为

1. ❌ 不得在 L1 层修改原文内容
2. ❌ 不得将硬件结构描述拆分
3. ❌ 不得省略计算公式的推导过程
4. ❌ 不得将概念和计算方法混在同一文档
5. ❌ 不得修改数值题目的原始数据
