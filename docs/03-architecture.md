# 考研知识库问答系统 · 系统架构设计

> 本文档分为两部分：**MVP 架构**（当前）和 **Commercial 架构**（后期）。

---

# 第一部分：MVP 架构

## 1. MVP 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                        用户浏览器                            │
│   单页 HTML + KaTeX (CDN) + Vanilla JS                      │
└────────────────────────────┬────────────────────────────────┘
                             │ HTTP
                             ↓
┌────────────────────────────────────────────────────────────┐
│                     Nginx (反向代理)                        │
│   /             → 静态文件（index.html）                    │
│   /api/*        → FastAPI :8000                            │
│   /wiki/*       → 静态文件（数学知识库MD）                  │
└────────────────────────────┬───────────────────────────────┘
                             │
             ┌───────────────┼───────────────┐
             ↓               ↓               ↓
┌──────────────────┐  ┌──────────────┐  ┌──────────┐
│   FastAPI 后端    │  │  Wiki文件    │  │ LLM API  │
│   单一文件 main   │  │  (只读)      │  │Claude/GPT│
│   :8000           │  │  20-30个MD   │  └──────────┘
└──────────────────┘  └──────────────┘
```

## 2. MVP 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| QueryRouter | `backend/main.py` | 接收问答请求，调用检索和LLM |
| SearchService | `backend/main.py` | glob读MD文件，关键词匹配 |
| LLMService | `backend/main.py` | 调用LLM API，流式返回SSE |
| 前端 | `frontend/index.html` | 提问界面，流式展示，公式渲染 |
| 知识库 | `wiki/math/*.md` | 20-30个数学概念MD文件 |

## 3. MVP 目录结构

```
/root/kaoyan/
├── backend/
│   └── main.py              # 单文件 FastAPI（路由 + 服务）
├── frontend/
│   └── index.html           # 单页HTML（无构建）
├── wiki/
│   └── math/                # MVP只做数学
│       ├── 极限.md
│       ├── 导数.md
│       ├── 积分.md
│       └── ...
├── nginx/
│   └── nginx.conf           # 反向代理配置
├── requirements.txt         # Python依赖
└── docker-compose.yml       # 一键启动（MVP验证后）
```

## 5. Commercial 模块职责

### 5.1 前端模块

| 模块 | 职责 | 依赖 |
|------|------|------|
| ChatPanel | 问答界面，流式显示 | Query API |
| ConceptTree | 概念树浏览 | Concept API |
| SubjectSwitcher | 学科切换 | 全局状态 |
| UserCenter | 历史/收藏/设置 | User API |
| MathRenderer | LaTeX公式渲染 | KaTeX |

### 5.2 后端模块

| 模块 | 职责 | 依赖 |
|------|------|------|
| query_router | 接收问答请求 | SearchService, LLMService |
| concept_router | 概念增删查 | Elasticsearch |
| SearchService | 混合检索编排 | ES, Milvus |
| LLMService | LLM调用与缓存 | Redis, Claude API |
