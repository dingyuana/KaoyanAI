# 考研辅助系统前端视觉规范 & 页面开发文档

## 一、整体设计总纲

### 1. 设计定位
面向大学生考研人群，采用**轻治愈极简元气风**，摒弃工业化后台生硬质感，弱化管理属性、强化学习陪伴感；整体视觉低饱和度、柔和无压迫，适配长时间备考浏览，兼顾网页端、移动端自适应。

### 2. 全局基础规范
1. **页面底色**：全局页面背景 `#FAFAF8`（奶白色），无纯白刺眼底色
2. **布局规则**：自适应瀑布流卡片布局，桌面端4列、平板2列、移动端单列，卡片间距统一24px，页面左右边距40px
3. **圆角规范**：所有卡片、按钮、输入框、进度组件统一 `16px ~ 20px` 超大圆角，禁止直角、小圆角
4. **阴影规范**：轻薄弥散软阴影，参数 `0 4px 16px rgba(120,160,150,0.08)`，无厚重深色投影
5. **动效交互**：hover悬浮卡片上浮3px，阴影轻微加深，0.2s缓动渐变，无闪烁、剧烈动效
6. **字体规范**
    - 标题：思源温柔黑体/苹方，18px，字重500
    - 卡片副标题：14px，字重400，灰色 `#666666`
    - 底部备注文字：12px，字重400，浅灰 `#999999`
    - 全局行高统一1.8，降低阅读疲劳

## 三、功能卡片统一结构（单卡片DOM开发模板）

所有功能卡片结构完全标准化，分为**顶部标签区、中部图文区、底部备注区**三层，统一尺寸：卡片宽高自适应，最小宽度320px，内部内边距24px。

### 1. 卡片顶部（左右布局）
- 左侧：功能大标题（18px）+ 一行小字描述（14px浅灰）
- 右侧：圆角标签（18px圆角），展示优先级P0/P1，标签内文字居中

### 2. 卡片中部（图文布局）
- 左侧文字，右侧3D轻渐变图标（线性柔边渐变，无描边、扁平化玻璃质感图标）
- 图标统一尺寸：80px × 80px，与卡片渐变色系保持统一

### 3. 卡片底部（左下角单行备注）
12px浅灰色文字，分为三类文案：
- 已完成模块：标注「完成度XX%」
- 存在偏差模块：标注「存在设计偏差」
- 暂停模块：标注「功能暂停，尚未开发」

## 五、交互逻辑开发规范

1. **卡片hover交互**
   - 鼠标悬浮任意卡片：`transform: translateY(-3px)`，阴影透明度提升至0.12，0.2s ease过渡
   - 暂停灰色卡片悬浮仅恢复原色，不上浮

2. **偏差详情弹窗**
   - 鼠标悬浮卡片底部「存在设计偏差」文字，弹出气泡悬浮框，展示完整偏差说明与后续优化方案

3. **视图切换功能**
   - 页面顶部增加切换按钮：「卡片视图」「精简列表视图」
   - 列表视图保留所有信息，去除渐变图标，适配快速查看进度

4. **深色夜间模式适配**
   - 切换夜间模式后，页面底色改为深米色 `#2C2C28`
   - 卡片渐变降低亮度，文字切换为浅白色
   - 状态色保持原有色相降低饱和度，不刺眼

5. **筛选功能**
   - 页面顶部增加筛选标签：「全部模块」「P0核心功能」「P1进阶功能」「已暂停功能」
   - 点击实时过滤卡片展示

## 六、页面顶部标题区域开发规范

1. **主标题「前端设计」**：粗黑体36px，下方搭配一条薄荷青短下划线装饰
2. **标题下方说明文本**：16px灰色文字，固定文案：
   `自由松弛的自适应瀑布流卡片布局，所有卡片元素采用16px-20x超大圆角、轻薄弥散阴影，奶白色(#FAFAF8)基底，适配考研系统年轻化视觉需求`
3. **右上角水印**：「FRTOUR DESIGN」，浅灰色透明度0.4，不遮挡业务内容

## 七、开发落地注意事项

1. 所有渐变、色值、圆角、阴影统一封装全局CSS变量，一处修改全局生效
2. 图标使用线性SVG矢量图标，保证缩放不失真，配色跟随卡片渐变主色
3. 页面采用弹性自适应布局，不固定死宽度，兼容笔记本、平板、手机多端
4. 暂停模块增加灰色遮罩层、弱化图标色彩，直观区分未开发功能
5. 完成模块统一增加小型对勾标识，强化视觉区分，无需文字重复说明完成状态
