# 用户故事

> **项目名称：** Kaoyan Wiki（考研智能学习助手）
> **版本：** 2.0.0
> **状态：** 正式发布

## 一、知识库基座（系统侧已预置，用户侧只读）

| 标识 | US-KB-01 |
|------|----------|
| **故事** | 作为考生，我希望能直接在一个按考点组织的知识库里，快速查看到概念定义、公式、典型例题和名师讲解，而不需要自己整理或上传任何资料。 |
| **优先级** | P0 |
| **验收标准** | 1. 知识库（数学二）已预置，涵盖考纲所有核心知识点。<br>2. 每个知识点页面包含定义、LaTeX 公式、经典例题、易错点。<br>3. 支持按章节目录树浏览和关键词全文搜索。<br>4. 页面底部标注内容来源（如“张宇《高数18讲》”）。 |
| **备注** | 知识库的编译和更新由内容团队通过后台流水线完成，普通用户无上传或编译权限。 |

| 标识 | US-KB-02 |
|------|----------|
| **故事** | 作为内容管理员，我希望系统能基于 AGENTS.md 规则，将指定的主干课程编译为知识基线，并在引入其他名师课程时仅提取差异点补充到已有页面，避免知识冲突。 |
| **优先级** | P0 |
| **验收标准** | 1. 系统能读取 AGENTS.md 中的编译规则并执行。<br>2. 编译新课程时，不覆盖原有主干定义，只追加“补充视角”或“方法对比”小节。<br>3. 所有补充内容自动标注来源教师与课程。 |

| 标识 | US-KB-03 |
|------|----------|
| **故事** | 作为考生，我希望系统能自动展示知识点之间的关联关系，例如前置知识、同类辨析和相关考题，这样我在学习一个概念时可以顺带巩固相关的内容。 |
| **优先级** | P0 |
| **验收标准** | 1. 每个 Wiki 页面展示“前置知识”、“关联考点”、“同类辨析”链接，至少 3 个。<br>2. 点击链接可直接跳转到对应页面。<br>3. 管理员可在后台手动增删关联关系。 |

| 标识 | US-KB-04 |
|------|----------|
| **故事** | 作为内容管理员，我希望系统能自动识别出学生在 AI 辅导中反复追问、但 Wiki 知识库尚缺乏的知识缺口，以便我及时补充和优化知识库。 |
| **优先级** | P1 |
| **验收标准** | 1. 系统自动统计每周期（如每周）AI 辅导中被高频提问但 Wiki 中无匹配页面的知识点关键词。<br>2. 在管理后台以“知识缺口列表”形式展示，按提问频次排序。<br>3. 管理员可将缺口条目标记为“已忽略”或“加入编译队列”。<br>4. 加入编译队列后，系统自动生成 Wiki 页面草稿，管理员审核后可正式发布。 |
| **备注** | 终端用户完全无感知，无法触发任何入库操作。 |

## 二、学习诊断

| 标识 | US-DG-01 |
|------|----------|
| **故事** | 作为首次使用系统的考生，我希望能快速完成一次水平测试，立即了解自己在各知识模块的掌握情况，以便知道从哪里开始复习。 |
| **优先级** | P0 |
| **验收标准** | 1. 测试题目覆盖用户所选科目（数学二）的核心模块。<br>2. 题目难度根据答题情况动态调整（自适应）。<br>3. 测试结束后即时生成诊断报告，包含各模块得分和主要薄弱点。 |

| 标识 | US-DG-02 |
|------|----------|
| **故事** | 作为考生，我不仅想知道哪道题错了，更想知道错在哪里——是概念不清、计算马虎，还是方法没用对，以便我能针对性地改进。 |
| **优先级** | P0 |
| **验收标准** | 1. 每道错题标注错误类型标签（概念/计算/审题/方法）。<br>2. 诊断报告将薄弱点关联到具体的 Wiki 知识点页面。<br>3. 薄弱点归因准确率 ≥80%（人工抽检）。 |

## 三、个性化学习规划

| 标识 | US-PL-01 |
|------|----------|
| **故事** | 作为每天只有 3 小时学习的在职考生，我希望系统能根据我的诊断结果和考试倒计时，自动生成一份精确到每天任务的复习计划，让我不用再自己头疼排期。 |
| **优先级** | P0 |
| **验收标准** | 1. 输入目标分数、每日可用时段后，系统立即生成计划。<br>2. 计划分解到“每日任务”，每项任务链接到 Wiki 页面或练习题。<br>3. 覆盖基础、强化、冲刺三个阶段。 |

| 标识 | US-PL-02 |
|------|----------|
| **故事** | 作为考生，我希望计划不是死的——如果我某天没完成任务或某个章节正确率特别低，系统能自动调整后续计划，加大薄弱点的训练量。 |
| **优先级** | P0 |
| **验收标准** | 1. 任务未完成时，后续日程自动重新排布。<br>2. 某知识点练习正确率 <60% 时，自动在未来 3 天内增加该知识点的复习任务。<br>3. 进度严重滞后时触发提醒。 |

## 四、AI 辅导

| 标识 | US-AT-01 |
|------|----------|
| **故事** | 作为遇到难题的考生，我希望用手机拍照上传题目后，AI 能先给我一个思路引导，而不是直接甩出答案，这样我才能锻炼自己的解题能力。 |
| **优先级** | P0 |
| **验收标准** | 1. 支持图片上传，识别印刷体和工整手写公式。<br>2. 默认回复先给出考点提示或第一步思路。<br>3. 用户点击“查看完整解析”后才展示详细步骤。 |

| 标识 | US-AT-02 |
|------|----------|
| **故事** | 作为考生，当 AI 辅导我一道题时，我希望它能结合我之前的错题记录，提醒我容易再犯的老毛病，比如“这道题你上次符号搞反了”。 |
| **优先级** | P0 |
| **验收标准** | 1. 辅导时自动调取用户近 30 天错题本，若存在相同知识点错题，答案中主动提醒。<br>2. 提醒内容具体到错误类型，非泛泛而谈。 |

| 标识 | US-AT-03 |
|------|----------|
| **故事** | 作为考生，我对 AI 给出的答案半信半疑时，希望能看到这个解答引用了哪个 Wiki 页面，并点击跳转查看原文核实。 |
| **优先级** | P1 |
| **验收标准** | 1. AI 回答底部标注引用来源，格式为 `> [来源：XXX知识点页面]`。<br>2. 点击来源可跳转到 Wiki 对应页面。 |

## 五、错题管理

| 标识 | US-EM-01 |
|------|----------|
| **故事** | 作为考生，我希望所有做错的题目都能自动记录下来，并按知识点归类，不用我自己手抄或截图整理。 |
| **优先级** | P0 |
| **验收标准** | 1. 诊断、练习、模考中的错题自动加入错题本。<br>2. 错题显示关联的知识点、错误类型标签。<br>3. 支持按知识点、时间、错误类型筛选。 |

| 标识 | US-EM-02 |
|------|----------|
| **故事** | 作为经常重复犯同样错误的考生，我希望系统能根据艾宾浩斯遗忘曲线，在即将遗忘时提醒我重练错题，巩固记忆。 |
| **优先级** | P0 |
| **验收标准** | 1. 错题重练提醒时间遵循艾宾浩斯间隔（1, 2, 4, 7, 15 天）。<br>2. 重练正确的题，自动延长复习间隔；连续 3 次正确可移出队列。<br>3. 用户可查看每道错题的复习记录。 |

| 标识 | US-EM-03 |
|------|----------|
| **故事** | 作为考生，练会一道错题后，我希望系统能再推荐几道类似的题目给我，检验我是真懂了还是只记住了答案。 |
| **优先级** | P0 |
| **验收标准** | 1. 每道错题详情页展示“同类题推荐”，至少 2 道。<br>2. 推荐题目与错题考察同一知识点，但题干不同。<br>3. 同类题也纳入错题跟踪体系。 |
