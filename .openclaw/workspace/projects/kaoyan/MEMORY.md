## Wiki 架构（重要决策 2026-05-09）

### 核心决策：Wiki基座与Domain分离

- **WIKI_SCHEMA.md** / **WIKI_AGENT.md**：所有学科通用，**MVP完成后不发生结构性变更**
- **math/SCHEMA.md** / **math/AGENT.md**：只管数学专属规则，可以演进
- 学科间物理隔离（锚点前缀 + 目录隔离）

### 当前 Wiki 结构

```
wiki/
├── WIKI_SCHEMA.md       # ⭐ 总宪法（通用规范，基座不动）
├── WIKI_AGENT.md        # ⭐ 通用AI行为约束
├── math/                # 数学学科
│   ├── SCHEMA.md        # Domain宪法（数学专属规则）
│   ├── AGENT.md         # Domain AI约束（数学专属约束）
│   ├── INDEX.yaml       # L2 索引
│   ├── RAW/             # L1 原始材料（待补充）
│   ├── L3/              # L3 最终文档（待补充）
│   ├── TEMPLATES/       # 文件模板
│   └── _meta/
│       └── concept_map.yaml  # 标准概念词表
├── english/              # 占位（后期扩展）
└── politics/             # 占位（后期扩展）
```

### 三层结构（永久不变）

- L1 (Raw)：原始材料，永久只读
- L2 (Index)：L1 的索引目录
- L3 (Generated)：最终应用文档（L1 → L2 → L3 单向流动）

### 锚点ID体系（永久不变）

- 格式：`RAW-{subject}-{来源}-P{页码}-C{序号}`
- 示例：`RAW-math-同济高数上-P023-C07`
- 学科前缀实现跨学科隔离

### 多源冲突处理（永久不变）

- 表述不同，含义一致 → 合并，多源对照
- 讲解侧重不同 → 并列呈现，不选权威
- 存在矛盾 → 显式标注，不擅自裁决
